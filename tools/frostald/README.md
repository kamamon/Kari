# Frostald / フロストアルド

通常のゲーム・公開版は高密度モデル（2,283,726三角形、1,188,163頂点、79関節、56クリップ、2048px PBR）を標準で読み込む。目は自然な青灰色の虹彩・丸い瞳孔・控えめな光沢に更新。発光なし。大きさ、攻撃、骨格、モーションは変えない。

## ビルドと配信
`npm run frostald:build`（predev / pretest / prebuild から実行）で軽量版と高密度版を生成し、両者の全骨格・逆バインド行列・全56モーションのバイナリ一致を検査する。高密度版の原型GLBは tools/out/frostald-master/ に保管。通常配信には public/assets/models/monsters/frostald_hd/frostald.gltf と分割 .bin を使う。全 bufferView の内容を元GLBとバイナリ比較し、各ファイル90MB未満を検査する（GitHubの100MB制限回避）。ポリゴン・2Kテクスチャ・スキン・モーションを削らない。従来の生GLBを公開フォルダに置かない。

通常URLで高密度版。負荷が大きい端末では `?frostaldQuality=game`（既存クエリがある場合 & で追加）を明示して329,250三角形の軽量版へ切り替え可能。軽量版にも同じ目の修正を適用する。モデル読み込み失敗を軽量版への暗黙の切り替えで隠さない。狩猟開始時に読み込む。

`npm run frostald:master` も互換のため残す。原型は採用原画に寄せた手続き的造形で、原画そのものや実写スキャンではない。iPhone実機性能は未確認。

## V5: 生成画像由来のPBR素材

`material_source/` は採用した3枚の素材アトラスから文字・枠を含まない10領域を抜き出した原寸ロスレスWebPと出典・ハッシュ。大域的な影を弱め、周期境界をブレンドして4K作業キャンバスへ補間し、ゲーム用主部位2K・小部位1KのBaseColorを生成。法線・AO・粗さを推定しORMに梱包。高さ・濡れ・霜マスクは生成処理内で使う。ネイティブ4K撮影素材や測定済みPBRではない。

背・腹の混合、頭、脚、顎下、氷冠、背板、爪、たてがみ、湿った皮膜、口内に独立素材。青い丸瞳孔は維持。表面材質のみを差し替え、頂点位置、三角形数、関節、攻撃・モーションキー、既存クエストを維持する。霜はマスクから静的にベイク、氷の屈折・半透明や動的霜デカールは未実装。

再生成: `npm run frostald:build`。制作用4K色・高さ・マスク出力: `python tools/frostald/material_atlas.py tools/frostald/material_source tools/out/frostald-materials/maps --master tools/out/frostald-materials/master`。元画像の陰影は完全に分離できないため実写同等とは断定しない。iPhone実機性能は未確認。

## V6 実体メッシュ再造形（2026-11-28）

`organic_sculpt.py` で、連続SDFによる胴・首・四肢・尾の一体皮膚、彫り込んだ眼窩・鼻孔、独立した下顎、曲面の氷冠・背板・爪・歯を生成。採用原画の拡大部位から8素材を更新し、UV・PBR V2を生成。高密度版のローカル生成実績2,606,400三角形、軽量386,612。環境による数値差を考慮して検査は高密度240〜285万・軽量30〜50万を許容し、配信メタデータには実測数を記録する。79関節・56モーションのノード、逆バインド行列、全キー値はV5とバイト一致確認済み。既存戦闘データとモデルURLは維持。新規scikit-image依存は専用requirements.txtから導入。手続き的造形であり、最新原画と同等の写実性・すべての姿勢での見た目・端末実機速度は未確認。
