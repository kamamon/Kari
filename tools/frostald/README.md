# Frostald / フロストアルド

通常のゲームでは自動生成された `frostald_game.glb`（329,250三角形・79関節・56クリップ・1024px PBR）を使う。

## 高密度モデル
```sh
npm run frostald:master
npm run dev
```
開発サーバーのURLに `?frostaldQuality=master` を付ける（既にクエリがあれば & で追加）。高密度版（2,283,726三角形、1,188,163頂点、79関節・56クリップ、2048pxテクスチャ）を読み込む。生成ファイルは `tools/out/frostald-master/` と `public/assets/models/monsters/frostald_master.glb`。通常URLでは従来LODのまま。公開のCIはこのファイルを標準配信しない。高密度版を公開する場合は容量・端末性能を別途判断する。

専用の生成器で原画に寄せた造形を高密度化したもので、実写同等のスキャンモデルではない。生成器を一時ディレクトリで動かすため通常版の1024pxテクスチャを混用しない。GLB構造、インデックス、ウェイト、両モデルの全骨格・逆バインド行列・全モーションのバイナリ一致を検査する。水中操作と幼体群れ、専用装備の3D外観は別工程。
