# Frostald / フロストアルド

通常のゲーム・公開版は高密度モデル（2,283,726三角形、1,188,163頂点、79関節、56クリップ、2048px PBR）を標準で読み込む。目は自然な青灰色の虹彩・丸い瞳孔・控えめな光沢に更新。発光なし。大きさ、攻撃、骨格、モーションは変えない。

## ビルドと配信
`npm run frostald:build`（predev / pretest / prebuild から実行）で軽量版と高密度版を生成し、両者の全骨格・逆バインド行列・全56モーションのバイナリ一致を検査する。高密度版の原型GLBは tools/out/frostald-master/ に保管。通常配信には public/assets/models/monsters/frostald_hd/frostald.gltf と分割 .bin を使う。全 bufferView の内容を元GLBとバイナリ比較し、各ファイル90MB未満を検査する（GitHubの100MB制限回避）。ポリゴン・2Kテクスチャ・スキン・モーションを削らない。従来の生GLBを公開フォルダに置かない。

通常URLで高密度版。負荷が大きい端末では `?frostaldQuality=game`（既存クエリがある場合 & で追加）を明示して329,250三角形の軽量版へ切り替え可能。軽量版にも同じ目の修正を適用する。モデル読み込み失敗を軽量版への暗黙の切り替えで隠さない。狩猟開始時に読み込む。

`npm run frostald:master` も互換のため残す。原型は採用原画に寄せた手続き的造形で、原画そのものや実写スキャンではない。iPhone実機性能は未確認。
