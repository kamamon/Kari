# 毒羽竜 ヴェノルカ V1
採用された原画を参照した、鳥竜型の実体モデル。根絡み湿原に初級〜上級で登場。骨格と56の動作を新規生成し、攻撃と部位判定を同じGLBの60Hz姿勢から算出。胴・首・四肢・毒嚢は連続SDF皮膚、膜翼は翼指・肩・肘・手首で変形。原画から抽出した10素材の画像をUV/PBRに使用する（解像度は補間、計測したPBRではない）。初級は単発毒吐きと短い滑空を中心とし、中級以上で連射、上級で毒霧。毒嚢破壊で毒の使用頻度・威力低下、翼破壊で滑空を制限、尾羽破壊で毒尾の技を止める。尾の切断ではない。全11系統の武器定義、現行7系統を有効化。防具5部位、3段階。アイコンは原画素材と個別シルエットを合成したもの（専用装備3Dモデルではない）。

`npm run venolka:build` は `tools/venolka/ensure_assets.py` を通じてゲーム・高密度の両GLBを生成。高密度は32MiB目安の分割 glTF で配信。明示 `?venolkaQuality=game` で軽量版。旧3種のIDや保存形式は変更しない。数値検査と実際のプレビューは原画品質や端末性能の保証ではない。採用原画の写実性・全動作の接触・狩猟バランスは実プレイで調整が必要。
