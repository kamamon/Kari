## 2. 設計の主要な判断

標準は`classic_hunt_v1`へ統一します。護刃のパリィ、長尖槍のカウンター、太刀の兜割り、双剣の命中による勢いを2G基準の動作構成へ置き換えます。納刀・使用を別の判断とし、手動照準・手動視点で成立する狩りを作ります。支持脚・移動・刃・判定・効果の時刻を揃えます。

モンスターは、足を踏み替える向き直り、攻撃方向の確定、突進の制動、反撃できる戻りを制作します。転倒・起き上がり・切断でも見える部位へ当たるようにし、既存の高速離脱を保って寝床での休眠へ接続します。

装備は11系統を最終対象にします。技能は正負合算と閾値、装飾品は装備内の枠、所持は装備個体へ移します。旧ID・強化・素材・四級・達成・外見を保持する移行を設計しています。

地形は、平坦で読める戦闘床の外側へ狭路・岩棚・段差・登攀・採取の枝を置きます。盆地の11エリア・14接続を初期に保持し、各エリアの形・目印・高さ帯を指定しました。地形と足・部位・カメラは同じ支持面を使い、未表示エリアの大型の移動・休眠・追跡期限も継続します。
