## 3. 継続して使う以前の観察

`docs/source/chatgpt-research-mh-20261125/visual_observations_v2.json`のO01〜O07は2G資料で、今回の観察と対応する。V02の11〜11.5秒の肉焼き・30〜31秒の支援表現は前回観察の継承として利用できるが、今回は再抽出していない。同行者を制作する時の参照に留め、今回の必須のハンター・モンスター・装備・地形の実装を待たせない。

O08以降にはMH3とMHP3rdの観察が含まれる。例えば3rd大剣の構えは身体制作の比較には使えるが、2Gの溜め段階・技ルート・硬直を確定する証拠にはしない。MH3の回復映像から、2Gの確定フレームを得たとも記録しない。

## 4. Claudeが動作を作る時の観察票

武器・モンスターの各actionに、次の情報を残す。1枚のスクリーンショットだけで攻撃の受付・硬直を完成判定しない。

```text
対象作品・機種・日本版/海外版：
資料のURL・動画ID・取得日：
映像内の開始〜終了時刻：
編集カットの有無、HUDの有無、通常/低速：
開始状態：納刀/抜刀、武器、向き、地形、相手の状態
目視したキー姿勢：K0開始、K1準備、K2接触、K3終端、K4復帰
支持脚・足の位置、胴と武器の向き、前進/後退：
画面から確認できた資源と結果の変化：
入力や内部仕様が不明な点：
対応するKari action IDと行動定義版：
Kariの姿勢・軌道・判定・入力受付の差：
数値区分：現行値/独自の仮値/原作実測（方法がある場合のみ）
修正内容と、同じ条件で確認した結果：
```

原作の時間を検証する必要がある場合は、入力が分かる日本PSP版の連続プレイを優先し、速度変更・フレーム欠落・画面切替を確認してから測る。読めない項目は空欄を推測で埋めず、未測定として残す。モデル・骨格・装備の寸法はKariのものを使い、原作で観察した重心・支持・動作順を対応させる。

今回、元動画やゲーム画像をゲーム用アセットとしてリポジトリへ追加していない。参照URL、時刻、確認内容、未確認点を文字化し、実装指示へつないだ。
