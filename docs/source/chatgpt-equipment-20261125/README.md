## 公開PDFの補修と圧縮

公開前の最終確認で、元PDFの第12ページ「ガルドロス」に上級・極級の素材行が表示されていないことを確認した。数値JSONには必要なレシピが揃っていたため、多数の素材がある表だけ素材名の表記と余白を詰め、第12ページの表示を補修した。**全250系列級の素材行とガルドロス48レシピの必要数を確認済み**。他199ページの本文・文字座標と、全102リンクは元PDFから維持した。根拠は [表示補修の検査記録](analysis/pdf-recipe-repair-validation.json) を参照。

元PDF約27.9MBの送信が転送エラーになったため、修正版の図版96枚（95系列と表紙）を **JPEG quality 65／4:2:0** で再圧縮した。画像の縦横寸法は縮小していない。公開閲覧版は**12,047,197バイト**で、修正版との比較により、200ページすべての本文・文字座標・画像寸法と配置・全102リンクの一致を確認した。図版は非可逆圧縮のため、細部の確認には同梱の原画PNGを使う。主原画95枚と履歴6枚のPNG、数値JSONは変更していない。根拠は [圧縮の検査記録](analysis/pdf-publication-validation.json) を参照。

公開PDFのSHA256は `ae231cec0f826c649769541268d5c3719843f9a23f7aae82d83014d217a91d3c`。公開閲覧版の視認は第11・12・181・199ページの4ページを対象とし、構造比較は全200ページを対象とした。

## 迷って決めたこと

- 四級は `rank.1`〜`rank.4`。星数と装備T番号を同一視しない。既存T2〜T5が四級の比較基準。
- 新系列は初登場級で直接生産し、次級以降は前級の同装備を消費する線形強化。既存ガルドロスのレシピ48件は原文保持。
- 武器は無属性・会心・単属性・状態異常・複合属性を分け、属性と状態異常を同時搭載しない。複合は上級・極級だけ。
- 全級で防具技能の予算は1部位1点、一式5点。上位化だけで技能点を増やさず、主技能Lv3と副技能Lv2を基本とする。
- 採取技能は作業時間・既知の近距離採取点の補助に限る。レア確定や抽選増加は付けない。
- No.57テムソギアは `monster.tarhegna`、No.71セオルミドは `monster.segranio` を使う。表示名からIDを再生成しない。

## 検証と再生成

Node v24.22.3で `npm ci` を実行済み。`bestiary:import --dry` はモンスター取込JSON向けで、この提案は別形式のため対象外。`runtimeImportable: false` を付け、現行ローダーへ直接渡さない。

数値・レシピの再生成は、原典コミット `1e078bfce1e68f287ae577cf41d2fe5bafb94afa` の別作業環境へこの資料を置き、そのリポジトリ直下から `python3 chatgpt-inbox/equipment-all-grades-20261125/tools/build_all_equipment.py` を実行する。ビルダーは作業環境の `public/data/` を読むため、v0.28.0上でそのまま実行すると原典基準の素材記録や監査を上書きする。この公開用整備では再実行していない。公開メタデータとチェックサムは、再生成後に改めて検証する。

確認済みの原画情報を上書きする初期草案作成用スクリプトは、公開パッケージに含めていない。

PDFの再出力にはPython、Pillow、pypdf、PyMuPDF、WeasyPrint 70、Noto Sans CJK JPが必要。`build_catalog_book.py --output <出力先>` を使用する。最終版は原画不足時に停止する。`--draft` は不足画像を「制作中」として表示するため、最終提出には使用しない。

数値の確認結果は `analysis/data-validation.json` と独立監査を参照する。`analysis/book-validation.json` と `analysis/final-pdf-structure.json` は、後日判明した第12ページの欠落補修より前の履歴である。現在の公開PDFは、表示補修・圧縮の2検査記録と `analysis/publication-validation.json` を参照する。元のゲームコードや公開データに対する動作試験を実施したという意味ではない。

公開用に一時作業場所の絶対パスを整理したため、完全JSONのSHA256は初版監査時と異なる。初版監査のハッシュはそのまま保存し、数値指紋が一致することを [publication-validation.json](analysis/publication-validation.json) で確認した。生成元の一時PNG名は履歴情報であり、公開PNGの所在は各系列の `artFile` と [art-manifest.json](data/art-manifest.json) を使う。

ファイルの同一性はこのディレクトリで `sha256sum -c SHA256SUMS` を実行して確認できる。公開255ファイルのうち `SHA256SUMS` 自身を除く254ファイルが検査対象になる。
