## 守れなかった決まり・迷って決めたこと

- 既存の全身4方向図を再発注せず、未制作だった部位近接資料を補いました。5枚は各部位の完全な四方向図ではなく、腰だけ前後の2図を1枚にしています。
- 兜は依頼7bを優先し、あごひも、鼻当て、左頬当ての大きさ、大きな岩面を補いました。採用済み全身原画に見られる小さな鼻当て・細かい多角形模様からの修正提案です。全身図へ自動で差し替えないでください。
- 防具の裏地、袖口や襟内側、留め帯は構造を伝えるための補完です。既存画像に隠れた部分がすでに確定していた、とは扱いません。
- 断岳剣の岩板は前面3枚、裏は鉄芯と3か所の留め金という非対称案にしました。板を両面へ増やして重くする意図はありません。前後の鋲の貫通位置は未確定です。
- 護刃の剣の岩殻は、独立した2枚の板というより細い連続帯に見えます。留め金で2区間に分かれています。
- 既存武器の寸法と握りを保持する意図で描いていますが、輪郭の実測一致を合格扱いにしていません。元の数値を正本として形を作ってください。
