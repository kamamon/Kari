## 何が変わり、何を保持したか

mainの新しい1コミットは、モンスターのモデル・動き・行動・描画効果等の更新だった。今回変更する21ファイルのうち、変更前の内容が変わったのは `src/render/view.ts` だけだった。ハンターの骨格、武器の行動・生成元、プレイヤーの戦闘処理はこの更新で変わっていない。

旧統合パッチは最新mainへ競合せず適用できた。ただし、古い `view.ts` の完成ファイルをそのまま上書きするとモンスター更新を失うため、最新mainを土台にした完成候補を別に作った。独立した差分レビューで、最新の統合 `view.ts` と旧提案の差が、mainに追加されたモンスター側の2つの差分と一致することを確認した。

## 採用するパッケージ

`implementation/current-main/` の `replacement.patch`、`manifest.json`、`apply-proposal.py` を使う。対象は同じ21ファイル。変更前後のハッシュを最新基点に合わせ、モンスター更新を含む `view.ts` も同梱した。

元の `implementation/replacement.patch` と、`implementation/motion/`・`implementation/balance/` は、v0.20時点の監査を再現するために残す。最新用と重ねて適用しない。適用先のファイルがさらに変わっている場合はハッシュ検査が止めるので、内容を見て移植する。
