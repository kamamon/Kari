### 再生成

Pythonの `PyMuPDF`、`Pillow`、`fontTools` と、`/usr/share/fonts/opentype/noto/` のNoto Sans/Serif CJKが必要。
リポジトリのルートから次を実行する。`--data-repo` は正本の登録簿を持つチェックアウトを指定する。

```sh
python3 chatgpt-inbox/009/build_encyclopedia_v2.py \
  --data-repo /path/to/current/Kari \
  --temp /tmp/veilbound-bestiary-v2 \
  --snapshot-sha e006b3500184e82b321ff8e64797e900113523a0 \
  --snapshot-version v0.16.0 \
  --date 2026-11-24
```

生成後はmanifestの `visualReview.status` が `pending` に戻る。再生成したPDFの描画を確認してから納品する。
