# 幼体の個体差と群れの反応 — v1

作成日: 2026-11-26（日本時間）  
対象: Kari / 霧境の狩人、実装済みの幼体8種  
基準: v0.34.0 / `0925487b686473e1a4d7e45fdc63449ef3a7d2ec`

## 1. 今回の修正方針

利用者の指摘「幼体が逃げる一択。逃げる個体もいれば攻撃的な個体もいる」を反映する。

**同じ種・同じ群れに、逃げる個体と、自分から威嚇して攻撃する個体を混在させる。** 幼体という成長段階だけで行動を決めない。性格は出現時に固定し、その時の体力や距離によって警戒・攻撃・退避を選ぶ。

これまでの反撃機能をなくす変更ではない。現行コードでは、接近時と仲間の逃走通知に個体差がなく、被弾か壁際以外では逃走しやすい。接近時から個体差が見えることを今回の受入条件とする。

## 2. 現行コードの確認

| --- | --- | --- |
| `stepHerdMember` の接近判定 | `fleeRange` 内へ入られると、疲労していない個体は基本的に逃走 | 性格・体力・距離で判断 |

| 壁際 | 狩人が近く、進めない時間が続くと反撃 | 逃げ道を作る反撃を維持し、瀕死の退避を優先 |
| `fight` 終了 | 基本的に逃走へ戻る | 有限の交戦と再交戦までの間隔を設ける |

## 3. 三つの性格

ここでいう「威嚇」は、既存の `alert` で狩人へ向き直って一定時間止まる予告を指す。専用の上半身ポーズや鳴き声は後続とする。

| 性格 | 狩人が近づく | 自分が攻撃される | 行動の読み取り方 |
| --- | --- | --- | --- |
| 臆病 `timid` | 顔を上げ、逃げる | 基本は逃げる。逃げ場がない時は短く反撃 | 逃げる向きへ胴を向け、距離を広げる |
| 慎重 `cautious` | 足を止めて向き直り、警戒する | 反撃する。密着を続けられた時にも威嚇して反撃 | まず止まって観察し、即座には追ってこない |
| 攻撃的 `aggressive` | 威嚇してから、自分で近づいて攻撃する | 反撃する | 狩人へ向き直って踏みとどまり、その後に間合いを詰める |

表の反撃・先制は、体力条件と交戦枠を満たす場合に行う。枠が空かない間は警戒または退避する。全性格に共通して、瀕死では退避を優先する。攻撃的な個体も短い交戦の後は間を置き、無制限には追い続けない。遠くにいる狩人へ、仲間の通知だけを根拠に突進しない。

### 同じ群れの中での見え方

狩人が近づくと、臆病な個体は逃げ始める。慎重な個体は足を止めて狩人を見る。攻撃的な個体はその場で威嚇してから向かってくる。逃げる一頭を追っている間にも、別の一頭がその場に残るため、群れをひとまとまりの逃走物として扱えなくなる。

## 4. 性格の割当

初期案は **臆病1・慎重2・攻撃的1を4頭あたりの目安**とする。少数の群れにも逃げる個体と攻撃的な個体を入れるため、完全な独立確率抽選にはしない。

統合用差分では4枠周期を使う。各周期の先頭2枠に臆病・攻撃的を一頭ずつ割り当て、順序を群れseed由来のハッシュで入れ替える。残り2枠は慎重とする。

| 群れの頭数 | 割当 |
| --- | --- |
| 2頭 | 臆病1・攻撃的1 |
| 3頭 | 臆病1・慎重1・攻撃的1 |
| 4頭 | 臆病1・慎重2・攻撃的1 |
| 5頭以上 | 同じ4枠周期を継続。端数で割合は変わる |

性格のために既存の群れ乱数や大型の戦闘乱数を余分に進めない。性格は行動のたびに引き直さない。今回は8種共通の配分とし、種ごとの好戦性の比率調整はプレイ評価後に行う。

## 5. 群れとしての制約

### 一頭ずつ交戦する

同じ群れで通常の接近・攻撃AIへ進める個体は原則一頭とする。他の個体は性格に応じて警戒または退避する。交戦中の個体が死亡・捕獲・行動不能になったり、交戦を終了したりした時は、他の個体が交戦できるようにする。

これは群れ単位の上限であり、別の群れや大型を合計した全域の攻撃数を保証するものではない。複数群れが同じ場所へ集まる状況は別途プレイ評価する。

### 体力・距離・時間を優先する

体力30%以下では退避を優先する。交戦の開始地点から離れすぎた場合も追跡を打ち切る。交戦の時間制限は技の再生中にも進め、現在の技を終えた後に離脱する。技の途中で急に逃走へ切り替えたり、同じ交戦を無限に更新したりしない。

時間・距離・技数の上限は、新しい技を開始できる条件である。最後の技が終わるまでの間は、上限の時間や距離を越える場合がある。タイマーは固定tickの群れAI更新で進み、ヒットストップや行動不能中に停止するため、常に壁時計の秒数と一致するとは限らない。距離は現行と同じ平面距離で、障害物による視線の遮断判定は新たに追加しない。

死亡・捕獲・ヒットストップ・怯み・罠・麻痺・睡眠・気絶の処理順は現行の `stepMonster` を維持する。性格によって行動不能を無視しない。毒の各ダメージtickを新たな反撃通知にしない。

### 親との関係を維持する

幼体が攻撃された時、同じエリアにいる親が気づく既存の処理を維持する。親が戦っていて、狩人との直接の接触がない時に幼体が隠れる既存の経路も維持する。親の死亡によって群れ全体の判断を変える処理は今回の差分には含めない。

## 6. モーション・ポリゴン・スケルトンへの反映

最初の統合では、既存の `alert`・`flee`・`fight` と攻撃技を使う。「止まる」「向き直る」「近づく」「離れる」の違いだけで、性格の違いを成立させる。既存の技が持つ予備動作・攻撃判定・終了動作は維持する。

この段階で、性格専用のモデルや骨格を増やす必要はない。性格によるポリゴン数・ボーン数の追加は0を目標とする。色違いだけで性格を伝える方式にも依存しない。

次の見た目の調整候補は以下とする。**いずれも今回の統合用差分には未実装。**

| 性格 | 既存骨格で足す予備動作 |
| --- | --- |
| 臆病 | 胴を逃げる方へ向け、頭だけ狩人へ返す。小さく後退する |
| 慎重 | 頭を狩人へ向けて止まり、一歩だけ間合いを調整する |
| 攻撃的 | 前傾して踏み締め、種に応じて頭・顎・鋏などを上げる |

器官の違いは種の個性として維持する。コルドピル・パルセイト・ヌマポロン・チルミカナ・コハルギス・ミトガロン・ユルテピカ・ヒナサルヴのIDや技の定義を新たに分割しない。

## 7. 受入条件

1. 未攻撃の狩人が同種の群れへ近づいた時、逃走する個体と、威嚇して自分から攻撃する個体が現れる。
2. 同じ個体の性格が、接近・被弾・逃走のたびに変わらない。
3. 仲間の危険通知が、全員を逃走または攻撃へ一律に上書きしない。
4. 攻撃的な個体も体力が減れば退避し、交戦の時間・技数・追跡範囲に上限がある。
5. 一群の一斉攻撃を抑え、行動不能の一頭が交戦枠を永久に占有しない。
6. 同じseedと入力の結果が一致し、性格追加のために大型の乱数列を消費しない。
7. 休息・移動・親の反応などを維持し、疲労・壁際の反応は新しい体力条件と交戦上限に従って動く。

## 8. 後続で評価すること

仲間を守るための割り込み、仲間や親が倒れた時の恐怖反応、複数群れを合わせた攻撃上限、性格専用の頭・胴のポーズは後続とする。現段階の数値は初期調整案であり、iPhoneでの視認性・操作感・難易度は未評価である。

統合用差分の正確な初期値、実行した検証、および取り込み手順は同じフォルダの `README.md` を参照する。
