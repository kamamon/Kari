# 第2便 ④ — 大槌（ハンマー）・太刀

資料：PSP版 [MHP2G@Wiki ハンマー](https://w.atwiki.jp/mhp2g/pages/151.html)、[太刀](https://w.atwiki.jp/mhp2g/pages/147.html)。現行Kari `actions/war_maul.json` と `long_blade.json`（v0.57.0）、`docs/classic-hunt.md` の太刀 v0.56.0対応。**映像の足順・武器の実軌道は未観察**。角度・秒数の提案は行わない。

## 大槌：当てた後も頭の重さが動く

【資料確認】2Gハンマーの通常は△三段の縦振り、○横振り、R保持の溜め。溜め3は**止まって放つか移動中に放つかで攻撃が分かれる**。【制作提案】前腕で頭を振り回すだけでなく、荷重を脚・骨盤→胸→柄→槌頭の順で受ける。これは人の動きとしての設計意図であり、2Gから読み取った関節角ではない。

### `player.war_maul.smash` / `smash2` / `upswing`（縦三段）

- **① 順序**: 【資料確認】縦の叩きつけ→再び叩く→終端の振り上げ。 【現行Kari】 `smash`→`smash2`→`upswing` を独立した技として持つ。
- **② 足・体**: 【制作提案】頭を下ろす打点の前に支持足を確定し、次段は膝と腰で一度重量を引き受けてから再び振る。どちらの足を先に置くか、腰の回る方向はPSP映像未観察。
- **③ 槌頭の経路**: 縦方向へ下ろした直後、次段の始点へ無理に跳ね上げず重量を感じる弧で運ぶ。最終は低い位置から上方へ通す（Kari制作案）。実際の軌道・回転方向は未観察。
- **④ 2G特有**: △の三連撃が基本。後年の追加された溜め変化や特定の移動打撃を標準に紛れ込ませない。
- **⑤ 確かさ**: 技の順は資料確認。支持脚・振りの角度は未観察。現行Kariの段間に槌がワープしていないかが最初の比較ポイント。

### `player.war_maul.swing`（横振り）

- **①**【資料確認】○の横振りから縦振り・溜めへ派生。【制作提案】槌頭を体の脇から横に通して相手へ当て、減速して次へつなぐ。
- **②**軸足と回転方向は原作映像未観察。Kariの制作では身体を正面へ固定して腕だけ横へ振らず、腰の旋回と足で支える。
- **③**槌頭が横に通る高さ・終端は不明。頭部の重さが減速して見えるような余韻はKari制作提案。
- **④**横振りが縦連係の入口になる。ガード動作を追加しない。
- **⑤**入力・派生は資料確認。手足の実軌道は未観察。

### `player.war_maul.charge` / `charge_smash`（溜め歩きと溜め1）

- **①**【資料確認】Rで溜め、保持中に移動できる。早く放すと溜め1。 【制作提案】構えを作り→槌を支えながら歩く→解放で踏み込み打つ→元の構えへ。
- **②**PSP版の溜め歩行の先行脚と柄の位置は未観察。制作では**歩いている足の接地と溜め姿勢を両立**し、立ち止まっている描画を平行移動するだけにしない。
- **③**槌を持つ手と槌頭がぶれずに移り、溜め1を放つ時の経路が溜め保持姿勢から連続する。
- **④**溜めはスタミナを使い、移動／停止が溜め3の解放分岐に関与する。
- **⑤**入力・状態は資料確認、溜め構えと足の動かし方は未観察。

### `player.war_maul.charge_upswing`（溜め2）

- **①**【資料確認】2Gの溜め2は**打ち下ろし→振り上げ**の二つの接触を含む。 【現行Kari】`charge_upswing`のクリップは通常の振り上げ `wm_upswing_01` を共有しており、同じ二段を表せたか確認が必要。
- **②**【制作提案】初撃で脚を沈める→反動で上体を起こして振り上げる。どちらの足から踏むかは未観察。
- **③**槌頭の「低い打点」と「最後の高い打点」の両方を示し、接触イベントを一つへまとめない。
- **④**原作の二接触の構成を保つ。後年の演出を入れて無理に速くしない。
- **⑤**二接触は資料確認、打点の実経路・間隔・支持足は未観察。

### `player.war_maul.pound`（停止中の溜め3）

- **①**【資料確認】停止した状態で溜め3解放は大きな振りかぶりと叩きつけ。【現行Kari】`pound`には複数打点を含む設計がある。原作の叩きつけと一致するかは未確認。
- **②**【制作提案】後脚に体重を預け→先脚へ伝えて地面近くで減速。原作の脚・胸の向きは未観察。
- **③**上から下への大きな弧を作る構想。槌頭が地面の下へ潜らず、頭部の当たりと同期。
- **④**移動中の溜め3を同じ `pound` で処理しない。
- **⑤**分岐は資料確認、打点数と身体の動きは映像未観察。

### `player.war_maul.spin`（移動中の溜め3）

- **①**【資料確認】移動中に溜め3を放すと回転攻撃。回転中に追加入力すると、押した段階に応じた異なる締めへ分岐。 【現行Kari】`spin`という独立技はあるが、途中分岐が再現済みかは要検証。
- **②**【制作提案】足を踏み替え、腰の回転と槌頭の慣性を一致させる。軸足と回転方向は原作未観察。
- **③**頭の通る円弧が身体の回転と一致し、終端に急ブレーキのないフィニッシュへつながる。
- **④**早期追加入力と後期追加入力と、無入力の出し切りを区別する。止まった溜め3とは異なる。
- **⑤**分岐の存在は資料確認、回転中の足・槌頭の実経路は未観察。

### `player.war_maul.draw_smash`・抜刀納刀

- **①**【資料確認】納刀から移動＋△で武器出しの振り上げがある。【現行Kari】`draw_smash`という別の抜刀打撃を持つため、**原作の「振り上げ」との対応を再確認**。
- **②**抜刀時の先行脚・重い槌を下ろす際の身体の回転は未観察。
- **③**柄を掴んでから打点へ至る経路を一本につなぐ。背負った槌頭が頭を通り抜けてはいけない。
- **④**抜刀から溜めへ派生できる。単純に着弾を早くするだけで2Gの抜刀打撃としない。
- **⑤**操作は資料確認、身体の形は未観察。

## 太刀：練気を使う攻撃の連係

【資料確認】通常は踏み込み斬り→縦斬り→突き→斬り上げ、複合の斬り下がり。気刃は **R気刃1→△突き→R気刃2→△斬り上げ→R気刃3**（途中の攻撃と入力許可に注意）。【現行Kari】 `spirit1`・`spirit2`・`spirit3` と `round` のclipが現在あるが、最後の大回り斬りはPSP版2Gの標準連係ではない。

### `player.long_blade.kesa` と通常の縦斬り

- **①**【資料確認】納刀から移動＋△は踏み込み斬り。次の△で縦斬りを出せる。【現行Kari】`kesa`が最初の斬りを担う。二段目の縦斬りを別のclipとして用意したかは要確認。
- **②**前へ進む打撃なので接地の前後と重心をそろえる（制作提案）。どちらの脚が前か原作映像未観察。
- **③**長い刀身を高い位置から斜めまたは縦に通す。弧の詳細は未観察。
- **④**太刀は片手剣の短い連続斬りではなく、長い刀身の回収と次段の入りを重視する。
- **⑤**連係は資料確認、正確な刀の傾きは未観察。

### `player.long_blade.thrust` / `rise`（突き・斬り上げ）

- **①**【資料確認】○で突き、突きの後△で斬り上げ。通常連係の途中にも入れられる。
- **②**【制作提案】突きは後脚で身体を押し出し、斬り上げへは踏ん張りを変えながら刃を下から返す。左右どちらへ身体をひねるかは原作未観察。
- **③**突きの細い刃先の通路と、上へ返す弧を別にする（技名からの制作案）。
- **④**気刃連係の中にも通常突き・斬り上げを挿入できる。後年の見切りや居合の特殊な姿勢を前提にしない。
- **⑤**操作と連係は資料確認、足・手の順は未観察。

### `player.long_blade.back_cut`（斬り下がり）

- **①**【資料確認】△+○で斬り下がり。斬撃を入れながら後退する技で、通常・気刃から派生できる。【現行Kari】`back_cut`の後退と攻撃がある。
- **②**【制作提案】後退の一歩目で支持脚を確認し、上体だけ先に後ろへ滑らせない。左右どちらの脚を引くかはPSP未観察。
- **③**刀身を横へ通しながら相手との距離を作る構想。原作でどちらから払うかは不明。
- **④**後退と攻撃を同時に行う。ただし後年の自由な方向への移動斬りと同一とはしない。
- **⑤**技の役割と入力は資料確認、足順と斬撃方向は未観察。

### `player.long_blade.spirit1` / `spirit2` / `spirit3`（気刃連係）

- **①**【資料確認】練気がある場合R→通常突き→R→通常斬り上げ→Rの流れ。気刃3では連続して複数の刃を通す。【現行Kari】各 `spirit` clipがある。途中の通常攻撃を抜かないこと。
- **②**【制作提案】連係の前段から脚の接地を引き継ぎ、毎段独立の歩幅を入れて連続して前へ押し進めない。実際の先行脚と骨盤回旋は未観察。
- **③**気刃1、2、3を同じ弧を繰り返すだけにせず、次段の打点へ刃先が無理なく移る構成にする。具体的な弧は映像確認。
- **④**2Gの気刃連係の終端は気刃3であり、**気刃大回転斬りは後年の技**。練気の状態の見せ方を混ぜない。
- **⑤**入力順は資料確認、3技の刃の実軌道と脚は未観察。

### `player.long_blade.round`（Kariの大回り斬り）

- **①**【現行Kari】 `round` clipが存在する。**【資料確認】PSP版2Gの上記気刃連係の終端にはこの後年の技がない**。
- **②・③**原作の対応技がないため脚・刀身の「2G観察」はできない。Kariの別バージョン用の旧技として持つなら出自を明示する。
- **④**2Gを標準へ採るなら気刃3の後は構え・回避など適切な遷移にする。後年の大回転を2Gの最後だと表記しない。
- **⑤**技構成の差は資料確認。モーション比較の対象外。

### `player.long_blade.draw_cut`、抜刀・納刀

- **①**納刀→柄を取る→抜いて前方へ切る→構えへ戻す（Kariの制作案）。資料上、移動を伴う△は踏み込み斬りにつながる。
- **②**武器を抜く脚・胴のひねりはPSP未観察。
- **③**鞘と刀身の接続が抜刀中に飛ばないようにする。長い刀身の先端が身体を貫かないこと。
- **④**抜刀から通常連係と気刃へどの入力で入れるかを分離。
- **⑤**入力の存在は資料確認、原作の具体演技は未観察。

## Claudeへの最優先事項

**大槌の溜め2が二接触か、太刀の気刃3の後に後年の大回転が入っていないか**、まず入力と技の段を確認。映像を観察せずに「肩と腰は原作どおり」とはしない。接触とroot motionはKariの現行simを正本として、実動画の観察結果ができた段階で修正する。
