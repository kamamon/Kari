# 第2便 ⑤ — 長尖槍（ランス）・環弓（弓）

資料：PSP版 [MHP2G@Wiki ランス](https://w.atwiki.jp/mhp2g/pages/153.html) と [MHP2G 弓Wiki 基本動作](https://w.atwiki.jp/mhp2gyumi/pages/17.html)。Kari v0.57.0 `public/data/actions/long_lance.json`・`ring_bow.json`。**原作PSPの連続映像による足順・武器の軌道は未観察**。

## 長尖槍：正面に盾を置いたまま身体を運ぶ

【資料確認】2Gのランスは△中段突き、○上段突きの組合せ、Rガード、ガード中△突き、×後方ステップ、方向＋×横・大後ステップ、△+○継続突進を持つ。**同じ槍と盾の構えでも、上へ刺すか正面へ刺すか、突進するか、盾で守るかが違う**。

### `player.long_lance.thrust1` / `thrust2` / `thrust3`（中段突きの連係）

- **①**【資料確認】中段突きは△。上段突きとの組合せで繰り返し攻撃でき、各打点の後にステップへつなげる。【現行Kari】中段 `thrust1`→`thrust2`→`thrust3` は同じ `ll_thrust_01` クリップを参照。先の打点と次の槍先の引き戻しがつながるかを確認。
- **②**【制作提案】盾で守る側の肩を前へ残し、槍側の腕を突き出す時は反対側の脚で重心を受ける。どちらの脚で支持するか、PSP原作は未観察。
- **③**細い槍先を正面の一点へ伸ばす（技名に基づく）。突いた後、槍先をいったん戻して次の上段・中段へ進む。正確な戻し幅は不明。
- **④**2Gは中段・上段の種類を交互に選べる。すべての突きを一方向の同じ軌道にしない。
- **⑤**技・連係は資料確認、足と肩の姿勢は未観察。

### `player.long_lance.high`（上段突き）

- **①**【資料確認】○で上段突き。通常突き連係の中で出せる。
- **②**【制作提案】槍先を高く向ける際、腰を先に持ち上げすぎて盾を胸から外さない。支持足の順番は不明。
- **③**槍を斜め前上へ伸ばすのが制作案。原作の上角・握り位置は未観察。
- **④**大型の高い部位へ届く打点と、中段の低い打点を姿勢でも区別する。
- **⑤**上下を選べることは資料確認、原作での身体の細部は未観察。

### `player.long_lance.guard_thrust` とガード歩行

- **①**【資料確認】Rでガード、R+△で防御しながら突く。ガード中のスティックで、盾を構えたまま歩ける。
- **②**【制作提案】盾のある腕・胸を攻撃方向へ向けたまま足を小さく移動する。ガード歩行中の先行脚と歩幅は原作未観察。
- **③**槍先は盾の横から前へ伸ばし、盾と槍が同じ軌道に重なって貫通しないようにする。
- **④**ガード時の後退・反動・ガード突きの違いを表現する。後年のカウンターガードを含めない。
- **⑤**入力とガード歩行は資料確認、身体の細部と盾が前面にある角度は未観察。

### `player.long_lance.hop`（後方・左右・大後ステップ）

- **①**【資料確認】×＝後方ステップ、後入力＋×＝大後ステップ、左右入力＋×＝サイドステップ。突き後からも出せる。【現行Kari】`hop`の単一IDに動きがあるため、方向別の足運びを別に比較する。
- **②**【制作提案】反対側の足で蹴り、移動先の脚で衝撃を止める。跳び始めにどちらの脚を前にするかは原作未観察。
- **③**槍と盾を身体の近くへ保持し、ステップ中に槍先だけ置き去りにならないようにする。
- **④**一般の前転回避と同じ回転アニメーションを全方向に向け直すのでなく、槍専用のステップとして区別する。
- **⑤**方向と連係は資料確認、浮遊や着地・向きは未観察。

### `player.long_lance.lunge`（現行の短い突進）と2Gの継続突進

- **①**【資料確認】△+○で突進に入り、走り続けられる。突進中△でフィニッシュ突き、○で停止。【現行Kari】`lunge`は通常行動として定めた短い突進。**継続状態・止め・フィニッシュへの派生を一つの短いclipで再現したことにはできない**。
- **②**【制作提案】低く構える→足で連続して進む→急停止するか槍を最後に突き出す。突進中は片脚だけを長時間地面に張り付けず、踏み直しを行う。原作の足周期は未観察。
- **③**槍先は進行方向を保持し、フィニッシュでは通常の突進とは別の接触姿勢に入れる。
- **④**「継続突進」と「攻撃を終える突き」と「停止」は別行動。2Gの状態遷移を作ることが形の修正より先。
- **⑤**入力と派生は資料確認、体の傾き・脚順は未観察。

### `player.long_lance.counter` / `counter_thrust`（Kari旧技）

- **①**【現行Kari】受け返し構えと反撃を行う。
- **②・③**2G標準にこの後年のカウンター行動を割り当てない。PSPの姿勢との照合対象ではない。旧組`v056`の挙動として温存するなら、新標準へ混ぜない。
- **④**2G基準では通常ガード、ガード突き、ステップ、継続突進に置き換えて役割を作る。
- **⑤**2Gの操作表と一致しない点は資料確認。カウンター自身の足や武器はKariの独自設計。

### 抜刀・納刀と通常構え

- **①**【現行Kari】`draw`・`sheathe`を持つ。【制作提案】右手で槍を起こし、左盾を前面へ出して構えを成立させてから歩き出す。
- **②**原作の槍を起こす脚・肩の順は未観察。
- **③**長い槍の刃先が背面装備や地面を貫かないように、柄・槍先・盾の順序を確認。
- **④**遅い抜刀移動・頑丈な防御と短い位置調整を組み合わせる。
- **⑤**役割は資料確認、実動作は未観察。

## 環弓：射撃は弦と矢が一つの軌道として動く

【資料確認】2G弓は△長押しで溜めて離すと射撃、Rで射線、○で二段まで近接、△+○でビン装填。通常の射撃種は弓の種類・溜め段階で決まる。**「散らし撃ち」の専用ボタンと拡散矢の射種は別概念**。

### `player.ring_bow.shot`（溜め撃ち）

- **①**【資料確認】弦に矢を掛け→引いて溜め→離して発射→次の射撃準備へ。溜め中の移動と射線表示がある。【現行Kari】`shot`の行動と射撃イベントはある。
- **②**【制作提案】左右の足の上で静かに体重を移しても、射撃中に弓腕は照準方向を維持する。溜め歩きの先行脚・胸回転は原作未観察。
- **③**【制作提案】左手の弓と右手の弦を同じ瞬間に動かし、放つ時に矢がノック点から実際の照準先へ出る。原作の腕の引き幅・矢の姿勢は未観察。
- **④**射線の方向がカメラと simulation の入力から決まり、勝手な標的吸着を標準へ混ぜない。後年の溜め維持滑走回避を前提にしない。
- **⑤**溜め・射線・発射の入力は資料確認、体の動きと発射の画面上の正確な経路は未観察。

### `player.ring_bow.spread`（Kari旧技、2Gの拡散矢とは別）

- **①**【現行Kari】単発の `spread`という攻撃IDがある。**【資料確認】**2Gの拡散射撃は弓と溜めによる射種であり、○を押すと近接攻撃になる。
- **②・③**原作に「○で散らし撃ち」という直接対応はないため足運びも刃先も観察対象として設定できない。削除・旧技保持はバージョンを分けて扱う。
- **④**拡散矢、連射矢、貫通矢の差を、弓の矢種の構成として別管理する。
- **⑤**操作の不一致は資料確認、Kariの`spread`は独自動作。

### 近接攻撃とビン装着（現行Kariには対応action未登録）

- **①**【資料確認】○で近接を連続二段まで。△+○でビンを装填する。 【制作提案】近接は弓を構えた姿から矢・弓で斬りつける→引く→二段目へ。ビンは手を矢へ運ぶ→材を装着→弦へ戻す。
- **②**どの足を前にするか、近接時に前進があるか、ビン装着でどちらへ胸を向けるかは未観察。
- **③**近接中の弓本体の軌道と、ビン装着中の右手の移動は、矢の射撃軌道と分ける。
- **④**射撃専用の武器に近接とビン装着があるのが2Gの操作。後年の特殊な近接矢行動と混同しない。
- **⑤**存在・入力は資料確認、正確な動作の形は未観察。

### 回避・バックステップ・抜刀納刀

- **①**【資料確認】抜弓状態の×はバックステップ、移動入力があれば通常回避に変わる。 【現行Kari】`draw`・`sheathe`・共通回避系がある。
- **②**後ろへ跳ぶ時の踏み切り脚は原作未観察。Kariでは方向入力と弓の構えを分けて支持足を決める（制作提案）。
- **③**弦と矢が回避中に意図せず射出されないようにする。抜刀では弓を取り出して左手へ支え、右手が弦を取る順を見せる。
- **④**バックステップと通常回避を区別し、溜め中の回避操作も別に扱う。
- **⑤**回避の入力は資料確認、足と弓の角度は未観察。

## Claudeへ伝える差分

ランスは**継続突進（移動中の状態）・終了突き・停止**と、カウンターを使わないガード／ステップの構成を先に実装確認。弓は**溜め・手動射線・射種・近接・ビン装着・バックステップ**の入力を定義した後でアニメーションを作る。両者の支持足と武器経路の細部はPSP映像を確認してから、現行Kariの正式クリップに反映する。
