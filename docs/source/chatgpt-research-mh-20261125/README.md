# MH2G・MH3・MHP3rd 調査資料（画像・動画追加 v2）

利用者の直接依頼「ゲーム画面・操作・システムを調査し、ClaudeがKariの参考にできるよう文字化」に、追加指示「画像や動画などからも情報を得て」を反映した資料です。

## 1. 返却物と読む順番

1. [MH2G_MH3_Claude_Research_20261125.txt](MH2G_MH3_Claude_Research_20261125.txt)：第1版を保持。23章、約2.4万字。作品差、操作、システム、Kari向け独自設計、出典。
2. [MH2G_MH3_Visual_Research_v2_20261125.txt](MH2G_MH3_Visual_Research_v2_20261125.txt)：今回の追加資料。約1.3万字。動画5本と静止画6枚から19件の観察、8項目のKari向け提案、Claudeへの指示文。
3. [visual_observations_v2.json](visual_observations_v2.json)：同じ観察の構造化台帳。出典URL、動画内時刻、画像ID、目視事実、未確定事項、提案への参照、取得動画のSHA256を収録。

動画は2Gの発売前PV2本、MH3のGDC展示プレイとTGS実演、3rdの公式武器紹介1本。実ファイルの時系列フレームを抽出して確認しました。静止画は2GのHUD、MH3の公式画面、3rdの村・工房・狩猟HUD・温泉です。

## 2. 守れなかった決まり・迷って決めたこと

リポジトリの変更はこの専用フォルダ内だけです。第1版を消さず、追加資料をv2として返します。READMEは索引として更新しました。原作の動画・画像・説明書本体は返却物に含めず、出典と独自の観察文を収録しています。

「3」はMH3（Wii）とMHP3rd（PSP）を分けて扱いました。番号付きの掲示板依頼がないため、利用者の直接依頼として日付付きフォルダを使用しています。

不足・制約は、第1版の日本製品版説明書の未網羅に加え、今回の動画が編集済みPV、開発中画面、展示・会場映像を含むことです。全尺・全フレームの確認や音声分析は行っていません。YouTubeのMHFUチュートリアル等の未取得動画は視覚観察の根拠から除外しました。

## 3. 確かめたこと・確かめていないこと

- 動画5本の取得、ffprobeによる長さ・解像度の確認、ffmpegによる指定時刻の抽出画像の目視。2Gは重点箇所を0.5～1秒、MH3は1～2秒、3rdは約0.5～0.67秒間隔で確認。
- 静止画6枚を目視し、作品・機種・出典画像を対応付けた。
- 作品ごとの観察結果を相互確認。3rdの抽出間隔と、非交戦場面の表現を修正。
- 動画のSHA256、UTF-8、JSON解析、ID重複、出典・提案参照、時刻範囲、本文と台帳の対応を確認。
- Node v24.22.3。追加調査時点のmainのpackage.json／package-lock.jsonを使った独立フォルダで、`npm ci --no-audit --no-fund --fetch-retries=0 --fetch-timeout=20000` が成功（50 packages）。
- ゲーム全体のビルド・自動テスト、原作PSP／Wiiの入力検証、原作の内部判定・無敵・硬直の計測、KariのiPhone実機検証は未実施。モンスターJSONのdry import対象はありません。
