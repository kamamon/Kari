## 見送ったこと

- **Service Worker / オフライン**: 設計書 p.30 の通り、配信と保存が安定してから追加する。
- **モデル・テクスチャの圧縮（Draco / KTX2）**: 正式素材がまだ無い。受け取ってから容量を見て決める。
- **ポインターロックのマウス視点**: 設計書の初期割当（中ボタンドラッグ）を優先。要望があれば設定として追加する。
