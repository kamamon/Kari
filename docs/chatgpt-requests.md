# ChatGPT への依頼文（docs/chatgpt-requests.md）

設計書の分担どおり、**画像・世界観・動きの演出設計・見た目のレビューは ChatGPT**、**コード・判定・検証・配信は Claude** が担当します。
このファイルは ChatGPT 側の作業をまとめたものです。上から順に、そのまま貼って使えます。

ChatGPT へファイルごと渡したい時は、同じ内容を ChatGPT 宛てに書いた [chatgpt-requests.txt](chatgpt-requests.txt) を使ってください。

## 進め方の決まり

1. **採用した画像を、次の依頼に必ず添付する。** 最初に決めた 1 体と 1 装備が、以後の見た目の基準になります。
2. **1 対象ずつ確認する。** 数十個を 1 枚に並べた画像は一覧確認用で、ゲーム用の素材にはしません。
3. **ChatGPT と Claude は会話を共有していません。** 毎回、下の「引き継ぎ」を依頼文の前に付けてください。
4. **受け取った画像は Claude へ添付してください。** Claude がファイル名・大きさ・透過を検査し、`art-source/`（原画）や `public/assets/`（実行用）へ置いて素材台帳に登録します。
5. 画像や動画は **3D モデルやアニメーションの完成品ではなく、制作の資料** として扱います。

合格の目安: 好みの方向が 1 つに決まる / 配色・素材・形の「固定する点」と「変えてよい点」が文章で付いている / 既存作品に似た輪郭やロゴが無い。

## 音について

設計書の分担では、ChatGPT が曲調・音の役割を設計し、音声ファイルは音声生成・録音・制作ツールで作り、Claude がループ・音量・圧縮・接続を行います。
いまは効果音をすべてコードで合成した仮の音で鳴らしていて、BGM はありません。必要な音の id は `docs/asset-manifest.json` の `audio.se.placeholder_synth` にあります。
