# 試験と確認の記録（docs/tests.md）

「機能の説明」ではなく「実際の結果」で合格を判断する（設計書 p.33）。
**実行していない確認は「未確認」と書く。** 実機（iPhone / iPad の Safari、手元の PC のブラウザ）での確認は、まだ 1 件も行っていない。

## 1. 自動で確認した結果（2026-11-22、v0.1.0）

| コマンド | 内容 | 結果 |
| --- | --- | --- |
| `npm run typecheck` | 型検査（strict） | 通過 |
| `npm run test` | 自動テスト 34 件（戦闘・時間・データ・素材台帳） | 34 件通過 |
| `npm run build` | 本番ビルド | 通過。配信物 合計 0.83MB、初回に読む分は約 0.76MB（gzip で約 0.2MB） |
| `npm run smoke` | 本番ビルドを `/Kari/` のサブパスで配信し、ヘッドレス Chrome で実際に操作 | 34 項目通過 |

`npm run smoke` の環境: Linux のヘッドレス Chrome（GPU なしのソフトウェア描画、約 26fps）。PC 相当 1280×720 と、横向きスマホ相当 844×390（タッチのエミュレーション）。**実機の代わりにはならない。**

### 自動テスト（`tests/`）が確かめていること

- **ダメージ式**: 設計書の計算例が 37 になる。完全無効は 0、下限は 1。
- **縦斬り**: 技データが設計書の値。有効判定 [22,30) の間にだけ当たる。届かない距離では当たらず、振り音だけ鳴る。ヒットストップの 4 tick だけ行動が止まる。連打しても最初へ戻らない。回避キャンセルは [58,72) だけ。溜めは段階に応じて威力が上がる。
- **横薙ぎ**: 脚と胴に同時に触れても加算は 1 回。縦斬りへの連係は [44,66)。
- **回避**: スタミナ 25、無敵は [3,11) の 8 tick だけ、3.4m 進み、壁を抜けない。スタミナ不足では出ない。
- **先行入力**: 6 tick 以内は実行、7 tick 前は消える。
- **標的の攻撃**: 無防備なら 1 回だけ被弾して転倒。正面の防御は削り 6 とスタミナ 30。背を向けた防御は不成立。スタミナ不足は防御崩れ。無敵を合わせればすり抜ける。攻撃開始 30 tick 以降は向きを変えない。
- **部位**: 耐久は本体 HP と別に減り、破壊で怯む。倒れると復帰する。
- **時間**: 同じ seed と tick 付き入力 2400 tick を、描画 60 / 30 / 144fps と不規則な間隔で再生し、全 tick の状態が一致。seed を変えると不一致を検出する。
- **時計**: 1/60 秒で 1 tick、端数の持ち越し、長い停止の後は上限まで、reset で蓄積を捨てる。
- **データ**: 全 JSON が検証を通る。壊れたデータは読み込みで弾く。武器の軌道が構えの位置に繋がる。
- **素材台帳**: id の重複なし、ファイルの実在、ゲームが参照する assetId・clip・音の id が台帳と仮素材の両方にある、clip の長さが技データと一致。

### ブラウザでの操作検査（`tools/smoke.mjs`）が確かめていること

起動 / W で前進 / 疾走でスタミナ減少 / 標的の胴を抜けない / 抜刀斬り・縦斬り・横薙ぎ・溜め斬りが 1 回ずつ命中 / 正面の防御 / 被弾と転倒 / 回避 / 納刀 / メニュー中の一時停止 / 30・60fps の一致チェック / 記録した入力の再生がいまの画面の状態と一致 / 0.3m の段を登る / 1.4m の岩棚で止まる / 描画量 87 draw calls・約 1.9 万 tri（目標 100・20 万以内）/ タッチ 3 本指で移動 + 視点 + 攻撃 / touchcancel で押しっぱなしが残らない / 同じボタンへ 2 本指でも 1 回 / HUD の「検証」「☰」がタッチで押せる / ボタンをドラッグで動かして保存できる / 縦持ちで案内と一時停止、横へ戻すと再開し入力が効く / 素材ビューアで仮リグの全高 1.750m、基準 GLB の寸法 / コンソールエラーと 404 が無い。

## 3. 実機チェック表（M0・M1 の合格条件）

公開した URL を開いて、当てはまるものに印を付けてください。うまくいかない項目は、メニュー →「検証」→「報告テンプレート」をコピーして、手順と一緒に Claude へ送ってください。

機種: ＿＿＿＿＿＿　OS: ＿＿＿＿＿＿　ブラウザ: ＿＿＿＿＿＿　ビルド: ＿＿＿＿＿＿（起動画面の下に表示）

**起動と画面**
- [ ] 通常の Safari タブで起動画面が出て、「はじめる」で 3D 画面になる
- [ ] 横向きで、ボタンがノッチ・ホームバー・タブバーに隠れない
- [ ] 縦にすると「横向きにしてください」が出て止まり、横に戻すと続きから動く
- [ ] 音が出る（振る音・当たる音・風）。出ない時、設定の「音声を再開」で出る（iPhone は本体の消音スイッチが入っていると鳴りません）

**操作（M0）**
- [ ] 左のスティックで歩ける。右側の空いた所をドラッグして視点を回せる
- [ ] 歩きながら視点を回し、そのまま攻撃ボタンも押せる（3 本指）
- [ ] 「疾走」で走り、スタミナ（黄色）が減る
- [ ] 壁・岩・標的をすり抜けない。北東の段々は登れて、南西の高い岩棚は登れない
- [ ] 視点を壁へ向けて下がると、カメラが手前へ寄る。「正面」で背後へ戻る
- [ ] ホームへ出て戻る、通知を引き出して戻す、をしても、勝手に歩き続けたり攻撃し続けたりしない

**戦闘（M1）**
- [ ] 「斬る」で抜刀斬り → 縦斬り。振りかぶってから当たるまでの「間」がある
- [ ] 「斬る」を押し続けると溜め（左上のひし形が点灯）、離すと振り下ろす
- [ ] 「薙ぐ」で横薙ぎ。その後すぐ「斬る」で縦斬りへ繋がる
- [ ] 標的が腕を振り上げたら、横へ歩く / 「回避」/ 「防御」のどれかで対処できる
- [ ] 「検証」を押すと、赤い判定（攻撃中）と色分けされた部位が重なって見える。刃の見た目と赤い判定が同じ場所を通る
- [ ] 頭を何度か斬ると「部位破壊: 頭」が出て、頭の面が外れる
- [ ] メニュー →「検証」→「30 / 60fps の一致」→「確認する」で「結果: 一致」「いまの画面の状態とも一致」と出る

**手触り（好みを教えてください）**
- [ ] ボタンの位置と大きさ（設定で変えられます。変えた後の配置が良ければそれを初期値にします）
- [ ] 視点の速さ、左右・上下の向き
- [ ] 縦斬りの重さ（遅すぎる / 速すぎる）、回避の距離、標的の攻撃の読みやすさ
- [ ] カクつき・発熱（ひどい時は 設定 →「描画の上限 30fps」「内部解像度」を下げて変化を見る）
