**起動と画面**
- [ ] 通常の Safari タブで起動画面が出て、「はじめる」で 3D 画面になる
- [ ] 横向きで、ボタンがノッチ・ホームバー・タブバーに隠れない

- [ ] 音が出る（振る音・当たる音・風）。出ない時、設定の「音声を再開」で出る（iPhone は本体の消音スイッチが入っていると鳴りません）

**操作（M0）**
- [ ] 左のスティックで歩ける。右側の空いた所をドラッグして視点を回せる
- [ ] 歩きながら視点を回し、そのまま攻撃ボタンも押せる（3 本指）
- [ ] 「疾走」で走り、スタミナ（黄色）が減る
- [ ] 壁・岩・標的をすり抜けない。北東の段々は登れて、南西の高い岩棚は登れない
- [ ] 視点を壁へ向けて下がると、カメラが手前へ寄る。「正面」で背後へ戻る
- [ ] ホームへ出て戻る、通知を引き出して戻す、をしても、勝手に歩き続けたり攻撃し続けたりしない

**戦闘（M1）**
- [ ] 「斬る」で抜刀斬り → 縦斬り。振りかぶってから当たるまでの「間」がある
- [ ] 「斬る」を押し続けると溜め（左上のひし形が点灯）、離すと振り下ろす
- [ ] 「薙ぐ」で横薙ぎ。その後すぐ「斬る」で縦斬りへ繋がる
- [ ] 標的が腕を振り上げたら、横へ歩く / 「回避」/ 「防御」のどれかで対処できる
- [ ] 「検証」を押すと、赤い判定（攻撃中）と色分けされた部位が重なって見える。刃の見た目と赤い判定が同じ場所を通る
- [ ] 頭を何度か斬ると「部位破壊: 頭」が出て、頭の面が外れる
- [ ] メニュー →「検証」→「30 / 60fps の一致」→「確認する」で「結果: 一致」「いまの画面の状態とも一致」と出る
