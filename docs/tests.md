### 自動テスト（`tests/`）が確かめていること

- **道具・捕獲・報酬（M2 後半、21 件）**: 支給品を持って出発する。回復液は効果の tick で 40 回復して 1 個減り、途中で攻撃を受けると回復せず減らない。抜刀中は納刀してから使う。罠は 60 tick で作動可能になり、踏むと 540 tick 止め、同時に 1 つまで。鎮静玉は正面 7m で当たり、外しても減り、900 tick で効き目が消える。捕獲は「弱り + 罠 + 鎮静玉 2 個」がそろった時だけで、同じ tick に倒していたら討伐になる。剥ぎ取りは本体 3 回・尾 1 回で、80 tick 目に素材が入る。結果が閉じた時に報酬が一度だけ確定し、閉じた後は何を入力しても変わらない。失敗・リタイアは報酬なし。同じ seed なら同じ素材。30fps と 60fps の再生が一致。
- **ダメージ式**: 設計書の計算例が 37 になる。完全無効は 0、下限は 1。
- **縦斬り**: 技データが設計書の値。有効判定 [22,30) の間にだけ当たる。届かない距離では当たらず、振り音だけ鳴る。ヒットストップの 4 tick だけ行動が止まる。連打しても最初へ戻らない。回避キャンセルは [58,72) だけ。溜めは段階に応じて威力が上がる。
- **横薙ぎ**: 脚と胴に同時に触れても加算は 1 回。縦斬りへの連係は [44,66)。
- **回避**: スタミナ 25、無敵は [3,11) の 8 tick だけ、3.4m 進み、壁を抜けない。スタミナ不足では出ない。
- **先行入力**: 6 tick 以内は実行、7 tick 前は消える。
- **標的の攻撃**: 無防備なら 1 回だけ被弾して転倒。正面の防御は削り 6 とスタミナ 30。背を向けた防御は不成立。スタミナ不足は防御崩れ。無敵を合わせればすり抜ける。攻撃開始 30 tick 以降は向きを変えない。
- **部位**: 耐久は本体 HP と別に減り、破壊で怯む。倒れると復帰する。
- **時間**: 同じ seed と tick 付き入力 2400 tick を、描画 60 / 30 / 144fps と不規則な間隔で再生し、全 tick の状態が一致。seed を変えると不一致を検出する。
- **時計**: 1/60 秒で 1 tick、端数の持ち越し、長い停止の後は上限まで、reset で蓄積を捨てる。
- **データ**: 全 JSON が検証を通る。壊れたデータは読み込みで弾く。武器の軌道が構えの位置に繋がる。
- **ガルドロス（`tests/galdros.test.ts`、21 件）**
  - 発見: 遠くでは動かない。視界に入ると気付いて咆哮。背後からは 6m まで気付かれない。攻撃すれば気付く。
  - 前脚叩き: プレイヤーが居る側の脚を選ぶ。28 tick 以降は向きを変えない。当たるのは 1 回。
  - 直線突進: 遠い正面でだけ使う。走り出した後は追わない。立ち止まると 1 回だけ当たり、横へ避ければ当たらない。壁際では選ばない。
  - 半円尾払い: 背後に居ると使う。尾を切ると短い尾払いに替わり、届く距離が縮む。
  - 鉱殻崩落: 落下地点は予告の時点で固定。その場に居れば 1 回当たり、離れれば当たらない。
  - 依頼の倍率 0.75 が受けるダメージに掛かる（倍率 1 なら技データの値）。
  - 部位: 頭と背殻は耐久が尽きると壊れ、肉質が柔らかくなる。尾は斬属性の蓄積でだけ切れ、判定が短くなる。脚の怯みは転倒。立ち直り直後は怯まず、次はより多く必要。
  - 怒り: 450 ダメージで怒って咆哮、2100 tick で収まる。死亡は終端で、以後は何も起きない。
  - 依頼の終了: 討伐で成功。制限時間で失敗。力尽き 3 回で失敗（2 回目まではキャンプから再開）。リタイアで失敗。討伐と時間切れが同じ tick なら討伐。終了後は攻撃も落石も当たらない。
  - ガルドロス戦 4200 tick の入力を、描画 30 / 60fps と不規則な間隔で再生して全 tick 一致。
- **素材台帳**: id の重複なし、ファイルの実在、ゲームが参照する assetId・clip・音の id が台帳と仮素材の両方にある、clip の長さが技データと一致。

### 自動操作での目安（人が遊んだ結果ではない）

数値を決めるために、simulation だけを動かす簡単な自動操作（脚の近くへ寄り、安全そうな時に縦斬り、技の予備動作が見えたら離れる）で 3 通りの seed を試した。記録用で、リポジトリには入れていない。

| --- | --- |
| HP 2600・受けるダメージ等倍（最初の案） | 3 回とも、136〜149 秒で 3 回力尽きて失敗。その時点の残り HP 738〜1038 |
| HP 1800・受けるダメージ 0.75 倍（採用） | 3 回とも討伐。146〜155 秒、力尽き 2 回、命中 32〜33 回 |

- [ ] 壁・岩・標的をすり抜けない。北東の段々は登れて、南西の高い岩棚は登れない
- [ ] 視点を壁へ向けて下がると、カメラが手前へ寄る。「正面」で背後へ戻る
- [ ] ホームへ出て戻る、通知を引き出して戻す、をしても、勝手に歩き続けたり攻撃し続けたりしない

**戦闘（M1）**
- [ ] 「斬る」で抜刀斬り → 縦斬り。振りかぶってから当たるまでの「間」がある
- [ ] 「斬る」を押し続けると溜め（左上のひし形が点灯）、離すと振り下ろす
- [ ] 「薙ぐ」で横薙ぎ。その後すぐ「斬る」で縦斬りへ繋がる
- [ ] 標的が腕を振り上げたら、横へ歩く / 「回避」/ 「防御」のどれかで対処できる
- [ ] 「検証」を押すと、赤い判定（攻撃中）と色分けされた部位が重なって見える。刃の見た目と赤い判定が同じ場所を通る
- [ ] 頭を何度か斬ると「部位破壊: 頭」が出て、頭の面が外れる
- [ ] メニュー →「検証」→「30 / 60fps の一致」→「確認する」で「結果: 一致」「いまの画面の状態とも一致」と出る

**画面（v0.2.1 で直した点）**
- [ ] ボタンを素早く 2 回押しても、画面の余白をダブルタップしても、拡大されない
- [ ] Safari の共有 →「ホーム画面に追加」でできたアイコンから開くと、URL の欄が出ない。ボタンがノッチやホームバーに隠れない
- [ ] ガルドロスが出ている間、カクつかない（重い時は 設定 →「内部解像度」を下げて変化を見る）
- [ ] （Safari のタブのまま遊ぶ場合）起動画面を上へなぞると、上の欄が小さくなる
- [ ] ガルドロスがこちらを目で追う。止まっている間に身震いやうなりをする。歩くと足音がして土ぼこりが立つ
- [ ] 頭や背殻を壊すと、岩が砕けて飛ぶ。体力が減ると足を引きずる

**ガルドロス戦（M2 前半）**
- [ ] 「はじめる」の後に拠点画面が出て、依頼「岩場の足音」を選ぶと狩場に出る
- [ ] 遠くのガルドロスは、近づくまでこちらに気付かない。気付くと吠える
- [ ] 前脚を持ち上げる・頭を下げて地面を掻く・腰をひねる・背が震える、の 4 つの構えを見分けられる
- [ ] 構えを見てから、歩く / 回避 / 防御で間に合う（間に合わない技があれば、どれか教えてください）
- [ ] 落石の輪（地面の橙色の輪）が見える。輪の外へ出れば当たらない
- [ ] 突進は、横へ走れば当たらない。走り出した後に曲がって追ってこない
- [ ] 頭を斬り続けると「部位破壊」、尾を斬り続けると尾が切れて地面に落ちる。脚を斬り続けると転ぶ
- [ ] 大きな体に近づいた時、カメラが体にめり込んだり、相手を見失ったりしない
- [ ] 倒すと少し間を置いて「依頼達成」の画面が出る。「拠点へ戻る」で戻れる
- [ ] メニュー →「依頼」→「リタイアする」で失敗として終わる
- [ ] 難しさ: 倒せたか、何分かかったか、何回力尽きたか、どの技で倒されたか

**手触り（好みを教えてください）**
- [ ] ボタンの位置と大きさ（設定で変えられます。変えた後の配置が良ければそれを初期値にします）
- [ ] 視点の速さ、左右・上下の向き
- [ ] 縦斬りの重さ（遅すぎる / 速すぎる）、回避の距離、標的の攻撃の読みやすさ
- [ ] カクつき・発熱（ひどい時は 設定 →「描画の上限 30fps」「内部解像度」を下げて変化を見る）
