## 2. 技術

- TypeScript 7.0.2 / Vite 8.3.8 / Three.js 0.187.0（WebGL2）/ Vitest 5.1.1、Node 22。版は package-lock.json で固定。
- 計算は 60Hz 固定 tick（`src/core/clock.ts`）。描画は端末の更新頻度、または設定で 30fps 上限。1 フレームで追いつくのは最大 6 tick、超過分は捨てる。非表示・回転・メニューから戻った時は蓄積時間を捨てる。
- simulation（`src/game/`）は DOM・Three.js・`Math.random`・現在時刻を使わない。乱数は seed 付き（mulberry32）。
- 座標: 単位 m、Y 上、+Z 前。yaw=0 で +Z を向き、右手側は -X。
- 素材と JSON の URL は `import.meta.env.BASE_URL` から作る。

縦斬りの値は設計書 p.23 の JSON と同じ。旋回は 10 tick まで毎秒 90°。ヒットストップは 4 tick（横薙ぎ 3）。

- **溜め**: 縦斬りの 18 tick 目（最大振り上げ）で主攻撃を押し続けていると動作が止まり、離すと続きへ進む。30 / 60 / 90 tick で段階 1 / 2 / 3、倍率 ×1.3 / ×1.65 / ×2.1、ヒットストップ +2 / +4 / +6。120 tick で自動的に振り下ろす。溜めない場合の時間は上の表と同じ。
- **防御**: 抜刀中に防御を押し続ける。構え 10 tick（5 tick 目から有効）、解除 14 tick。正面 120° だけ有効。受けると攻撃ごとの防御コスト分のスタミナを消費し、ダメージの 25% を受けて 24 tick 後退。スタミナが足りないと防御崩れ（70% 被弾、60 tick 硬直）。
- **回避**（`player.common.roll`）: 36 tick、3.4m、スタミナ 25、無敵 [3,11)。入力方向へ転がる（入力が無ければ正面）。抜刀中は体の向きを保つ。

## 5. ダメージ（設計書 p.10）

```
物理 = 基礎攻撃力 × 技倍率 × 刃補正 × 物理部位係数 × 会心補正
属性 = 属性値 × 技属性倍率 × 属性部位係数
ダメージ = floor((物理 + 属性) × クエスト補正)   完全無効は 0、有効な攻撃の下限は 1
```

会心は 1 命中につき seed 付き乱数を 1 回引く（会心 ×1.25、負の会心 ×0.75）。
命中台帳のキーは `attackInstanceId + hitWindow.id + targetEntityId`。複数部位に同時に触れた時は、掃引で最初に触れた部位、同時なら部位の並び順（頭 → 尾 → 背殻 → 脚 → 胴）。

## 8. 入力

- タッチ: Pointer Events。pointerId ごとに「スティック / 視点 / ボタン」の所有者を固定。左側 44%（上端 22% を除く）に触れるとその位置にスティックが出る。同じボタンへの 2 本目の指は二重発火させない。pointercancel・回転・非表示・メニューで全解除。
- 疾走: 既定は疾走ボタン（押すと切替、スティックを離すと解除）。設定で「外周まで 0.3 秒倒し続ける」方式に変更可。
- ロックオン（v0.16.0。D-076）: タッチ「ロック」/ PC T / ゲームパッド RT で入・切。里では使わない（ボタンも出さない）。
- PC とゲームパッドの割当は README の操作表。
- 保存する設定: 感度、左右/上下反転、左利き配置、ボタンの大きさ・濃さ・個別位置、疾走の方法、向き直り補助、揺れ、描画上限、内部解像度、影、音量、検証表示、標的の攻撃。

## 9. カメラ

背面追従。距離 5.2m、上下角 -14°〜66°。視線が外周・岩・地面に当たると手前へ寄せる。正面復帰は毎秒 7 ラジアンで回し、急に切り替えない。設定「対象への向き直り補助」を入れると、正面復帰が標的の方向へ向く。画面の揺れは 無 / 弱 / 中。

**ロックオン**（v0.16.0。D-076）: 入れている間、カメラの左右の向きが標的の真ん中（部位の当たり形状の平均。モンスターの定義から決まる）へ向き続ける。回す速さは毎秒 2.5〜9.5 ラジアン（ずれが大きいほど速い）。標的に 2m より近い時は回さない。横の視点操作は効かない（上下は効く）。標的に照準（四隅のかぎ）が出て、タッチの「ロック」ボタンが点く。標的が倒れた・捕獲された・別のエリアへ移った・70m より離れた時は自動で外れ、「ロックオンが外れた」と出す。描画だけの機能で、simulation は変えない（移動の向きは、これまでどおりカメラ基準。入力の記録は世界の向きで残るので、再生は変わらない）。攻撃の向きを標的へ自動で合わせる補助は無い。

## 10. 画面と端末

- viewport-fit=cover と safe-area-inset、高さは 100dvh。操作領域だけ touch-action:none、メニューは通常のスクロール。
- 縦持ち（タッチ端末）は回転の案内を出して一時停止。全画面や向きの固定には頼らない。
- 拡大の防止: touch-action に加えて、操作領域の touch イベントの既定の動作・Safari のピンチ・連続タップの 2 回目を止める（`src/input/gestureGuard.ts`）。
- 画面を広く使う方法（任意）: ホーム画面に追加したアイコンから開くと、ブラウザの枠なしで起動する（`public/manifest.webmanifest`）。Fullscreen API が使える端末（iPad・Android・PC）では、拠点画面と設定に「全画面にする」を出す。iPhone の Safari には全画面の API が無いので、拠点画面にホーム画面への追加を案内する。
- 音声は「はじめる」の操作で開始。設定に「音声を再開」。
- WebGL2 が使えない場合と読み込み失敗は、理由と再試行ボタンを表示する。
- 内部解像度は DPR 上限 1.5 × 倍率 0.65〜1.0（HUD は HTML なので鮮明なまま）。

**動きの数**: 技として 23（尾を切った後の短い版 3 つを含む）、技の clip は 20。ほかに、待機中のしぐさ 7 種と、歩く・走る・向き直る・怯む・転倒・罠でもがく・眠る・倒れるがある。**大型モンスターは 1 体あたり 20〜50 の動きを持たせる**（D-053。訓練標的は試験用なので数えない）。

**怒り**: 受けたダメージが 450 たまるたびに怒り、咆哮してから 2100 tick（35 秒）続く。怒っている間は 旋回と歩行 ×1.25、与えるダメージ ×1.2、技の待ち時間 ×0.6。

上の表のダメージは技データの値。依頼の倍率（13 章）と怒りの倍率を掛け、端数を切り捨てた値が実際のダメージになる。

**見た目（仮モデル、`src/render/galdrosRig.ts`）**: 骨 53 本で曲がる皮と、1 枚ずつ骨を持つ岩板 15 枚をコードで組む。皮の色は設定図（右側面）から焼いた絵（`public/assets/textures/galdros/galdros_hide_v1.webp`、区画の並びは `src/render/galdrosAtlas.ts`）、岩は設定図から取った明暗の模様（`galdros_rock_v1.webp`）を使う（D-039）。背殻は 1 つのなめらかな殻の面を 6 枚で分け合う薄い板で、縁は青銅色（D-040）。体つき（全長・頭・尾・腹の高さ）と当たり判定は設定図の比率に合わせてある（D-041）。脚の太さと殻の大きさは設定図とまだ違う。陰は Blender で焼いた値を頂点の色へ掛ける（`src/render/galdrosAo.ts`）。
- 歩行と旋回は、足先を地面に置いたまま体を進め、離れたら対角の 2 本ずつ踏み出す。毎秒 4.2m を超える速さ（突進）では駆け足に切り替える。
- 前脚叩きの脚と尾払いの尾は、判定と同じ軌道データに従う。尾はそれ以外の時、付け根の向きに遅れて付いてくる。
- 気付いた後は、頭を狩人へ向ける（±0.45 ラジアンまで）。呼吸、まばたき、止まっている間のしぐさ（身震い・鼻息・うなり・地面を掻く・尾を振る。気付く前は地面を嗅ぐ・見回す）。
- 命中した部位と位置に応じて、体・頭・尾がのけぞる。頭と背殻の破壊では、岩板が砕けて飛ぶ。
- 体力が 25% 以下になると、頭と尾が下がり、息が荒くなり、左後ろ脚を引きずる（弱った合図。見た目だけ）。
- 足音と土ぼこりは、脚が着いた瞬間に出す。

見た目は描画だけの処理で、判定と入力の再生には影響しない。

## 13. 依頼と狩猟の流れ（`public/data/quests.json`）

- 「はじめる」の後は **拠点画面（灯継ぎの里）** で行き先を選ぶ: 依頼「岩場の足音」か、訓練場（M1 の訓練標的）。3D の村は M3 で作る。
- 依頼「岩場の足音」（`quest.basin.003`）: 風礫盆地でガルドロス 1 頭を狩る（`kind: hunt` = 討伐でも捕獲でも達成）。制限 15 分（54000 tick）、力尽き 3 回で失敗。地形は訓練区画と同じ。支給品は回復液 5・拘束罠 1・鎮静玉 3。報酬は 600 通貨と岩殻片 1。
- 受けるダメージの倍率（`monsterAttackScale`）は、回復液を支給するようにしたので **1.0（指定なし）へ戻した**（D-042）。HP 1800 はそのまま。遊んでの確かめはまだ。
- 終了の種類: 討伐・捕獲（成功）/ 時間切れ・力尽き 3 回・リタイア（失敗）。同じ tick に重なった時は 討伐 → 捕獲 → リタイア → 力尽き → 時間切れ の順で 1 つだけ確定する。確定後は成否が変わらず、モンスターは技を出さない。
- 力尽きても 2 回目までは、キャンプから体力全快で再開する（時間は進む）。
- リタイアはメニューの「依頼」から。入力の 1 つ（`Btn.Retire`）として扱うので、入力の記録を再生しても同じ tick に終わる。
- 結果画面: 結果が閉じて（14 章）から 50 tick 後、失敗は確定の 90 tick 後に出る。依頼名・結果・かかった時間・力尽きた回数・壊した部位・与えたダメージ・報酬（通貨、素材と入手元）。「もう一度」で同じ依頼を最初から、「拠点へ戻る」で拠点へ。
- 画面の右上に、残り時間・目標・力尽きた回数を出す。

未実装: 帰還の演出、依頼の一覧（いまは 1 件だけ）、採取、支給品の受け取り箱。

## 14. 道具・捕獲・剥ぎ取り・報酬（`public/data/items.json`、`loot.json`）

**道具**（依頼の支給品を持って出発する。訓練場では持たない）

| 道具 | 使う行動 | 効果 |
| --- | --- | --- |
| 回復液 | 92 tick。58 tick 目に効果 | 体力 +40（上限 100）。依頼の外や達成後でも使える |
| 拘束罠 | 112 tick。84 tick 目に設置 | 足元の 0.9m 前に置く。60 tick で作動可能になり、大型の中心が縁から 0.9m 以内（半径 1.5m + 0.9m）へ入ると 540 tick 止める。同時に 1 つ、90 秒で消える。2 回目からは止まる時間が 6 割ずつになる |

- 道具ボタン（タッチは画面の下・中央、キーボードは E、切り替えは ◀▶ / Q・ホイール）。**納刀中だけ使える**。抜刀中に押すと、納刀してから続けて使う。

**捕獲**（`kind: hunt` の依頼で、`captureAllowed` の相手だけ）

次の 3 つが同時にそろった tick に成立する: 体力が最大の 25% 以下（`capture.hpRatio`。弱った合図の見た目と同じ値）/ 罠にかかっている / 鎮静玉が 2 個たまっている（`tranqNeeded`）。
死亡はこれより先に確定するので、同じ tick に倒していたら討伐になる。捕獲した相手は眠り、以後はダメージを受けない。

**達成の後**

- 討伐: 本体から 3 回、切り落とした尾から 1 回、剥ぎ取れる。対象の近く（本体は胴の半径 + 1.4m、尾は 1.7m）で攻撃ボタン（道具ボタンでも可）。1 回 100 tick で、80 tick 目に素材が手に入る。
- 拠点へ戻るまでの時間は 60 秒（`returnTicks`）。剥ぎ取りを使い切ると 150 tick 後、「帰還する」（画面上部のボタン / メニュー）ならすぐ、結果が閉じる。捕獲は 300 tick 後に閉じる（剥ぎ取りは無い）。
- 壊した部位（頭・背殻）の追加の素材と、捕獲の素材（4 個）は、達成が確定した tick に抽選する。
- **結果が閉じた時に報酬を一度だけ確定する**（`hunt.rewards`）: 通貨 + それまでに手に入れた素材 + 依頼の固定の素材。閉じた後は何を入力しても変わらない。失敗・リタイアは、報酬も素材も無しで、確定と同時に閉じる。
- 抽選は seed 付き乱数で、同じ seed と同じ入力なら同じ素材になる。
- 素材 4 種: 岩殻片・硬骨・青銅晶脈・前脚甲（尾端晶と脈動晶芯は拡張）。

**持ち物**: 拠点の持ち物（通貨と素材の数）は、端末に保存する（15 章）。依頼 1 回につき一度だけ足す。

## 15. 保存と工房（`src/save/`、`public/data/recipes.json`）

v0.6.0。設計書 28 章と CLAUDE.md の Save、ChatGPT の計画 13 章（D-056）に合わせた。

**何を保存するか**（1 つのデータ。スロットは `main` だけ）

| 項目 | 内容 |
| --- | --- |
| `schemaVersion` | データの構造の版。いまは 3（v0.9.0 で防具を足して 2、v0.14.0 で「身に着けている防具」を足して 3。古い版は、開いた時に 1 段ずつ直す。17 章） |
| `revision` | 書き込むたびに 1 増える |
| `updatedAt` / `appVersion` / `contentVersion` | 最後に保存した時刻と版（記録用） |
| `money` / `items` | 通貨と、素材の数（ID → 個数） |
| `weapons` / `equippedWeaponId` | 持っている武器と、装備している武器 |
| `armor` | 持っている防具（版 2 から。17 章） |
| `equippedArmorIds` | 身に着けている防具（版 3 から。装備箱で、部位ごとに替える・外す。17 章） |
| `progress.questClears` | 依頼ごとの達成回数 |
| `settledRuns` | 報酬を確定した依頼の識別子（直近 300 件） |

- 置き場所は IndexedDB。DB の名前は `veilbound-hunters:prod:save`（ゲーム固有）。操作と表示の設定は、これまでどおり別（localStorage の `veilbound-hunters:prod:settings`）で、触っていない。
- **狩りの途中は保存しない。** 依頼の途中でページを閉じると、その依頼は無かったことになり、出発前の里の状態に戻る（設計書どおり）。
- 保存するのは、報酬の確定・強化・武器の持ち替え・取り込みの時。何も変えていない間は、端末に何も置かない。

**確定の決まり**

- 報酬の受け取りと強化は、「いまのデータを読む → 確かめる → 書く」を **1 回の書き込み（1 つの readwrite transaction）** で行う。持ち物の表示が変わるのは、書き込みが完了してから。結果の画面には「保存しています…」→「保存しました」と出る。
- 報酬は、依頼 1 回ごとの識別子（出発のたびに作る）につき 1 度だけ。処理済みの識別子を、同じ書き込みで記録する。
- 書き込みに失敗したら、持ち物は増えず、「保存できませんでした」と「もう一度保存する」が出る。拠点へ戻っても、保存できていない報酬があることを知らせる（ページを閉じるまで、やり直せる）。
- **別のタブ**: 書く時に、こちらが見ていた `revision` と置いてあるデータの `revision` を、同じ書き込みの中で比べる。違っていたら書かずに、新しい内容を読み直す。報酬の受け取りだけは、新しい内容の上へ足し直す（同じ依頼は 1 度だけなので安全）。強化と持ち替えは、読み直して知らせるところまで。
- 同じタブの中の書き込みは、1 つずつ順番に行う。

**消さない決まり**

- この版に無い ID（素材・武器）は、捨てずに持ち続ける。拠点には「この版では使えないもの」として出す。装備がこの版で使えない武器なら、遊ぶ時だけ持っている別の武器を持たせる（保存データは書き換えない）。
- この版より新しい構造のデータ（`schemaVersion` が大きい）と、形が壊れているデータには **触れない**。知らせを出し、その回はメモリの上だけで遊べる（ページを閉じると消える）。壊れているデータは、利用者が選んだ時だけ、控えへ移して新しく始められる。
- 古い構造からの変換は 1 段ずつ（`MIGRATIONS`）。いまは版 1 が最初なので、変換は無い。変換した時は、元のデータを控えへ入れる。
- 保存できない端末（IndexedDB が使えない）では、保存なしで動かし、拠点に知らせを出す。

**書き出し・取り込み・控え**（拠点の「データ」）

- 書き出し: JSON のファイル、またはコピー。目印 `format: "veilbound-hunters-save"` を付ける。
- 取り込み: ファイルを選ぶか、貼り付ける。形と数を検証し、内容を見せてから入れ替える。入れ替える前の内容は控えに残る。読めない・別のファイル・数が不正なら断り、いまの内容を変えない。
- 控え: 起動して最初の書き込みの前の内容、取り込む前、控えから戻す前の内容を、5 個まで残す（古いものから消える）。拠点から戻せる。
- 「永久に保存」とは書かない。ブラウザのデータを消すと無くなること、端末の側で消されることがあることを、画面に書いてある。対応しているブラウザでは「消されにくい保存」（`navigator.storage.persist`）を頼むが、結果は表示に使うだけ。

**設計書との違い**: 取り込みを「別スロットへ」ではなく、いまのスロットへ入れ替える（入れ替える前を控えに残す）。スロットは 1 つだけ。出発の時には保存しない（出発で変わるものがまだ無い）。

**工房（2 段目の強化 7 件。3 段目から先と防具は 17 章）**

- `recipes.json`。`kind: "upgrade"` は、持っている武器を、素材と通貨で別の武器に変える。元の武器は無くなる。
- いまあるのは 7 件（v0.6.0 で断岳剣、v0.8.0 で残り 6 つ。D-059）。どれも「里鍛ちの〜 → 岩殻の〜」で、**120 通貨**。攻撃力だけが元の 1.15 倍になる（**机上の値**）。属性・会心・刃補正・技・当たり判定は同じ。

  | 武器 | 岩殻片 | 硬骨 | 青銅晶脈 | 前脚甲 | 攻撃力 |
  | --- | --- | --- | --- | --- | --- |
  | 断岳剣 | 3 | 2 | 1 | - | 80 → 92 |
  | 護刃 | 2 | 2 | - | 1 | 66 → 76 |
  | 大槌 | 4 | 2 | - | - | 86 → 99 |
  | 双剣 | 2 | 1 | 2 | - | 60 → 69 |
  | 太刀 | 3 | - | 2 | - | 76 → 87 |
  | 長尖槍 | 3 | - | - | 2 | 72 → 83 |
  | 環弓 | 1 | 3 | 1 | - | 70 → 80 |

  断岳剣は設計書 p.24 の例。ほかの 6 つは本作で決めた（設計書の「岩殻の護刃」は硬石 3 を使うが、採掘がまだ無いので硬骨に替えてある）。7 つ全部で、岩殻片 18・硬骨 10・青銅晶脈 6・前脚甲 3・840 通貨。
- 見た目は、元の形に岩の板と青銅色の留め帯を足した **仮の形**（設定図は無い）。断岳剣は峰に板 4 枚（`buildHeavyBlade('shell')`）、ほかの 6 つは共通の作り（`src/render/shellPlates.ts` の `withShell()`。板の位置は武器ごとの表）。双剣は左の剣にも付く。盾（護刃・長尖槍）は変わらない。素材ビューアの `?subject=weapons&tier=2` で並べて見られる（`tier=2` を付けると、ビューアのハンターも強化後の形を持つ）。
- 工房の並びは、装備している武器 → 強化できる → まだ足りない（v0.9.0 から、持っているものの「次の強化」を 1 つずつ出す。17 章）。
- 拠点の「工房」に、必要な数と持っている数（`岩殻片 2 / 3`）が出る。足りていれば「強化する」→ 確認 → 保存が完了してから「強化しました」。
- データの検査: 元と結果の武器があること、同じ系統であること、**素材が、いまの依頼のどこかで手に入ること**（手に入らない素材を要求するレシピは、起動時に弾く）。

## 16. 刃の状態と研磨石（`public/data/weapons.json` の `edge`、`items.json`）

v0.7.0。設計書 p.10「刃補正」、p.12「刃の状態: 段階ごとにダメージと弾かれ条件。砥ぎで回復」をもとに、数値と細かい決まりは本作で決めた（**すべて机上の初期値**）。

**刃の状態**（0〜100。狩りごとの値で、保存しない。出発のたびに 100 から）

| 段階 | 値 | ダメージ（刃補正へ掛ける） | 弾かれる硬さ（物理部位係数がこれより小さいと弾かれる） |
| --- | --- | --- | --- |
| 鋭い | 60 以上 | ×1.0（これまでと同じ） | 0.22 |
| 並 | 25 以上 | ×0.88 | 0.32 |
| 鈍い | 25 未満 | ×0.7 | 0.42 |

- **減り方**: 武器を当てるたびに「技の威力の係数 × 系統の `wearPerMotion`」だけ減る。溜めや勢いの倍率は掛けない。空振りでは減らない。
  - 系統ごとの値: 断岳剣 1.6、太刀 1.6、護刃 1.5、長尖槍 1.4、大槌 1.3、双剣 1.2。**環弓には刃の状態が無い**（矢は減らさず、弾かれない）。
  - 目安（断岳剣でガルドロスを狩る時）: 縦斬り 25 回ほどで「並」、さらに 22 回ほどで「鈍い」。研がずに倒すと、当てる回数が 1 割ほど増える。
- 画面の名前は系統で変える: 刃（断岳剣・護刃・双剣・太刀）、打面（大槌）、穂先（長尖槍）。
- **力尽きてキャンプへ戻っても、刃の状態は戻らない。**

**弾かれ**

- 当てた部位の物理部位係数（斬 / 打。壊した部位は壊した後の値）が、いまの段階の境目より小さいと弾かれる。
- 弾かれても **ダメージは入る**。行動はその tick で止まり、26 tick の間よろけて動けない（0.3m 下がる）。同じ行動の残りの判定は出ない。**被弾ではない**ので、体力は減らず、無敵も付かない。
- 弾かれた時は、刃が 2 倍減る。
- ガルドロスでは: 鋭い時はどこも弾かれない / 並では背殻（斬 0.25）だけ / 鈍いと背殻・前脚・後脚（斬る武器）。大槌は、鈍い時に背殻と尾（打 0.4）だけ。壊した背殻（斬 0.45）は弾かれなくなる。

**研磨石**（`item.whetstone`）

- 使うと、刃の状態を最大まで戻す。120 tick の行動で、**96 tick 目に効果と消費が一緒に決まる**。それより前に攻撃を受けると、戻らず、減らない。102 tick 目からは回避で切り上げられる。
- **抜刀して、手に持った武器を研ぐ。** 納刀中に使うと、先に抜いてから続けて研ぐ。研ぎ終わっても抜刀のまま。
- 刃が最大の時は使えない（「まだ研がなくてよい」。減らない）。
- 持てる数 10。依頼「岩場の足音」の支給品は 3 個、訓練場では 10 個。環弓では持たない。
- 「納刀（抜刀）してから使う」の待ちは、道具を替えたら取り消す（替えた先の道具が勝手に使われないように）。

**見た目と音（仮）**

- 画面の左上の棒が、刃の状態。段階で色が変わり（鋭い = 青緑、並 = 黄、鈍い = 赤）、段階の名前も出る。段階が下がった時と弾かれた時は、文字で知らせる。
- 研ぐ動き（`common_item_whet_01`）: 片ひざを突き、ひざの前に渡した武器を、左手の石でなでる（3 往復）。左腕に盾を持つ護刃・長尖槍は、右手で支えるだけ。
- 弾かれた時は、白い火花と、のけぞる姿勢。**専用の動きと音はまだ無く**、のけぞりは怯みの姿勢を大きくしたもの、音は防御の音、研ぐ音は納刀の音、研ぎ上がりは溜めの音を流用している。

**大型の移動と休息（`roam`、`routes`）**

| 状態 | すること |
| --- | --- |
| stay（居る） | ふだんどおり戦う。気づいていない間は、エリアの中をゆっくり歩いては立ち止まる（速さ 0.55 倍、4〜9 秒立ち止まる、縁から 10m 内側）。居る時間は 90〜150 秒（seed で決まる） |
| leave（立ち去る） | 居る時間が過ぎ、技の途中でなければ、次のエリアへの出口へ**走る**（v0.20.0: 9m/s。弱っている時は 7.6m/s。どちらも、狩人の走る速さ 6.4m/s より速い。向きを変える速さは 4 倍で、大きく向きを変える間も 6 割の速さで弧を描いて走る。それまでは、ふだんの歩く速さの 1.25 倍・0.7 倍で、狩人が追いつけた）。**この間は、技を出さない**（攻撃は当たるし、怯みも罠も効く）。出口に着くと、行き先の `arriveLarge` へ移り、気づいていない状態に戻る |
| sleep（眠る） | 体力が 25% 以下になると、巣へ向かう（途中のエリアは 1 秒で通り抜ける）。巣に着くと寝床（エリアの中央）まで歩き、着いたら眠る。60 秒眠り、1 秒に最大体力の 0.4% ずつ、40% まで戻る。**攻撃されると起きて、気づく**。眠り終えると、また巡る |

- **巡る順**（ガルドロス）: 3 → 7 → 4 → 2 → 3 …。巣はエリア 10。道順は、大型の通れる出口だけをたどる（幅優先）。

- **巣で起こされた時**: 弱ったままなので、30 秒戦った後、その場でまた眠る。
- **出来事**: `area_change`、`monster_leave`、`monster_move`、`monster_sleep`、`monster_wake`、`monster_lost`。
- **状態の指紋**（`hash`）: 居るエリア、大型のエリア・状態・残り時間・巡る番号・ぶらつきの行き先・眠りを含める（フィールドの時だけ）。

**フィールドを使うか**

- simulation は、`SimOptions.field` が true で、依頼に `fieldId` がある時だけフィールドになる。指定しなければ、これまでの 1 つの狩場（依頼の `mapId`）で始まり、結果は v0.10.1 までと同じ。訓練場は、いつも 1 つの狩場。

**画面**

- 描くのは、居るエリアだけ（初めて入った時に作り、覚えておく）。別のエリアに居る大型は描かない。
- 出口には、壁の切れ目・門柱・踏み跡がある。近づいてそちらを向くと「この先: エリア 1（礫の坂）」と出る。
- エリアを移ると、画面が一瞬暗くなり、番号と名前が出る。
- 右上に、いま居るエリアと、標的の居るエリア（眠り・移動中の印つき）。その下に小さな地図（マス目に番号。現在地は青銅色の枠、標的は赤、眠っていれば青）。**標的の居場所は、いつも出る**（探す遊びは、まだ無い）。
- 種類ごとの見た目の違いは、地面の色（通り道は乾いた色、巣は青み）と、巣の晶の柱だけ。

| データ（`FieldAreaDef`） | 意味 |
| --- | --- |
| `shape` | 歩ける範囲の外周。[x, z] の点の列（1.6m ほどおき、面積が正の向き）。**当たりの正本**（`src/game/world.ts`）で、岩壁の形も、これに沿う（`src/render/arena.ts`） |

**商店**

| 道具 | 値段 | 狩りへ持ち出せる数（carryMax） |
| --- | --- | --- |
| 回復液 | 60 | 10 |
| 研磨石 | 40 | 10 |
| 鎮静玉 | 150 | 6（v0.12.0 で 4 → 6） |
| 拘束罠 | 300 | 2（v0.12.0 で 1 → 2） |

- 買う: 通貨が減り、道具が増える。1 つの道具は 99 個まで持っておける（`holdMax`）。足りない・売っていない・持てない時は、何も変わらない。
- 売る: 素材だけ。初級の素材 20〜40、中級 70〜90、上級 140〜180、極級 280〜360 通貨。道具は売れない。売った素材は戻らない。

**持ち込み（自分の道具を狩りへ持っていく）**

- 依頼へ出る時、持っている道具を、支給品に足して持っていく。**道具ごとに、支給品と合わせて carryMax まで**（回復液は 支給 5 + 自分 5、拘束罠は 1 + 1、鎮静玉は 3 + 3、研磨石は 3 + 7）。入りきらないぶんは、里に残る。選ぶ画面は無い。

**まだ無いもの**: 人（受付・店主・鍛冶）、道具を選んで持つ画面、道具箱、まとめ売り、訓練場への門、出発の門から狩場へ歩いて出る流れ、里の正式な建物。

**検査**（`validators.ts`）: 起動時に登録簿を検査する。依頼の標的（`targetMonsterId`）は、登録簿に無ければならない。歩ける狩場は、登録簿の狩場の案とつながっていなければならない。

**まだ無いもの**: 2 体が同時に出る狩り、幼体を何体も狩る依頼、超大型との戦い（どれも、登録簿に書けるだけ）。ガルドロス以外の体と動き。登録簿から、遊べる定義（体力・部位・技）を作る仕組み。図鑑の「狩った数」「見つけた印」。

### 22.2 技の動き（v0.21.0。D-087）

- **書く所**: `tools/monster_moves.py`（種ごとの関数。道具は `tools/monster_lib.py`）。`npm run monsters:gen` が `src/render/creaturePlans.ts` の `moves` へ書く。型は `src/render/creatureMoves.ts` の `MoveDef`。
- **鍵の姿勢**: 技データの 3 つの区間（構え `w` = 0〜攻撃の始まり、攻撃 `s`、後隙 `r`）の中の位置（0〜1）に、姿勢（体の高さ・前後・左右・傾き・ねじれ・背骨・首・頭・顎・尾・脚の組ごとの振り/曲げ/開き・飾り）を置き、間を緩急（`io`・`o`・`i`・`lin`）でつなぐ。始まりと終わりは、ふだんの姿勢（0）。左右のある値（横・ひねり・首と頭と尾の左右）は、技の側（左 = +1、右 = -1）を掛ける。
- **飾りの決まり**: 跳ぶ（hop）・震える（shake。構えだけ・攻撃だけ・全部）・小刻みな足（scurry）・水を掻く（paddle）・体をくねらせる（und）・体ごと回る（spin = 回数）・輪で転がる（roll。転がり終えた時に、ちょうど何周かして元の向きに戻るよう、回る量を合わせる）・並んだ物を前から順に（seq。嚢・帆）。
- **体の部位に付けた判定**（`bind`）: 判定の形（カプセル）を、体の印から印へ付ける。印は `sp:N`（背骨の点。小数で点の間）・`leg:組:側:関節`（`end` = 足先）・`own:名前:側`（動かす物の骨）・`tip:名前:側`（その物の、骨からいちばん遠い点）。側は S（技の側）・O・L・R・C。**`npm run monsters:bake`**（`monsters:gen` の最後に走る）が、Node の中で体を動かして（揺れのずれ 0）、2 tick ごとの印の位置から `public/data/tracks/<key>.json` の軌道を作り直す。判定は simulation の側のデータのまま（描画の値を戦闘に使わない）。軌道と動きがずれると、`npm run test` が落ちる。体に付けた判定は 173（大型 135・幼体 38）。
- **当たる**: どの技の、どの判定の区間も、正面の狩人に当たる（区間ごとに 1 つだけ残して試す。地面から届く高さの点を選ぶ）。AI が技を選ぶ距離は、その技の判定が届く距離を超えない。
- **大きく動く**: どの技も、技の中で、背骨の点か脚の先のどれかが、体の高さの 12% 以上動く（飾りだけが動く技にしない）。
- **吹き出し**（v0.21.0 で足したもの）: 体のまわり（`around`。内へ吸う・外へ吹く）・後ろ・前の 3 つの向きの、風・泥・音・灰・火花・氷・霧・毒。

### 22.3 技以外の動き（v0.21.0。D-087）

種ごとに `idle`（型は `src/render/creaturePlan.ts` の `IdlePlan`）を持つ。どれも見た目だけで、戦闘の計算に使わない。

| 場面 | 動き |
| --- | --- |
| 気付く前 | 餌を探す構え（頭を下げる・嗅ぐ）。首と頭が、個体ごとにずれた速さで、ゆっくり揺れる |
| 気付いた後 | 身構え（頭を上げ、飾りを少し立てる） |
| 弱った・怒った | 弱ると頭と尾が下がる。怒ると飾り（角膜・冠・嚢・帆・板）を立てる |
| 速く動く | 出ていく・逃げる時（動きの速さの 1.3 倍より速い）は、歩幅を広げ、走る構えへ |
| しぐさ | 止まって落ち着いている間、ときどき（1.8〜5.3 秒ごと）。気付く前だけ・気付いた後だけ・いつでも、の 3 つ。大型は 5〜7、幼体は 3〜4（合わせて 92）。例: セルヴァルクは角膜を弾く・振り返る・足踏み・頭を振る・風を嗅ぐ・尾を振る・伸び |
| 眠る・捕獲 | 種ごとの寝姿（四足は伏せ、鳥は座って頭を背へ、輪の虫は横に寝て丸まる、長胴はとぐろ） |
| 怯む | 種ごとの、のけぞり（叩かれた向きの揺れに足す） |
| 転倒 | 横に倒れる → もがく（脚をばたつかせる）→ 種ごとの起き上がり |
| 死ぬ | 膝を折る → 横に倒れる → 力が抜ける（2〜3 の鍵の姿勢を時間で） |
| 群れ（幼体） | 食む姿勢（`graze`） |

- **後から付いてくる動き**: 向きを変えると、尾は遅れて外へ振れ（ばねのように戻る）、首は曲がる側へ先に向く。
- **地面に横たわる**: 眠る・転倒・死の姿勢では、**体を支える所**（胴の筒と、袋・甲羅・嚢・胴に付いた塊）の下が、地面に着くように高さを合わせる（種と姿勢ごとに、その姿勢を置いて 1 回だけ測る）。地面へ潜った脚（鋏も）と、動かす飾り（翼・冠・帆など）は、付け根 → 膝 → 足首の順に回して、地面の上へ出す（骨ごとの形の端の点で測る）。細い飾り（鉤・ひれ）が少し刺さるのは許す。落ち着いた寝姿・死に姿では、この補正を 4 フレームに 1 回だけ解き、間は使い回す（群れが一緒に伏せても重くならないように）。
- **検査**（`tests/creature-motion.test.ts`）: 鍵の姿勢が有限で、始まりと終わりがふだんの姿勢へつながる。体の印が体の近くを指す。動きを種の間で使い回さない。技以外の動きの一揃いがある。眠る・転倒・死の姿勢で、体を支える所の下が地面の高さ（体の高さの -6%〜+5%）で、全体も深く潜らない。

### 22.4 形を原画に寄せる（v0.21.0。D-089）

- **体の太さ**: 手で書いた 13 点ほどの太さの間をつなぐ代わりに、原画の輪郭（背景と違う所）を、背骨に沿って細かく（区間ごとに 10 点）測る（`profile`）。脚も、脚の線に沿って輪郭の幅を測る（`prof`）。脚・翼・角膜などの付き物は、測る前に輪郭から除く。手で書いた値の 0.55〜1.6 倍に収める。
- **面の細かさ**: 背骨の輪は 18 点 → 28 点、輪の間は 0.09m → 0.05m。脚は 10 点 → 16 点、0.07m → 0.04m。
- **足先**: 原画の足の形から、蹄（2 つに割れる。セルヴァルク）・丸い指と爪（ヌメラドン・ボルナケル・ラズメル・ヴェルガイト・コルドピル）・鳥の足と鉤爪（アシュレイア・ルミスカ）。
- **目**: 濡れて光る、別の材質。
- **肌**: 原画の濃淡を、面の凹凸にも使う（しわ・鱗・羽の筋に、光の差が付く）。横から貼った絵が伸びる面（前・後ろ・上・下を向いた面）には、原画から作った肌の細かな模様（`<key>_skin_v1.webp`、256px、端がつながる）を 3 方向から貼って掛ける（`npm run monsters:art`）。
- **ひれ足**（キリサーヴ・ヒナサルヴ）: 腹の 2 対のひれを、動かせる骨に（`own:fin0`・`fin1`、`ch: 'fin'`）。歩く周期で前後に漕ぎ（前と後ろ、左と右で逆）、水を掻く技（paddle）では速く漕ぐ。姿勢の `fin` で開く（+）・畳む（-。滑る技では畳む）。前のひれの下の縁を、地面の線まで上げた（原画の線のままだと、立っていても地面へ刺さっていた）。
- **幼体の器官の欠落を直した**: チルミカナの燐節（2 つ残すはず）と、ユルテピカの紡糸管（2 つ残すはず）が、生成器の不具合（写す前の物を `id()` で選んでいた）で全部落ちていた。同じ部位の中の番号で選ぶようにした（ChatGPT の設計提案、Pull Request #6 の指摘）。
- **仮のまま**: 原画は 1 枚（真横）だけなので、上・下・正面からの形は推し量り。正式モデル（4 方向の設定図から作るもの）は無い。**口は開かない**（顎の骨と、口の中の形が無い。姿勢の `jaw` は使われていない）。

- **体**: 親の原画の形を、尾を縮め・頭を大きく（1.25〜1.35 倍）・飾り（角膜・帆・皿・羽袋）を小さくして、登録簿の全長の 0.68 倍にした（`Juv`）。コルドピルだけは、ガルドロスの設定図（右側面）から形を書いた（`GALDROS_PLAN`。遊べるガルドロス自身は、これまでの専用の仮モデル）。ヒナサルヴは、親に無い短い脚 4 本を足した。コハルギスは、右の大鋏を左と同じ小鋏にした。
- **絵**: 親の絵をそのまま貼り、色を少し明るく・淡くする（`plan.look`。幼体の原画は取り込んでいない）。ガルドロスの設定図の右側面を `npm run monsters:art` で絵にした（`galdros_side_v1.webp`）。
- **体力 140〜300**（親の 1/4 より小さい）。肉質は柔らかく（0.55〜0.9）、怯みやすい（蓄積 30〜60）。部位は登録簿の 2 つ + 頭・胴・脚。2 つの部位は壊せる（素材は出ない）。**捕獲はできない**（`captureAllowed: false`）。罠は幼体では作動せず、鎮静玉は幼体に当たらない。
- **攻撃は弱い**（4〜12。親の半分以下）。判定は地面から 1.2m より低く、体から 4m 以内。
- **素材**: 登録簿の 2〜3 つ。倒すと、その場で 1 回剥ぎ取れる。買い取りあり（10〜24 通貨）。

**群れの動き**（`src/game/herd.ts`。データは `MonsterDef.herd`）

| 気分 | すること |
| --- | --- |
| graze（食む） | 群れの居場所の中心のまわりに、1 頭ずつの場所（ひまわりの種の並び。間は spacing）がある。そこへゆっくり歩いて（速さ 0.3 倍）、立ち止まって頭を下げて食べる（2.5〜7 秒）。離れすぎたら急いで戻る。中心は 15〜35 秒ごとに 3〜8m 動く。**親が同じエリアで落ち着いていれば、親から 9m の所へ寄る** |
| rest（休む） | 1〜2 分ごとに、群れで 15〜30 秒伏せる。気づく距離が 0.6 倍になる |
| alert（見る） | 狩人が気づく距離に入ると、顔を上げて狩人の方を向き、止まる。狩人が離れて 5 秒たつと戻る |
| flee（逃げる） | 狩人が逃げ出す距離に入ると、狩人から離れる向きへ走る（速さは種ごと 1.5〜1.8 倍。**狩人の走る速さ 6.4m/s より遅い**）。群れの真ん中へ寄りながら逃げる（コハルギスは、1 頭ずつ違う向きへ散る）。壁際では、壁に沿って狩人から遠い側へ。**5〜8 秒走ると息が上がり、2.5 秒止まる**（その間は逃げない） |
| fight（反撃） | 攻撃されると、種ごとの割合で向き直って反撃する（3〜8 秒。この間だけ技を出す）。そうでなければ逃げる。息が上がっている時に攻撃されたら、必ず反撃する。**追い詰められる**（狩人が 5m の内に居て、0.7 秒ほとんど進めない）と、反撃する |
| hide（隠れる） | **親が同じエリアで戦っている間**（狩人に気づいて起きている）、群れの真ん中に近い岩の、親から見て裏側へ寄る。岩が無ければ、親から 20m 離れる |
| travel（移る） | 住みかが 2 つ以上ある群れは、3〜5 分ごとに、群れで次のエリアへ歩いて移る（どの出口も使う。途中のエリアも歩いて通る）。1 分たっても着かない仲間は、そのまま移す |

- **知らせ**: 1 頭が気づく・逃げ出すと、仲間へ知らせる。仲間は、0.1 秒 + 1m ごとに 0.025 秒 + ばらつき（〜0.22 秒）遅れて、顔を上げる・逃げ出す（近い仲間ほど早い）。逃げる知らせは、顔を上げているだけの仲間にも届く。
- **静まる**: 騒ぎ（見る・逃げる・反撃）が終わると、逃げた先が新しい居場所になる（もとの場所へは戻らない）。
- **親との関わり**: 幼体が攻撃されると、同じエリアに居る親（`parentId`）が気づく（眠っていれば起きる）。
- **群れの乱数は群れごと**（`SeededRng`。シミュレーションの乱数とは別）。幼体どうし・幼体と大型が重なる時は、**幼体だけを押し出す**。だから、群れが居ても、大型の動き（位置・乱数の並び）は変わらない（テストで確かめている）。幼体は狩人の体を避けて歩く（すり抜けない）。
- **状態の指紋**（`hash`）: 群れの乱数・中心・休み・移る時間、1 頭ずつの気分・時間・知らせ・行き先を含める。

**群れの依頼**（`QuestDef.targets`）

- `targets: [{ monsterId, count }]` の頭数を、種ごとに討伐すると達成（`kind: slay`。捕獲は無い）。同じ種なら、標的の群れでなくても数える。`targetMonsterId` は 1 つ目の種。
- 依頼 9 件（どれも初級、最初から受けられる）: 8 種に 1 件ずつ（頭数 2〜4。群れの少ない方以下）と、「盆地の若い群れ」（コルドピル 2 頭とパルセイト 3 頭）。制限時間 10 分（フィールドでは 20 分）。支給品は回復液 3・研磨石 2。報酬は 360〜520 通貨 + 素材 1。帰還まで 30 秒。
- **標的の群れ**: フィールドでは、その種の住みかの最初のエリアに、依頼の頭数より少なくない群れが出る。1 つの狩場（`?hunt=arena`）では、依頼の位置（4, 15）のまわり。
- **剥ぎ取り**: 倒れた幼体は、その場で 1 回剥ぎ取れる（`carves` の `body:<個体の id>`）。**狩りの途中は、納刀している時だけ**（抜刀中の攻撃ボタンは、攻撃のまま）。達成した後は、抜刀していても剥ぎ取れる。手に入れた素材の入手元は `carve:<種の id>`。帰還を早める判断（剥ぎ取りを使い切った）は、標的のぶんだけを数える（周りの幼体のぶんは数えない）。
- 失敗・リタイアでは、剥ぎ取った素材も出ない（これまでどおり）。

**画面**

- 幼体の体は、居るエリアへ入った時に作る（同じ種の面の形は 1 回だけ作って、群れで分け合う。骨は 1 頭ずつ）。別のエリアの群れは描かない。
- 姿勢: 食んでいる時は頭を下げて口を動かす（首の長い種ほど深く）。見ている時は顔を上げ、角膜・帆を立てる。休む時は伏せる。逃げる時は速い足取り。息が上がると呼吸が速い。
- 群れが騒いだ時: 足元に小さな土ぼこりと、体つきに合った短い鳴き声（成体の声を小さく流用）。幼体の技の音は小さい。
- HUD: 目標に「コルドピル 3 頭の討伐（あと 2 頭）」。倒すと「コルドピルを討伐（あと 2 頭）」。右上の地図は、まだ倒していない標的の居るエリアに印。周りの幼体を倒すと「〜を倒した（剥ぎ取れる）」。幼体の転倒は知らせない。
- 拠点の依頼の欄: 段階ごとに、1 体の標的の依頼の後に「幼体の群れの依頼」の見出しと、9 件。目標は「コルドピル 3 頭の討伐」。
- 結果: 「討伐　コルドピル 3 頭（目標 3）」。素材の入手元は「コルドピルの剥ぎ取り」。
- **ロックオン**: 群れの依頼では、同じエリアの、いちばん近い、まだ倒していない標的へ。ロックした相手が倒れたら、次に近い標的へ移る（居なければ外れる）。カメラの「標的の方へ向く」も同じ相手。
