============================================================
0. 引き継ぎ
============================================================

プロジェクト：霧境の狩人 - VEILBOUND HUNTERS（横画面、三人称 3D の狩猟アクション。ブラウザで遊ぶ）
現在の版　　：v0.55.0
遊べる場所　：https://kamamon.github.io/Kari/

利用者の指示（2026-11-26 20:46）：
  「ハンターのモーションも今のモーションを一旦保留して2Gのモーションを採用して」
そのあとの確認で、範囲は「全部」（移動・走り・回避・抜刀納刀・道具・剥ぎ取り・採集・登攀などの共通の動きと、
7 武器の全部の攻撃）、手本は「ChatGPT にも頼む」と決まりました。

これまで（v0.40.0〜v0.55.0）、技の組み立て（どのボタンで何が出るか・連係・溜め・強化の状態）は 2G に合わせてきましたが、
体の動き（構え・振りかぶり・踏み込み・足の運び）は、Claude が考えた Kari の形でした。
これからは、体の動きも、PSP 日本版『モンスターハンターポータブル 2nd G』の動きを手本にします。
いまの動きは消さずに残し（切り替えられるようにします）、新しい動きを標準にします。

Claude は動画を見られません。そこで、あなたに、2G の映像から、動きごとの「観察票」を作ってもらいたいです。
Claude は、その観察票を手本に、Kari の体（骨・寸法・武器の大きさは Kari のまま）でキー姿勢を作り直します。


============================================================
1. 決まり（大事）
============================================================

・原作の動きのデータ・モデル・画面写真・動画を、リポジトリへ置かないでください。
  置いてよいのは、資料の URL と時刻、見て分かったことの文章と数字、あなたが描いた図（棒人間など）だけです。
・名前は Kari のままにします（技の表示名は変えない）。観察票には、2G での技の名前を「どの技を見たか」の印として書いて構いません。
・見えないこと・測れないことは、推測で埋めず「未測定」「不明」と書いてください。
  特に、時間（フレーム数）は、入力の分かる連続したプレイ映像から測れた時だけ書いてください。宣伝映像の編集された場面からは書かない。
・数値は「目で見て、だいたい」でよいです。その場合は「目測」と書いてください。
・日本版 PSP を優先し、無ければ海外版（MHFU）でも構いません（どちらを見たか書く）。MHP3rd・MH3・2G for iOS は使わない。

3. 観察票の形（JSON）
============================================================

座標は Kari のハンターの体から見た向きで書きます（Claude がそのまま使えるように）:
  ・前 = +Z、左 = +X、上 = +Y（「右」は −X）。長さは m、角度は度。
  ・体の高さの目安: 身長 1.75m、股関節 0.92m、肩 1.45m。
  ・腰（骨盤）・胸の向き: yaw は + が左回り（左を向く）、pitch は + が前かがみ、roll は + が右へ傾く。
  ・武器: 握り（右手）の位置と、握りから刃先へ向かう向き（単位ベクトル）、刃の向く方（刃のある武器だけ）。
    大剣・太刀・ハンマー・ランスは両手（左手が柄のどこを持つか書く）、片手剣は左手に盾、双剣は左手にもう 1 本、弓は左手に弓。

{
  "kariActionId": "player.heavy_blade.overhead",
  "observed2gMove": "縦斬り（2G での呼び名）",
  "source": [{ "title": "…", "url": "…", "edition": "PSP 日本版 / MHFU", "from": "00:12.3", "to": "00:14.0", "note": "連続プレイ・HUD あり・通常速度 など" }],
  "startState": "抜刀・立ち・正面の敵",
  "keys": [
    {
      "key": "K0",                      // K0 開始 / K1 予備動作（振りかぶり・溜め）/ K2 接触（当たる瞬間）/ K3 振り終わり / K4 構えへ戻る。連撃は K2a・K2b のように
      "time": "未測定 または 0.40 秒（目測）",
      "support": "左足 / 右足 / 両足 / 空中",
      "feet": { "L": [x, z, つま先の向き], "R": [x, z, つま先の向き] },   // 体の真下を原点にした足首の位置（m）とつま先の向き（度。+ が左向き）。目測でよい
      "pelvis": { "height": 0.85, "yaw": -20, "pitch": 10, "roll": 0 },
      "chest": { "yaw": -35, "pitch": 15, "roll": 0 },
      "head": "どこを見ているか",
      "weapon": { "grip": [x, y, z], "tip": [x, y, z], "edge": "刃の向く方（例: 前下）", "leftHand": "柄の握りから 0.25m 下を持つ など" },
      "root": "この時までに体がどれだけ動いたか（例: 前へ 0.5m）",
      "notes": "特徴（例: 剣を右肩に担いでから、左足を大きく踏み出す）"
    }
  ],
  "weaponPath": "刃先の通り道（例: 右肩の後ろ → 頭上 → 体の正面の地面）",
  "rootMotion": "全体で、前後左右へどれだけ動くか（目測）",
  "contactEvents": "足が地面を離れる・着く順番",
  "differencesFromKari": "いまの Kari の動き（tools/weapons/*.mjs など）と違う所。分かる範囲で",
  "unknowns": ["読めなかったこと"]
}

4. 共通の動き（武器を問わないもの・武器ごとに違うもの）
============================================================

Kari の ID または場所 → 見てほしい 2G の動き

・構え（抜刀して立っている時）: 武器ごとに 7 つ。tools/weapons/*.mjs の stances.idle、断岳剣は src/render/poses.ts
・歩き・走り（納刀）、疾走（スタミナを使う走り）: src/render/hunterAnim.ts（いまは手で作った歩き）
・抜刀して歩く（武器ごと）
・回避: player.common.roll（納刀の前転）。抜刀中の回避（武器ごと。前後左右）。長尖槍は player.long_lance.hop（跳び）
・抜刀・納刀: 武器ごとの draw・sheathe（player.<武器>.draw / sheathe）
・抜刀攻撃: 武器ごとの draw_slash / draw_cut / draw_cross / draw_smash / lunge
・道具: player.common.drink（回復液を飲む。飲み終わりの決め姿勢まで）、whet（研磨。しゃがむ）、throw_orb（玉を投げる）、set_trap（罠を置く）
・剥ぎ取り・採集・採掘・納品: player.common.carve / gather / mine / deliver
・被弾: 怯み・吹き飛ばされて倒れる・起き上がる・力尽きる（src/render/poses.ts）
・登攀（蔦の壁）・段差の乗り越え・飛び降りと着地（src/render/poses.ts の climb / vault / land）
・防御（大剣・片手剣・ランス）: 構える・受ける・押し返される


============================================================
5. 武器の技（Kari の ID → 見てほしい 2G の技）
============================================================

断岳剣（大剣）: overhead=縦斬り、side_sweep=薙ぎ払い（2026-11-26 に直した。最初は「横殴り」と書き間違えていた）、upswing=斬り上げ、upswing_low=（縦斬りの後の）斬り上げ、
                draw_slash=抜刀斬り、溜め斬り（overhead・draw_slash を押し続けた時の溜めの姿勢）、guard=武器で受ける
護刃（片手剣）: slash1=斬り下ろし、side=横斬り、slash2=横斬り（返し）、return=斬り返し、round=回転斬り、bash=盾攻撃、
                guard_slash=ガード中の攻撃、lunge=突進斬り（抜刀攻撃）、ガード中の道具
双剣: slash1・slash2・cross=通常の連撃、round=回転斬り、stab=突き（同時押し）、demon_on / demon_off=鬼人化の開始・解除、
      flurry=乱舞、draw_cross=抜刀攻撃。鬼人化の間の構え・歩き・回避も
大槌（ハンマー）: smash=縦振り、smash2=縦振り（2）、upswing=アッパー、swing=横振り、charge=溜め（溜め歩きの姿勢も）、
                  charge_smash=溜め 1、charge_upswing=溜め 2、pound=溜め 3（止まって）、spin=回転攻撃（溜め 3・動きながら）、draw_smash=抜刀攻撃
太刀: kesa=縦斬り、rise=斬り上げ、thrust=突き、back_cut=斬り下がり、spirit1〜3=気刃斬り 1〜3、round=気刃大回転斬り、draw_cut=抜刀攻撃
長尖槍（ランス）: thrust1〜3=中段突き、high=上段突き、guard_thrust=ガード突き、lunge=突進（続けて走る突進も）、hop=ステップ（後ろ・横）、
                  counter / counter_thrust=（Kari にだけある受け返し。2G には無いので、代わりに何を作るべきかの意見でよい）
環弓（弓）: shot=溜め撃ち（引き絞って歩く姿勢も）、spread=（いまの散らし撃ち。2G の弓の撃ち方の種類と、近接攻撃・ビンの付け方の動き）
