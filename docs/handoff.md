## Blender の使い方（作業環境）

- `pip install bpy`（Blender 5.3 を Python の部品として入れる。約 430MB。画面は無く、スクリプトで動かす）
- ガルドロスの形を変えたら、区画の並び → 皮と岩の絵 → 陰 の順に焼き直す:
  `npm run build && node tools/export-galdros-mesh.mjs`（「並びが変わった」と出たら、もう一度この 2 つを実行）→ `python3 tools/art/galdros_skin.py && python3 tools/art/galdros_bake.py` → `python3 tools/blender/bake_ao.py` → `npm run build`
