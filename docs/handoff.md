## Blender の使い方（作業環境）

- `pip install bpy`（Blender 5.3 を Python の部品として入れる。約 430MB。画面は無く、スクリプトで動かす）
- ガルドロスの形を変えたら陰を焼き直す: `npm run build && node tools/export-galdros-mesh.mjs && python3 tools/blender/bake_ao.py`
- 次に Blender でやること（未着手）: 正式モデル（GLB）の作成、固有の UV と焼いた画像、キーを打った動作クリップの書き出し。ゲーム側で GLB のクリップを再生する経路は、素材ビューアにだけある。
