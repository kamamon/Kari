## 次の一作業

**M2: ガルドロスを狩る（設計書 COPY 05）。**
四足の仮モデルで、前脚叩き・直線突進・半円尾払い・鉱殻崩落を「予備動作 → 攻撃 → 後隙」として実装。本体 HP・部位耐久・切断・怯み・怒り・状態異常を分け、頭/背殻の破壊、尾切断、死亡、捕獲。受注 → 出発 → 戦闘 → 討伐/捕獲 → 素材 → 帰還を 1 回完走できるようにする。

着手時の足場:
- モンスターの技は訓練標的と同じ形式（`public/data/actions/`、`tracks/`）で書ける。移動を伴う技（突進）は `rootMotion.curveId` が既に使える。
- 足りないもの: 行動選択の条件（後方・側面・壁・体力・怒り）、部位ごとの怯み蓄積、切断属性の蓄積と尾の判定の付け外し、クエストの状態遷移、複数の hitWindow を持つ技。
- 実機チェックで操作や数値への指摘が出たら、M2 より先に直す（「完成条件を満たした段階だけ次へ進める」）。
