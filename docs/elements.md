# 属性の方針（docs/elements.md）

**まだ実装していない。** 利用者の指示（2026-11-24）と、こちらから出して **利用者が承認した案**（同日。「追加属性などもそれで良い」。D-063）の記録。
実装する時は、ここの内容を `docs/spec.md` へ移す。経緯は `docs/decisions.md` の D-062・D-063。

**まだ決まっていないこと**: 火の持ち主（設計書の 12 種に火の獣がいない。灰帷鳥アシュレイアを火にするか、1 種足すか）。属性ごとの持ち主は、どれも候補のまま。複合属性の名前。

## 1. 利用者が決めたこと

1. **ガルドロスは無属性。弱点は火。雷には強い。**
2. **ガルドロスの防具（岩殻〜輝殻）も同じ**: 火に弱く、雷に強い。
3. これ以降のモンスターは、属性を持つ: 火・雷・氷・麻痺・毒 など（ほかの属性は 2 章の案から選ぶ）。
4. 武器には、属性が付くものと付かないものがある。**付かない武器は、その分、攻撃力か会心率が高い。**
5. **強いモンスターは、複合属性を持つことがある。** 2 つの属性から新しい属性になり、属性値が高い。その素材の武器も非常に強い。
6. **複合属性は、相手の弱点が入っていないと、逆に効きづらい。**
7. 防具は、素材になったモンスターの個性が見た目に出るようにする（絵の依頼 7 `docs/chatgpt-request-7.txt` の 1 章）。

実装の時期は「後で良い」（利用者）。

## 2. 属性（決定: 属性 6 つ、状態異常 4 つ）

設計書の大型 12 種（p.16）と、世界設定「霧と晶脈の辺境」（p.15）に合わせた。持ち主は候補で、決まっていない。

**ダメージの属性**

| 属性 | 出どころ | 持ち主の候補（設計書の 12 種） |
| --- | --- | --- |
| 火 | 利用者の指定 | 12 種に火の獣がいない。灰帷鳥アシュレイア（灰幕）を火にするか、新しく 1 種を足す |
| 雷 | 利用者の指定 | 燐尾鳥ルミスカ（発光する尾節・予告照射） |
| 氷 | 利用者の指定 | 氷帆蛇キリサーヴ |
| 水 | 案 | 泥冠獣ヌメラドン（泥玉・腹滑り） |
| 風 | 案 | 帆角獣セルヴァルク（横跳び・風圧） |
| 霧 | 案（この作品の看板になる属性） | 絹霧蟲ヴェリト、霧灯獣ヴェルガイト |

**状態異常**（設計書 p.10 は 毒・麻痺・睡眠・気絶 の 4 つ）

| 状態 | 出どころ | 持ち主の候補 |
| --- | --- | --- |
| 毒 | 利用者の指定・設計書 | 絹霧蟲ヴェリト |
| 麻痺 | 利用者の指定・設計書 | 鉤輪蟲テンガロ |
| 睡眠 | 設計書 | 未定 |

**決定**: ダメージの属性は 火・雷・氷・水・風・霧 の 6 つ、状態異常は 毒・麻痺・睡眠・気絶 の 4 つ。

入れないもの（役目が重なる。後で足すことはできる）: 音（鐘嚢獣。気絶と役目が重なる）、光（燐尾鳥。雷と重なる）、晶（晶脈そのもの。終盤用）、灰（相手の狙いを甘くする状態）、糸（動きを鈍らせる状態）。

## 3. 複合属性（決定。名前だけは案）

- 2 つの属性の組に、名前を 1 つ付ける。例（名前は案）: 火 + 雷 = **灼雷**、氷 + 風 = **凍嵐**、霧 + 氷 = **霧氷**。
- 属性値は、同じ段の単属性の武器の **1.5 倍**。
- 効き方: 相手の部位の係数は、2 つの属性のうち **高い方** を使う。ただし、**2 つのどちらも相手の弱点でない時は半分**。
- 「弱点」は、モンスターのデータに印を付ける（係数がいちばん高い属性、とはしない。ガルドロスのように「無属性で、弱点は火」と書けるようにする）。
- 複合属性を持つのは、上の段階（上級・極級）のモンスターと、その素材の武器だけにする。

## 4. 無属性の武器（決定）

- 属性値 0 の代わりに、攻撃力が高い系列と、会心率が高い系列を作る。
- ガルドロスの武器（岩殻〜輝殻）は「攻撃力が高い無属性」の系列。いまの数値のままでよい。

## 5. いまのデータとの差（実装する時に足すもの）

| 場所 | いま | 足すもの |
| --- | --- | --- |
| モンスターの部位（`monsters/*.json`） | `elementZone` が 1 つの数（どの属性にも同じ） | 属性ごとの係数と、弱点・耐性の印。ガルドロスは 火が高く、雷が低い |
| 武器（`weapons.json`） | `element: { type: "none", value: 0 }`、`affinity: 0` | 属性の種類の一覧、複合属性、無属性の系列の上乗せ |
| 防具（`armor.json`） | 防御力だけ | 属性ごとの耐性。ガルドロスの防具は 火が負、雷が正 |
| モンスターの攻撃（`actions/*.json`） | 物理だけ | 属性つきの攻撃と、防具の耐性での軽減 |
| 状態異常 | 無い（設計書 p.10: 閾値・持続・耐性上昇・解除条件） | ためる値、効果、ハンター側の状態異常と解除の道具 |

ダメージの式（設計書 p.10、`docs/spec.md`）の「属性 = 属性値 × 技属性倍率 × 属性部位係数」は、すでに計算へ入っている。
