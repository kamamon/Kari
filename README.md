# 霧境の狩人 - VEILBOUND HUNTERS

ブラウザで動く、横画面・三人称 3D のオリジナル狩猟アクション。
敵の予備動作を読み、間合いを取り、重い一撃を差し込む狩猟を目指して制作中です。
モンスター・武器・人物・世界・コードはすべて本作のための新規制作です。

- 遊ぶ: **https://kamamon.github.io/Kari/**
- iPhone で画面を広く使う: Safari の共有 →「ホーム画面に追加」。できたアイコンから開くと、URL の欄が出ません（設定は Safari とは別に保存されます）
- 素材ビューア: https://kamamon.github.io/Kari/viewer.html
- 設計書: [docs/source/VEILBOUND_HUNTERS_design_v1.0.pdf](docs/source/VEILBOUND_HUNTERS_design_v1.0.pdf)
- ChatGPT の追加制作計画 v1（2026-11-23）: 原本は [docs/source/chatgpt-plan-v1/](docs/source/chatgpt-plan-v1/)。いまの実装との突き合わせと採否は [docs/plan-review-v1.md](docs/plan-review-v1.md)。次の目標は「受注 → 狩猟 → 報酬 → 帰還 → 強化 1 件 → 再読込後の復元」
- 武器種は 7 系統（大剣・短剣と盾・ランス・弓・大槌・双剣・太刀）: [docs/weapons.md](docs/weapons.md)。拠点の画面で持ち替えられる（強さは仮）。v0.5.0 で大鎌（旋鎌）をやめ、大槌・双剣・太刀を足した。**この 3 つは設定図がまだ無く、見た目は単色の仮の形**。断岳剣以外の 6 系統の体の動きは、人にできる動きとして組んである（足が地面に付いたまま踏み込む・腰から回す・盾は腕に固定）。形の一覧は [素材ビューアの「武器」](https://kamamon.github.io/Kari/viewer.html?subject=weapons)

設計書: 第 1 版 [docs/source/VEILBOUND_HUNTERS_design_v1.0.pdf](docs/source/VEILBOUND_HUNTERS_design_v1.0.pdf)、第 2 版 [docs/source/VEILBOUND_HUNTERS_design_v2.0.pdf](docs/source/VEILBOUND_HUNTERS_design_v2.0.pdf)（2026-11-24。いまの実装と決定を反映）。

依頼は野営地から始まります。出口（壁の切れ目と門柱）へ入ると次のエリアへ移ります。標的の居るエリアは、右上の地図に赤で出ます（眠っている時は青）。アドレスに `?hunt=arena` を付けると、エリアに分ける前の 1 つの狩場で始まります。`?hub=menu` を付けると、里を歩かず、これまでの一覧の画面で始まります。

依頼では回復液 5・拘束罠 1・鎮静玉 3 が支給されます。受けるダメージの倍率は 1.0 へ戻しました（難しさは、人が遊んで確かめてはいません）。

何を確認済みで何が未確認かは [docs/tests.md](docs/tests.md)、次にやることは [docs/handoff.md](docs/handoff.md) にあります。

## 操作

| 行動 | タッチ | PC | ゲームパッド |
| --- | --- | --- | --- |
| 移動 / 疾走 | 左スティック / 疾走 | WASD / Shift | 左スティック / LB |
| 視点 / 正面復帰 | 空いた所をドラッグ / 正面 | 中ボタンドラッグ・矢印キー / F | 右スティック / 押込み |
| 主攻撃 / 副攻撃 | 斬る / 薙ぐ | 左クリック / 右クリック | X(□) / Y(△) |
| 回避 / 防御 | 回避 / 防御 | Space / Ctrl または C | A(×) / RB |
| 抜刀・納刀 | 抜刀 | R | B(○) |
| メニュー / 検証表示 | ☰ / 検証 | Esc / F3 | Start / - |

- 縦斬りは押してから当たるまで約 0.4 秒、全体で 1.2 秒。終わり際（0.97 秒以降）だけ回避へ繋がります。
- 主攻撃を押し続けると溜め（3 段階）。離すと振り下ろします。
- 防御は抜刀中に正面だけ。回避はスタミナ 25、出始めの短い間だけ無敵です。
- メニューの「設定」で、感度・反転・左利き配置・ボタンの大きさ/濃さ/位置・描画の軽さ・音量を変えられます。
- ガルドロスの技: 前脚を持ち上げたら叩きつけ（横か後ろへ）、頭を下げて地面を掻いたら突進（横へ走る）、腰をひねったら尾払い（離れるか防御）、尾を高く上げて後ろの地面を叩いたら落石（打ち上がった岩が、地面の輪へ落ちてくる。輪の外へ。尾のそばにも居ない）。首を引いたら噛みつき、体を傾けたら横への体当たり、沈み込んだらのしかかり、前脚で地面を掻いて岩が飛んだら一列の落石（横へ）。脚を斬り続けると転倒します。
- 依頼をやめる時は、メニューの「依頼」→「リタイアする」。

## 開発

Node.js 22 以上。

```bash
npm ci
npm run dev        # 開発サーバー
npm run check      # 型検査 + 自動テスト + 本番ビルド
npm run preview    # 本番ビルドをローカルで確認
npm run smoke      # 本番ビルドをヘッドレス Chrome で操作する検査（要 Chrome）
```

| 場所 | 中身 |
| --- | --- |
| `src/game/` | 60Hz 固定の simulation（プレイヤー状態機械・モンスター・命中判定・ダメージ式・依頼の進行）。DOM と Three.js に依存しない |
| `src/input/` | タッチ・キーボード/マウス・ゲームパッド → 共通の入力 |
| `src/render/` | 仮モデル・仮アニメーション・カメラ・エフェクト・検証表示 |
| `src/ui/` `src/save/` `src/core/` | HUD とメニュー・拠点 / 保存（持ち物・装備・進行）と設定 / 時計・乱数・音・読み込み |
| `public/data/` | 技・軌道・武器・モンスター・依頼・マップのデータ（JSON、読み込み時に検証） |
| `docs/` | 仕様・決定の記録・素材台帳・アニメーション規格・引き継ぎ・試験・ChatGPT への依頼文 |
| `art-source/` | 原画などの編集原本（配信物には含めない） |
| `tools/` `tests/` | 検査スクリプト、Blender 用のスクリプト（`tools/blender/`）/ 自動テスト |

## 公開（GitHub Pages）

ビルドした結果を `gh-pages` ブランチへ置き、GitHub Pages がそれを配信します。

1. 最初の 1 回だけ: GitHub の **Settings → Pages → Build and deployment** で、Source を **「Deploy from a branch」**、Branch を **「gh-pages」** と **「/ (root)」** にして Save。
2. 以後は main へ push するたびに、Actions（Build and publish）が型検査・テスト・ビルドを行って `gh-pages` を更新します。手元から行う場合は `npm run publish:pages`。
3. https://kamamon.github.io/Kari/ を開く。起動画面とメニュー「検証」にビルド番号が出ます。

main ブランチをそのまま配信すると、ビルド前のページが表示されてゲームは始まりません（その場合は画面に設定の案内が出ます）。

## 制作の分担

- **Claude**: コード・データ接続・判定・再生・検証・配信設定（このリポジトリ）
- **ChatGPT**: 世界観・画像（設定図・アイコン・環境）・動作の演出設計・見た目のレビュー → 依頼文は [docs/chatgpt-requests.md](docs/chatgpt-requests.md)
- **Blender**: 正式モデル・骨格・動作の仕上げ
- **ユーザー**: 実機で操作して最終判断
