## 何を合わせたか

最新mainの97変更ファイルと、今回の差し替え対象21ファイルの共通部分は **`src/render/view.ts` だけ**。最新のモンスター描画追加は、ハンターの変更と別の位置だった。旧統合パッチはv0.21へ `git apply --check` / `git apply` とも成功し、手動の競合解消は不要だった。

統合済みviewとv0.20提案viewの差分は、差分ヘッダと行番号を除くと、upstreamのv0.20→v0.21のview差分2箇所と完全一致した。**18種類の追加VFXと `around` の吹き出し分岐をすべて保持**している。別担当の読み取りレビューでも同じ結果を確認した。

21ファイルの変更前・変更後ハッシュで、元のパッケージと違うのはviewだけ。残る20ファイルは同一で、ハンターのモーション・攻撃力設計は変わっていない。旧版のview全文を最新mainへコピーするとモンスター側の追加を消すので、この追補の統合パッチを使う。

## 最新基点への適用

このinboxのあるリポジトリのルートから始める。元のv0.20向けパッチと二重には適用しない。

```sh
git worktree add ../Kari-motion-review-v021 --detach 9a5443ab1ac813512deac03422ee996f57f8a900
python3 chatgpt-inbox/motion-combat-20261125/implementation/current-main/apply-proposal.py --repo ../Kari-motion-review-v021
python3 chatgpt-inbox/motion-combat-20261125/implementation/current-main/apply-proposal.py --repo ../Kari-motion-review-v021 --apply
cd ../Kari-motion-review-v021
npm ci
node --experimental-strip-types --no-warnings tools/gen-weapons.mjs --strict
npm run check
```

`--apply` がなければ読み取り確認のみ。戻す確認は `--reverse`、戻す実行は `--reverse --apply`。いずれも対象ファイルのハッシュが一致する場合に限る。さらにmainが進んだときは、不一致を無視して上書きせず、新しい差分を確認する。

v0.21の変更では `src/game/`、`src/core/`、`src/data/`、全7武器のプレイヤー側データ、ガルドロスのゲーム用データは変わっていない。元の制御DPS・行動時間・軌道測定の前提を維持している。この追補で42単独行動と37反復を別途測り直したという意味ではない。
