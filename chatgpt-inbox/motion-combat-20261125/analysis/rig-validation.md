# 骨格・モーションの独立検証

基点: `1d8e084d0d16fe77c376570f9542dd3c54fb5332` / v0.20.0。確認日: 2026-11-25（日本時間）。対象は、この納品の差し替えコードを適用した一時的な検証用コピー。最終確認した 4 ソースの SHA256 は `rig-validation.json` に記録した。

最終スナップショットで再確認済み。`playerRenderTick` によるプレイヤーのヒットストップ表示時刻の修正と、弓の `shoot.tick` に対する接触窓の追加が入った最後の `hunterAnim.ts` / `view.ts` を検証用コピーへ同期し、以下の独立テスト 3 件を同じ条件で再実行して合格した。811 姿勢・36 旋回ケースの数値は前回と同じ。今回の 3 件は骨格・実メッシュ・旋回の検査であり、ヒットストップ・溜め・弓の発射イベント自体の専用 assertion は `implementation/motion/tests/motion-replacement.test.ts` にあり、別の実行記録で報告する。

## 確認結果

**今回確認した数値ゲートは合格。** 断岳剣の握り、実際の靴メッシュの床への沈み、歩行中の急な方向転換で見つけた問題を修正した後、同じ条件で再測定した。

| 確認 | 方法 | 最終結果 |
| --- | --- | --- |
| 断岳剣 3 技の両手到達 | 実際の `HunterRig.setPose → weaponToTrack → socket`。0.25 tick 間隔、計 811 姿勢 | 両手の最大位置誤差は約 `1.56×10^-15 m`。2 mm のゲートを全点で満たす |
| 断岳剣の膝・肘 | 同じ実リグの関節位置 | 膝の最大屈曲 92.04°、肘 149.28°。膝は今回の 150°ゲート以内、肘は既存検査の 154°以内 |
| 靴の実メッシュと床 | 実際の `SkinnedMesh.applyBoneTransform`。足骨に影響される 254 頂点、811 姿勢 | 最下点は約 `−1.90×10^-10 m`、計算誤差の範囲。`−2 mm` のゲートを満たす |
| 90° / 180° の移動入力変更 | 6 武器 × 2 方向 × 30 / 60 / 120 fps。入力方向へ移動し、身体の向きは武器設定の速度で追従 | 36 ケース、計 7,560 フレーム。脚の到達不足 0 m、確認した関節・手・自己交差の違反 0 |

### 修正が必要だった箇所

- 断岳剣の横薙ぎは、初期案でも添え手が最大約 8.75 cm 離れていた。身体のひねりを腰へ分けるだけでは足りず、構えを低くし、刃が前を通る間に骨盤を少し前へ出した。刃の既存軌道、攻撃時刻、腕の長さは変えていない。
- 踵を母指球の位置で回すと、つま先の骨を持たない現行の硬い靴が地面へ沈んだ。初期案では約 4.85 cm。実メッシュを使って発見し、靴底の支持高を直して膝を解き直した。上体と握りを保ったまま床への沈みを除いた。
- 移動中の急反転で足を固定し続ける初期案は、脚の到達不足が最大約 46 cm になった。身体の向きと移動方向のずれが大きい間は、80 ms の足上げを経て固定を解除し、届く歩行姿勢へ戻す処理を追加した。

既存版の靴の最下点は、縦斬り・抜刀斬りで約 −1.57 cm、横薙ぎで約 −1.32 cm。最終案はこの点も改善している。旧版の値と最終案の各技の値は JSON に全件を残した。

## 再実行

`validation-tests/` の 3 つのテストソースは、適用済みの検証用リポジトリの `tests/` にコピーして使う。ソース中の相対 import はこの位置を前提とする。元の `main` へ直接コピーして適用する手順ではない。

```sh
npx vitest run tests/rig-final-reach.test.ts tests/rig-foot-mesh-audit.test.ts tests/runtime-turn-audit.test.ts
```

上記に相当するローカル実行は、各数値に対する assertion を追加した後で **3 テスト合格**。各テストは作業ディレクトリへ JSON の測定結果も出す。検証には実際の骨の transform、IK、skin weight、頂点変形を使い、画像読み込みだけを代替した。WebGL・ブラウザ・実機の描画検査ではない。

## 残る範囲

- 急な方向転換で固定を解除する間は、世界座標で足が完全に滑らないことまでは保証しない。脚の過伸展・大きなねじれを避けるための制限であり、正式な方向別ステップ clip は今後の制作対象。
- 手の検査は位置であり、掌の向きや指が柄を包む形までは保証しない。正式モデルの手首・ねじり・指の設計は `rig-design.md`。
- 靴の実メッシュの床検査は、現行のハンターの身体と断岳剣 3 技が対象。全防具、他武器の全クリップ、共通回避、被弾、傾斜地の網羅検査ではない。
- 移動中の関節検査では、既存の歩行テストと同様に近似の重心ルールを除外した。武器の質量や完全な動力学を検証したものではない。
- 0.25 tick ごとの検査は有限個のサンプルであり、任意の連続時刻すべての数学的な証明ではない。
- iPhone の性能、通常速で人が見た自然さ、実戦の快適さは未確認。正式 GLB・Blender アセットの制作完了を示すものでもない。
