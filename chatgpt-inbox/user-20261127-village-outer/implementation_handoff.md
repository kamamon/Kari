# Claudeへの統合引き継ぎ（v0.59.0基準）
このPRは絵と配置提案のみ。原本の画像やSVGをそのまま当たり付き3D地形と扱わないこと。

## P0: 外周を一つの山として見せる
- `src/render/hubScene.ts::buildHubGroup` の既存里グループに **非衝突・非対話** の外周景観グループを追加する設計。座標・ロジックの正本は `public/data/hub.json` を維持。
- `src/render/villageScene.ts` の既存の背後の大岩（z約70〜75）を新景観と重複させず、途切れない傾斜にする。
- 最初は遠方の山稜・杉林・雲海を、深度レイヤー（1〜2メッシュ）かバッチ化した低ポリ地形で表示。SVG は制作の色・シルエット資料。全周に同じ一枚を平貼りする方法は避ける。
- 近外周は実際の三角形地形で水路・崖の裏面をつなぐ。現行の可動範囲 `[-46,24] × [-44,62]` は維持する。

## P1: 暮らしの痕跡
- [outer_layout_v1.json](outer_layout_v1.json) の `near` と `mid` から、石垣・杉林・木樋・小屋・吊橋の橋台を組み込む。**周辺の橋は見た目だけ**とし、行けない道を近景に作らない。
- 水車は `mill.garden` 1台。西の木樋はそこへ落ちるように繋ぐ。東の滝は別の沢として下流へ落とす。
- 北側は灯見の台の現行背後岩山を移行。南側は閉鎖門と既存の灯の進行状態を妨げない。
- 大量の住民を新しく置かず、既存NPCを維持。遠方だけ小さな影・煙で生活を暗示する。

## P2: 場所ごとの環境変化
- 高い場所からは遠い見張り灯、中腹は湯気、低い場所は水の音が届く（既存の`VillageFrame.ambience`を拡張するときは値の上限に注意）。
- 日中・夕方・雨・夜の見え方を調整。装置や湯気の派手なエフェクトより静かな生活の音と温度感を優先。
- iPhone横画面でカメラの仰俯角を変えても遠景の終端が見えないこと。外周景観のLOD・インスタンス化・draw calls を確認。

## 受け入れ確認
1. 初期広場（0,0）を中心に水平に360度見回して、端の色ベタ・断崖の途切れ・空虚な裏側が目立たない。
2. [配置仕様の7視点](outer_layout_v1.json)（広場・炉・水辺・宿・灯見・狩場門・谷門）で高低差と遠近感が続く。
3. 既存施設7か所の利用、NPC4人の表示、階段、橋、五段の段差の歩行、クエスト受注、帰還を壊さない。
4. 谷への門（`gate.valley`）は閉じたまま。飾りの遠景橋に侵入できない。
5. 水車が二重にならず、水と木樋が無重力に見えない。
6. 追加素材は不要な衝突判定・探索目標・セーブ項目を増やさない。
7. `npm ci`、`npm run hub:gen`（必要なら）、`npm run check`、`npm run smoke`、横画面実機試遊。実行記録はClaudeが残す。
