依頼：ゲーム画面・操作・システムを調査し、ClaudeがKariの設計参考に使える形へ文字化する。

## 1. 返却物

- [MH2G_MH3_Claude_Research_20261125.txt](MH2G_MH3_Claude_Research_20261125.txt)：23章、約2.4万字の日本語資料。
- A部は原作の調査。確認事実、画面観察、補助資料、未確認を明示。
- B部はKari向けの独自設計参考。画面ごとの内容、入力、カメラ、行動、7武器、生態、判定、捕獲、採集、進行、確認シナリオ。
- C部は調査時点のKariとの対応、優先順位、Claudeへ渡す指示文、制約、出典。原作資料23件とKari資料4件を掲載。

## 2. 守れなかった決まり・迷って決めたこと

リポジトリへの追加はこの専用フォルダ内のみ。原作の素材や説明書本体は返却物に含めず、出典URLと独自の要約を置いた。

「3」はMH3（Wii）とMHP3rd（PSP）の両方を区別して扱った。掲示板の依頼番号がないため、利用者の直接依頼として日付付きフォルダを使用した。

不足は、日本製品版3作品の説明書を全ページそろえて照合できなかったこと。MHFUの海外版資料、MH3の海外公式デモ説明書、当時の記事を使った箇所は本文に適用範囲を示した。原作の全内部数値は未確定。

## 3. 確かめたこと・確かめていないこと

- 公式ガイドのHUD、MH3の公式デモ操作図、CESAの3rd画面を目視。
- 作品を分担した調査の後、原稿を相互確認。出典の対応・記事日付・単発と多段の表現を修正。
- Node v24.22.3。
- 調査基準コミットのpackage.json／package-lock.jsonを使った独立フォルダで、npm ci --no-audit --no-fund --fetch-retries=0 --fetch-timeout=20000 が成功（50 packages）。
- UTF-8、出典IDの参照漏れ、空文字・制御文字を確認。
- この依存導入はゲーム全体のテストやビルド成功を意味しない。調査文書のみのためモンスターJSONのdry import対象はない。
- PSP／Wii／iPhone実機、原作のフレーム計測、Kariの本体コード監査は未実施。
