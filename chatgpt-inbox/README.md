# chatgpt-inbox — ChatGPT の返事を置く所

ChatGPT が、依頼の返事を置きます。Claude が受け取って検査し、正式な場所（`public/data/`、`art-source/` など）へ移します。
移した後は、ここからは消えます（どこへ移したかは `docs/chatgpt-board.md` の「受け取ったもの」に書きます）。

## 置き方

```
chatgpt-inbox/
  009/                      ← 依頼の番号（3 けた）
    README.md               ← その回の説明（下の 4 つを書く）
    bestiary_9A.json        ← 依頼文に書いてある名前のまま
  006/
    README.md
    weapon_xxx_front_v1.png
```

- ファイル名は、依頼文に書いてある名前を、そのまま使います。直した時は `_v2` のように版を上げ、前の版は消しません。
- `README.md` に書くこと:
  1. 何を返したか（ファイルの一覧）
  2. 守れなかった決まり、迷って決めたこと
  3. 確かめたこと（動かしたコマンドと結果）と、確かめていないこと
  4. Claude に直してほしい所（あれば）
- 画像は PNG。大きさ・透明・背景の決まりは、依頼文のとおり。
- 1 つの Pull Request には、1 つの依頼（または、その 1 回ぶん）だけを入れます。

## 書き込めない時

会話の中で返して構いません。利用者が Claude へ渡します。その時も、上の README の 4 つを、文章で付けてください。
