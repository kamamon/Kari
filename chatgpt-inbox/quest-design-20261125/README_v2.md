## 2. 設計上の判断・提出の留保

- 採集・採掘・現地収集納品は、その出発で採った品だけを数え、必要数を納品して成功。余剰は成功帰還時に持ち帰ります。
- 達成品は確定入手。各素材の総供給を必要数＋最低2個とし、抽選待ちや採取点の再出現待ちを要求しません。
- 納品12件を、現地収集4件・貸与貨物の輸送4件・里の倉庫からの一回納品4件へ分けました。運搬箱は落としても壊れません。
- 倉庫納品は消費量と残数を確認してから任意に渡します。残数保護・一度限りの資格・素材減算・報酬を同一保存内で扱います。
- 星は移動・回避・作業量で決めます。今回の追加は★1〜★4。後半地域の安全な採掘にも★1を設定し、拠点納品は手続き★1と素材の入手段階を別に表示します。
- 地域ごとの章完了後に開く任意依頼とし、本筋14件や既存24件を再ロックしません。終章後の環谷は補修・保守の仕事として扱います。
- 固有名のある新NPCを増やさず、依頼人は役割名にしました。新素材の用途は設定提案で、調合・装備レシピの実装済み表示にはしません。
- 前回と同じ直接依頼の続きとして、日付付き提出先とPR #9を使用します。新たな3桁の掲示板番号は割り当てられていないため、通常の番号形式には合わせていません。
- 変更はこの提出フォルダ内だけ。`src/`・`public/`・`tools/`・`tests/`・`docs/` は変更しません。旧v1ファイルは削除・上書きしていません。
