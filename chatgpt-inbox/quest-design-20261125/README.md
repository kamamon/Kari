- 掲示板で新たな3桁の依頼番号を割り当てられていない直接依頼のため、既存番号を流用せず `chatgpt-inbox/quest-design-20261125/` としました。提出番号の形式だけが通常の案内と異なります。
- 専用ブランチ `chatgpt/quest-design-20261125` からPRにします。`main` へ直接pushしません。
- 変更許可範囲は守り、`src/`・`public/`・`tools/`・`tests/`・`docs/` は変更していません。
- 依存導入は `npm ci --ignore-scripts --no-audit --no-fund --offline` で確認しました。指定の素の `npm ci` とは異なり、ライフサイクルスクリプト・監査・ネットワーク取得は実行していません。設計資料だけの提出であり、ゲームのビルド確認の代わりにはしません。

### 設計上の判断

- 星は1〜8。初級1〜2、中級3〜4、上級5〜6、極級7〜8を目安にしますが、実際の強さを変える `rankId` とは分けます。
