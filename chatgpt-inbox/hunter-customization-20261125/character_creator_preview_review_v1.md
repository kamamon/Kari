# キャラメイク操作見本の確認記録

2026-11-25 / Kari / 仕様を確認するための操作見本

## 役割と範囲

`character_creator_preview_v1.html` は、会話内で表示する独立したHTML断片。ゲームへ組み込む完成UIではない。簡易2Dの人物表示で、選択・比較・ランダム固定・履歴・確認・取消の操作を確かめる。

| 見本で動くもの | 範囲 |
|---|---|
| 選択 | 開始見本6、肌12色、髪型16、髪色12、体型4 |
| 体型調整 | 筋肉量と柔らかさの2軸だけ。完成仕様の8軸とは分ける |
| 固定つきランダム | 肌・髪・体型を個別に固定。髪は髪型と髪色を一緒に扱う簡略版 |
| 比較・履歴 | 編集前／現在、一手戻す・やり直す。最大50操作 |
| 初期化・確定 | 編集開始値へ戻す、変更破棄の確認、外見確認、「この見本内で確定」 |

外部通信、ゲームへの接続、永続保存は行わない。お気に入り6枠、JSONレシピ、全8体型軸、顔の詳細編集、3D回転、照明切替、装備表示、実際の保存・競合・復帰は設計書の要件であり、この操作見本の完成機能ではない。会話表示を閉じたり再読み込みしたりすると、見本内の編集は残らない。

## 実施した確認

変更していないHTML断片内のJavaScriptをDOM／イベント検査環境で実行した。実ブラウザの描画結果とは区別する。

- 初期P02で人物の顔・服を表示する状態を確認。
- 肌色・髪色のID、名称、HEX、髪型のIDと名称を既存カタログと照合。
- 16髪型が異なる簡易輪郭へ切り替わることを確認。
- タブ、肌変更、編集前比較、Undo／Redoを確認。
- 3つの固定条件の全8組合せで、固定したカテゴリがランダムに変わらないことを確認。
- スライダーの複数inputを1回のドラッグ履歴として記録することを確認。
- pointercancel、画面幅変更、画面回転、ポインター操作中のフォーカス喪失では開始値へ戻し、履歴を増やさないことを確認。
- NaNやInfinityを値・履歴へ反映しないことを確認。
- リセット、取消、確認、見本内の確定と、その後の新しい比較基準を確認。
- 50手の履歴上限、Undo後の別編集でRedoを破棄することを確認。

## 確かめていないこと

この実行環境ではChromiumがOSのsocket権限制限で起動できず、360px／736pxでの実表示、ネイティブのポインター操作、SVGの描画、実ブラウザのコンソールを確認できなかった。CSSには狭幅で縦並びへ切り替える指定を入れたが、iPhone Safari、iPad、PCでの表示・操作は別途確認が必要。

ゲームの3D変形・装備干渉・保存移行・入力遮断・性能は、この見本では検証していない。[機能仕様](character_creator_function_spec_v1.md)と[状態・保存契約](character_creator_state_contract_v1.md)の受入条件を実装後に確認する。

## 迷って決めたこと・守れなかった決まり

見本では選択結果が分かる簡易2D表示と基本4カテゴリへ絞った。完成3Dや保存が実装済みと誤解されないよう、画面内にも「操作見本」「簡易プレビュー」「この見本内で確定」を明示した。変更は指定のinbox内だけで、ゲームのコードや実行データは変更していない。実ブラウザの目視確認だけは環境制限により未完了。
