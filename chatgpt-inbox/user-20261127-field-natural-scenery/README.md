# フィールド外周の没入感改善
利用者指摘: エリアの外に何もない草原が広がって見える。2Gのように自然の中にいる景観へ改善する。
基準: v0.66.0 / b9770eb。原因は arena.ts の GROUND_MARGIN=130 と、外側が平坦な草地であること。全狩場で盆地の共通遠景を使っていたことも一因。
- プレイ可能範囲・境界・出口・岩・段差・採取点・戦闘/カメラの当たりは変更しない。描画用の適応格子を同一頂点から内外へ分離。内側の高さは reliefAt を使う。外周に近い頂点は既存の地面高を維持。外側を山稜・岩塊・林・水辺にする。
- 登録済み20地域の景観パレット。盆地、森、湿地、海岸、雪峡、断崖、鉱洞、熱石、硝晶原。広い原・谷・巣・野営地で個別に密度・高さ・遠景を変える。
- 出口は手前の衝突を変えず、外側へ曲がる踏み跡と自然景観を追加。遠方の稜線・大気遠近法、霧と空の地域色を統合。地域ごとに既存の草・岩・苔・樹皮・葉・水の画像材質を使用。盆地以外の同じ山のパノラマを非表示。
- 新規の高精細原画や3Dスキャンではなく、既存素材を再利用した描画用プロシージャル景観。樹木・岩・水面は外側の背景であり、歩ける新規地形ではない。雪・熱・洞窟は簡易表現で、気候や地形のシミュレーションは変えない。
- AGENTS.mdの通常担当範囲はinboxのみだが、利用者の本体変更の指示に基づく専用ブランチのPR。mainへの直接pushはしない。型検査、全テスト、ブラウザでの景観検証を別途記録する。iPhone/iPad実機は未確認。
