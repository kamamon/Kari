# 第2便 ③ — 護刃（片手剣）・双剣

資料：PSP版 [MHP2G@Wiki 片手剣](https://w.atwiki.jp/mhp2g/pages/149.html)、[双剣](https://w.atwiki.jp/mhp2g/pages/150.html)。現在のKari `public/data/actions/guard_blade.json`・`twin_blades.json`、`docs/classic-hunt.md`（v0.57.0）と比較。**原作の連続動画の関節・足運びは未観察**。

## 護刃：共通の演技方針

【資料確認】2Gの片手剣は△系の斬り連係、○回転斬り、△+○飛び込み斬り、ガード中の二種類の攻撃と道具使用を持つ。**左盾が守る向きと右剣が斬る向きが別**である点を、Kariの身体づくりの優先事項とする。【制作提案】連係の開始を無理に同じ構えへ戻さず、前の刀身の残った位置から次の斬撃を開始する。

### `player.guard_blade.slash1` / `side` / `slash2` / `return`（通常の斬り連係）

- **① 順番**: 【資料確認】斬り下ろし→追加入力による連続攻撃。飛び込み斬りやガード中の斬り上げの後からも連係可能。【現行Kari】 `slash1`→`side`→`slash2`→`return` の一連の動作が存在するが、原作の斬り下ろし1・2・3への正確な対応は未確定。
- **② 足・体**: 【制作提案】通常連係では攻撃の度に身体を前へワープさせず、足の小さな踏み替えで剣側の肩を動かす。前進の先行脚・骨盤の回転方向は原作未観察。
- **③ 刃の道**: 【制作提案】斬り下ろしから次の斬りへ刀身の始点をつなぐ。剣を振る間も左の盾は完全に背中側へ消さず、胸前の防御域を意識する。右上から左下などの実際の軌道方向は未観察。
- **④ 2G特有**: △の追加入力で段階的に連係し、○の回転斬りや回避へ移る。後年の盾を使った連係全体をそのまま移すのではなく、2Gの入力表に合わせる。
- **⑤ 確かさ**: 連係と入力は資料確認。刀身と盾の実際の位置、先行脚と方向は未観察。Kariの4つのIDが原作3段のどこに一致するかはClaudeと要整理。

### `player.guard_blade.round`（回転斬り）

- **①**【資料確認】○の回転斬りで、通常の連係からもつながる。【制作提案】前段の終わり→骨盤と胸をひねる→剣を横方向に通す→勢いを受け止め→次の構え。
- **②**軸足・どちらへ回るかはPSP未観察。Kariでは骨盤の向きと刃の回転方向を同期させる。
- **③**刃は横に払う（技名・役割からの制作案）。回す高さと終点は動画で比較が必要。
- **④**一段ごとの短い斬撃と、回転による広い薙ぎを分ける。
- **⑤**存在と入力は資料確認、足運び・軌道は未観察。

### `player.guard_blade.lunge`（ジャンプ斬り）

- **①**【資料確認】△+○でジャンプ斬り。納刀から移動＋△でも同種の抜刀斬りにつながる。**【制作提案】**重心を前へ→前足を着く→剣で打点を通過→勢いを止め→連係へ。
- **②**実際に跳ぶ高さ・踏み込む脚・盾の振り方は未観察。足が地面に付く前に武器だけ前へ飛ばないことを制作で確認する。
- **③**剣の軌道は前方へ接近して接触する構想。上下・左右の刃の向きは未観察。
- **④**2Gの複合入力は独立したジャンプ斬り。後年の高速な突進派生と混同しない。
- **⑤**入力・接近系の役割は資料確認、実際の重心・手足は未観察。

### `player.guard_blade.bash` / `guard_slash`（ガード攻撃・盾と剣の連係）

- **①**【資料確認】R+△はガードからの斬り上げ、R+○はガード攻撃。両者は**別の入力**。 【現行Kari】盾攻撃 `bash` とガード斬り `guard_slash` はあるが、原作の各技への対応は要検証。
- **②**【制作提案】盾を前に残す間は左肩と脚の支持を固定し、右肩だけ剣の動きへ移る。盾打撃では支持脚の受け止めを先行させる。PSP原作の支持足は未観察。
- **③**右剣と左盾を**同じ武器軌道に吸着させない**。ガードで盾が身体の前に残りながら剣が動く場合は両方の通り道を分ける。
- **④**2Gの片手剣にはガード中の道具使用（R+□）もある。攻撃しか使えないガード状態にしない。
- **⑤**ガード中の2入力と道具は資料確認、盾の実姿勢は未観察。Kari `bash` を原作盾技と断定しない。

### 抜刀・納刀・抜刀構え・ガード中の道具

- **①**背・腰の収納位置から右手で抜く→剣と盾をそれぞれ構える／戻す、という順はKari制作案。ガード中の道具は右手を道具へ移し、道具使用後に剣へ戻す。
- **②**原作の右足・左足の前後、ガード道具中に左盾をどの角度で維持するかは未観察。
- **③**右手の剣だけを収納して左盾がどこへ移るかを実機で確認。盾の中を剣が貫通しないこと。
- **④**道具使用のために必ず納刀してから再抜刀する方式と、片手剣のガード道具を区別する。
- **⑤**例外操作は資料確認、モーション細部は未観察。

## 双剣：通常状態と鬼人化状態を混ぜない

【資料確認】2Gの双剣は、通常時の△連係、○回転、△+○斬り払い、R鬼人化、鬼人化中○二回転・△+○乱舞。近年作の鬼人強化ゲージと同じだと見なさない。【現行Kari】 `demon_on/off` と `flurry` はあるが、`stab`（二段突き）を通常△+○として扱うことは2Gの操作表と合わない。

### `player.twin_blades.slash1` / `slash2` / `cross`（通常斬り連係）

- **①**【資料確認】△の連続入力で、斬り下ろしから二連斬り上げ・突きと斬りのコンビネーションなどへ進む。【現行Kari】 `slash1`→`slash2`→`cross` の段を使うが、2Gの派生と一対一には対応していない。
- **②**【制作提案】左右の刃を動かすたび、胸だけ反転するのではなく左右脚の支持を交換して体幹の釣合いを保つ。先行脚と軸足は未観察。
- **③**右刃・左刃の軌道と接触イベントは別に追う。左右が同時に出る技だけ手を交差させる。2G映像でのどちらが先かは不明。
- **④**2Gの通常連係は軽い武器の手数で進み、鬼人化による乱舞とは別。
- **⑤**連係の名前・操作は資料確認、腕の上下順と足順は未観察。

### `player.twin_blades.round`（回転斬り）

- **①**【資料確認】通常状態の○は回転斬り。左入力中の回転方向の派生がある。【制作提案】膝と骨盤で軸を作る→左右の刃を身体の外へ通す→回り終わりを支え→構えへ。
- **②**PSP映像での足の踏み替えと体の回転量は未観察。
- **③**一方の刃だけ地面へ刺さらないよう両方を離して描く。
- **④**鬼人化時の○二回転とは別物。Kariの通常回転を鬼人時に単純2倍速で再生しない。
- **⑤**入力分岐は資料確認、軌道と姿勢は未観察。

### `player.twin_blades.stab`（Kari二段突き。2G標準からの置き換え候補）

- **①**【現行Kari】二度前方へ突く。【資料確認】PSP版2Gの通常△+○は**斬り払い**。現行`stab`を通常複合入力の正規技として維持すると不一致。
- **②**足と体は原作にこの技として対応しないので、記憶で補わない。
- **③**【制作提案】新しい斬り払いは左右の刃を前へ通し、移動と刃の接触を同じ動作にする（方向の詳細は映像確認）。
- **④**鬼人化中の△+○は乱舞になるので、状態別の入力表を最優先にする。
- **⑤**置き換えの必要性は資料確認、斬り払いの正確な軌道は未観察。

### `player.twin_blades.flurry`（乱舞）

- **①**【資料確認】鬼人化中の△+○が乱舞。左右から連続して複数回接触する。**【現行Kari】**`flurry`には複数の接触イベントがあるが、原作の連続打点と同一かは未確認。
- **②**【制作提案】一発ごとに腰の向きと荷重を切り替え、最後の強い斬撃だけ急に浮かないようにする。支持足の実順は未観察。
- **③**両手の剣が入れ替わりながら攻撃する様子は原作動画で確認する必要がある。実際の左右順、終端の軌道は不明。
- **④**乱舞は鬼人化中だけに限定。ゲージが切れた通常状態のコンボへそのまま延長しない。
- **⑤**条件と多段は資料確認、姿勢と打点の時刻は未観察。

### `player.twin_blades.demon_on` / `demon_off`（鬼人化の開始・解除）

- **①**【資料確認】Rで鬼人化、再度Rで解除。 【制作提案】動きを止めて構える→足幅と肩の張りを変える→武器を左右へ構える→強化状態の歩きへ。解除では姿勢を解いて通常の構えへ戻す。
- **②**【未観察】PSP版で両足を開くか、どちらの足を踏むか、解除時に剣を下げる方向。
- **③**強化開始時も両刃を同じ位置へ重ねない。
- **④**スタミナを消費し続ける強化状態であり、後年の鬼人強化ゲージを足さない。
- **⑤**入力・状態の存在は資料確認、見た目の形は制作案。

### `player.twin_blades.draw_cross`・抜刀／納刀・鬼人中の回避

- **①**【現行Kari】抜刀交差斬りを構えずに始める。 【資料確認】2Gは移動中の抜刀で斬り払いへつなぐ。鬼人中は回転と乱舞に切り替わる。
- **②**抜刀斬りの先行足、鬼人化中の回避の方向・足の持ち上げ方は未観察。
- **③**鞘から抜いて刃を振るなら、両刃がそれぞれの鞘と両手を無理なく通る経路を作る（制作提案）。
- **④**鬼人中も常に同じ通常回避を再生するだけでは状態の重さが伝わらない。原作の回避形は動画確認。
- **⑤**連係・入力は資料確認。抜刀斬りと回避の形は未観察。

## Claudeへ伝える差分の優先順位

**最優先は2Gに実在する技への対応付け**。片手剣の `guard_slash` と `bash` をガード中の2種類の攻撃と区別し、双剣の `stab` を通常△+○斬り払いへ改める。その次に2G本来の左右の刃・盾の具体姿勢を動画で観察してIKを直す。Kariの技名を勝手に変更せず、アクションIDと入力ルートの仕様をまず相談する。
