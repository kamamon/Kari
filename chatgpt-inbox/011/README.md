# 依頼011 第2便 — 2Gの技構成から見たハンター動作の文章票（数値なし）

2026-11-26。**Kari main v0.57.0**（`5fb9131920b92f6269c6c5ac45a222a6cbb63ca9`）に対する、掲示板の「第1便の数字は手本にしない。第2便は動きの順番・足・体・武器の通り道・2Gらしい部分・確かさを文章で」という更新指示への回答。

## 結論・第1便との関係

**この第2便は、PR #21の暫定座標130票を置き換える、数値のない**「資料による技の構成 + Kari現在の演技との比較 + 制作側が確認するポイント」の文書です。数値票の採用は依頼していません。

PSP日本版2Gの連続プレイ動画をこの環境ではコマ送り再生していないため、**実際に見たように支持足・骨盤の回転方向・刃の通り道を断言しません**。攻略資料から確かめた「どの攻撃が出るか」は【資料確認】、Kariの最新仕様の形は【現行Kari】、演技についての案は【制作提案】、PSPの映像を見ないと分からない点は【未観察】と明記しました。「はっきり覚えている」と嘘の確信度を付けないため、確かさは証拠の種類で示します。

## 使い方

各技に掲示板の5項目を付けました。**①順番**は攻略文書や現行Kariに基づく。**②足・体の回転、③武器経路**は見えない場合「PSP版未観察」、Kariの形がある場合は現行仕様と記して区別。**④2G特有**は同シリーズの後年の技を紛れ込ませないための境界。**⑤確かさ**は「資料確認／Kari確認／未観察」で表示します。

ゲームの実装、正式な3Dアニメーション、オリジナル映像の検証済み比較ではありません。Claudeの受け入れ先は `src/` 等の制作管理下で、ChatGPTは `chatgpt-inbox/` のみ変更。ゲームの動作を勝手に切り替えたり、`v056` を消したりしないこと。

## 守れなかった決まり・迷って決めたこと・未検証

- 守れなかったこと: 2G PSPの実プレイ映像を技ごとに観察して足順・腰の向き・刃先の軌道を示すこと。**実際のフレームの観察記録は納品できない**。
- 判断: ない観察結果を「うろ覚え」と捏造しない。代わりに操作表で確認できる構成と、現在のKariの演技に対する可視化・検証のチェックポイントを提供。
- 未検証: 原作PSPの個々の姿勢、装備の大きさと軌道、モーション発生順の映像上の実尺、足の接地タイミング、iPhone端末での見え方、Kariでのプレイ検査。
