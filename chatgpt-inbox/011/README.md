# 依頼011：2Gを手本にするハンターモーション観察票（第1便・暫定制作案）

**重要：原作映像の姿勢を実測・観察した完成票ではありません。** この環境では、PSP版2Gの連続動画を実際にコマ送りで取得・検査できなかったため、動画の説明欄に載る「武器訓練」の章開始〜次章開始を参照箇所として記録し、実際のK0〜K4の時刻とは区別しました。K0〜K4の姿勢・支持足・足先・武器位置は、現行Kariの骨格・ready武器座標と、動作制作上の推論による**暫定案**です。原作由来の測定値として使わないでください。

## 1. 今回返したもの

- `*.json` **41票**：大剣の行動7＋大剣の防御状態1＋共通の前転・飲む・研ぐ・剥ぎ取り4＋7武器の構え7・抜刀歩行7・抜刀7・納刀7＋納刀歩行／走り／疾走3。実在の行動IDと、行動IDを持たない描画状態の「コード位置」を明確に区別しています。
- `MOTION_INDEX.json`：各ファイル名とGitHubのblobハッシュ、観測状況。
- `SOURCES.md`：参照資料、動画の章時刻と測定上の制約、横殴り／薙ぎ払いの呼称問題。
- `validate_observation.py`：JSONの構造とK0〜K4、Kariの現行行動IDを検査するスクリプト。

各票は依頼された `kariActionId`、`observed2gMove`、`source`、`startState`、`keys`、`weaponPath`、`rootMotion`、`contactEvents`、`differencesFromKari`、`unknowns` を持ちます。全キーに `support`、`feet`、`pelvis`、`chest`、`head`、`weapon`、`root` を置き、数値の分類 `valueBasis` を追加しています。見えない手と収納中の武器は「不明」のままです。

## 2. 守れなかった決まり

- **最重要の「原作の連続映像から観察する」を満たせていません。** 原作から支持脚・握り・座標・姿勢を観測した数値だとは言えず、すべての票を「暫定制作票」として残しています。動画説明欄の章時刻は、動作の開始・接触・終了を示しません。
- 希望項目Bの **棒人間K0〜K4の正面・真横PNG** は作成していません。観測していない姿勢を原作比較図として描くと誤認につながるためです。
- 依頼011の「全部」のうち、片手剣・双剣・ハンマー・太刀・ランス・弓の**攻撃**と、道具の残り・採集・被弾・登攀・防御は、次のまとまりです。抜刀／納刀／構え／歩行だけ先に含めました。
- `npm ci` とゲーム本体の実機動作確認は、GitHub API経由の登録しかできないため実施していません。

## 3. 迷って決めたこと

- 掲示板は `player.heavy_blade.side_sweep=横殴り` としていますが、PSP版2Gの大剣の操作資料では `○=薙ぎ払い` と説明されています。二つを同じ技だと断定せず、票に「対応未同定」を記載しました。Claudeは動画で区別してから1:1の置き換えを決定してください。
- 新しい行動IDを捏造しないため、構え・歩行・防御のような手続き動作の `kariActionId` には、実行されるコード位置を指定しました。専用のアクションJSONがあるものは `player.*` IDを使います。
- 2G原作のフレーム数、モーション値、前進距離は今回のJSONへ転記しません。原作からのアニメーション抽出、動画・画像の無断同梱も行っていません。現在のKariの `durationTicks` などは、`kariReference` で既存値だと明示しました。
