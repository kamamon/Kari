## 3. 発動契約

【制作提案】頭・胴・腕・腰・脚と装飾品の合計点を符号付き整数として集計する。武器本体には原則技能点を持たせず、装飾品枠0〜3を許可。防具本体の技能は複数の配列にし、各部位・個体ごとの装飾品を足す。部位重複は既存wornPiecesと同じ。装飾品個体の二重装着不可。シリーズ・武器の適合チェックは装着時・出撃時の両方で実施。
- 個別属性/状態/瓶は id:target で分離。水と氷を合算しない。対象なし/対象不正は拒否。
- 発動: 各系統ごとに正なら満たす最大閾値、負なら満たす最も負の閾値のみ。+9/-9は無効果。正負両側を同時発動しない。2段階の技能でも10/15型と10/20型がある。最高閾値超過の余剰点は効果なし。発動技能数の強制上限なし。
- 未対応武器の技能はポイント表示は行うが「対象外」として効果なし。all/melee/guard/charge/bow/bluntは装備または命中タグの能力判定に変換。guardは防御機構がある武器のみ。bluntは打撃判定タグ（護刃の盾打ち等含む）で判定。chargeは溜め機構を持つ武器のみ。未実装のフックはUIで「準備中」とし生産不可、無効果の技能を装備に発生させない。
- 旧技能のvalues配列はそのまま新閾値10/15/20へ。値の維持は発動時の効果を指し、装備ごとの発動状態維持ではない。
- 負段階は定義した系統だけ。2段階負なら-10/-15で打ち止め。正しかない系統は負10でも無効果。符号付きvalueを「短縮率」等に従い適用: 例えば+20%短縮→0.8倍、-20%→1.2倍。
- 複合技能は別系統ポイント+10で発動。メンバーの効果キーごと最大の正段階一つだけ。通常技能側が負で発動中ならそのメンバーの正効果は抑止、負効果は残す（打消しなし）。複合ID自体は今後正式な技能マスターに登録、装飾品なし。固有技能も装飾品から付与しない。
- 同じ効果キーの加算禁止。道具整備/研磨術の同じ短縮効果は正側最大、負側があれば最終短縮に別途加える（係数0.5〜1.5）。個別状態耐性/耐症は対象ごと最大値、負は別途差引。防御・回避スタミナ等の異なるキーは個別。
- 属性攻撃・物理攻撃・会心・固定ダメージ・蓄積は独立。物理技能を属性や毒に掛けない。物理上昇は基礎攻撃力へ一度、会心は既存計算の物理項へ一度。最終会心は-100〜+60%に収め、既存の1命中1乱数消費を維持する。会心率の上限により抜き技も確定会心にならない。
- 物理攻撃の強化は同時条件込み1.25倍、属性1.25倍を初期上限候補。回避無敵時間0.42秒上限は元の通常回避/ステップにのみ適用し、緊急回避等の既存長時間無敵を短くしない。既存時間を下回らない。無敵時間・硬直・速度・判定軌道を一括スケールしない。
- 研磨・道具・採集時間は動作開始時に確定し、モーションの効果発生フレームも対応して再配置。60Hzの論理tickで時間を扱い描画FPSと独立、端数丸めは最後。ガード性能段階は押し戻し/崩れの閾値を能力別データ化し実測調整（JSONの段階値は未確定の閾値値ではない）。
- 確率効果は決定論的にリプレイできる独立した用途別乱数。報酬はクエスト開始時のビルドを固定しrunIdに紐付け、清算の再試行で再抽選しない。通常追加素材のみと指定した系統ではレア抽選を行わず階級制限を保持。採集点の利用回数はノード初期化時に決め、エリア往復で復元しない。

## 4. 防具・装飾品・技能ビルド

四級テンプレートは頭/胴/腕/腰/脚順。既定は主、副、負、固有。初級主11・副10・負-10、枠3。中級主15・副10・負-10・固有10、枠5。上級主16・副12・負-12・固有10、枠7。極級主20・副15・負-12・固有10、枠9。固有はrankStart/技能minRankの条件を満たす系列のみ。これは各系列用の初期配分案であり、全系列同じ分布にはしない。単段階技能に余る点は配分調整して枠/別技能へ振る。初出の目安は生産可否に適用し、技能のレベルそのものをHRで制限しない。
例: セルヴァルク初級→身かわし+11（基本）、身軽+10（基本）、受け支え-10（悪化）、装飾枠3。上級の防具と混ぜても同じポイント算定。
例: ガルドロス中級→盾構え+15（盾構えの上位は20なので基本）、刃持ち+10、身軽-10、晶脈の構え+10。非ガード武器では固有と盾構え対象外。
例: オルゼリオンは看板案として極級からと仮定。雷翼の残響は回避を連発しただけでは出ない。回避成功の実ヒット判定・属性・期限・1回消費・CTが必要。登録済みの恒久ID/実装・生態の確定後に配分。
【装飾品】各武器/防具に0〜3枠、同じ装備内で必要枠を確保する。2枠装飾品を1枠+別装備1枠には入れられない。付け外しは拠点のみ、破壊せず在庫へ返す。各級で作れる素材を用い、レア素材の強制を避ける。1枠の通常品は+1〜2/-1、2枠+3/-1、3枠+5/-2を目安。JSONの8品は例示、素材レシピと価格は採取マスター確定後に作る。瓶適応は機能未対応のため現段階では生産不可。
【組み合わせ目標】初級で正2/負0〜1、 中級正2〜3、上級正3〜4、極級正4〜5（固有込み）。目標値であり強制制限なし。混合防具で負の打ち消し・他技能への伸長を可能にする。主技能が単段階/対象外の場合は防御と枠の価値を再配分。近接/射手は同じ素材で選択式、頭のみ共用などの例外は明示。
【素材ルート】鉱石だけの装備は採鉱術/道具保全、骨だけは砕き/刃持ち、虫は回避/虫捕り、植物は調剤/採集、魚は持久/釣技を優先。通常素材の追加はレア素材テーブルを変更しない。各級のフィールドから得られる素材だけで各級の採集装備を生産可能にする。6系列例に含まない全86種の配分は別途装備PR#20と突合して設計する。

## 5. UI・データ移行・実装順

- 装備箱に「発動技能」「未発動技能点」「対象外」「準備中」。符号、合計、次の閾値まで残りを表示。防具選択前後の差分と負発動警告を表示する。工房には枠、正負点、発動例、必要素材、級別フィルタ。保存した装備セットには武器/防具の個体IDと装飾品割当を保存する。
- E01: 保存版6の装備個体移行。既存持ち物・装備ID・強化段階を維持し、決定的に個体IDを付ける。装飾品は初期未所持、既存個体に新規枠の空き状態。未知IDは消さない。旧版控えを保存し、失敗時原本を残す。技能点は定義から導出しセーブに重複保存しない。現在の版と実装順はClaudeが直前に再確認。
- E02: gear.tsの純関数を skillPoints → activate → effectResolve に分離し、skillLevelsの呼出箇所（UI、sim、テスト）を全検索。既存12技能を第一段階として実装。旧版の1点を一律変換すると単品Lv1を維持できないため、系列の主副配点を全件棚卸し。旧ロジックを比較用として並走させるが新旧効果を重ねない。移行前後の装備差分レポートを出し、大幅弱体化は配点修正/配布の検討後に切替。新規正負点が未整備の系列は旧計算のみとし、新旧の点は混算しない（実際の全系列切替時に旧計算を廃止）。
- E03: 装飾品と保存・UI、E04: 近接/射手の適合を実装。現行値を維持したまま新技能のフックを段階追加。生成器の原本とデータ検査も更新。
- 戦闘P1: 攻撃/精撃/刃質/蓄勢/回避/防御など既存フックに近い機能から。P2: 咆哮/風圧/地形のタグ、採集/捕獲/報酬、瓶対応を対応するゲーム機構と同時追加。P3: 固有と複合、伴獣（伴獣未実装なら保留）。自動防御、銃、砲、笛、護石は今回は除外。
- 旧装備の大量データ置換、スキル値一律の上昇、回避無敵の一括設定、未実装技能を有効表示することは避ける。
