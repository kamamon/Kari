## Claudeへの引き継ぎ
原画は静止画の制作資料。発光系は加算合成、煙・泥は別途アルファマスクを作成し通常合成。岩片は3D粒子。地面材質で砂・土・雪・水を切替。攻撃予兆、命中、残留を分離し、既存の判定時刻を変更せず同期。オルゼリオン専用に翼・角の放電、蓄電、着地雷撃を設計する。iPhone向け粒子上限とLOD、画面点滅抑制を設ける。
