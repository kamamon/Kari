# 灯継ぎの里・専用3D区画と生活拡張（PR #37の続き）
2026-11-27。ユーザーの直接指示で本体を変更。v0.64.0のmain a7c88fd010b68815ef83ff3848aaf9d3d8dbca5b を基準。既存の受付、狩猟、5段の地形とセーブ構造を維持する。

## 実装
- 主要施設・家屋12棟：工房、商店、4級の受付、装備箱、宿、民家2棟、集会所、倉庫。石・木・瓦・金具・布・灯のメッシュを材質別バッチ化。256pxのオリジナル材質・法線マップ、窓、屋根の厚み、柱、格子、戸、釘、商品など。元原画の板を貼った四面を置き換え。従来の当たり・施設位置・煙の位置を維持。
- 自室：12種の家具を最大24点。上からの3D配置、連続位置・1度単位の回転、3材質、追加、撤去、保存、初期配置、室内歩行・展示。壁、入口、家具同士、歩行空間を検査。従来の左右選択の保存も読み取る。別タブではなく本体のSaveManager。
- 灰層の坑道・沢鏡の養魚池：独立した歩行区画。Lv1〜4の領域・採取点、採掘タイミング・釣り合わせ。現行の採集回数、素材抽選表、級、保存を共用する。農場タブまたは里の入口から開く。
- 家畜：ヤマツノ山羊、アシハネ鶏、コブヤギ荷獣。胴・頭・脚・尾を分けた可動モデル、囲い、餌箱。購入、給餌、依頼1回達成後に素材回収、商店売却。種類ごとに最大3頭。
- オリジナル音源「灯の尾根」：約20秒ループの通常・警戒版、家畜3種、採掘、釣り、雷、戸、給餌、報酬の独自PCM。外部録音・既存ゲーム楽曲不使用。既存BGM/環境音/効果音の音量設定とミュートに従う。
- 看板物語：#18の「帰り道の灯―雷が帰る峰」の報告の方針に沿う。既存のガルドロスとセルヴァルクの達成に連動して予兆・警戒報告、霧、遠雷、警戒版BGM。帰還報告を自動で開き、集会所で再閲覧できる。オルゼリオン本体・高地・正式な最終依頼がmainに無いので新規狩猟を偽って有効にしない。将来正式ID quest.story.thunder_return と monster.orzelion の達成保存に連動する帰還分岐を用意。

## 判断・制約
- 3Dモデルは手続き型の詳細立体・材質生成で、完成した手彫りZBrush/写真級PBRの外部GLBではない。メッシュは全方向確認可能。室内と採集区画は独立した非戦闘・一人称歩行モード（狩人の三人称戦闘マップに組み込むのではない）。家畜の囲いは既存里の景観用で、新規の本体当たりを足さない。自室と専用区画の歩行衝突は別に検査。
- 家畜産物の用途は売却から開始。音源はランタイムで合成するPCM（外部のwav録音ではない）。
- 既存の正本の地形を変えない。描画の実機性能、iPhoneのWebGLコンテキスト、詳細の見た目、実際の音質、ゲームパッドでの専用区画操作は実機確認が必要。
- AGENTS.mdの分担から外れ、本体に変更を加えたのはユーザーの明示依頼による。mainの直接pushはしない。CIの型検査・全体テスト・ビルドに合格してからマージ判断。
