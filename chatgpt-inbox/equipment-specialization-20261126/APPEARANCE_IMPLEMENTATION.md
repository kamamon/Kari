# 見た目を系列ごとに作り分ける仕様

## 制作の基準

採用済み `art-source/board/style_board_v2.png` の、岩・皮・骨・繊維と鈍い青銅を中心にした質感を継続する。全86種の `appearance` が形の原本で、比較原画は立体の読み方を伝える制作資料。最終3Dや全方向の設定図、全級・全武器の完成画像ではない。

同じ鎧の板を色だけ変える方式は使わない。種ごとに、主量塊、補助形、重心のある部位、非対称、器官の数、関節の空き、握り方を固定する。全602武器形状と430防具部位、登場級から極級までの発達を書いた。幼体8種の素材も成人用の防具で、未発達の角・薄膜・小板を使った軽さが親の系列との違いになる。

## 各系列の形の原本

| JSON欄 | 制作上の役割 |
|---|---|
| `silhouette` | 小さく表示しても識別できる外形 |
| `palette` | 主材・支持材・アクセントの3色 |
| `organTranslation` | 原種の器官を防具・武器・技能表現へ移す理由 |
| `armorParts` | 頭・胴・腕・腰・脚の別々の形 |
| `weaponShapes` | 7武器ごとの固有形状 |
| `gradeEvolution` | 級が上がった時の構造・留め・器官面の発達 |
| `production` | 主量塊・器官数・左右・クリアランス・握りの固定条件 |
| `skillCue` | 平常と発動の差、位置、最大点灯面積 |
| `avoid` | 親や他系列へ似せないための具体的な禁止形 |

例えばガルドロスは左肩・前腕・腰の大きい岩量塊、セルヴァルクは背肩に畳んだ短い帆、ヌメラドンは頭と前腰の浅い泥皿、ボルナケルは胸1＋肩2の閉じた共鳴室になる。原種の属性や状態異常を新しい見た目から逆算して追加しない。ヌメラドンは原本どおり水であり、毒ではない。

## モデルと装備IDを分離する

`data/appearance/` は214系列・級の外観IDと、その外観を使う武器ID・防具IDをつなぐ表。既存の所持ID・生産IDを見た目の都合で変更しない。外観は `appearance.<種>.r<級>` から、各武器または5部位のモデルを解決する。

1. まず1系列・登場級の頭胴腕腰脚と代表武器を作る。
2. 共通リグに装着し、握り・抜納刀・回避・防御・最大関節角で接触を調べる。
3. 7武器へ各形状を展開する。打点、刃先、弦、盾の面を登録済みの位置へ保つ。
4. 素材の留め方と器官面を級別に発達させる。単純な全体拡大・金色化で代用しない。
5. 他系列との混成を全5部位で確認する。1セットだけ着た時の良さで合格にしない。

モデルが未完成なら、読み込みに失敗しない共通形へフォールバックする。ただし装備箱では「系列専用の見た目は準備中」と表示し、完成済みと見せない。現在の追加武器は共通の里武器モデル、防具は系列専用モデルを持たないので、性能だけ接続しても外観の再設計が入ったことにはならない。

## 握りと可動域

- 断岳剣は採用済みの両手位置と有効刃長を維持。岩や晶の突出を攻撃判定の延長へ使わない。
- 護刃は片手剣と独立した盾。盾裏に握りと前腕帯を残し、膜の系列も防御面の裏に硬い支持面を作る。
- 大槌の両打面は閉じた硬い面。嚢、膜、共鳴孔は側室へ寄せ、空洞や柔らかい膜を打面にしない。
- 双剣は必ず二本。左右に意匠の差があっても、刃長と重心を揃える。
- 太刀は連続した細い刃と鞘の通り道を保つ。峰の飾りが抜刀を塞がない。
- 長尖槍は長い直槍と独立盾。飾りで有効リーチを増やさず、比較原画の画面都合の縮尺は実寸に採用しない。
- 環弓は細い弓身、一本の直線弦、小さい照準環と矢。主形を円盤や大きい輪に変えず、曲がる区間を殻で固めない。

兜の視界・首の振り向き、肩上げ、肘内側、手首、股関節、膝裏、足首を全系列で空ける。器官を付けた腕でも手指と握りを残す。腰の器官は前後左右の指定を守り、長い尾を追加しない。原画で背面の小器官が隠れている場合、前面へ移さずJSONから作る。

## 技能の見える合図

平常は暗い溝、閉じた膜筋、鈍い縁などとして見せる。発動中は指定部位だけの小さな点灯・反射にする。全身の点灯面積は各JSONの上限以下で最大8%。画面全体を覆う粒子、大きな羽の展開、新しい攻撃判定、全身の点滅は追加しない。

効果の開始・終了はsimulationイベントから描画へ通知する。描画の明るさから技能の有無を判定しない。色覚・低画質でも確認できるよう、HUDの形と短い名前を併用する。

## 比較原画の読み方と未検証

22枚で86種を比較する。通常は4種ずつ、最後は2種。各種は成人用全身防具と代表2武器系統を描き、別々の剣と盾、双剣2本などを含む。対応するNoとLatin IDを照合する。No57は和名テムソギアでもIDは `tarhegna`、No71はセオルミドでも `segranio` を保持する。

画像の主器官数・位置・代表武器・枠切れを目視で確認した。修正した箇所と、立体制作時にJSONを優先すべき細かな差は各 `art/manifest-*.json` に残す。奥行き、正投影、背面の細部、全級の専用画像、正式モデル、LOD、混成時の衝突、iPhoneでの読みやすさは未検証。これらを合格扱いしていない。

PNGは転送上限への対処としてバイト列を分割している。`python3 reference/materialize_art.py` により原寸PNGを1バイトも変えず復元できる。リポジトリで分割ファイルを画像として直接表示できないことは形式上の制約で、原画の欠落や低解像度化ではない。
