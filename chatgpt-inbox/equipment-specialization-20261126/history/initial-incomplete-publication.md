## 1. 再設計の基本

86種それぞれに、素材器官、生態、得意な戦い方、明確な代償、推奨武器、避けたい状況を定義しました。静的な性能は物理・会心・属性または異常・刃容量・刃消耗・戦闘スタミナ消費・防御・部位別重量配分・属性耐性に分けています。

外観は各種について、シルエット、素材色3色、器官の転用3点以上、頭・胴・腕・腰・脚、7武器種の形、初登場級から極級までの発達、技能発動の小さな合図を記載しました。幼体の素材でも成人用装備です。

モンスター装備の再設計対象は214系列・級、武器1,498点＋防具1,070点＝2,568点。前回の採集・採掘・虫取り9系列、432点を継続し、総3,000装備の一覧へまとめました。初登場前の級に架空の装備を作らず、その種が登場する級から極級までを扱います。

### ガルドロス

左肩の大きな岩板と後腰の晶錘に荷重を集める、受けから部位を割る装備。物理基準比1.16、防御基準比1.10に対し、会心-20%、戦闘スタミナ消費1.18倍を代償にしました。

固有「岩荷の返し」は、同じ相手をガードした後4秒、部位破壊・切断蓄積をLv1で18%、Lv2で25%増加。その間の回避消費は10% / 15%増加。HPダメージまで25%増やす効果にはしません。

### セルヴァルク

閉じた二重帆と長い脚の腱帯が特徴。風属性側を強め、防御基準比0.78を弱点にしました。

「折帆の息継ぎ」は、スタミナ45%以下で敵の接触を回避すると3秒、自然回復速度12% / 20%増加。同時に被ダメージ8% / 10%増加。回避の無敵時間・距離は変えません。

### ヌメラドン

浅皿形の頭と、前面の二室水圧袋を保護する枠を採用。水属性係数1.65、物理基準比0.84。「水皿の蓄え」で、高いスタミナを残した受けから属性攻めへ移る設計です。嚢は刃や打面にせず、支持枠と弁に収めます。

### ミルタセア

「三露の封じ溜め」は、スタミナ85%以上で納刀を完了すると、次の別の命中行動へ属性12% / 16%増加。準備中は被ダメージ8% / 12%増加。持続420tick、再発動待ち900tick。未実装の睡眠道具は要求しません。

## 2. スキルの概念

既存の共通12スキルを継続し、新しいモンスター固有スキル86種類を別枠で加えます。

| 概念 | 条件 | 役割 |
|---|---|---|
| 共通スキル | 各防具に1点。同一キーの合計はLv3まで | 部位の混成で調整 |
| 防具固有スキル | 同一系列の異なる2部位でLv1、4部位でLv2 | 生態に合った戦法を強化 |
| 武器特性 | 装備中の武器1点、条件成立で小さな効果 | 武器だけ採用しても個性を得る |

2部位＋2部位＋自由1部位なら、異なる固有Lv1を2つ使えます。4部位＋自由1部位なら、1つの固有Lv2。武器は部位数へ数えず、5部位目に隠れた倍率は付けません。級違いの同系列も数えます。固有効果の倍率は級によらず同じで、級の上昇は基礎性能と素材加工に反映します。

武器特性は86主題を全7武器種へ適合し、602定義に展開。168定義には、操作や効果を適合した理由を明記しました。たとえばガード不能武器では成功回避、無溜め武器では明示した終端技、環弓の刃消耗軽減は回避消費軽減へ対応させます。

現行の整備道具は研磨石だけで、環弓は使えません。コルドピルの環弓特性は「スタミナ80%以上で納刀完了」へ条件も変更。整備道具起点の防具No20/53/74は、推奨から環弓を除外しています。

## 3. 発動・計算の契約

- 時計は60Hz simulation tick。持続は半開区間。再発動待ちは発動時から数えます。
- 同一行動は同一機構の回数へ1回だけ貢献。多段・複数矢で回数を増殖させません。
- 攻撃用の強化は、起点となった動作そのものへ乗せません。溜め解放や抜刀にも `originActionId` による除外を適用します。
- 次の一撃は、次に当たった別の1行動。空振りでは消費せず、その行動の後続ヒット・矢は最初の命中時のsnapshotを使います。
- 対象限定、被弾・納刀・対象変更による解除、死亡・終了・装備変更での一時状態破棄を定義しました。解除で再発動待ちを払い戻しません。
- 処理済みイベントの遅延再配送は、時計を進める前に除外します。新しい過去tickは順序違反として検出します。
- 成功回避は敵の実際の接触を回避行動の無敵区間で避けた時。入力だけ、復活・転倒後の無敵は対象外です。
- 通常guardとparry/counterを別イベントにし、ガード崩れを成功扱いしません。
- `hit` の状態タグは命中前、`status_inflicted` は今回新しく成立した状態だけを使います。蓄積だけでは発動しません。
- 共通スキル・武器特性・固有効果を同じ百分率チャネルで加算し、上限を一度適用してから対応する項へ一度だけ掛けます。
- 物理、属性、毒/麻痺/睡眠、部位破壊、気絶を分離。部位強化をHPや通常怯みへ重ねません。
- 自動回復、追加攻撃、無敵付与、無償の異常発症、速度改変は今回のDSLへ含めません。

| チャネル | 合算後の範囲 |
|---|---:|
| 物理 | -20〜+12% |
| 属性 / 毒・麻痺・睡眠 | 各 -30〜+20% |
| 部位破壊 | -30〜+25% |
| 気絶 | -30〜+15% |
| 会心加算 | -15〜+15ポイント。最終会心の正上限60% |
| ガード消費 | -30〜+25% |
| 回避消費 | -25〜+25% |
| 刃消耗 | -25〜+40% |
| 自然回復速度 | -25〜+20% |
| 被ダメージ | -12〜+25% |
| 整備道具時間 | -20〜+25% |

刃容量は最大値と段階の境界を同比率で変更。戦闘スタミナ係数は回避・通常ガード・槍counter/hop・弓の溜め維持など実消費へ適用し、sprint・採集・納刀には掛けません。通常攻撃の基礎消費が0でも、代償が実際に効く設計にしています。
