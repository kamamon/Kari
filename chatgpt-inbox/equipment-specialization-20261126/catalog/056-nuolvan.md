## 戦い方

**低体力の受けから整備へ退く水重装**

胸下の濾沼ひげと、腹に分かれた押水室。太いひげで根を押し上げ、食料を濾した水だけを目立つ腹孔から短く放出する。 餌場ではゆっくり歩き、ひげで足元を調べてから進む。根の多い浅瀬を順に巡るが、腹の下に強い刺激があると体を持ち上げて警告する。

HP60%以下で受けを成功→短い耐久窓に整備→回復薬の効果や時間は変えず安全に立て直す。

- 得意：同級基準の物理倍率0.90、会心率-10ポイント。既存のwater属性量を1.40倍。固有技能「濾沼の低水位支度」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.90（同級基準比10%低い。系統補正前）、会心率-10ポイント、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.20倍。弱点耐性は一式でice -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：回復薬の短縮や受けた当の打撃の軽減を期待する運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：濾沼の低水位支度

HP60%以下で受けを成功させ、腹室を畳んで整備へ移る。発動した受け自体は軽減せず、回復量も変えない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から360tick有効、900tick再使用。攻撃への補正は起点と別の次行動から有効。解除しても再使用時間は戻さない。

## 見た目と制作

幅広い胴の胸前だけへ短い濾過房を並べ、低く膨らむ腰の左右に一対の丸い水室。肩は高くせず下側に量を置く。

配色：灰褐 / 泥緑 / 生成り

### 器官の転用

- 胸下の濾沼ひげ→胸前の短い濾し房三束
- 分かれた押水室→腰外側の二つの丸い小室
- 根を持ち上げる太いひげ→短い骨白の前腕縁

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 幅広い刃元の背へ短い濾し房三束と小水室。刃は一続きの硬い灰褐面 |
| 護刃 | 短い濾歯縁の剣と、左右下へ小水室を納めた幅広い硬盾 |
| 大槌 | 閉じた太根甲の二打面と、中央側面の短い三束の濾し縁 |
| 双剣 | 二本の峰に同じ短い濾し房。丸い小室を刃元に一つずつ置く |
| 太刀 | 細い長刃の根元へ短い三本の濾し筋。柔らかな房は鞘の外へ垂らさない |
| 長尖槍 | 太い直槍の根元に短い房筋、盾の左右下側に丸い小室 |
| 環弓 | 中央下へ短い三束の濾し縁を置く。細い弓端、小環と一本弦を水室から離す |

### 級別の形状発達

- 上級：灰褐の広胴と左右二水室。生成りの短房は胸前に三束。
- 極級：水室の外縁へ短い二重留めを置く。濾し房の根だけ淡くし、長さと数を増やさない。

### モデル制作の固定条件

- primaryForm：低い腹の量と二水室
- secondaryForm：胸前の三短房
- dominantRegion：胸下と腰外側
- asymmetry：左右対称の二室
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は胸前三束の根元の小窓。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 濾過房を長い髭や触手にしない
- 水室を肩へ移して高くしない
- 腹甲を股下へ長く垂らさない
