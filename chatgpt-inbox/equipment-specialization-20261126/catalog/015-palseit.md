## 戦い方

**小さな耳膜で一歩を拾う幼帆装**

四〜六頭で向きを違えて立ち、危険を見つけた個体から跳ねる。離された個体はまず群れへ戻ろうとする。

体力を保って一度の接触回避を成功させ、短い回避効率の区間で位置を整える。

- 得意：戦闘スタミナ消費0.90倍、風倍率1.25。高体力の回避成功を守りに変える。
- 代償：基礎物理0.88倍、防御0.80倍。HP75%未満では固有を始められず、成体帆装ほど属性は伸びない。
- 推奨：環弓、双剣、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.88倍、防御0.80倍。HP75%未満では固有を始められず、成体帆装ほど属性は伸びない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：二耳の身寄せ

HP75%以上で接触回避すると、4秒間だけ小さな移動を続けやすくする。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。 回避入力ではなく、敵の攻撃との接触を回避無敵で抜けた成功時だけ判定。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 敵の接触を回避無敵で避けた時 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 75〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 回避消費 -12/-20%、スタミナ自然回復 +6/+10% |

## 見た目と制作

成人の軽い生成り服に、肩後ろの閉じた小耳膜を二枚だけ。長い脚の線を見せ、翼や大帆の量は持たない。

配色：淡い灰緑 / 生成り / 灰茶

### 器官の転用

- 閉じた耳状の幼角膜と未発達の整流孔。風を感じ取れるが、成体ほどの風圧を作れない。
- 閉じた幼角膜を肩後ろの小耳へ縮め、まだ風圧を作れない軽さを維持。
- 群れが危険を先に見つける行動を、高体力の最初の接触回避へ置換。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の根元へ閉じた小耳膜二片を沿わせる薄刃 |
| 護刃 | 細い短刃と、閉じ膜を硬い小盾へ二枚貼る |
| 大槌 | 閉じた硬骨打頭の側面へ小耳膜二片 |
| 双剣 | 小耳の折り筋を峰に一本ずつ持つ二短刃 |
| 太刀 | 細い腱を巻く鍔と、低い折り筋だけの曲刃 |
| 長尖槍 | 幼腱の直槍と、小耳二枚の低い硬盾 |
| 環弓 | 握り横の小耳膜二片。細い弓身、小環と直線弦 |

### 級別の形状発達

- 初級：閉じた二耳を淡い灰緑の小片として置く。
- 中級：耳の縁へ細い象牙線。開いた帆にはしない。
- 上級：足の腱帯を二重にし、耳のサイズは固定。
- 極級：耳の内折りへ細い青銅の点。成体の大帆を足さない。

### モデル制作の固定条件

- primaryForm：細い成人胴着と閉じた二耳
- secondaryForm：腱の縦帯
- dominantRegion：肩後ろ
- asymmetry：二耳は対称、背の大帆はない
- repeatCount：小耳膜2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は肩後ろの二耳の折り。平常：淡い灰緑。発動：回避成功で二つの内折りだけ薄く反射。点灯面積は全身の2%以下。

避ける形：

- セルヴァルクの大帆を小型化して載せない
- 小児の体格にしない
- 背中を翼やマントで覆わない
