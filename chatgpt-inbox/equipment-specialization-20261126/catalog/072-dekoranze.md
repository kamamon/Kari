## 戦い方

**重い右畝で低余力を受ける火重装**

右腹の厚い畝に分かれた蓄熱発酵室。根を分解して得る熱を鉱物層へ保ち、膨らんだ畝から狭い方向へ熱気を逃がす。

通常ガード後の余力が少ない時に右畝を閉じ、受ける痛みを下げる。逃げる前に余力を回復する。

- 得意：基礎攻撃1.12倍、防御1.10倍、刃容量1.30倍。技能中は被ダメージ-8/12%。
- 代償：会心-15、火量0.95倍、回避・ガード等の消費1.20倍。技能中は回避消費+15/20%、水耐性-25。
- 推奨：断岳剣、護刃、長尖槍
- 避けたい状況：不利な運用: 技能中に回避を連打して脱出する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：右畝の閉じ溜め

通常ガード後のHPが50%以上、スタミナ40%以下なら畝を閉じる。重さの代償で回避はさらに重くなる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続420tick、発動時から再使用1020tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

右腰だけ厚い畝皮を段で垂らし、左脚を細く見せる。低い襟と重い腹の水平線。

配色：灰黒 / 灰褐 / 鈍い琥珀

### 器官の転用

- 蓄熱発酵室→右腹から腰への三つの畝
- 鉱物熱層→畝の内側だけの琥珀筋
- 遅い方向転換→低い重心の板割り

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三段の厚畝を峰側へ集めた重剣 |
| 護刃 | 短い厚刃と、右下へ厚みを寄せた閉じた盾 |
| 大槌 | 重い三段畝を側面へ持つ硬い箱槌 |
| 双剣 | 同長二刃の峰へ三つの低い畝、刃先は軽く保つ |
| 太刀 | 刀身下半分の峰だけ厚い畝留めの太刀 |
| 長尖槍 | 太い刃元と細い直先端の槍、右下が厚い独立盾 |
| 環弓 | 畝板を握りの側へ低く収め、細い弓身と小環、一本の直線弦 |

### 級別の形状発達

- 極級：灰黒の厚皮を右腰へ段状に垂らし、左脚は細い甲で軽くする。低い襟と腹側の鈍い琥珀色で巨体を写す。 極級完成形のみ。巨体由来の厚みを右腰と腹へ集中し、左右すべてを重くしない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：厚い畝皮
- secondaryForm：細い左脚
- dominantRegion：右腹と右腰
- asymmetry：右が重い、左は細い
- repeatCount：右畝3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は右腰の畝の内側。平常：鈍い灰黒の皺。発動：畝の奥だけに低い琥珀線が灯る。点灯面積は全身の4%以下。

避ける形：

- 技能中に回避を連打して脱出する運用
- 左右の腰を同じ厚さにする形
- 背へ炎の冠を増やす形
