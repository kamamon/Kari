## 戦い方

**袋の休息を次の睡眠打へ移す装備**

位置のずれた二つの袋肩発酵嚢。食べた草根を分解する共生菌が作る眠り成分を水滴へ移し、肩を縮めた側だけへ霧を出す。

HPとスタミナを保って正式に納刀し、次の一撃に眠りを溜める。発動後の乱打は刃を消耗する。

- 得意：睡眠量1.60倍、蓄えた次行動の睡眠+12/16%。
- 代償：基礎攻撃0.80倍、防御0.82倍、風耐性-30。発動中の消耗+10/18%、HP80%未満では起動しない。
- 推奨：断岳剣、太刀、双剣
- 避けたい状況：不利な運用: HPを削られながら納刀を繰り返す運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：ずれ袋の休息仕込み

正式な納刀完了時にHP・スタミナとも80%以上なら眠り滴を蓄える。武器の自動収納では発動しない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続600tick、発動時から再使用1200tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

左前肩と右後肩の丸い袋を前後にずらし、顔と腰を小さく見せる。袋の間に背の空間が見える。

配色：灰緑 / 灰褐 / 青銅

### 器官の転用

- 袋肩発酵嚢→前後にずれた二つの肩袋
- 袋の口→胸前と肩甲骨側の別々の小栓
- 水滴→袋下の短い灰白溝

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 前袋と後袋を峰の側室へずらした厚刃大剣 |
| 護刃 | 小栓鍔の剣と、前後の丸みを側面で見せる硬盾 |
| 大槌 | 硬い両打面の間に前後ずれた二側室 |
| 双剣 | 同長の短剣二本へ前袋の曲線と後袋の曲線を分ける |
| 太刀 | 鍔元の小側室から細い眠滴溝を通す太刀 |
| 長尖槍 | 直槍の刃元に小袋を内蔵し、盾の裏へ二袋を低く配置 |
| 環弓 | 握り周囲の二小室を前後にずらし、細い弓身・小環・一本の直線弦 |

### 級別の形状発達

- 上級：灰緑の丸い肩を左右で前後にずらし、前袋は胸側、後袋は背側へ寄せる。兜と腰は小さくし、袋の非対称を輪郭の中心にする。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級では袋の容器を内側へ収め、前後のずれを保つ。発酵液の継ぎ目を低く二段化し、外側の袋を巨大化しない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：二つの丸袋
- secondaryForm：細い四肢
- dominantRegion：左前肩と右後肩
- asymmetry：袋を左右の前後へずらす
- repeatCount：袋2、小栓2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は肩袋の二つの小栓。平常：袋に灰緑の皺。発動：前袋の栓から後袋へ小さい白点が移る。点灯面積は全身の4%以下。

避ける形：

- HPを削られながら納刀を繰り返す運用
- 左右同位置の巨大肩球
- 腰や兜にも袋を増やす形
