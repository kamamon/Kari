## 戦い方

**三拍を揃える鈍器装**

普段の音は仲間の位置確認で、見境なく大音量を出すわけではない。狭い正面へ近づく相手にだけ嚢を膨らめて警告する。

頭へ別行動を二回当て、三連嚢の響きを次の打撃群へつなぐ。

- 得意：基礎物理1.08倍、三連嚢の同期で気絶蓄積を強める。
- 代償：会心-10、刃容量0.85倍、戦闘スタミナ消費1.12倍。頭へ当てられないと固有が働かない。
- 推奨：大槌、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。会心-10、刃容量0.85倍、戦闘スタミナ消費1.12倍。頭へ当てられないと固有が働かない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三嚢の重拍

同じ相手の頭へ二回の打撃行動を当てて嚢を同期。気絶を直接付与せず、気絶値を持つ頭打撃の蓄積を増やす。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | blunt, head / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 5秒 |
| 効果（Lv1 / Lv2） | 気絶蓄積 +10/+15%、スタミナ自然回復 +6/+10% |
| 持続 / 再発動待ち | 6秒 / 13秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：一鐘の返響

頭への打撃で一つ目の嚢を鳴らし、次の別行動の正規の気絶蓄積だけを上げる。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

両肩と胸の三つの閉じた共鳴室が、低い鐘頭を囲む三角形。腹腰は布を絞って膨らみを限定。

配色：灰褐色 / 鈍い骨白 / 黄銅色

### 器官の転用

- 胸と両肩に一つずつある三連共鳴嚢。嚢の間の硬い弁を順に閉じると、狭い前方へ低い圧力波を出す。
- 三嚢は必ず胸一つ・肩二つ。武器でも三の拍を閉じた側室に反映。
- 反響で餌を探す生態を頭の打点を二回確認する仕組みへつなぐ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 幅広い刃元に閉じた小鐘室を一つ置く硬骨片刃 |
| 護刃 | 短刃と、中央一嚢を硬板で覆う丸角盾 |
| 大槌 | 硬い両打面の間に三つの閉じた鐘室を横並び。開口打面にしない |
| 双剣 | 刃元の小弁板を左右一つずつ持つ短剣 |
| 太刀 | 細い峰の根元に小さい響室一つ。刃は滑らかな連続線 |
| 長尖槍 | 骨芯の直槍、胸嚢型の丸い硬板を低く収めた盾 |
| 環弓 | 上下弓身の内側に小さな閉じた弁室。小環一つ、直線弦 |

### 級別の形状発達

- 初級：三嚢の硬皮を灰褐色で分け、口縁を薄い骨白に。
- 中級：弁板に鈍い黄銅の線を一周だけ付ける。
- 上級：三嚢を別々の硬い縁で支え、腹の布を広く残す。
- 極級：胸から肩へ細い三本の連結筋。嚢を増やさず体積も抑える。

### モデル制作の固定条件

- primaryForm：三角配置の丸い共鳴室
- secondaryForm：細い連結帯と硬い弁板
- dominantRegion：肩と胸中央
- asymmetry：肩二つは対称、胸を中心軸にする
- repeatCount：主嚢3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は胸と左右肩の弁縁。平常：鈍い骨白。発動：二接触の後に三縁だけ順に琥珀が灯る。点灯面積は全身の5%以下。

避ける形：

- 開口部を銃口のように前へ伸ばさない
- 腕や脚にも主嚢を追加しない
- 大槌の打面を膜や空洞にしない
