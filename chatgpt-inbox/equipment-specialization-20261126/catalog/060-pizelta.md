## 戦い方

**受け止めて氷を置く低姿勢装備**

前へ三葉に開く扇趾冷床。趾の下面へ冷却液を薄く流し、踏みしめた地点だけを凍らせて足掛かりにする。

余力を残してガードし、次の別行動の氷攻撃を置く。追いかける前に姿勢を戻す。

- 得意：氷量1.52倍、防御1.00倍。高スタミナの受けから氷補正10/15%。
- 代償：基礎攻撃0.87倍、消耗1.18倍、火耐性-25。技能中の回避消費+8/12%。
- 推奨：護刃、断岳剣、長尖槍
- 避けたい状況：不利な運用: 回避を連打しながら冷床の利点を使う運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三葉冷床

ガード解決後にもスタミナ65%以上を残すと冷床を定着。氷を強める代わりに足を離す回避が重くなる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続360tick、発動時から再使用900tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

頭・肩を小さくまとめ、三葉に分かれる足先と短い腰布へ輪郭を集中する。

配色：灰青 / 淡灰 / 鈍い青銅

### 器官の転用

- 扇趾冷床→靴の甲上へ低く重なる三葉板
- 冷却液溝→脛から足先へ続く細い内溝
- 短翼→腰の短布にだけ残る筋

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三葉の段差を刃元へ寄せた幅広大剣、刃先は一続き |
| 護刃 | 低い三葉鍔の剣と、三枚が中央で重なる硬い扇盾 |
| 大槌 | 三葉板を側面に積んだ短い槌頭、前後は閉じた打面 |
| 双剣 | 三葉形の低い鍔を対にした短剣二本 |
| 太刀 | 足跡の四角い冷溝を峰へ連続させる細身太刀 |
| 長尖槍 | 三葉の刃元を持つ直槍と、下縁が三段の独立盾 |
| 環弓 | 靴甲の薄い筋を弓身へ移し、小環の下に冷溝を一筋、弦は一本の直線 |

### 級別の形状発達

- 上級：足先に横へ広がる灰青の三葉板を置き、肩と首は短くまとめる。胴は淡い灰色で、翼膜の筋を腰の短い布へ写す。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級では三葉板の接合を二重の低い稜へ変え、足先の横幅は据え置く。冷床の細溝が脛から足先へ連続する。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：低い三葉
- secondaryForm：短い羽皮
- dominantRegion：足先
- asymmetry：左右同形、片足を前に見せる構え
- repeatCount：各足先3葉
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は脛から足先の溝。平常：灰青の溝に白点1つ。発動：足先の三葉へ白点が順に届く。点灯面積は全身の4%以下。

避ける形：

- 回避を連打しながら冷床の利点を使う運用
- 歩幅を変える大きな横張りの靴
- 大きい翼肩や長い首飾り
