## 戦い方

**三つの突きをつなぐ雷の循環装**

後ろ三節の櫂脚に蓄電膜があり、湿った地面を擦ると節ごとに弱い琥珀色が灯る。全てを同時に放たず、先に灯った脚から地面へ電気を渡す。 短い前脚で陸を歩き、後ろの櫂脚で泥を押して体を支える。驚くと後ろから灯りを走らせ、近づく側だけを払う。

同じ敵に突き三行動→雷と回復速度を得る→スタミナを立て直しながら次の突き位置を選ぶ。

- 得意：同級基準の物理倍率0.83、会心率+15ポイント。既存のthunder属性量を1.60倍。固有技能「三櫂の順送り」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.83（同級基準比17%低い。系統補正前）、刃容量0.90倍、刃消耗1.10倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.08倍、防具一式の基準防御力0.81倍。弱点耐性は一式でice -20。形状による当たり判定・リーチの優遇はない。
- 推奨：双剣、太刀、長尖槍、護刃
- 避けたい状況：突きの無い技だけを繰り返す構成。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三櫂の順送り

同じ敵へ三つの別行動の突きを通し、後ろ三節の導膜を順に満たす。突きの入力回数ではなく命中行動数で数える。  240tick以内に異なる行動で3回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | thrust / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 4秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、スタミナ自然回復 +12/+18% |
| 持続 / 再発動待ち | 4秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：櫂節の終灯

終段で後節の灯りを受け渡し、次の別行動の雷を強める。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

## 見た目と制作

低い節板を胸へ沿わせ、腰の後ろだけに三段の横長の櫂板。前は細く短く、後腰で水平の三拍を作る。

配色：暗灰緑 / 琥珀 / 青銅

### 器官の転用

- 後ろ三節の櫂脚→後腰の三段櫂板
- 節別の蓄電膜→各櫂根の一つずつの小窓
- 短い前脚→小さく薄い肩甲

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元に短中長の櫂板を三枚だけ重ねる。刃先側は細い単面 |
| 護刃 | 三節の細剣と、中央下へ三枚の櫂を低く重ねた盾 |
| 大槌 | 槌頭側面に三つの櫂形窓、左右の打面は硬い灰緑の角丸面 |
| 双剣 | 細い二本刃の峰へ三つの短い櫂縁を伏せる。突き先は連続させる |
| 太刀 | 峰に三節の細い青銅線を通し、刃元だけ小さな櫂鍔を付ける |
| 長尖槍 | 直槍の刃元に三つの低い櫂節、盾下縁へ三段の櫂板を収める |
| 環弓 | 中央下へ短い櫂板三枚を重ねる。小環の位置を上に保ち、一本弦へ板を触れさせない |

### 級別の形状発達

- 中級：暗灰緑の櫂三枚と小さい琥珀点三つ。前胸は低い節だけ。
- 上級：各櫂の外周に青銅の短い縁を増し、根元の線を三つ独立させる。
- 極級：櫂の裏面に細かい膜目を見せる。点灯面を増やさず、三櫂の段差を明確にする。

### モデル制作の固定条件

- primaryForm：後腰の三櫂
- secondaryForm：前側の薄い節
- dominantRegion：後腰
- asymmetry：左右対称、後ろのみ三櫂
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は後腰三櫂の根元の琥珀点。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 胸や肩にも大きな櫂を付けない
- 櫂板を長い尾にしない
- 雷を常時全身に走らせない
