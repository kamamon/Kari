## 戦い方

**三梁へ溜めを通す部位崩し装備**

背の前半を横に渡る三本の中空梁骨と、その下の圧気嚢。梁の隙間をずらして空気の出口を作り、片側ずつ短い風圧を放つ。

三つの異なる溜め行動を解放し、圧気が揃う短時間に部位破壊と息継ぎを得る。

- 得意：基礎攻撃1.02倍、風量1.22倍。技能で部位+18/25%とスタミナ回復+12/18%。
- 代償：会心-10、回避・ガード・溜め維持等の消費1.16倍、氷耐性-25。溜めのない武器では固有技能を起動できない。
- 推奨：断岳剣、大槌、環弓
- 避けたい状況：不利な運用: 溜め不能の武器で固有技能を主力にする運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三梁の吸気揃え

600tick内に1段階以上の溜めを異なる3行動で解放する。溜め中の各tickは回数に含めない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続300tick、発動時から再使用900tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 1段以上の溜め解放 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 10秒 |
| 効果（Lv1 / Lv2） | 破壊・切断蓄積 +18/+25%、スタミナ自然回復 +12/+18% |
| 持続 / 再発動待ち | 5秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |

### 武器主題（Lv1固定）：梁端の締め圧

締めの命中後、次の別行動へ梁端の圧を渡す。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続180tick、発動時から再使用540tick。

## 見た目と制作

首の後ろに横長の三本中空梁を低く重ね、後腰を短く切る。穴は梁端だけに見せる。

配色：灰緑 / 灰褐 / 鈍い青銅

### 器官の転用

- 中空梁骨→低い襟後ろの三本梁
- 圧気嚢→梁下の薄い柔皮室
- 左右の出口→梁端の小さい開口

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三本梁を峰へ低く束ねた大剣、切先は一本 |
| 護刃 | 三段鍔の剣と、硬い裏板上へ三梁を置く盾 |
| 大槌 | 三つの梁端を側面に見せる硬い両打面槌 |
| 双剣 | 二短剣の峰へ三本の低い稜を同じ位置に配置 |
| 太刀 | 刀身の刃元へ三梁の細い留めを置く太刀 |
| 長尖槍 | 直槍の刃元を三稜で支え、独立盾へ低い三梁 |
| 環弓 | 握り近くの三つの留めと小環、上下弓身は細く一本の直線弦 |

### 級別の形状発達

- 極級：灰緑の低い襟に横長の三本骨を重ね、後ろ腰を短くする。穴の縁だけ鈍い青銅色を見せる。 極級完成形のみ。三本の横骨と中空の開口を低く見せ、巨大な肩梁は付けない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：三本の横梁
- secondaryForm：短い後腰
- dominantRegion：襟の後ろ
- asymmetry：左右の梁端は同形
- repeatCount：横梁3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は三本梁の端穴。平常：暗い穴の青銅縁。発動：穴の内縁に三つの白点が順に灯る。点灯面積は全身の4%以下。

避ける形：

- 溜め不能の武器で固有技能を主力にする運用
- 梁を六本以上に増やす形
- 盾面全体を貫通する大穴
