## 戦い方

**追い詰められた足を立て直す氷装備**

後踵の裏に並ぶ刻氷蹄板。細い溝へ冷却液を流して足元だけを固め、固まった小さな板を踏み弾いて進路を作る。

HP半分以下で敵の接触を回避し、軽い回避と氷補正を使って位置を戻す。回復そのものは発生しない。

- 得意：氷量1.38倍、会心20、回避等の消費0.90倍。窮地の回避消費-15/20%。
- 代償：基礎攻撃0.89倍、防御0.83倍、雷耐性-30。HP50%を越えると固有技能を新たに起動できない。
- 推奨：太刀、双剣、環弓
- 避けたい状況：不利な運用: 低HPのまま被弾を受けて技能を維持する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：刻蹄の窮地踏み替え

HP50%以下で敵の接触を回避した時だけ足元を整える。無敵時間やHP回復は増やさない。 回避入力ではなく、回避無敵中に敵攻撃の接触を避けた成功だけを数える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続300tick、発動時から再使用900tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 敵の接触を回避無敵で避けた時 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜50% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 回避消費 -15/-20%、属性ダメージ +8/+12% |
| 持続 / 再発動待ち | 5秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken, sheathe。再発動待ちは戻さない |

### 武器主題（Lv1固定）：踵溝の返り氷

背側から当てた後の氷攻撃を強め、踵を向けた退路をなぞる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続300tick、発動時から再使用720tick。

## 見た目と制作

肩を絞り、厚い腰から後踵へ低く曲がる線を落とす。四角い溝を足先へ集める。

配色：灰青 / 淡灰 / 青銅

### 器官の転用

- 刻氷蹄板→既存靴の内に収まる後曲がり踵甲
- 冷却溝→四角い刻みを足甲へ配列
- 後脚の力→腰だけ厚い灰青の板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 踵の低い反りを峰へ、刃先はまっすぐに収める大剣 |
| 護刃 | 四角溝の剣と、下縁だけ低く反る硬盾 |
| 大槌 | 踵板を束ねた四角い硬頭、打面は平ら |
| 双剣 | 同じ低反りを持つ二短剣、溝は峰側のみ |
| 太刀 | 後踵線を写す浅い反りの太刀 |
| 長尖槍 | 四角溝の直槍と、下方へ重心を置いた独立盾 |
| 環弓 | 踵の低い曲線を上下の細い弓身へ、小環と一本の直線弦 |

### 級別の形状発達

- 上級：後ろへ低く曲がる踵板を脚に写し、四角い溝を足先へ刻む。肩を細く、灰青の腰だけを厚くして後脚の強さを示す。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級では刻印の溝を二筋にして冷却経路を分ける。踵の突出を増やさず、四角い打面の縁だけを厚くする。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：低く曲がる踵
- secondaryForm：四角い溝
- dominantRegion：腰と足先
- asymmetry：肩は対称、後腰へ重さを集める
- repeatCount：各足甲の刻み4
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は踵から足先の刻み。平常：暗い灰青の四角。発動：四角溝の内側だけ白く曇る。点灯面積は全身の4%以下。

避ける形：

- 低HPのまま被弾を受けて技能を維持する運用
- 踵が接地外形を越えて突き出す靴
- 肩や頭へ大きな氷柱を増やす形
