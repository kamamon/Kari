## 戦い方

**三滴を次の氷の一手へ順に通す装備**

尾の手前に三つ並ぶ冷滴嚢。鉱泉の水を冷却液と混ぜて滴として保ち、嚢を絞る順に小さな氷塊へして落とす。

同じ弱点へ三つの別行動を丁寧に通し、次の氷攻撃と軽い回避で距離を整える。

- 得意：氷量1.82倍、会心20、消費0.92倍。次行動の氷+10/16%、回避消費-10/16%。
- 代償：基礎攻撃0.80倍、防御0.76倍、刃容量0.88倍、消耗1.22倍、火耐性-30。被弾・対象変更で三滴が崩れる。
- 推奨：太刀、環弓、双剣
- 避けたい状況：不利な運用: 多段技一回だけで三行動を満たす運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三滴の順通し

300tick内に同じ対象の弱点へ3行動を命中させて冷滴を揃える。次の別行動へ氷を渡し、消費されるまで回避の負担も軽くする。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続300tick、発動時から再使用900tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | weakspot / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、回避消費 -10/-16% |
| 持続 / 再発動待ち | 5秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | あり / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：冷滴の退き芯

回避後もスタミナ60%以上を保つと、次の別行動へ冷滴の芯を渡す。 回避入力ではなく、回避無敵中に敵攻撃の接触を避けた成功だけを数える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続180tick、発動時から再使用600tick。

## 見た目と制作

滑らかな背と細い灰青の胴。三つの短い雫を後腰だけへ並べ、肩と頭を平らに保つ。

配色：灰青 / 白灰 / 鈍い青銅

### 器官の転用

- 三つの冷滴嚢→後腰の短い三滴
- 滴を絞る順序→三滴を左から順に読む間隔
- 滑らかな背→継ぎ目を抑えた薄い背甲

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三滴の小室を刃元の峰へ並べる細幅大剣 |
| 護刃 | 三点鍔の剣と、下縁に短い三滴を刻む硬盾 |
| 大槌 | 槌頭側面に三つの小室、前後は硬く閉じた打面 |
| 双剣 | 同長二短剣の峰に三点ずつの冷溝、滴を長く垂らさない |
| 太刀 | 三つの低い滴室を鍔元へ寄せた細い太刀 |
| 長尖槍 | 直槍の刃元に三点の低い室、盾の下縁へ短い三滴 |
| 環弓 | 三つの小室は握りの後ろへ、小照準環と一本の直線弦を空ける |

### 級別の形状発達

- 極級：背は灰青の滑らかな面にし、腰の後ろだけ三つの短い雫形を下げる。肩や頭には大きな氷板を付けない。 極級完成形のみ。三つの雫を後腰へ限定し、肩や頭へ大きな氷板を増やさない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：滑らかな背
- secondaryForm：短い三滴
- dominantRegion：後腰のみ
- asymmetry：三滴は中央に等間隔、肩は平ら
- repeatCount：後腰の雫3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は後腰の三つの雫の根元。平常：三つとも灰青。発動：三つの小点が左から順に白く曇る。点灯面積は全身の4%以下。

避ける形：

- 多段技一回だけで三行動を満たす運用
- 肩や兜へ大きい氷板を追加する形
- 三滴を胸前や左右の肩へ移す形
