## 戦い方

**二度のため解放で火と整備をつなぐ**

氷帆の冷却組織から変化した蒸帆熱嚢。温かい晶脈から蓄えた熱と餌由来の樹脂を、後ろへ伏せた帆の溝で分けて送る。 キリサーヴから温暖な晶脈帯へ適応し、冷却より蓄熱が優位になった亜種である。露頭と低木地を巡り、まず帆を起こして余熱を見せる。

二つのため解放→次の別行動から火を強める→短縮された整備時間を使って刃を戻す。

- 得意：同級基準の物理倍率0.89、会心率-5ポイント。既存のfire属性量を1.70倍。固有技能「蒸帆の二度伏せ」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.89（同級基準比11%低い。系統補正前）、会心率-5ポイント、刃容量0.85倍、刃消耗1.30倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.15倍、防具一式の基準防御力0.85倍。弱点耐性は一式でwater -20。形状による当たり判定・リーチの優遇はない。
- 推奨：断岳剣、大槌
- 避けたい状況：ためを持たない武器での固有技能運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：蒸帆の二度伏せ

二度のため解放で板帆を伏せ、熱を火属性へ渡す。短い整備の窓を作るが、ためを放った当の行動には火を足さない。 1段階以上ためて放った行動だけ。ため中のtickは数えない。 480tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 1段以上の溜め解放 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 8秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、整備使用時間 -12/-20% |

### 武器主題（Lv1固定）：蒸帆の残圧

ためを放って帆を伏せた後に、残圧を次の別行動へ渡す。 1段階以上ためて放った行動だけ。ため中のtickは数えない。 300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

## 見た目と制作

肩から背へ伏せた三枚の板帆が後ろへ流れ、胸下だけが暗い嚢で膨れる。全体を低く長く見せ、上へ棘を出さない。

配色：灰銅 / 暗灰 / 鈍琥珀

### 器官の転用

- 後ろへ伏せる蒸帆→背の三枚の低い重ね板
- 胸下の熱嚢→下胸の一つの暗灰の厚み
- 分かれた熱溝→板帆裏の短い琥珀線

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の三枚板を後ろ向きに寝かせた長い平刃。刃元の下に小さな嚢覆い |
| 護刃 | 低い後傾帆の鍔を持つ剣と、三枚を下後ろへ重ねた硬い盾 |
| 大槌 | 槌頭の上側へ三枚の低い板帆、下側に閉じた小嚢。両打面は硬面 |
| 双剣 | 二本とも峰の板を後ろへ伏せ、刃元の小嚢を同じ大きさにする |
| 太刀 | 細い連続刃の峰を後ろ向きの三段線で区切る。鞘は滑らか |
| 長尖槍 | 直槍の根元へ後傾の三小帆、盾は上が薄く下が厚い嚢形面 |
| 環弓 | 中央の背側へ三枚の小帆を伏せる。弓端を細く保ち、一本弦と小環を帆へ埋めない |

### 級別の形状発達

- 上級：灰銅の三帆は低く後ろ向き、胸下は暗灰。琥珀は板裏の短い溝。
- 極級：板帆の根元を短い二重縁で締める。嚢と脚に棘を足さず、後ろへの流れを維持。

### モデル制作の固定条件

- primaryForm：後ろへ伏せた三板
- secondaryForm：下胸の一嚢
- dominantRegion：背と下胸
- asymmetry：左右対称、上薄下厚
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は三板帆裏の琥珀溝。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 帆を上へ高く立てない
- 原種の氷色の棘を付けない
- 胸嚢を金属の大砲口にしない
