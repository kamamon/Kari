## 戦い方

**浅皿の水を戻す幼泥装**

三〜六頭で同じ泥筋を歩き、互いの頭皿へ水が跳ねる距離を保つ。乾き始めると群れごと水場へ向かう。

軽い一撃を受けて生き残った後に一度落ち着き、短い守りと呼吸で立て直す。

- 得意：水倍率1.20、防御1.04倍。HP60%以上を保った直撃後の立て直し。
- 代償：基礎物理0.87倍、刃容量0.82倍。HP60%未満の大きい損傷には固有が働かない。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.87倍、刃容量0.82倍。HP60%未満の大きい損傷には固有が働かない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：幼皿の水戻し

敵の直接・非ガードの非致死被弾後、HP60%以上なら4秒だけ姿勢を整える。HPを回復する効果ではない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 生存する直接非ガード被弾 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 60〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 被ダメージ -6/-10%、スタミナ自然回復 +8/+12% |
| 持続 / 再発動待ち | 4秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | sheathe。再発動待ちは戻さない |

### 武器主題（Lv1固定）：浅水の留め

通常ガードから次の別行動の水属性を小さく支える。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

浅い丸皿を前腰一か所に置き、腹の生成り皮が見える成人の作業軽装。肩は低く、前腰だけ丸い。

配色：淡い泥褐 / 生成り皮 / 灰緑

### 器官の転用

- 浅い頭皿に通じる一対の幼水圧嚢。少量の水を保持でき、泥玉は近距離の小粒に留まる。
- 幼体の低い頭皿を前腰の一皿に移し、腹側の薄皮を成人の腹巻へ。
- 互いの皿へ水を戻す小さな群れの動きを、軽い損傷後の呼吸へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 浅い水溝を刃元だけへ持つ薄い大剣 |
| 護刃 | 幼冠甲の短刃と、浅い丸皿の軽い硬盾 |
| 大槌 | 小さな閉じた泥骨打頭。下面に幼嚢二つ |
| 双剣 | 短刃の根元へ水溝一筋ずつ、先端は揃える |
| 太刀 | 耐水皮を巻いた鍔と、低い水溝の曲刃 |
| 長尖槍 | 小皿状の留めを持つ直槍と、低い丸盾 |
| 環弓 | 弓の握り下に小さな浅皿。細い弓身、小環、直線弦 |

### 級別の形状発達

- 初級：一つの丸皿を浅くし、生成り腹皮を広く見せる。
- 中級：皿の縁に灰緑の細線。頭を深い皿兜にしない。
- 上級：腹皮の横重ねを三層に整える。
- 極級：前皿の内縁を二重に磨く。大きな貯水槽は足さない。

### モデル制作の固定条件

- primaryForm：一つの低い前腰皿
- secondaryForm：生成りの横重ね皮
- dominantRegion：前腰と腹
- asymmetry：前のみ丸い、背は平たい
- repeatCount：主皿1、幼嚢覆い2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は前腰皿の内縁。平常：淡い泥褐。発動：軽い直撃後に内縁だけ濡れ色へ変わる。点灯面積は全身の2%以下。

避ける形：

- 成体の前重装をそのまま縮小しない
- 丸皿を頭肩脚へ大量反復しない
- 小児服の比率にしない
