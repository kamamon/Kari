## 戦い方

**毒が入った未破壊部位を見届ける装備**

後縁の扁甲に沿う濾霧鰓と、口房の毒粘腺。湿った空気を鰓で集め、口房を絞ると毒の滴を含む低い霧へ変える。

まず毒を入れ、毒中の未破壊部位へ二行動を通して崩す。安全な横位置へ移る手を残す。

- 得意：毒量1.48倍、防御1.03倍、刃容量1.20倍。条件成立後の部位+18/25%。
- 代償：基礎攻撃0.86倍、会心-5、消耗1.18倍、消費1.10倍、風耐性-25。技能中の被ダメージ+8/12%。
- 推奨：護刃、双剣、太刀
- 避けたい状況：不利な運用: 毒になっていない相手だけを殴って固有技能を狙う運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：毒房の見届け

毒中の同じ対象の未破壊部位へ240tick内に2行動を通す。毒の成立そのものを無料で起こさず、部位補正と被弾の代償だけを付ける。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続480tick、発動時から再使用960tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | poisoned, unbroken / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 4秒 |

## 見た目と制作

後腰だけ横へ広い扇甲、襟から短い二房。腕を同寸に保ち、胸を平らにする。

配色：灰紫 / 灰褐 / 青銅

### 器官の転用

- 霧扁甲→後腰の短い扇甲
- 毒口房→襟から下がる短い二房
- 濾霧鰓→扇甲の後縁の細い襞

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 扇甲の低い弧を峰へ寄せる幅広大剣 |
| 護刃 | 双房の短い鍔の剣と、後扇の弧を写した硬盾 |
| 大槌 | 短い二房は側室へ、前後は硬く閉じる槌 |
| 双剣 | 二本房の細線をそれぞれの峰へ写す同長二短剣 |
| 太刀 | 後扇の浅い反りを低い峰へ写す太刀 |
| 長尖槍 | 直槍の刃元に短い二房縁、扇形の閉じた独立盾 |
| 環弓 | 扇筋を細い上下弓身へ、握りに二短溝、小環と一本の直線弦 |

### 級別の形状発達

- 極級：灰紫の扇形板を腰の後ろだけ広げ、襟から二本の短い房を下げる。腕は左右同じ大きさにまとめる。 極級完成形のみ。後腰だけの扇幅と左右同寸の腕を維持し、長い房は付けない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：短い後扇
- secondaryForm：二本房
- dominantRegion：後腰と襟
- asymmetry：腕は左右同寸、広がりは後腰のみ
- repeatCount：襟房2、主扇甲1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は襟の二本房の根元。平常：暗い灰紫の対点。発動：二つの小点が交互に紫灰へ曇る。点灯面積は全身の4%以下。

避ける形：

- 毒になっていない相手だけを殴って固有技能を狙う運用
- 左右で大きさの違う腕甲
- 襟房を胸下まで垂れる長い紐へ変える形
