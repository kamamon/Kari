## 戦い方

**蓋を開ける一手を選ぶ火力装備**

頭上の帽殻に分かれた温胞房。上房で眠り胞子を育て、左右の熱房では少量の樹脂を酸化させ、蓋を開く順で胞子と熱粒を送り分ける。

納刀で熱を逃がし、抜刀後の別行動へ火を載せる。蓋を開いたまま乱打せず研ぐ。

- 得意：火量1.72倍、抜刀後の火+10/16%。
- 代償：基礎攻撃0.82倍、防御0.86倍、刃容量0.76倍。技能中は消耗+12/18%、水耐性-30。
- 推奨：太刀、断岳剣、双剣
- 避けたい状況：不利な運用: 発動中の消耗を無視して長時間乱打する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三蓋の開炉

抜刀完了時にスタミナ70%以上なら帽房を開く。抜刀攻撃そのものには乗らず、次の別行動へ火をまとめる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続240tick、発動時から再使用660tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 抜刀完了 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 70〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、刃消耗 +12/+18% |
| 持続 / 再発動待ち | 4秒 / 11秒 |
| 1行動消費 / 同じ個体への限定 | あり / なし |
| 解除 | damage_taken, sheathe。再発動待ちは戻さない |

### 武器主題（Lv1固定）：帽房の熱粒

同じ頭部へ異なる2行動を当て、熱粒を逃さず次の火攻撃へ送る。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続180tick、発動時から再使用540tick。

## 見た目と制作

三枚の帽殻を額上で横にずらし、背から腰へ細い節を一本だけ通す。片胸の小室が火の中心。

配色：灰褐 / 琥珀 / 青銅

### 器官の転用

- 温胞房→片胸の小さな熱室
- 帽殻の三蓋→兜のずらした三枚帽
- 細節腹→背から腰へ続く一条の節

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三蓋の段差を峰の刃元へ重ね、前端は一枚の火刃 |
| 護刃 | 帽縁を鍔へ写す剣と、三枚がずれた硬い低盾 |
| 大槌 | 帽殻を横へ積む硬い槌頭、琥珀室は側面の小窓だけ |
| 双剣 | 三枚の帽縁を各刃の峰に小さく配した二短剣 |
| 太刀 | 薄い帽の段差を鞘口と鍔へまとめ、刀身は細い連続刃 |
| 長尖槍 | 三つの浅い節輪を刃元に置いた直槍と、小熱室付き独立盾 |
| 環弓 | 三枚の低い薄片を握り上の小環周囲だけへ、弓身は細く一本の直線弦 |

### 級別の形状発達

- 上級：灰褐色の低い帽殻を兜へ三枚ずらし、背から腰は細い節でつなぐ。小さな琥珀色の熱房を片胸にだけ置く。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級で帽殻の縁に狭い放熱孔を増やす。火を噴く装飾は付けず、片胸の琥珀色の範囲を保つ。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：三枚のずれた低帽
- secondaryForm：細い背節
- dominantRegion：額と片胸
- asymmetry：熱室は右胸だけ
- repeatCount：帽殻3、熱室1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は右胸の熱室内縁。平常：暗い琥珀点が一つ。発動：三枚の蓋の縁に細い琥珀筋が順に点く。点灯面積は全身の4%以下。

避ける形：

- 発動中の消耗を無視して長時間乱打する運用
- 全身を炎で覆う発光表現
- 帽殻を高い冠や大きい笠にする形
