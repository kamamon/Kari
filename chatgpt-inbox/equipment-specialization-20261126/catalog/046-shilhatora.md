## 戦い方

**背面の三行動で部位と息をつなぐ**

ルミスカの尾節が枝分かれした枝燐導条。三本を別々に帯電させ、翼の送風で短い放電路を順に変える。 尾の再生時に導電節が三枝へ分かれたルミスカの希少個体である。岸の餌場を徒歩で巡り、短い滑空も着地できる近い砂州へ限る。

背面へ三つの別行動→部位攻撃とスタミナ回復→細い刃が摩耗する前に接近し直す。

- 得意：同級基準の物理倍率0.82、会心率+15ポイント。既存のthunder/wind属性量を1.70倍。固有技能「三枝の背風渡り」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.82（同級基準比18%低い。系統補正前）、刃容量0.72倍、刃消耗1.40倍、防具一式の基準防御力0.76倍。弱点耐性は一式でice -20。形状による当たり判定・リーチの優遇はない。
- 推奨：双剣、太刀、環弓
- 避けたい状況：正面固定の盾運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三枝の背風渡り

敵の背面へ三行動を通し、三枝の導条に順を付ける。部位破壊と息継ぎで背後を保ち、正面の火力勝負では条件を満たさない。  300tick以内に異なる行動で3回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

細い胴と低い肩膜に対し、後腰の三枝だけが短く分かれる。枝は水平に近く、胸と頭へ大きな角を付けない。

配色：灰青 / 青銅 / 小さい琥珀点

### 器官の転用

- 三枝の尾節→後腰の短い三分枝
- 枝燐導条→三枝それぞれの小さい琥珀点
- 短い送風翼→低い肩膜二枚

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元を三つの短い枝節へ分け、先の連続刃は一本のまま |
| 護刃 | 三分枝の低い鍔を持つ細剣と、下縁に短い三枝節を収めた盾 |
| 大槌 | 側面に三枝の導条を伏せた閉じた槌頭。枝の先を打面へ出さない |
| 双剣 | 二本の峰の根元に同じ三枝模様。分かれた刃先を作らない |
| 太刀 | 細い長刃の峰へ三つの短い節線。鞘口の小鍔だけ三分枝 |
| 長尖槍 | 直槍の穂は一本、根元だけ短い三枝節。盾下側へ三つの小節を置く |
| 環弓 | 中央から三つの小節が短く開く骨弓。主弓身は二本の細い枝と一本弦、小環を保つ |

### 級別の形状発達

- 上級：灰青の細身に後腰三枝。青銅は枝の節を細く囲み、琥珀点は三つだけ。
- 極級：三枝の各節へ独立した小さい導条窓。枝の長さを増やさず、肩膜を低く保つ。

### モデル制作の固定条件

- primaryForm：後腰の短い三枝
- secondaryForm：細い胸骨線
- dominantRegion：後腰
- asymmetry：左右の枝を同高にし中央枝を短くする
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は後腰三枝の琥珀点。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 三本の長い尾を引きずらない
- 槍や剣の刃先を三又にしない
- 雷の大きな翼を追加しない
