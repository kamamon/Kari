## 戦い方

**三節の額で頭を見届ける打撃装備**

筋で繋がった三節の連額甲と、その下の蓄電粘膜。額甲を順番に開いて電荷を表へ移し、開いた節の正面へ短い痺電を出す。

同じ頭を異なる三行動で狙い、会心と気絶蓄積が上がる時間に硬い打撃を通す。

- 得意：会心10、雷量1.10倍。頭狙いを続けると会心+8/12・気絶+10/15%。
- 代償：基礎攻撃0.96倍、防御0.91倍、刃容量0.82倍、消耗1.25倍、水耐性-25。気絶補正は有効な打撃頭部命中だけ。
- 推奨：大槌、護刃
- 避けたい状況：不利な運用: 打撃を持たない系統で気絶補正を主力にする運用

### 防具固有：連額の三節見届け

420tick内に同じ頭へ3行動を当てて三節の額を開く。気絶補正は大槌や護刃の打撃など既存の気絶判定を持つ命中にだけ使う。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続360tick、発動時から再使用840tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

三節の低い額甲を左右へ短く張り、胸と脚は細くする。後腰だけ短い折甲。

配色：灰褐 / 灰黒 / 青銅

### 器官の転用

- 連額甲→三節に分かれた低い額
- 蓄電粘膜→額内縁の青銅線
- 閉じ直す動き→節間の柔らかな暗い隙間

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三節額を峰の刃元へ低く重ねた大剣 |
| 護刃 | 三節鍔の剣と、額の横線を写した硬盾 |
| 大槌 | 三つの低い側節と閉じた硬い両打面を持つ槌 |
| 双剣 | 同長二刃の峰へ三節の低い段差 |
| 太刀 | 額の内縁を細い鍔と峰溝へ写す太刀 |
| 長尖槍 | 三節の刃元から伸びる直槍と低い横額盾 |
| 環弓 | 握り近くに三節の低い留め、小環と一本の直線弦 |

### 級別の形状発達

- 極級：灰褐色の三節額を兜の左右へ低く張り、後ろ腰には短く折れた甲を置く。額の内縁だけ青銅色を見せる。 極級完成形のみ。額の内縁の青銅だけを強調し、三節を高い角へ変えない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：三節の額
- secondaryForm：短い折腰
- dominantRegion：額
- asymmetry：額甲は左右へ低く、後腰は中央
- repeatCount：額の連続節3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は額甲の内縁。平常：鈍い青銅の細線。発動：三節が順に点き、外面は暗いまま。点灯面積は全身の4%以下。

避ける形：

- 打撃を持たない系統で気絶補正を主力にする運用
- 額を高い三本角へ変える形
- 気絶補正を物理ダメージへ二重加算すること
