## 戦い方

**燐節を一列に整える精密装**

警戒すると尾節を順に点灯させ、逃げ道のある方へ身を向ける。追い詰められた時だけ放電し、翼で空中に留まり続けない。

弱点へ別行動を二度通し、次の連携を雷の放電区間にする。

- 得意：会心+25、雷倍率1.50。弱点への反復で雷を集中。
- 代償：基礎物理0.83倍、防御0.78倍、刃容量0.78倍。固有中は戦闘の守りがさらに薄い。
- 推奨：環弓、太刀、双剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.83倍、防御0.78倍、刃容量0.78倍。固有中は戦闘の守りがさらに薄い。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：燐節の順放ち

同じ相手の弱点へ二つの別行動を通すと、雷の蓄積区間が開く。反撃を受けると解除。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | weakspot / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 4秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、被ダメージ +8/+12% |
| 持続 / 再発動待ち | 5秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change。再発動待ちは戻さない |

## 見た目と制作

前面は細い青灰革、背骨の下へ太さの違う燐節を五つ連ねる。長い尾そのものは付けない。

配色：青灰 / 琥珀の点光 / 濃茶

### 器官の転用

- 尾の節ごとに蓄電層と鈍い燐光板をもつ燐節器。電気を出す節から先に光り、尾先と地面の間に短い放電路を作る。
- 太い尾節を背骨の五つの節窓へ縮め、装備の後方への張り出しを削る。
- 順に光る尾の予告を、弱点二接触の後に短く開く雷区間へ置換。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰側の刃元へ五つの低い節窓を埋める細い大剣 |
| 護刃 | 細い雷筋の短刃と、片側に節窓五点を並べた小盾 |
| 大槌 | 閉じた硬い打面、頭の上面に五節窓を埋めた横槌 |
| 双剣 | 二本とも峰に二小節、鍔の共通意匠に一小節 |
| 太刀 | 連続曲刃の峰に五点の小さい燐節を埋め込む |
| 長尖槍 | 長い直芯の根元へ節窓、細長い盾に五点の列 |
| 環弓 | 上側弓身の根元へ五つの小節。細い小環と直線弦 |

### 級別の形状発達

- 初級：五節は不透明な青灰、窓の琥珀は細点。
- 中級：節の間に濃茶の革間隔を明瞭に残す。
- 上級：最下節だけ一段大きくし、上の四節は細くする。
- 極級：五節の内側を二重縁にする。大型の尾や翼は付けない。

### モデル制作の固定条件

- primaryForm：細身の縦軸と五つの節
- secondaryForm：小さい燐板窓
- dominantRegion：背骨下部
- asymmetry：節は背中心、前面には列を作らない
- repeatCount：主要燐節5
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背骨の五節窓。平常：鈍い琥珀の点。発動：二接触後に上から下へ一度だけ点灯。点灯面積は全身の5%以下。

避ける形：

- 全身を青い稲妻で覆わない
- 長い尾状の装飾を追加しない
- 節を等間隔同寸の機械電池にしない
