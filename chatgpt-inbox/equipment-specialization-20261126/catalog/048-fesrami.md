## 戦い方

**毒を付けた敵の部位へ張り付く糸装**

左右の羽袋が一つの結節でつながった結絹胞。毒を含む細い霧糸を三本ずつ吐き、結び目の膨らみで射出順が分かる。 ヴェリトの羽袋が成長時に連結した希少個体である。根の回廊を巡って古い糸を食べ直し、侵入者には胸の結節を膨らませる。

毒を新しく付与→同じ敵の部位へ張り付く→被ダメージ増の窓は回避位置を優先する。

- 得意：同級基準の物理倍率0.81、会心率+10ポイント。既存のpoison蓄積量を1.60倍。固有技能「結節に残る毒糸」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.81（同級基準比19%低い。系統補正前）、刃容量0.82倍、刃消耗1.42倍、防具一式の基準防御力0.78倍。弱点耐性は一式でwind -20。形状による当たり判定・リーチの優遇はない。
- 推奨：双剣、太刀、護刃
- 避けたい状況：毒を付けた後に別の敵へ移る運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：結節に残る毒糸

自分が新たに毒を付与した相手へ部位攻撃を続ける。糸袋を開く間は被ダメージも増えるため、毒を付けて直ぐ安全圏へ離れるだけでは活かせない。 今回新しく付与した状態だけをタグにする。既に付いていた状態は数えない。 300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から420tick有効、900tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 状態異常を新しく発症させた時 |
| 必須タグ / いずれかのタグ | poisoned / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 破壊・切断蓄積 +18/+25%、被ダメージ +8/+12% |
| 持続 / 再発動待ち | 7秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：結絹の毒筋

毒が付いている敵を糸筋の目印にして次の一撃を狙う。毒の継続ダメージ自身は増えない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |

| HP / スタミナ残量 | 0〜100% / 0〜100% |

## 見た目と制作

左右の小袋が胸上で一つの高い結節へ寄る。肩を翼にせず袋を内側へ集め、後腰の三房だけを短く分ける。

配色：淡灰紫 / 糸白 / 暗灰

### 器官の転用

- 連結した結絹胞→胸上の一つの結節
- 左右の羽袋→肩から胸へ寄る二つの小袋
- 三房の糸尾→後腰の短い糸房三つ

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元に二つの小袋が一節で結ばれる形。刃側は暗灰の連続硬面 |
| 護刃 | 結節の小鍔を持つ剣と、中央上で二袋を結んだ硬い小盾 |
| 大槌 | 二つの袋を閉じた硬面の内側へ納める槌頭。中央の結節は側面だけ |
| 双剣 | 二本の峰へ小さい結節を同寸で一つずつ。糸を刃から垂らさない |
| 太刀 | 細い長刃の根元に一つの低い結び節。白い糸筋を峰へ平らに沿わせる |
| 長尖槍 | 直槍の根元へ一つの結節、盾上に二袋・下に短い三本糸筋 |
| 環弓 | 中央の二袋を一つの結節で結ぶ細い弓。弦は糸房と分けた一本直線、小環を一つ |

### 級別の形状発達

- 上級：淡灰紫の二袋を一つの胸節で結ぶ。糸白の三房を短く保つ。
- 極級：結節の暗灰覆いを二重縁にし、三房の根に細い毒色点。結び目の数と袋の量は変えない。

### モデル制作の固定条件

- primaryForm：胸上の一結節
- secondaryForm：後腰の三短房
- dominantRegion：胸上
- asymmetry：左右の袋は一つの中央節へ集める
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は胸上結節の短い縫い目。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 胸に結節を三つ並べない
- 糸を足首まで長く垂らさない
- 袋を巨大な蝶の翼へ広げない
