# 042 グラセドン — 裂扇

原種ID `monster.grasedon`。上級〜極級。 [JSON原本](../data/species/042-grasedon.json) / [全級の装備・レシピ](../data/equipment/042-grasedon.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**部位破壊を境に火力を解放する裂扇装**

長年の晶脈摂取で左背の岩板にだけ育つ裂扇炉。隙間の共生菌が鉱物を酸化して蓄熱し、開いた板の間へ熱い砂を通す。 ガルドロスのうち裂扇炉が成熟した、まれな長寿個体である。普段は草地と露頭を順に巡り、接近者にはまず左背を開いて警告する。

未破壊部位へ集中的に当てる→破壊で裂扇を開く→同じ敵へ火と物理を集中→大きい摩耗を整備する。

- 得意：同級基準の物理倍率1.10、会心率-20ポイント。既存のfire属性量を1.25倍。固有技能「裂扇炉の開いた傷」は同系列2部位でLv1、4部位でLv2。
- 代償：会心率-20ポイント、刃消耗1.50倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.16倍。弱点耐性は一式でwater -20。形状による当たり判定・リーチの優遇はない。
- 推奨：断岳剣、大槌、長尖槍
- 避けたい状況：破壊済みの敵から別の敵へ効果を運ぶ運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：裂扇炉の開いた傷

部位破壊で左の裂扇炉を開く。壊した敵に対してのみ物理と火を強め、別の敵へ乗り換えて効果を持ち越さない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から360tick有効、900tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 部位破壊 |

| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |

## 見た目と制作

左肩だけ縦に割れた厚い扇板が立つ。胴は低く重く、右腕は小さいまま。原種の横広い岩板との差を縦裂きの断面で出す。

配色：灰褐 / 青銅 / 琥珀

### 器官の転用

- 成熟した左裂扇炉→左肩の三枚の厚い縦割れ板
- 鉱物の共生層→割れの奥の短い琥珀線
- 長寿の岩殻→低い胴の厚い段違い断面

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の左面を縦の三板に割った重い一枚刃。琥珀線は隙間の奥だけ |
| 護刃 | 左峰が縦割れの短剣と、左寄りの三枚扇を持つ厚い盾 |
| 大槌 | 三つの割れ板を閉じた硬面で挟む槌頭。開口部を打面にしない |
| 双剣 | 厚い二本刃の峰を同じ三本線で割り、見た目の左右重量を揃える |
| 太刀 | 細い連続刃の根元に三つの低い縦割れ。鞘の外周へ突起を出さない |
| 長尖槍 | 槍の根元の左側に三条の裂扇、盾は左に厚板・右に小面の非対称 |
| 環弓 | 中央左側に低い裂扇三枚。両端のしなる骨弓と一本弦は確保し、小環を前へ離す |

### 級別の形状発達

- 上級：灰褐の左縦扇三枚を厚い断面で見せ、青銅は割れの外縁だけ。
- 極級：三裂の根元へ小さな琥珀窓。厚板の成長線を一本足すが、右側は小さいまま。

### モデル制作の固定条件

- primaryForm：左側の縦三裂扇
- secondaryForm：低い厚殻
- dominantRegion：左肩と左前腕
- asymmetry：左のみ大板、右は小さい面
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は左肩三裂の根元。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 原種の岩板を単に赤く塗らない
- 右肩にも同じ扇を付けない
- 割れ目を炎の大面積にしない
