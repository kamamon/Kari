## 戦い方

**背後の冷気を刻む交互帆装**

広い岩棚では滑るが、狭い足場は短い肢で這う。氷帆を立てる動作が威嚇で、攻撃の前に白い欠片が少量落ちる。

相手の背後へ回り、二つの別行動で薄氷の列を作る。正面へ戻る前に離れる。

- 得意：氷倍率1.85。背後二接触の後に属性と回避効率が伸びる。
- 代償：基礎物理0.83倍、防御0.81倍、刃消耗1.32倍。正面での攻撃では固有を始められない。
- 推奨：双剣、太刀、環弓
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.83倍、防御0.81倍、刃消耗1.32倍。正面での攻撃では固有を始められない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：交帆の冷路

同じ相手の背後へ二つの別行動を当て、薄氷を保つ6秒間を作る。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | rear / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、回避消費 -8/-12% |

## 見た目と制作

左肩、右背、左腰に三枚の薄い氷帆を交互配置。片側の翼にせず、斜めに折れた細い輪郭。

配色：薄い青灰 / 半透明氷 / 灰緑革

### 器官の転用

- 左右交互の薄板へ冷却液を送る冷晶管。板の表面に薄い氷を作り、体を振ると進行方向の狭い列へ欠片が落ちる。
- 交互に張る氷帆を三か所へ絞り、体を長くする代わりに視線の斜め移動を作る。
- 狭い氷片列を敵の背後へ二度通す条件として表す。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の三か所だけ交互に薄氷板を沿わせる大剣 |
| 護刃 | 細い氷刃と、硬い裏板へ交互の三薄板を重ねた盾 |
| 大槌 | 硬い冷晶打面の側面へ三枚の薄板を寝かす |
| 双剣 | 峰の板を左右互い違いに置く二短刃 |
| 太刀 | 低い三枚薄板を峰へ連ねる滑らかな曲刃 |
| 長尖槍 | 冷晶芯の直槍と、三段の交互板を閉じた芯へ付けた盾 |
| 環弓 | 細い弓身の根元へ三枚の低い氷片。直線弦一本と小環 |

### 級別の形状発達

- 初級：三枚の縁を曇らせ、皮の間隔を広く取る。
- 中級：冷晶管の細筋を薄帆の根元に見せる。
- 上級：左右の交互位置を強め、板の面に短い霜線。
- 極級：三枚の内縁だけ透けを深める。板数と輪郭は維持。

### モデル制作の固定条件

- primaryForm：交互に寝た三枚の薄帆
- secondaryForm：灰緑革の細い胴
- dominantRegion：左肩・右背・左腰
- asymmetry：左右交互、上へ尖らせない
- repeatCount：主氷帆3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は三枚の薄帆の根元。平常：曇った淡青。発動：二接触で根元三点だけ白く曇る。点灯面積は全身の4%以下。

避ける形：

- 全身を氷柱の棘で覆わない
- 左右対称の大翼へ揃えない
- 半透明板を刃の判定外へ伸ばさない
