## 戦い方

**無傷の部位を崩しながら受ける棚装**

左の棚肋に囲まれた連室風嚢。移動時の呼吸で空気を各室へ分け、棚の縁を持ち上げて一本ずつ低い圧縮風を出す。 温厚な採食者だが、左棚の下へ入り込む相手は強く押し返す。複数の広い岩盆を決まった順に歩き、狭い回廊では体を傾けて通る。

未破壊部位へ三つの別行動→部位を削りながら受けを節約→壊れた後は次の未破壊部位へ条件を作り直す。

- 得意：同級基準の物理倍率1.04、会心率-15ポイント。既存のwind属性量を1.20倍。固有技能「三棚の押し道」は同系列2部位でLv1、4部位でLv2。
- 代償：会心率-15ポイント、刃消耗1.30倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.20倍。弱点耐性は一式でthunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：断岳剣、護刃、長尖槍
- 避けたい状況：破壊済み部位だけで固有技能の蓄積を作る運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三棚の押し道

未破壊部位へ三行動を通して左棚下の道を押し開く。部位を崩す間の受けを助けるが、破壊済み部位では再準備できない。  360tick以内に異なる行動で3回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | unbroken / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 6秒 |
| 効果（Lv1 / Lv2） | ガード消費 -12/-20%、破壊・切断蓄積 +14/+20% |
| 持続 / 再発動待ち | 5秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：棚下の押し返し

左棚で受けた圧を別の一撃へ渡す。HPダメージではなく部位蓄積を増す。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |

## 見た目と制作

左肩から左腰へ大きさの違う三段の岩棚。右側を低い短板だけにして、左側面の三つの水平な空隙を読み取れる形にする。

配色：灰褐 / 灰緑 / 鈍青銅

### 器官の転用

- 左棚肋三枚→左肩・脇・腰の三段棚
- 連室風嚢→棚下の細い灰緑室三つ
- 広い岩盆を押す重い前脚→短い太い前腕甲

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の左面へ三段の厚い棚を伏せた幅広刃。棚下に灰緑の細い空隙 |
| 護刃 | 左片鍔の剣と、左側に三つの低い棚・右側に硬い平面を持つ盾 |
| 大槌 | 側面左に三段の棚窓、両打面は厚い閉じた岩面 |
| 双剣 | 二本の峰に同じ低い三棚。刃は短い連続面で左右の重心を揃える |
| 太刀 | 細い刃の根元だけ低い三段棚。先端は長い一枚面 |
| 長尖槍 | 厚い直槍の根元へ三棚の細い筋、盾の左側に低い三段棚 |
| 環弓 | 握り左側へ短い三棚を置き、弓端は細い骨弓。一本弦と小環へ棚を干渉させない |

### 級別の形状発達

- 上級：灰褐の三棚を左側だけへ置き、灰緑室を細く見せる。右は短板。
- 極級：三棚の下の支持稜を短く二重にする。左腕が見える空隙を保持し、棚の幅や数を増やさない。

### モデル制作の固定条件

- primaryForm：左側面の三棚
- secondaryForm：棚下の細い風室
- dominantRegion：左肩から左腰
- asymmetry：左のみ三棚、右を低くする
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は左三棚の下の灰緑室。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- ボラゼルンの正面三庇と同じ形にしない
- 左棚で腕全体を隠さない
- 棚を大きな翼へ伸ばさない
