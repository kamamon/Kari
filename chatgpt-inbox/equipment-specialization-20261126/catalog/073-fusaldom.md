## 戦い方

**氷礁の肩で受け流し後を砕く装備**

左右の肩甲に浅く広がる氷礁腺。体内の冷却液が肩の溝で固まり、肩を傾けた側へ低い氷塊を押し滑らせる。

受け流しに成功した同じ相手へ、次の別行動を部位狙いで当てる。失敗を硬さだけで補わない。

- 得意：氷量1.45倍、防御1.08倍。返しの一行動に部位+18/25%・氷+8/12%。
- 代償：基礎攻撃0.93倍、会心-5、消耗1.30倍、回避・ガード等の消費1.15倍、火耐性-25。
- 推奨：護刃、長尖槍
- 避けたい状況：不利な運用: 受け流しを使わず被弾を重ねる運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：氷礁の肩返し

受け流した対象だけへ、次の別行動の氷と部位破壊を集中する。敵を変えると対象限定の攻撃補正は乗らない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続180tick、発動時から再使用720tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |

## 見た目と制作

左右の肩だけ水平な広板。片側をわずかに高くし、腰と脚を細く絞って礁の棚を見せる。

配色：灰青 / 白灰 / 青銅

### 器官の転用

- 氷礁腺→水平に広い肩板
- 低い氷塊→肩の下縁の小さい段
- 片側の踏ん張り→左右で少し違う肩高

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 肩棚の平板を峰へ写した幅広大剣 |
| 護刃 | 短い氷溝剣と、上辺だけ広い水平棚盾 |
| 大槌 | 水平礁を側面に積む扁平な硬い槌頭 |
| 双剣 | 同長二短剣の峰に低い水平段 |
| 太刀 | 幅の細い刃元へ水平棚鍔を低く置く太刀 |
| 長尖槍 | まっすぐな細槍と、肩棚を写す上幅の広い独立盾 |
| 環弓 | 肩棚は握り近くだけの低い飾り、細い弓身と小環、一本の直線弦 |

### 級別の形状発達

- 極級：肩だけ水平に広い灰青の大板を張り、腰と後ろ脚は細くまとめる。左右の板の高さを少し変える。 極級完成形のみ。肩の水平線と左右の高さ差を残し、腰や脚を太らせない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：水平な礁棚
- secondaryForm：細い下半身
- dominantRegion：両肩
- asymmetry：左肩を少し高く、左右板幅は同程度
- repeatCount：主肩板2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は肩板の下縁。平常：薄い灰青の段。発動：受けた側の段の内側だけ白く曇る。点灯面積は全身の4%以下。

避ける形：

- 受け流しを使わず被弾を重ねる運用
- 肩板が腕の挙上を塞ぐ大きさ
- 腰や脚を肩同様の幅広甲にする形
