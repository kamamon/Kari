# 013 エンバルグ — 熾炉

原種ID `monster.embarg`。初級〜極級。 [JSON原本](../data/species/013-embarg.json) / [全級の装備・レシピ](../data/equipment/013-embarg.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**危機を熱へ換える熾炉装**

熱を逃がす間は動きを止め、殻の隙間をゆっくり開く。追い詰められた時ほど排気が増え、吐息の向きを胸の向きで示す。

生存した直接被弾で炉が開く。低体力の短い火力区間を使うか、直ちに退いて整えるかを選ぶ。

- 得意：火倍率1.65と基礎物理1.00倍。HP40%以下で被弾後の火属性が強い。
- 代償：会心-10、刃消耗1.40倍、戦闘スタミナ1.15倍。発動中は被ダメージ+12/+18%。
- 推奨：断岳剣、大槌、長尖槍
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。会心-10、刃消耗1.40倍、戦闘スタミナ1.15倍。発動中は被ダメージ+12/+18%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：熾炉の逼迫

生存した敵の直撃後HP40%以下で発動。ガード削り・自傷・継続ダメージ・致死では起きない。納刀で危険な炉を閉じられる。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 生存する直接非ガード被弾 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 1〜40% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、被ダメージ +12/+18% |

溜めを解放して弁を開く。次の別行動の火属性を強め、溜め攻撃自身には乗らない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

黒い胸腹の一枚炉殻が前に張り、背の三枚弁は低く伏せる。腕脚は節を細くして炉だけを重くする。

配色：黒灰 / 鈍い赤銅 / 暗い琥珀

### 器官の転用

- 胸腹の鉱物層を酸化させて熱を蓄える熾炉器と、背の排気弁。弁を開くと琥珀色の熱筋が見え、前方へ短い熱気を吐く。
- 熾炉を胸腹一か所へ集約、背の排気弁を低い三枚板として残す。
- 追い詰められるほど排気が増える生態を、低体力の被弾後に守りを削る火力へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 黒い大刃の刃元内側に炉筋、峰の低い弁三つ |
| 護刃 | 短い黒殻刃と、中央閉鎖の炉殻盾 |
| 大槌 | 閉じた黒殻の硬打頭、側面に低い三弁 |
| 双剣 | 左右の刃元に小炉筋一つずつ。火柱を出さない |
| 太刀 | 黒い連続曲刃の根元だけ細い赤銅筋 |
| 長尖槍 | 直槍の刃元に小炉室、前へ厚い閉鎖盾 |
| 環弓 | 細い骨弓の握り背面だけ黒殻二枚。小環と直線弦 |

### 級別の形状発達

- 初級：黒殻の継ぎ目だけ暗い琥珀。
- 中級：胸殻下縁に赤銅の細い受け帯。
- 上級：背弁三枚を独立させ、閉じた面を残す。
- 極級：胸内縁に二重の細い熱筋。殻全体を溶岩色にしない。

### モデル制作の固定条件

- primaryForm：前に張る一枚炉殻
- secondaryForm：低い三枚弁と細い熱筋
- dominantRegion：胸腹
- asymmetry：前重心、背は低い
- repeatCount：主炉1、背弁3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は胸炉の下縁。平常：ほぼ黒い細筋。発動：危機の区間だけ暗い琥珀が細く強まる。点灯面積は全身の6%以下。

避ける形：

- 前面を開いた火口や砲口にしない
- 背へ長い煙突を立てない
- 全身の黒殻を赤い溶岩へ変えない
