## 戦い方

**ずれた二皿で受け流して水を運ぶ装備**

翼端の重なる溝に繋がる湧皿水嚢。浅瀬で掬った水を胸の下へ溜め、翼をずらす向きに沿って薄い水刃状の流れを出す。

受け流しを成功させ、軽い回避で皿をずらしながら水の別行動を重ねる。

- 得意：水量1.48倍、会心10。受け流し後の水+10/14%・回避消費-12/18%。
- 代償：基礎攻撃0.90倍、防御0.96倍、消耗1.20倍、氷耐性-25。受け流し不能の系統では固有技能が起動しない。
- 推奨：護刃、長尖槍
- 避けたい状況：不利な運用: 通常ガードだけで受け流し条件を満たす運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：湧皿のずらし返し

受け流し成功で二皿をずらし、水の流れと踏み替えを整える。即時回復や無敵延長は行わない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続300tick、発動時から再使用840tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

胸下の二皿を横へずらし、右前腕と右脛を細長くする。皿同士の段差が正面でも見える。

配色：灰緑 / 灰青 / 青銅

### 器官の転用

- 湧皿翼甲→胸下の二枚のずれ皿
- 翼端水路→青銅色の細い縁筋
- 右長足甲→右脛だけ長い一枚板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 二枚の皿線を刃元へ重ねる平たい大剣 |
| 護刃 | 細い水溝剣と、ずれた二皿を硬い裏面で支える盾 |
| 大槌 | 閉じた打面の側に二皿の段差を見せる槌 |
| 双剣 | 同長二刃の峰へ左右の皿縁を分けて写す |
| 太刀 | 細い連続刃の鍔元へ低い二皿鍔 |
| 長尖槍 | 直槍の刃元に二枚縁、独立盾の中央にずれた二皿 |
| 環弓 | 皿の二本溝を細い弓身へ、小環の周囲は空け一本の直線弦 |

### 級別の形状発達

- 極級：灰緑の二枚皿を胸の下でずらして重ね、右脛だけ細長い板にする。水路の筋を青銅色の縁として使う。 極級完成形のみ。胸下の二枚のずれと右脛の長さを保ち、水路筋を太い発光へ置き換えない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：ずれた二皿
- secondaryForm：右の長い脛板
- dominantRegion：胸下と右脛
- asymmetry：左皿は高い、右脛だけ長い
- repeatCount：主皿2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は胸下の皿の縁。平常：鈍い青銅の二本筋。発動：二皿の縁を細い灰青の点が交互に通る。点灯面積は全身の4%以下。

避ける形：

- 通常ガードだけで受け流し条件を満たす運用
- 胸皿のずれを消して一枚板にする形
- 右脛甲が足首まで固定する形
