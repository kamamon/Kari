## 戦い方

**三環で直線を揃える雷装備**

喉を囲む三段の礫環と、その内側の蓄電砂嚢。食物を擦り潰す鉱物粒へ電荷を移し、襟の開く段から狭い方向へ吐き出す。

刺突か射撃を同じ相手へ三行動通し、次の別行動へ雷と部位補正を集中する。

- 得意：雷量1.75倍、会心15。次行動の雷+12/16%・部位+12/18%。
- 代償：基礎攻撃0.84倍、防御0.81倍、回避・ガード等の消費1.08倍、水耐性-30。対象変更で三環の準備を失う。
- 推奨：長尖槍、環弓、護刃
- 避けたい状況：不利な運用: 対象を替えながら三行動の準備を貯める運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三環の直芯合わせ

300tick内に同じ対象へ刺突または射撃を異なる3行動で通す。三環が揃った後の別行動へ、雷と部位破壊を集中する。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続240tick、発動時から再使用720tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

|---|---|

| 必須タグ / いずれかのタグ | なし / thrust, projectile |

## 見た目と制作

首の後ろだけ三段の礫環を高め、胴腰を滑らかに絞る。粒は襟の内側へ隠す。

配色：灰褐 / 青銅 / 暗灰

### 器官の転用

- 三段礫環→首後ろの三段襟
- 蓄電砂嚢→襟内側の小さい礫室
- 細い胴尾→継ぎ目の少ない細胴

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三段環の短い支えを刃元へ集めた細幅大剣 |
| 護刃 | 三段の低い鍔の剣と、襟段を写す硬い縦盾 |
| 大槌 | 側面に三段環、前後の打面を硬く閉じる槌 |
| 双剣 | 同長二短剣の刃元へ三つの低い支え |
| 太刀 | 三段鍔からまっすぐ伸びる細い峰の太刀 |
| 長尖槍 | 三つの低環で刃元を支える直槍と三段襟の独立盾 |
| 環弓 | 三つの低い留めを細い弓身へ、小照準環と一本の直線弦 |

### 級別の形状発達

- 極級：灰褐色の三段襟を首の後ろだけ高くし、胴と腰は滑らかに絞る。襟の内側へ青銅色の礫粒を置く。 極級完成形のみ。青銅色の礫粒を襟の内側に収め、体表へ散りばめない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：三段の後襟
- secondaryForm：滑らかな胴腰
- dominantRegion：首の後ろ
- asymmetry：後ろだけ高く前襟は低い
- repeatCount：礫環3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は三段襟の内縁。平常：内側に青銅色の粒。発動：三段へ一粒ずつ小さい点が上がる。点灯面積は全身の4%以下。

避ける形：

- 対象を替えながら三行動の準備を貯める運用
- 礫粒を身体全体へ散りばめる形
- 三段襟を頭上の三輪へ浮かせる表現
