## 戦い方

**低スタミナで二度避けて冷風を集約**

原種の分割角膜が上下二層へ分かれた双帆冷腺。上層で風を受け、下層の揮発液で冷やした微細な氷粒を狭い扇へ流す。 セルヴァルクの一部で角膜の分岐が二重になった希少個体である。見張り場と採食斜面を歩いて巡り、逃げ道を塞がれた時だけ跳びかかる。

スタミナ40%以下で二度接触を回避→次の別行動で冷風と会心を集中→薄い防御を補う位置へ退く。

- 得意：同級基準の物理倍率0.78、会心率+20ポイント。既存のwind/ice属性量を1.85倍。固有技能「双帆の冷気すり替え」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.78（同級基準比22%低い。系統補正前）、刃容量0.82倍、刃消耗1.35倍、防具一式の基準防御力0.75倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：環弓、双剣、太刀
- 避けたい状況：回避入力だけを二度数える運用と被弾覚悟の殴り合い。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：双帆の冷気すり替え

スタミナ40%以下で二度接触を避け、上下の帆を入れ替える。次の別行動だけ風氷と会心へ集中する。 回避入力ではなく、敵の接触を回避の無敵時間で実際に避けた時だけ数える。 300tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

## 見た目と制作

肩の二つの薄帆が上下にずれ、細い胴から高く見える脚へ抜ける。頭は小さく、頭上に帆角を巨大化させない。

配色：灰青 / 白氷 / 生成り

### 器官の転用

- 上下二層の帆角→左右肩で高さをずらした二つの薄帆
- 下層の冷腺→帆の下縁の小白膜
- 高い後肢→長く見える細い脛と短い腰

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の根元で上下にずれた二枚帆を伏せ、連続刃を細く保つ |
| 護刃 | 二段の薄い片鍔の剣と、上左・下右に薄帆面を分けた硬い盾 |
| 大槌 | 上下にずれた白膜窓を側面に持つ小さめの閉じた槌頭 |
| 双剣 | 二本の細刃の峰の帆位置を上下にずらすが、全長と重心は揃える |
| 太刀 | 細い湾曲刃の根元に上下二筋の帆縁。鞘の中へ収まる低さ |
| 長尖槍 | 直槍の根元に二層の薄い帆筋。盾面の左右を上下に少しずらす |
| 環弓 | 中央の上下へ小さな帆を一枚ずつ。しなる弓端と一本弦、小照準環を帆から独立させる |

### 級別の形状発達

- 上級：灰青の二帆を異なる高さに置く。白氷は下縁、生成りは短い腰膜。
- 極級：二帆の下縁へ独立した細い冷筋を追加。帆の数と低さを保ち、脚を太くしない。

### モデル制作の固定条件

- primaryForm：上下にずれた二帆
- secondaryForm：長く細い脚
- dominantRegion：両肩
- asymmetry：左帆が高く、右帆が低い
- repeatCount：2
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は肩帆の下縁の白膜。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 頭の鰭を肩帆より大きくしない
- 大きな鳥翼を背へ付けない
- 全身を透明な氷鎧にしない
