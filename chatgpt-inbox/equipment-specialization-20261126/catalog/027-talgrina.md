## 戦い方

**三擦板を受け流して帯電する左腕装**

体を横に向けたまま礫河床を移動し、接近者には鋏を鳴らして警告する。水から遠ざけられると膜を守るため退く。

同じ敵を二度受け流し、三枚の擦晶板が揃う短い雷の連係へ移る。

- 得意：雷倍率1.60。二受け流し後に雷と部位補正を同時に得る。
- 代償：基礎物理0.90倍、防御0.90倍、戦闘スタミナ1.10倍。通常ガードでは回数が進まない。
- 推奨：長尖槍、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.90倍、防御0.90倍、戦闘スタミナ1.10倍。通常ガードでは回数が進まない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三板の帯電合わせ

同じ相手の二つの攻撃行動を受け流し、5秒間だけ擦晶板を同期する。麻痺耐性のパラメーターはpara。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 6秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、破壊・切断蓄積 +10/+15% |
| 持続 / 再発動待ち | 5秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change, sheathe。再発動待ちは戻さない |

## 見た目と制作

左前腕の三段擦晶籠手が最も大きく、肩殻を左から右へ低く落とす片流れ。顔と右手を軽く見せる。

配色：鈍青銅 / 灰褐 / 琥珀の細筋

### 器官の転用

- 左鋏の内部に三枚の擦晶板があり、順に締めると電荷を蓄える。板の間をつなぐ湿った膜が、触れた相手へ電気を渡す。
- 左鋏の三擦晶板を左籠手の三段へ、片流れ甲羅を肩から胸の斜め面へ移す。
- 晶板を順に締める充電行動を、二度の受け流しから始まる雷区間へ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元を三段擦晶板で挟む雷大剣 |
| 護刃 | 三つの低い擦筋を持つ短刃と、左上が大きい閉鎖盾 |
| 大槌 | 硬い両打面の内側へ三板筋を埋める横槌 |
| 双剣 | 三筋を二対の峰へ細く彫る短剣二本 |
| 太刀 | 連続曲刃の鍔側に三段の低い擦板 |
| 長尖槍 | 三枚の擦晶芯を直線に揃える槍と、左上三段の硬盾 |
| 環弓 | 握り横へ三枚の小擦晶板。小環、直線弦、細い弓身 |

### 級別の形状発達

- 中級：左の三段板を青銅で区切り、右腕を軽くする。
- 上級：三板の間へ湿膜の細筋を見せる。
- 極級：各板の内縁へ琥珀の小窓。板数や籠手の長さは増やさない。

### モデル制作の固定条件

- primaryForm：左籠手の三段板
- secondaryForm：湿膜の細い継ぎ目
- dominantRegion：左前腕
- asymmetry：左大、肩は右へ低くなる
- repeatCount：左擦晶板3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は左籠手の三つの間隙。平常：鈍い青銅。発動：二受け流し後に三間隙だけ琥珀色。点灯面積は全身の4%以下。

避ける形：

- 左腕を開閉する巨大鋏にしない
- 雷属性と麻痺属性を同時に武器へ足さない
- 三板を多数の機械フィンへ増やさない
