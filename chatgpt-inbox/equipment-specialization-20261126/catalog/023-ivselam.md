## 戦い方

**低体力で霜扇を返す左肩装**

風向きを確かめてから草場を渡り、危険には横跳びで距離を取る。角膜を傷つけられると左側を隠して警戒する。

被弾を避けながら低体力の接触回避を通し、短い氷の反撃だけで勝負する。

- 得意：会心+25、氷倍率1.80。HP60%以下の回避成功後に氷が伸びる。
- 代償：基礎物理0.79倍、防御0.77倍、刃容量0.78倍。固有中の物理補正は-4/-6%。
- 推奨：双剣、太刀、環弓
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.79倍、防御0.77倍、刃容量0.78倍。固有中の物理補正は-4/-6%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：左扇の薄氷返し

HP60%以下の接触回避成功で霜扇を返す。物理を減らして氷へ寄せる区間で、体力を回復しない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。 回避入力ではなく、敵の攻撃との接触を回避無敵で抜けた成功時だけ判定。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 敵の接触を回避無敵で避けた時 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 1〜60% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、物理ダメージ -4/-6% |
| 持続 / 再発動待ち | 4秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken。再発動待ちは戻さない |

### 武器主題（Lv1固定）：霜扇の返し縁

斬る締め技の命中から、次の別行動の氷属性へ霜を渡す。系統適合版で同一技にないタグの組合せを解消する。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

左肩にだけ半円の薄い霜扇、背は低い二折り。右肩と両脚を細い灰革で抜き、横に片寄る細身。

配色：くすんだ青灰 / 淡霜白 / 灰革

### 器官の転用

- 左の角膜に冷晶を含む薄層が重なり、集めた水滴を細かな氷片へ変える。扇の開閉方向が、氷片の飛ぶ範囲を示す。
- 左だけ半円に育つ霜扇を一枚の左肩へ移し、背の低い折りを残す。
- 左側を隠す警戒を、低体力の接触回避からの短い属性反撃へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の片側に半円霜扇の低い骨筋を添える大剣 |
| 護刃 | 霜筋の短刃と、左側に半円扇を貼る硬い盾 |
| 大槌 | 硬い冷晶の打頭、片側面だけ半円筋 |
| 双剣 | 峰に半円の一部を低く添える二短刃。長さは揃える |
| 太刀 | 鍔の左側だけ半円霜筋を持つ連続曲刀 |
| 長尖槍 | 直槍の根元に短い扇骨、左張りの閉鎖盾 |
| 環弓 | 握り上の片側へ小さな霜扇骨。小環と直線弦 |

### 級別の形状発達

- 中級：左の半円扇を薄く低く置く。
- 上級：扇骨を三本に分け、間の薄膜を残す。
- 極級：三本の内筋だけ霜白を濃くする。扇の半径を大きくしない。

### モデル制作の固定条件

- primaryForm：左一枚の半円扇
- secondaryForm：細い灰革と低い背折り
- dominantRegion：左肩
- asymmetry：左のみ横へ張る。右肩は平ら
- repeatCount：主霜扇1、背折り2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は左肩扇の内筋三本。平常：くすんだ青灰。発動：回避成功で内筋三本だけ白く曇る。点灯面積は全身の3%以下。

避ける形：

- 右肩にも同じ霜扇を付けない
- 巨大な花冠や氷翼にしない
- 薄膜を硬い打面や盾の唯一の支持材にしない
