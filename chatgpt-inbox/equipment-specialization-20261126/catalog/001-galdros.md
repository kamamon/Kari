## 戦い方

**受けて殻を割る左重装**

普段は決まった採食場所をゆっくり巡る。進路を塞がれると頭冠を低くして警告し、距離を取れば追い過ぎない。

正面をガードし、次の別行動で同じ部位を割る。横回避の連打を捨てて位置を先に取る。

- 得意：基礎物理1.14倍と防御1.10倍。受け止めた直後の部位破壊に集中。
- 代償：会心-15、戦闘スタミナ消費1.18倍、刃消耗1.18倍。固有発動中は回避消費+10/+15%。
- 推奨：断岳剣、長尖槍、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。会心-15、戦闘スタミナ消費1.18倍、刃消耗1.18倍。固有発動中は回避消費+10/+15%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

通常ガード成立で左殻を支点にし、6秒間の部位攻撃を強める。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

左肩・左前腕・左腰に三つの大岩塊を置く、低い片流れの城壁形。右半身は革地を広く見せる。

配色：灰褐色 / 鈍い青銅 / 琥珀の細い縁

### 器官の転用

- 背と頭に鉱物を析出させる皮下の晶脈床。左背面の成長が速く、尾端では塊になって打撃を重くする。
- 左の成長の速さを三か所の重量配分へ置換。右は関節を支える細帯にする。
- 晶脈を受けてから割る技能の溜まりとして、殻の外周でなく内側の細筋へ表す。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 左側に厚い岩殻を抱く斜め断面の大剣。先端は斜めに切り落とす |
| 護刃 | 細い岩刃と左寄りの巨板を一枚使う台形盾。盾裏は革帯 |
| 大槌 | 横長の閉じた岩頭。左側面だけ晶脈が深い両打面 |
| 双剣 | 二本とも直線的な短い岩楔。左右の重さは同じで面割りだけ反転 |
| 太刀 | 低い岩片を連ねた連続曲刃。峰に一本だけ沈んだ晶筋 |
| 長尖槍 | 平たい尾端晶の槍穂と、左に厚い三層岩盾 |
| 環弓 | 硬骨弓の握り外側だけ岩片を二枚。小照準環一つと直線弦一本 |

### 級別の形状発達

- 初級：大岩塊三つの面を粗く残し、晶筋は一本だけ。
- 中級：三つの主塊を維持し二重の革留め。浅い晶筋を二本へ。
- 上級：左肩と左腰の内面へ小さな琥珀晶面。輪郭を増幅しない。
- 極級：三本の沈んだ晶筋と左前腕の晶面。右半身の革面は残す。

### モデル制作の固定条件

- primaryForm：斜めに重なる扁平な岩塊
- secondaryForm：細い革帯と沈んだ晶筋
- dominantRegion：左肩・左前腕・左腰
- asymmetry：左大、右小。正面の体軸は傾けない
- repeatCount：主岩塊3、尾端晶1
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は左肩の岩板内縁。平常：灰色の沈んだ筋。発動：受け止めると内側二筋だけ琥珀が灯る。点灯面積は全身の4%以下。

避ける形：

- 右肩も同じ大岩塊にしない
- 王冠状の角・長い尾・全身金色を足さない
- 装飾岩を刃の有効長へ突き出さない
