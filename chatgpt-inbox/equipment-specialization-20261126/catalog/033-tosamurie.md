## 戦い方

**疲弊域の回避から風を返す細身装**

前肘の逆鉤の内側に送風膜が張り、畳んだ肘を開くと狭い空気の刃を押し出す。鉤は枝を引き下ろす採食器官でもある。 頭を低くして根の間を歩き、枝を折らずに引く場所を覚える。追われると斜め跳びで樹間の広い方へ逃げる。

スタミナを半分以下まで使う→敵の接触を回避で避ける→風と低い回避消費で位置を変える。

- 得意：同級基準の物理倍率0.88、会心率+22ポイント。既存のwind属性量を1.50倍。固有技能「逆肘の風抜け」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.88（同級基準比12%低い。系統補正前）、刃容量0.88倍、刃消耗1.05倍、防具一式の基準防御力0.76倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：双剣、太刀、環弓
- 避けたい状況：回避を入力するだけで敵の接触を避けない移動。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：逆肘の風抜け

残りスタミナ50%以下で接触を避けた時に膜が開く。追い回すより、敵の一撃を読んで風の懐へ戻る。 回避入力ではなく、敵の接触を回避の無敵時間で実際に避けた時だけ数える。 300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |

| 起点 | 敵の接触を回避無敵で避けた時 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜50% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 回避消費 -12/-20%、属性ダメージ +8/+12% |

## 見た目と制作

胸と腰を極端に短くし、肘の外へ折り畳んだ逆鉤と細い脛だけを長く見せる。膜は脇に小さく残し翼にはしない。

配色：灰緑 / 生成り / 青銅

### 器官の転用

- 逆肘鉤→前腕外の下向きに伏せた二つの短鉤
- 送風膜→脇と鉤の内側の細い張り膜
- 斜め跳びの脚→露出の多い足首と縦長の脛甲

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元へ短い逆鉤二本を伏せ、先を細く絞った軽い見た目の大剣 |
| 護刃 | 低い逆鉤の鍔を持つ細剣と、折り膜の細帯を縁に収めた縦長の盾 |
| 大槌 | 鉤骨を畳んだ芯を硬い打面で両側から閉じ、側面だけ小膜を見せる |
| 双剣 | 下向きの短鉤を峰に沿わせた細い二本刃。刃先は前へ連続させる |
| 太刀 | 細い湾曲刃に沿って一筋の青銅腱、刃元の小鉤は鞘へ納まる高さ |
| 長尖槍 | 細い直槍の刃元に小さな逆鉤、盾は中央骨筋と両側の硬い細面で構成 |
| 環弓 | 内側の鉤を小環の支持へ写した細い骨弓。膜は中央脇の小片だけ、弦は一本直線 |

### 級別の形状発達

- 中級：灰緑の骨縁と生成りの小膜。鉤を低く伏せて肘との間の空間を残す。
- 上級：鉤の内側へ青銅の細筋を一つ足し、脛甲を細い二層にする。
- 極級：膜の折り目だけ淡く透ける。鉤の数や長さを変えず、胸の金属面を増やさない。

### モデル制作の固定条件

- primaryForm：下へ伏せた一対の逆鉤
- secondaryForm：短い胸腹と細い脚
- dominantRegion：両前腕
- asymmetry：左右対称の一対鉤
- repeatCount：2
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は二つの肘鉤の内側膜。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 鉤を手首や指の先まで伸ばさない
- 肩へ巨大な翼膜を作らない
- 鉤をリーチ増加の判定にしない
