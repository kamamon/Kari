# 008 テンガロ — 鉤輪

原種ID `monster.tengaro`。初級〜極級。 [JSON原本](../data/species/008-tengaro.json) / [全級の装備・レシピ](../data/equipment/008-tengaro.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**輪を閉じる麻痺連係装**

歩く時は体節を開き、追われた時だけ輪になる。回転は短距離で止まり、向きを変える前に再び体を開く。

別行動の締め技を同じ相手へ二度通し、短い麻痺蓄積区間にまとめる。

- 得意：麻痺倍率1.45、戦闘スタミナ0.94倍。連係の締めを狙うほど蓄積が伸びる。
- 代償：基礎物理0.84倍、防御0.82倍。刃消耗1.26倍に加え、発動中+12/+18%。
- 推奨：双剣、太刀、長尖槍
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.84倍、防御0.82倍。刃消耗1.26倍に加え、発動中+12/+18%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：傾輪の締め継ぎ

同じ相手への二つの締め技で輪留めを閉じる。攻撃回数そのものでは進まず、納刀で解ける。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

右肩から左腰へ一周未満の螺旋節甲。短い外鉤が一方向へ寝て、胴の前に大きい空隙を残す。

配色：赤褐色 / 鈍青銅 / 黒茶

### 器官の転用

- 円弧状の体節を固定する輪留め腱と、外側の鉤に通じる痺液管。鉤を地面へ掛け、傾いた輪のまま短距離を転がる。
- 輪留め腱を斜めに継ぐ節甲へ、短距離だけ転がる輪を閉じない螺旋へ移す。
- 締め技二回で継ぐ機能を、外鉤の消耗という代償と結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元から峰へ三つの低い鉤節を沿わせる片刃 |
| 護刃 | 短い鉤刃と、三節を斜めに組む閉じた盾 |
| 大槌 | 硬い節甲を横巻きした閉じた槌頭。鉤は側面へ寝かせる |
| 双剣 | 短い外鉤を峰側へ一つずつ持つ二本の連続刃 |
| 太刀 | 三節の筋を峰に沈めた曲刀。返し鉤を刃先へ出さない |
| 長尖槍 | 痺液管を内側へ刻む直槍と、斜め輪節の硬盾 |
| 環弓 | しなる弓身の根元へ開いた三小節。直線弦一本と小環 |

### 級別の形状発達

- 初級：赤褐色の六節と丸い短鉤。
- 中級：節の間に青銅の細い輪留め。
- 上級：左腰の三節だけ深い色と二重縁。
- 極級：六節の内縁へ細い管筋。鉤の長さは増やさない。

### モデル制作の固定条件

- primaryForm：開いた螺旋節甲
- secondaryForm：短く寝た外鉤
- dominantRegion：右肩から左腰
- asymmetry：斜めの流れ、前中央は開く
- repeatCount：主節6、外鉤は各節1つ
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は左腰の輪留め三つ。平常：暗赤褐の溝。発動：締め技二回で内縁が一周未満だけ淡く灯る。点灯面積は全身の4%以下。

避ける形：

- 閉じた巨大な車輪を背負わせない
- 鉤を長い牙や角へ成長させない
- 全身を同じ環甲で覆わない
