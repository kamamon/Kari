# 038 ヌフラケン — 冷壺

原種ID `monster.nufraken`。中級〜極級。 [JSON原本](../data/species/038-nufraken.json) / [全級の装備・レシピ](../data/equipment/038-nufraken.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**納刀して冷壺を満たす氷の単発装**

首の後ろの冷壺に、冷晶を含む襞と湿気を集める内膜が重なる。壺腹を縮める前に首が高くなり、溜めた冷たい水粒を細い帯へ吐く。 長い胴を伏せて静かに進み、獲物が動くと首を持ち上げる。冷壺を傷つけられると、尾で距離を作って退く。

スタミナ90%以上で納刀完了→次の別行動へ氷を集中→回復が鈍る準備時間を長引かせない。

- 得意：同級基準の物理倍率0.80、会心率-10ポイント。既存のice属性量を1.85倍。固有技能「首壺の静かな充填」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.80（同級基準比20%低い。系統補正前）、会心率-10ポイント、刃容量0.80倍、刃消耗1.25倍、防具一式の基準防御力0.78倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：環弓、断岳剣、大槌
- 避けたい状況：低スタミナのまま納刀を連打する運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：首壺の静かな充填

スタミナ90%以上で納刀し冷壺を満たす。次の氷の一撃を待つ間は回復速度が下がり、出入りを詰めると冷壺を満たせない。 明示した納刀行動の完了時のみ。道具・採集による暗黙の納刀は除く。 300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、900tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

|---|---|
| 起点 | 明示的な納刀完了 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 90〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +14/+16%、スタミナ自然回復 -10/-15% |

## 見た目と制作

首の後ろだけが一つの壺のように丸く膨らみ、正面の胸から脚は細い。肩の横幅ではなく背後の一点へ量を集める。

配色：くすんだ青灰 / 白膜 / 暗革

### 器官の転用

- 首後ろの冷壺→後襟の丸い一壺
- 湿気を集める襞→壺の内縁の白い細襞
- 長く細い尾→腰後ろの短い一本筋へ省略

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 細長い単面刃の根元の背側へ丸い冷壺を一つ、先は細く平ら |
| 護刃 | 細い壺首形の鍔を持つ剣と、中央上だけ丸く膨らむ縦盾 |
| 大槌 | 一つの丸い冷壺を硬い二打面で挟んだ槌頭。内膜は側面の小窓だけ |
| 双剣 | 二本とも刃元の小壺を同寸で持つ。刃は細い直線で袋をぶら下げない |
| 太刀 | 細い連続刃の根元に低い壺形の覆い。鞘口へ白い襞一筋 |
| 長尖槍 | 細い直槍の根元に丸い小壺、盾は上部の一壺と下部の細い硬面 |
| 環弓 | 握りの上背側に丸い小壺を一つ。細い弓身と一本弦、小環は壺から離す |

### 級別の形状発達

- 中級：後襟の一壺を不透明な青灰にし、白膜は口の細い内縁だけ。
- 上級：壺の根元に短い二重帯を付ける。前胸と脚は細いまま。
- 極級：壺の内縁を半透明の白にする。丸さを一か所に保ち、胴へ壺を増殖させない。

### モデル制作の固定条件

- primaryForm：首後ろの一壺
- secondaryForm：細い鱗の縦線
- dominantRegion：後襟
- asymmetry：左右対称、後方一点だけ大きい
- repeatCount：1
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は後襟の壺の内縁。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 肩を左右とも丸い壺にしない
- 壺口を武器の発射口のように大きくしない
- 脚を氷塊で太くしない
