## 戦い方

**二つの環で同じ部位を測る穿ち装備**

古いヴェルガイトに生じる副環冠と二室整霧嚢。大小の環のどちらを開口側にするかで、霧滴と圧縮空気を異なる高さへ送り分ける。

刺突か射撃を同じ対象へ二行動通し、物理を少し落として部位へ風霧を送り込む。

- 得意：風霧量1.58倍、発動時の部位補正+16/25%。HPと部位ゲージを分離して崩しを狙う。
- 代償：基礎攻撃0.85倍、防御0.81倍、雷耐性-30。技能中の物理-5/8%、HPだけを急いで削る用途に弱い。
- 推奨：長尖槍、環弓、護刃
- 避けたい状況：不利な運用: 物理HPダメージだけを優先する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：大小環の高低合わせ

180tick内に同じ対象へ刺突または射撃を2行動命中させる。高低を揃える間は物理を落とし、部位破壊へ寄せる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続300tick、発動時から再使用840tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | なし / thrust, projectile |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 3秒 |
| 効果（Lv1 / Lv2） | 破壊・切断蓄積 +16/+25%、物理ダメージ -5/-8% |
| 持続 / 再発動待ち | 5秒 / 14秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe。再発動待ちは戻さない |

### 武器主題（Lv1固定）：副環の吹き直し

部位を壊した時に副環で気流を整え、後の属性攻撃へ渡す。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続360tick、発動時から再使用900tick。

## 見た目と制作

大小二つの斜環を襟の後ろへ低く重ね、胸下の小灯を一方へ偏らせた細身。

配色：灰緑 / 青銅 / 琥珀

### 器官の転用

- 副環冠→襟後ろの大小二斜環
- 二室整霧嚢→胸下の二つの小区画
- 高さの送り分け→環の傾きと小灯の低位置

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 大小環の一部を刃元に重ねた細幅大剣 |
| 護刃 | 二段鍔の剣と、大小斜環を閉じた盾面へ刻む |
| 大槌 | 側面に大小の二室、前後は閉じた硬い打面 |
| 双剣 | 同長二刃へ大小の低い環飾りを分ける |
| 太刀 | 大小の斜環鍔から一本の細刃を伸ばす太刀 |
| 長尖槍 | 細い直槍に大小二つの低い支え、独立盾の環は装飾のみ |
| 環弓 | 小照準環の後ろにさらに小さい環縁を置き、視線と一本の直線弦を空ける |

### 級別の形状発達

- 極級：灰緑の細い防具に大小二つの斜環を襟の後ろへ置き、琥珀色の小灯を胸下へ偏らせる。 極級完成形のみ。大小環は襟の後ろ、灯点は胸下に限定し、全身へ発光を広げない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：大小の斜環
- secondaryForm：細い二室
- dominantRegion：襟の後ろ
- asymmetry：胸下の小灯は左寄り
- repeatCount：環2、胸下室2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は襟の大小環の内縁。平常：灰緑の二環。発動：大環から小環へ低い白点が移る。点灯面積は全身の4%以下。

避ける形：

- 物理HPダメージだけを優先する運用
- 大小環を同じ大きさの円盤にする形
- 二室を新しい霧噴射攻撃として実装すること
