## 戦い方

**弱点へ三行動を通して水と刃を保つ**

ヌメラドンの泥受け皿が三段に重なった蓮冠槽。各槽の水を別々の頬管へ送り、順番の異なる低い水弾を吐く。 泥皿の成長輪が剥がれず重なったヌメラドンの希少個体である。浅瀬の餌場を順に回り、縄張りへの侵入には冠を傾けて水を見せる。

弱点へ三つの別行動→水と刃持ちの窓を得る→同じ敵の弱点へ精度を保つ。

- 得意：同級基準の物理倍率0.88、会心率-5ポイント。既存のwater属性量を1.40倍。固有技能「三段蓮冠の澄み水」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.88（同級基準比12%低い。系統補正前）、会心率-5ポイント、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.08倍。弱点耐性は一式でthunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：太刀、双剣、護刃
- 避けたい状況：硬い部位へ無差別に連打する狩り。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三段蓮冠の澄み水

物理部位係数0.55以上へ三つの別行動を当て、三段槽の澄んだ水だけを通す。狙いを保つほど水と刃持ちを維持する。  360tick以内に異なる行動で3回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

頭だけが三段の低い丸冠で横へ広い。低い肩と小さい手脚を添え、右胸の太い頬管を一筋だけ落とす。

配色：灰緑 / 生成り / 泥褐

### 器官の転用

- 蓮冠槽の三段→兜の三枚の低い同心皿
- 独立した頬管→右胸の三短節の太い縁
- 泥皿の成長輪→冠の段ごとの鈍い堆積色

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の根元に三段の低い蓮皿を斜めに収めた広刃。先端は平らな一枚面 |
| 護刃 | 三段の小さい円鍔の細剣と、三段の浅皿を平らに重ねた丸盾 |
| 大槌 | 三段の冠形の側面を持つ閉じた槌頭。打面は硬い円面で縁を丸める |
| 双剣 | 二本とも同じ小さい三段鍔を持つ短刃。水管を刃元の内側へ伏せる |
| 太刀 | 細い刃の根元に三層の浅い皿鍔。鞘へ収まる低い成長輪 |
| 長尖槍 | 直槍の根元に小さい三段皿、盾は三つの浅槽を刻む丸面 |
| 環弓 | 中央に三層の小さな半皿を重ねる。小環は別に一つ、弦は一本で弓端を太くしない |

### 級別の形状発達

- 上級：灰緑の冠三段と右胸の短い三節管。泥褐の堆積縁を各皿に見せる。
- 極級：冠の各段に一つずつ小さな澄み窓を足す。生成りの布は短いまま、冠の段数を増やさない。

### モデル制作の固定条件

- primaryForm：三段の低い円冠
- secondaryForm：右胸の太い管縁
- dominantRegion：頭と右胸
- asymmetry：冠は対称、管は右のみ
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は三段冠の浅い水窓。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 三段冠を高い王冠にしない
- 原種の毒袋を残して水と毒を同時に示さない
- 太い管を腕の可動域へ横切らせない
