# 045 ドベルケン — 重鐘嚢

原種ID `monster.doberken`。上級〜極級。 [JSON原本](../data/species/045-doberken.json) / [全級の装備・レシピ](../data/equipment/045-doberken.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**頭への二拍を雷と気絶へ変える鐘装**

左の共鳴嚢の中へ育った重鐘導膜。鉱物を含む二枚の膜を擦って帯電させ、鐘音の前に縁が琥珀色に瞬く。 共鳴嚢内に導電鉱物の薄膜が育ったボルナケルのまれな個体である。音を試しながら露頭と菌床を巡り、まず鐘頭を揺らして警告する。

同じ敵の頭へ二つの打撃行動→気絶値を持つ頭打撃と雷で攻める→気絶そのものを自動付与しない。

- 得意：同級基準の物理倍率0.98、会心率-10ポイント。既存のthunder属性量を1.45倍。固有技能「重鐘の二拍共鳴」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.98（同級基準比2%低い。系統補正前）、会心率-10ポイント、刃消耗1.18倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.12倍、防具一式の基準防御力0.95倍。弱点耐性は一式でice -20。形状による当たり判定・リーチの優遇はない。
- 推奨：大槌、護刃
- 避けたい状況：気絶値の無い斬撃へ気絶を追加する期待。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：重鐘の二拍共鳴

頭への二打撃行動を二重鐘嚢の拍へ写す。元から気絶を生む頭打撃の蓄積と雷だけを強める。  300tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 起点 | 命中 |

### 武器主題（Lv1固定）：重鐘の受け拍

受け流した拍の後に二重鐘嚢の振動を別の一撃へ重ねる。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

左肩へ大小二つの丸い鐘殻が低く垂れ、右肩は極小。傾いた襟線と丸い量の大小で二拍を表す。

配色：灰褐 / 琥珀 / 骨白

### 器官の転用

- 二重の左鐘嚢→左肩の大小二殻
- 重鐘導膜→二殻の内側の琥珀細縁
- 右に傾く頭→右を低く切った襟線

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の根元に大小二つの低い丸殻を置く厚刃。刃は平らな連続面 |
| 護刃 | 大小二円の低鍔の剣と、左上へ二つの鐘殻を埋めた硬い盾 |
| 大槌 | 大小二殻を側室に持つ閉じた槌頭。二打面の直径は同じで重心を揃える |
| 双剣 | 二本の刃元へ大小二つの小殻を同じ配置で伏せる。鈴を吊るさない |
| 太刀 | 細い長刃の根元へ二つの浅い円を低く並べ、鞘を太らせない |
| 長尖槍 | 槍の根元に二つの低い丸殻、盾は左へ大小二殻・右へ平らな硬面 |
| 環弓 | 中央の左側に大小二つの閉じた小殻。弦と小環は独立し、可動鈴を付けない |

### 級別の形状発達

- 上級：左の大小二殻を灰褐、内縁だけ鈍い琥珀。右側は小さい骨板。
- 極級：二殻の内縁へ一筋ずつ導膜を見せる。二殻の大小比を変えず、鈴や鎖を増やさない。

### モデル制作の固定条件

- primaryForm：左の大小二殻
- secondaryForm：右へ傾く短い襟
- dominantRegion：左肩
- asymmetry：左に二殻、右は極小
- repeatCount：2
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は左肩の大小二殻の内縁。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 左右対称の二つの鐘肩にしない
- 槌の打面を柔らかい嚢にしない
- 鐘を長い鎖でぶら下げない
