## 戦い方

**苔槽を満たして守る右腰装**

普段は殻を濡らしながらゆっくり歩き、近づく相手には右腰を見せて警告する。槽の水が減ると争いを切り上げる。

スタミナを残してガードし、槽の水を使う短い属性・防護区間を保つ。

- 得意：水倍率1.60、防御1.10倍。高スタミナの通常ガード後に守りと水が伸びる。
- 代償：基礎物理0.86倍、会心-10、戦闘スタミナ1.15倍。ガード後60%未満なら固有が出ない。
- 推奨：長尖槍、護刃、断岳剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.86倍、会心-10、戦闘スタミナ1.15倍。ガード後60%未満なら固有が出ない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：右槽の含水守り

通常ガード後にスタミナ60%以上を保つと、5秒間だけ苔水の槽を閉じて守る。毒を武器へ追加しない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 60〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、被ダメージ -6/-10% |
| 持続 / 再発動待ち | 5秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken。再発動待ちは戻さない |

### 武器主題（Lv1固定）：槽殻の継ぎ水

部位破壊の後に槽の水を整え、同じ相手への次の別行動から水属性を強める。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

右腰の浅い槽殻一つを最も大きくし、頭肩は低い灰緑板。左上から右下へ荷重が流れる段差。

配色：灰緑 / 苔の鈍緑 / 青銅溝

### 器官の転用

- 背殻の内面に苔水を蓄える槽があり、腹筋で片側の溝へ押し出す。槽の苔膜には餌から取り込んだ毒が薄く蓄積する。
- 右腰へ傾く槽殻を防具でも右腰一か所へ集中し、頭冠は薄く保つ。
- 水が減ると争いを切る生態を、ガード後のスタミナ残量による起動条件へ置く。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰側に浅い槽溝を一筋抱える片刃大剣 |
| 護刃 | 低い槽縁の短刃と、右下に浅槽を持つ閉じた盾 |
| 大槌 | 硬い苔晶の閉打面、片側に浅い槽室を添える |
| 双剣 | 刃元に小水槽溝を一つずつ持つ短剣二本 |
| 太刀 | 刃元から峰へ細い苔水溝を一筋通す曲刀 |
| 長尖槍 | 深い直芯の槍と、右下に槽板を寄せた大盾 |
| 環弓 | 握り外側に小槽板一枚。細い弓身、小環、直線弦 |

### 級別の形状発達

- 中級：右腰の一槽と低い頭冠。苔は溝の内だけ。
- 上級：槽の上縁へ二重の青銅留め、板を深くしない。
- 極級：内側の含水筋を二本へ整える。右腰の一槽という形を維持。

### モデル制作の固定条件

- primaryForm：右腰の低い槽板
- secondaryForm：苔膜と一本の青銅溝
- dominantRegion：右腰
- asymmetry：右下が大きく左肩は低い
- repeatCount：主槽1、胸板2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は右腰槽の内溝。平常：鈍い苔緑。発動：高スタミナガード後だけ溝が濡れ色に変わる。点灯面積は全身の3%以下。

避ける形：

- 背中に巨大な水タンクを付けない
- 毒を新しい武器属性として足さない
- 槽板を左腰にも同量複製しない
