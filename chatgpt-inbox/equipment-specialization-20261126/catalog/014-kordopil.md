## 戦い方

**補修して小板を保つ幼岩装**

三〜五頭で互いの背を近づけ、外側の個体が先に逃げる。親の警戒姿勢を見ると近くの岩陰へ集まる。

整備アイテムを使い、残った体力と小さな晶床を保って継戦する。

- 得意：防御1.03倍、刃容量1.22倍。整備後は刃持ちと軽い被ダメージ軽減。
- 代償：基礎物理0.96倍、会心-5、戦闘スタミナ1.05倍。HP60%未満では固有を起動できない。
- 推奨：断岳剣、護刃、長尖槍
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.96倍、会心-5、戦闘スタミナ1.05倍。HP60%未満では固有を起動できない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：幼床の繕い

HP60%以上で整備を終え、小板の表面を保つ。回復薬や未消費の操作では起きない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。 砥石など整備アイテムを実際に消費した完了時のみ。環弓は対象外。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 整備アイテムの実消費 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 60〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 刃消耗 -12/-20%、被ダメージ -4/-6% |
| 持続 / 再発動待ち | 8秒 / 16秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken。再発動待ちは戻さない |

## 見た目と制作

成人用の生成り胴着に、左肩だけ丸い幼岩板を三枚寄せる。親の巨大な左岩塊は作らず、小点の軽い輪郭。

配色：淡い灰褐 / 青銅の点 / 生成り

### 器官の転用

- 左背にだけ先行して育つ柔らかな晶脈床。頭冠は薄い一枚で、尾端晶はまだ丸い粒である。
- 未発達の柔晶床を左肩の丸小板へ、尾端晶を腰後ろの一粒へ縮めて置く。
- 小板を育てる未完成さを、整備を挟むことで保つ技能として表す。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元へ丸い補修板三枚を留めた細身の岩刃 |
| 護刃 | 薄い岩短刃と、小板三枚を生成り裏板に置く軽盾 |
| 大槌 | 硬い小岩を閉じた打面へまとめた小ぶりの槌頭 |
| 双剣 | 薄い小板を峰へ二枚ずつ置く短剣二本 |
| 太刀 | 低い小岩片を刃元だけへ貼る連続曲刀 |
| 長尖槍 | 丸い尾晶を刃元へ一粒置く直槍と、小板三枚の軽盾 |
| 環弓 | 弓の握り外に丸い岩粒一つ。細い骨弓身、小環と直線弦 |

### 級別の形状発達

- 初級：三枚の幼岩板を薄く丸くする。成人の可動域を保つ。
- 中級：小板の周囲へ点留めを足す。板を親の岩塊へ成長させない。
- 上級：柔晶の縁を二重に仕上げるが灰褐の丸さは残す。
- 極級：点留めを青銅に揃え、尾粒を滑らかに磨く。板数を増やさない。

### モデル制作の固定条件

- primaryForm：生成り布と三枚の丸小板
- secondaryForm：青銅の小点留め
- dominantRegion：左肩
- asymmetry：左肩のみ小さな偏り。左右の腕量は近い
- repeatCount：左肩板3、尾粒1
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は左肩の点留め三つ。平常：鈍い青銅点。発動：整備完了時に三点だけ弱く明るむ。点灯面積は全身の2%以下。

避ける形：

- ガルドロス装の縮小版にしない
- 尖った成体冠や大尾晶を付けない
- 幼体用の小さい人体比例にしない
