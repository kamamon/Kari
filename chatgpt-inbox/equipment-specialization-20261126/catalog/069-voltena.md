## 戦い方

**未破壊部位へ三層の露を通す装備**

古いヴェリトの左羽袋に分かれて育つ三層貯露房。水分と毒糸液を層ごとに保ち、低い水糸と薄い霧滴を別の向きへ押し出す。

同じ対象の未破壊部位を三行動で探り、露が巡った間だけ消耗を抑えて水霧攻撃を続ける。部位IDまでは固定しない。

- 得意：水霧量1.80倍、発動中は消耗-12/20%。
- 代償：基礎攻撃0.78倍、刃容量0.72倍、通常消耗1.32倍、火耐性-25。技能中の被ダメージ+8/12%。
- 推奨：双剣、護刃、太刀
- 避けたい状況：不利な運用: すでに破壊した部位だけを殴って起動を狙う運用

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

## 見た目と制作

左肩から短い帷を三層だけ重ね、右腕を細く露出。下端の滴形で三枚を数えられる。

配色：灰紫 / 生成り / 青銅

### 器官の転用

- 三層貯露房→左肩の三枚短帷
- 水糸と霧滴→上下で分かれる細い縁筋
- 右側から動く脚→右腕と右腰の露出

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三層の帷を峰の三段薄板へ写し刃面は一枚 |
| 護刃 | 三層の低い鍔の剣と、硬い裏板上に短帷を重ねる盾 |
| 大槌 | 側面に三段の滴室、前後は閉じた硬い打面 |
| 双剣 | 一方の峰に水糸、他方に霧滴の三段を写す二短剣 |
| 太刀 | 三枚の低い留めを刃元へ重ねた細長い太刀 |
| 長尖槍 | 三層縁を刃元に収める直槍と三段帷の独立盾 |
| 環弓 | 握り上の三つの薄片と小環、弓身を細く保ち一本の直線弦 |

### 級別の形状発達

- 極級：灰紫の短い帷を左肩から三段に重ね、右腕は細く露出させる。縁に鈍い青銅の滴形を付ける。 極級完成形のみ。三層は左肩側へ集め、全身を長い布で覆わない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：三層の短帷
- secondaryForm：滴形の縁
- dominantRegion：左肩
- asymmetry：左に三層、右は露出
- repeatCount：左の帷3、各層の代表滴1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左帷の三枚の縁。平常：鈍い青銅の滴形。発動：上層から下層へ三つの白滴が巡る。点灯面積は全身の4%以下。

避ける形：

- すでに破壊した部位だけを殴って起動を狙う運用
- 三層を四層以上へ増やす形
- 両肩を同じ厚い帷で覆う形
