## 戦い方

**尾輪の三拍で弱点へ雷風を刺す軽装**

高原の鉱物藻を食べ続けたルミスカに育つ環燐器。湾曲した燐板で尾の空気流を絞り、点灯した節から短い放電を重ねる。

敵の接触を三度回避して輪の下半分を灯し、弱点へ別行動を集中する。

- 得意：雷風量1.70倍、会心25。回避継続で会心+8/12・属性+10/16%。
- 代償：基礎攻撃0.80倍、防御0.76倍、消耗1.22倍、氷耐性-30。被弾で三拍が崩れる。
- 推奨：環弓、双剣、太刀
- 避けたい状況：不利な運用: 回避回数を稼ぐため正面で被弾を許す運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：環燐の三拍灯

420tick内に敵の接触を3回回避すると、輪の下半分が灯る。回避回数は攻撃一回ごとではなく行動ごとに数える。 回避入力ではなく、回避無敵中に敵攻撃の接触を避けた成功だけを数える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続240tick、発動時から再使用720tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 敵の接触を回避無敵で避けた時 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 7秒 |
| 効果（Lv1 / Lv2） | 会心pt +8/+12pt、属性ダメージ +10/+16% |
| 持続 / 再発動待ち | 4秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken, sheathe。再発動待ちは戻さない |

### 武器主題（Lv1固定）：環燐の照点

弱点へ異なる2射撃行動を通し、輪の開口を狙いに合わせる。近接系は適合定義で締めの命中へ置き換える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続180tick、発動時から再使用600tick。

## 見た目と制作

細い灰青の身体に、右後腰だけ開いた輪。上半分を暗く、下半分へ灯りを偏らせる。

配色：灰青 / 青銅 / 琥珀

### 器官の転用

- 環燐器→右後腰の開いた一輪
- 尾の絞り流→腰輪の下半分だけの細溝
- 燐板→細い脛と腕の低い弧板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 開口輪の弧を刃元の峰へ残す細幅大剣 |
| 護刃 | 細剣と右下に開口弧を飾る閉じた盾面 |
| 大槌 | 輪は槌頭側面の低い弧、前後の打面は硬く閉じる |
| 双剣 | 同長二刃の峰に半輪ずつを低く添える |
| 太刀 | 開口弧を小さい鍔へ写す細身太刀 |
| 長尖槍 | まっすぐな芯の刃元に弧、盾下側に低い輪縁 |
| 環弓 | 腰輪は小照準環の形へ縮小し、細い上下弓身と一本の直線弦 |

### 級別の形状発達

- 極級：灰青の細身を保ち、右腰の後ろだけに開いた青銅色の輪を置く。灯りは輪の下半分へ偏らせる。 極級完成形のみ。開いた輪の空隙と、下半分に偏る灯点を固定する。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：開口輪
- secondaryForm：細い弧板
- dominantRegion：右後腰
- asymmetry：右後腰だけ輪、左腰は平ら
- repeatCount：開いた輪1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は右後腰の輪の下半分。平常：上半分も下半分も鈍い青銅。発動：下半分だけ三点が順に灯り、上半分は暗い。点灯面積は全身の4%以下。

避ける形：

- 回避回数を稼ぐため正面で被弾を許す運用
- 閉じた円盤や左右対称の二輪
- 輪の全周を強く発光させる表現
