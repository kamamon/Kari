## 戦い方

**割れた部位へ熱電を送り続ける装備**

胸下の二枚の砕脈板と、その根元の熱電筋床。板を打ち合わせて付着鉱物を砕き、蓄えた熱と電荷を接触した側へ放つ。

部位を一つ壊して熱電筋を開き、壊れた場所へ当て直して消耗を抑える。

- 得意：基礎攻撃1.05倍、火雷量1.40倍。部位破壊後の属性+12/16%。
- 代償：会心-15、刃容量0.70倍、消耗1.45倍、消費1.15倍、水耐性-25。技能中は被ダメージ+6/10%。
- 推奨：大槌、断岳剣、太刀
- 避けたい状況：不利な運用: 未破壊の相手へ無計画に連打して消耗を放置する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：二板の破砕放熱

部位破壊で胸の二板を開き、火雷の流れを強める。開いた板の防護が落ちる代償を同時に受ける。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続600tick、発動時から再使用1200tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 部位破壊 |
| 必須タグ / いずれかのタグ | なし / なし |

| 必要な別行動 / 集計窓 | 1行動 / 5秒 |

既に壊れた部位へ当てると砕脈の粉が刃へ戻る。環弓では同値の回避消費軽減へ適合させる。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続300tick、発動時から再使用720tick。

## 見た目と制作

高い肩から胸下へ二枚の縦板を並べ、背腰を低く落とす。右は琥珀、左は青銅の細縁。

配色：灰黒 / 青銅 / 琥珀

### 器官の転用

- 砕脈板→胸下の二枚縦板
- 熱電筋床→左右別色の細い内縁
- 冷却停止→背腰の薄い低板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 二枚砕脈板を峰の両側へ寄せた厚い大剣 |
| 護刃 | 左右色の低い鍔の剣と二枚板の硬盾 |
| 大槌 | 前後の硬い打面の間に二色の縦側板 |
| 双剣 | 二短剣の片方に琥珀縁、片方に青銅縁、刃長同一 |
| 太刀 | 細い連続刃を二枚の低い峰留めで支える太刀 |
| 長尖槍 | 二色の刃元から伸びる直槍と縦二板の独立盾 |
| 環弓 | 二枚板は握り左右の小片のみ、小環と一本の直線弦を空ける |

### 級別の形状発達

- 極級：灰黒の胸へ二枚の縦板を並べ、肩を高く、背と腰を低く落とす。右板を琥珀、左板を青銅の細い縁にする。 極級完成形のみ。胸の二枚板を識別できる余白と、左右異なる細い縁色を保つ。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：二枚の縦板
- secondaryForm：低い後腰
- dominantRegion：胸下
- asymmetry：右板の縁は琥珀、左は青銅
- repeatCount：主胸板2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は胸下の二板の内縁。平常：二本とも鈍い暗色。発動：右の琥珀線と左の青銅線が交互に灯る。点灯面積は全身の4%以下。

避ける形：

- 未破壊の相手へ無計画に連打して消耗を放置する運用
- 胸の二枚を一枚の巨大板にする形
- 左右の全表面を強く発光させる表現
