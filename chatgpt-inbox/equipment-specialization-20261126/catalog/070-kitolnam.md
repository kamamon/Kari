## 戦い方

**息が細い時に折帆を返す氷霧装備**

キリサーヴの帆根に育つ折返し冷霧管。冷却液を薄い霧へ変え、菌食で得た眠り成分を混ぜた滴を帆の間へ蓄える。

余力が減った抜刀時に折帆を開き、軽い回避と氷霧補正で狭い間を抜ける。

- 得意：氷霧量1.64倍、スタミナ40%以下の抜刀で回避消費-12/20%・属性+10/14%。
- 代償：基礎攻撃0.84倍、防御0.84倍、刃容量0.82倍、火耐性-30。高スタミナの抜刀では起動しない。
- 推奨：双剣、太刀、環弓
- 避けたい状況：不利な運用: 満タンのスタミナで抜刀を反復して発動を狙う運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：折返しの薄息

抜刀完了時のスタミナが40%以下なら折帆を返す。スタミナそのものは回復せず、抜刀攻撃へ属性は乗らない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続240tick、発動時から再使用660tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

左右の低い折板を前後にずらし、背中の中央を空ける。後腰の短滴だけを垂らす。

配色：灰青 / 白灰 / 青銅

### 器官の転用

- 折返し冷霧管→肩の低い二重折板
- 帆を畳む向き→左右でずらした折れ線
- 冷霧滴→後腰の短い小滴

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 折返し線を厚い峰へ寄せた平たい大剣 |
| 護刃 | 返し鍔の細剣と、二重折板を硬い面へ重ねる盾 |
| 大槌 | 側面に折管の二段線、打面は硬く閉じる |
| 双剣 | 左右の折れ向きを対にした同長二剣 |
| 太刀 | 浅い返しを刃元の峰へ置く細い太刀 |
| 長尖槍 | 直槍の基部へ折管、盾は低い二重折れ |
| 環弓 | 折板は握り近くだけ、細い弓身に小環と一本の直線弦 |

### 級別の形状発達

- 極級：灰青の低い折板を左右ずらして肩へ重ね、背中の中央を空ける。後ろの腰だけに短い霧滴形を下げる。 極級完成形のみ。中央の背の空隙と、後腰だけの霧滴形を保つ。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：ずれた折板
- secondaryForm：短い霧滴
- dominantRegion：両肩と後腰
- asymmetry：肩板を前後へずらす
- repeatCount：肩の主折板左右1、背中央は0
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は肩の折れ線。平常：灰青の細溝。発動：折れ線だけ白く曇り、中央の背は暗いまま。点灯面積は全身の4%以下。

避ける形：

- 満タンのスタミナで抜刀を反復して発動を狙う運用
- 背の空隙を大きな板で塞ぐ形
- 折板を長い翼や肩氷柱へ変える形
