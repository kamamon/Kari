# 035 ケサルピナ — 庇頬

## 戦い方

**抜刀後の短い窓へ睡眠を濃縮**

左頬庇の裏に刷毛状の嚢があり、餌の菌胞子を細かく篩い分ける。頬庇を開いて短い翼で扇ぐと、睡眠成分を含む粉が片側だけへ流れる。 地上を歩いて尾で草を掃き、相手へ左頬を向けて距離を測る。翼は短い滑走と威嚇に使い、長く飛ばない。

スタミナ70%以上まで整える→抜刀完了→次の別行動で睡眠を載せる→摩耗窓を長引かせず納刀する。

- 得意：同級基準の物理倍率0.83、会心率+10ポイント。既存のsleep蓄積量を1.60倍。固有技能「片庇の乾いた一払い」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.83（同級基準比17%低い。系統補正前）、刃容量0.80倍、刃消耗1.40倍、防具一式の基準防御力0.78倍。弱点耐性は一式でthunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：双剣、太刀、護刃
- 避けたい状況：抜刀攻撃自体への技能加算を期待する一撃離脱。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：片庇の乾いた一払い

スタミナ70%以上で抜刀を終え、乾いた刷毛粉を次の別行動へ載せる。粉が付く間は消耗も増え、長い抜刀連撃には向かない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 抜刀完了 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 70〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 状態蓄積 +12/+16%、刃消耗 +15/+25% |
| 持続 / 再発動待ち | 3秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | あり / なし |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

## 見た目と制作

左頬の一枚だけ長い低庇と、後腰へ平たく伏せた短い尾羽。右肩と右頬を大きく空け、正面から明確に左重心。

配色：灰緑 / 生成り / 淡い骨白

### 器官の転用

- 片側の頬庇→左顔側の低い一枚庇
- 刷毛状の嚢→左前腕の小さな閉じた刷毛房
- 扁平な尾→後腰の薄い三枚尾羽

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 左頬庇を一枚の長い峰板へ写し、根元の小刷毛房を硬い覆いで閉じる |
| 護刃 | 庇状の片鍔を持つ細剣と、左縁だけ広い低い楕円盾 |
| 大槌 | 扁尾骨の閉じた硬面を二つ置いた槌頭。刷毛は中央側室だけに収める |
| 双剣 | 平たい細刃二本の峰へ同じ短い刷毛覆い。刃側へ毛を出さない |
| 太刀 | 長い庇を薄い峰へ写し、低い片鍔と短い尾羽形の鞘口を付ける |
| 長尖槍 | 直槍の根元へ低い片庇、盾の左上だけ幅広くし中央は硬い平面 |
| 環弓 | 左上の固定部に小さい庇と閉じた粉房。弓身は細く、一本弦と小環を保つ |

### 級別の形状発達

- 中級：左庇と三尾羽を灰緑、刷毛房を生成りにする。金属は小留めのみ。
- 上級：左庇の裏へ細い骨の支え、粉房に短い二重の留めを付ける。
- 極級：刷毛房の口縁だけに淡い白い点を並べる。右側へ庇を増やさず、尾羽は短い三枚のまま。

### モデル制作の固定条件

- primaryForm：左の単庇
- secondaryForm：水平三尾羽
- dominantRegion：左頬と左前腕
- asymmetry：左だけ重く、右を開ける
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は左前腕の刷毛房の短い口縁。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 両頬へ同じ長い庇を付けない
- 粉を常時大きな雲として出さない
- 尾羽を足首まで伸ばさない
