## 戦い方

**眠りを作って静かに収める帷装**

長い首だけを動かして周囲を探り、危険には帷羽を広げて距離を取る。翼は跳躍後に低く滑るためのもので、飛行を続けられない。

睡眠を蓄積してから一度納刀し、眠る相手への次の一撃を慎重に選ぶ。

- 得意：睡眠倍率1.50。睡眠成立後の次の別行動だけ会心を強める。
- 代償：基礎物理0.80倍、防御0.80倍。睡眠が成立しない相手には固有の機会がない。
- 推奨：双剣、太刀、環弓
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.80倍、防御0.80倍。睡眠が成立しない相手には固有の機会がない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：灰帷の静寂

自分の蓄積で睡眠が成立した相手に限り、次の別行動一つへ会心と物理を添える。眠りを自動再付与しない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 状態異常を新しく発症させた時 |
| 必須タグ / いずれかのタグ | asleep / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 会心pt +8/+12pt、物理ダメージ +4/+6% |
| 持続 / 再発動待ち | 8秒 / 16秒 |
| 1行動消費 / 同じ個体への限定 | あり / あり |
| 解除 | damage_taken, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：帷を落とす刃

抜刀完了後、次の別行動の睡眠蓄積を強める。抜刀攻撃自体には乗らない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

低い顔開き兜から細い立襟へつながる縦長の軸。背だけ短い灰の帷を二層垂らし、前脚は軽く見せる。

配色：灰白 / 淡い灰紫 / 焦げ茶の革

### 器官の転用

- 短い翼の内側にある灰粉房。菌食で得た成分を眠気を誘う粉へ蓄え、垂れた帷羽を振って狭い幕にする。
- 翼の灰粉房は背上部の薄い二層帷に限定し、長い首を細い襟で示す。
- 眠るまでの蓄積と、眠った後に攻撃を選ぶ静けさを分ける。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 暗い骨芯の片刃に短い灰羽房を刃元の片側だけ |
| 護刃 | 細身の短刃と、灰帷を硬い薄板に貼る小盾 |
| 大槌 | 閉じた灰骨打頭の側面だけ短い灰羽。布の打面にしない |
| 双剣 | 刃元の低い粉房を一つずつ持つ細い二短刃 |
| 太刀 | 鞘口と鍔の後ろにだけ灰帷を折る細い曲刀 |
| 長尖槍 | 低い羽房の直槍と、帷二層を閉じた裏板に添えた盾 |
| 環弓 | 弓身の根元へ短い灰羽束。照準小環と直線弦一本 |

### 級別の形状発達

- 初級：乾いた灰帷二層。端を腰上へそろえる。
- 中級：内側の帷だけ淡い灰紫。襟を高くしない。
- 上級：背の房口へ小さい黄銅留め。布の揺れ幅は固定。
- 極級：二層の縁に細い粉色の点。翼状に広げない。

### モデル制作の固定条件

- primaryForm：縦長の襟と短い二層帷
- secondaryForm：乾いた小灰羽
- dominantRegion：首と背上部
- asymmetry：前は細く背だけ垂らす
- repeatCount：主帷2、外腕羽3枚ずつ
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背上の帷の留め。平常：灰白の点。発動：睡眠成立時だけ留め三点が淡く灯る。点灯面積は全身の2%以下。

避ける形：

- 長い裾や顔を隠す深いフードにしない
- 背に大きな飛行翼を付けない
- 眠り粉の常時大煙幕を出さない
