# 003 ヌメラドン — 泥冠

原種ID `monster.numeradon`。初級〜極級。 [JSON原本](../data/species/003-numeradon.json) / [全級の装備・レシピ](../data/equipment/003-numeradon.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**水圧を集める部位掘削装**

採食中は鈍重だが、泥皿に触れられると敏感に反応する。移動前には必ず皿へ水を補う。

同じ個体の未破壊部位へ別行動で三度触れ、水圧を保ったまま破壊まで押す。部位IDは固定しない。

- 得意：水倍率1.75、防御1.05倍。三接触後の部位ダメージ+18/+25%。
- 代償：基礎物理0.82倍、会心-10、刃消耗1.30倍。技能中は刃消耗がさらに+12/+20%。
- 推奨：長尖槍、護刃、断岳剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.82倍、会心-10、刃消耗1.30倍。技能中は刃消耗がさらに+12/+20%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三掬いの穿皿

同じ相手の未破壊部位へ三つの別行動を当てると、刃を磨耗させて破壊を進める。状態異常は追加しない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | unbroken / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 7秒 |
| 効果（Lv1 / Lv2） | 破壊・切断蓄積 +18/+25%、刃消耗 +12/+20% |
| 持続 / 再発動待ち | 5秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：泥皿の圧返し

通常ガードで泥皿の圧を揃え、次の別行動の水属性を強める。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

## 見た目と制作

兜と前腰に二つの浅い泥皿。腹の耐水皮を横に張り、背は低くすぼめる前重心の半円形。

配色：泥褐色 / 灰白の皮 / くすんだ青緑

### 器官の転用

- 頭頂の泥受け皿と、その縁に並ぶ水圧嚢。取り込んだ水と細泥を練り、皿の前端から小さな塊として飛ばす。
- 頭皿を兜と前腰の浅い板へ分割し、丸い水圧嚢は前腕の短い側室へ。
- 泥を三度掬ってから押す行動を未破壊部位の三接触へ置換。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 広い泥受け面を峰の半面へ置く片刃。刃先は連続金属 |
| 護刃 | 浅皿形の閉じた盾と、水圧溝一本の短い刃 |
| 大槌 | 低く幅広い硬質泥晶の打頭。丸い嚢は頭の下の側室 |
| 双剣 | 二本の短刃の根元に小さな皿溝、先端は細く揃える |
| 太刀 | 峰に浅い水樋一本を走らせた平たい連続曲刃 |
| 長尖槍 | 前縁を斜めに閉じた槍穂と、浅い半円皿の大盾 |
| 環弓 | 弓の握り下だけ小さな水皿飾り。細い弓身、小環、直線弦 |

### 級別の形状発達

- 初級：二つの皿を浅く保ち、泥褐の皮を広く残す。
- 中級：皿の前縁へ一筋の青緑溝。後ろ縁は上げない。
- 上級：前腰の皿を二重縁にし、胸の三層皮へ短い留めを足す。
- 極級：圧溝を二筋へ整える。背に大型タンクや毒袋は付けない。

### モデル制作の固定条件

- primaryForm：浅い半円皿
- secondaryForm：横方向の耐水皮
- dominantRegion：前腰と前腹
- asymmetry：前が厚く背が薄い。左右の脚は均等
- repeatCount：主要皿2、腹皮3層
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は前腰の皿溝。平常：乾いた青緑の溝。発動：三接触で前縁だけ水色の薄い反射。点灯面積は全身の3%以下。

避ける形：

- 毒属性や毒袋を追加しない
- 兜を深いバケツ状にしない
- 皿を足・肩すべてに繰り返さない
