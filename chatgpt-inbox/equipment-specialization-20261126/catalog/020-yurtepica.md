## 戦い方

**整備で毒糸を編み直す幼糸装**

四〜八体が一枚の小さな糸床を共有し、乾いた場所へ一頭で出ない。危険を感じると尾糸を引いて隣の個体へ知らせる。

砥石などの整備後に短い毒区間を作り、被弾する前に離れて糸を保つ。

- 得意：毒倍率1.25。整備後に毒蓄積+12/+16%。
- 代償：基礎物理0.86倍、防御0.78倍。固有中は被ダメージ+6/+10%。環弓では整備条件が満たせない。
- 推奨：双剣、護刃、太刀
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.86倍、防御0.78倍。固有中は被ダメージ+6/+10%。環弓では整備条件が満たせない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：二糸の巣繕い

整備後6秒間だけ毒糸を張り直す。薄い羽袋を開くため被弾が痛くなり、被弾または納刀で区間を閉じる。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。 砥石など整備アイテムを実際に消費した完了時のみ。環弓は対象外。

## 見た目と制作

背の上部に平たい羽袋一枚と、左右へ短く出る二本の糸縁。生成り布の成人軽装で、ふくらんだ成体袋を持たない。

配色：淡い灰紫 / 生成り糸 / 灰茶

### 器官の転用

- 湿りを保つ平たい幼羽袋と二本の細紡糸管。毒を含む短い糸を巣の周囲へ張れるが、広い面にはできない。
- 幼羽袋を背上の平たい一枚へ、二本の紡糸管を短い左右の糸縁へ。
- 古い糸を回収して張り直す生態を、整備アイテム後の短い毒区間へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元背面へ平たい袋留め一つと二筋の糸巻き |
| 護刃 | 細い毒糸溝の短刃と、薄羽袋の面を硬板へ貼る軽盾 |
| 大槌 | 閉じた硬骨頭を二筋糸で締める小ぶりの大槌 |
| 双剣 | 平たい刃元へ糸を一筋ずつ巻く二短剣 |
| 太刀 | 峰の根元へ二筋だけ糸溝を刻む滑らかな曲刃 |
| 長尖槍 | 細い直槍の根元に平袋留め、薄い硬盾へ二筋の縁 |
| 環弓 | 薄い袋飾りを握り背面へ。小環と直線弦。外見設定のみで整備技能は発動不可 |

### 級別の形状発達

- 初級：薄く平たい袋一枚、灰紫を淡くする。
- 中級：袋縁の細い縫い目を二重にする。
- 上級：左右の糸縁の撚りを明瞭化。
- 極級：袋の内縁に細い鈍紫の点。成体の膨れ袋へ変えない。

### モデル制作の固定条件

- primaryForm：平たい背の一袋
- secondaryForm：二本の短い糸縁
- dominantRegion：背上部
- asymmetry：左右の糸縁は短く対称
- repeatCount：平羽袋1、糸縁2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は平袋の縫い目。平常：生成りの短い線。発動：整備完了で縫い目二筋だけ淡く紫がかる。点灯面積は全身の2%以下。

避ける形：

- ヴェリトの二つの大袋を縮小して載せない
- 糸縁を長い触手にしない
- 環弓の外見を整備技能の有効性と混同しない
