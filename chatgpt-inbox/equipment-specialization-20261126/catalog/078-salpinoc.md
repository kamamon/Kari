## 戦い方

**左帷で受け右鋏で一手を返す装備**

左の柔らかな帷甲に付く圧露嚢と、右鋏の内側の毒溝。帷で空気を押し、鋏から落ちる毒性の水滴を低い霧へ散らす。

同じ相手を二度受けて左帷へ圧を溜め、別行動の物理を一度だけ強める。

- 得意：風霧量1.62倍、二度受け後の物理+8/10%。
- 代償：基礎攻撃0.90倍、防御0.90倍、刃容量0.85倍、消耗1.38倍。技能中の消耗+15/25%、火耐性-25。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：不利な運用: 被弾しながら二度受けを貯める運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：左帷右鋏の一返し

同じ相手を300tick内に通常ガード2回で受け、次の別行動へ圧を渡す。返しの強さと刃の消耗が同時に増す。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続240tick、発動時から再使用720tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

左肩だけ縦の帷板を高くし、右籠手は下へ重く垂れる形。左右の高さが逆になる輪郭。

配色：灰緑 / 暗灰紫 / 青銅

### 器官の転用

- 圧露嚢→左肩の高い薄板の裏
- 右鋏の毒溝→右籠手の短い暗紫溝（武器は風霧のみ）
- 脚を揃える待機→細い左右対称の脚

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 左帷の縦面を峰へ、刃元の右側へ鋏の短溝を置く大剣 |
| 護刃 | 短い鋏刃と、左帷を硬い裏板で支える独立盾 |
| 大槌 | 右鋏の硬殻を打面に、左帷は側面の低い室だけ |
| 双剣 | 同長二刃の片方は薄帷峰、片方は鋏溝峰 |
| 太刀 | 短い鋏溝を刃元へ収めた細長い太刀 |
| 長尖槍 | 右鋏線の直槍と左帷板を写す縦長盾 |
| 環弓 | 左帷を薄い弓身の筋へ、右鋏溝を握りへ。小環と一本の直線弦 |

### 級別の形状発達

- 極級：灰緑の縦板を左肩だけ高くし、右籠手は太く下へ伸ばす。毒溝は暗い灰紫で短く区切る。 極級完成形のみ。右腕の毒溝は暗灰紫の短区間に限定し、左肩と右前腕の非対称を固定。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：高い左帷
- secondaryForm：重い右前腕
- dominantRegion：左肩と右籠手
- asymmetry：左は上、右は下へ体積を寄せる
- repeatCount：左主板1、右鋏甲1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左肩板の裏と右籠手溝。平常：暗い灰紫の短溝。発動：左裏の白筋が消えた後、右の短溝が細く灯る。点灯面積は全身の4%以下。

避ける形：

- 被弾しながら二度受けを貯める運用
- 右籠手が手首と指を覆って曲がらなくなる形
- 毒溝の外見から毒蓄積を追加すること
