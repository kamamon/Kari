## 戦い方

**熔継板を閉じて受ける複合重装**

長年の鉱物摂取で背板・頭冠・胸甲の継ぎ目に育つ熔継晶床。擦れで熱と電荷を蓄え、開いた板の側へ熱した鉱粉や電荷を放つ。尾端晶へ通じる導晶管も持ち、尾の放電は晶が灯ってから起こる。

三度の通常ガードで板を閉じ合わせ、軽減を得た時間に火雷の別行動を通す。

- 得意：基礎攻撃1.11倍、防御1.10倍。技能で被ダメージ-8/12%、火雷の属性+8/12%。
- 代償：会心-20、消耗1.40倍、回避・ガード等の消費1.20倍、水耐性-25。受けるだけでスタミナが尽きる。
- 推奨：断岳剣、護刃、長尖槍
- 避けたい状況：不利な運用: スタミナを空にしてガードを継続する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：熔継三板の閉合

480tick内に通常ガードを3回成功させて大板を閉合。属性を持つ武器だけが属性補正を受ける。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続360tick、発動時から再使用960tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

|---|---|
| 起点 | 通常ガード成功 |

## 見た目と制作

左肩から左腰へ灰黒の大板を段で渡し、低い横割れ冠へつなぐ。光は継ぎ目に限る。

配色：灰黒 / 青銅 / 琥珀

### 器官の転用

- 熔継晶床→大板の接合線だけの琥珀と青銅
- 左成長板→左肩から腰へ落ちる段
- 導晶管→腰の内側へ収めた短い尾端芯

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 熔継大板を峰へ重ねる重剣、刃縁は一本 |
| 護刃 | 継ぎ目の短剣と、左上へ厚さを寄せた独立盾 |
| 大槌 | 晶芯を内蔵する閉じた両打面、側面だけ継ぎ目が見える |
| 双剣 | 灰黒二短剣の峰に火と雷の細い接合線 |
| 太刀 | 低い継ぎ板を刃元へまとめた重い太刀 |
| 長尖槍 | 厚い刃元から細く伸びる直槍と段板大盾 |
| 環弓 | 大板を小片へ分け握り近くへ配置、しなる弓身・小環・一本の直線弦 |

### 級別の形状発達

- 極級：灰黒の段状大板を左肩から腰へ渡し、板の継ぎ目だけ青銅と琥珀にする。兜の冠は低く横へ割る。 極級完成形のみ。継ぎ目の青銅と琥珀を細線に限定し、次級の大型化や金色化を作らない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：段状の大板
- secondaryForm：細い継ぎ目
- dominantRegion：左肩から左腰
- asymmetry：左は大板、右は小分割
- repeatCount：左の主板3、冠の割れ1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左胸と腰の継ぎ目。平常：暗い灰黒面。発動：継ぎ目だけ琥珀と青銅が交互に点く。点灯面積は全身の4%以下。

避ける形：

- スタミナを空にしてガードを継続する運用
- 全身の金色化や全面発光
- 右肩を左と同じ大きさにする形
