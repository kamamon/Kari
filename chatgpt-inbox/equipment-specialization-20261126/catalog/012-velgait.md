## 戦い方

**納めて六灯を整える霧装**

灯節を弱く光らせながら静かに巡回する。警戒時は頭冠を向けてから霧球を落とし、球が膨らむ間に離れられる。

明示的に納刀して呼吸を揃え、短い守りと会心の区間で再接近する。

- 得意：霧倍率1.80。納刀完了後の会心と被ダメージ軽減で接近を助ける。
- 代償：基礎物理0.80倍、防御0.79倍。納刀の隙を作れないと低い防御を補えない。
- 推奨：環弓、太刀、双剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.80倍、防御0.79倍。納刀の隙を作れないと低い防御を補えない。

## 見た目と制作

後頭部の低い半環と、背中一列の六灯だけが明るい細い靭皮装。胸腹は暗く大面を作らない。

配色：暗い灰緑 / 鈍い琥珀 / 灰青

### 器官の転用

- 背の六つの灯節と、環状の頭冠に囲まれた凝霧孔。体表の水分を薄い霧へし、粘液膜で包んだ小球を前方へ落とす。
- 環状の頭冠は後頭部の寝た半環へ、六灯は背の一本列だけへ移す。
- 静かに巡回して間合いを整える生態を、明示納刀で短い区間を作る技能へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の根元に六つの小霧窓を並べた薄い大剣 |
| 護刃 | 暗い短刃と、六点を縦に埋めた硬い細盾 |
| 大槌 | 閉じた靭骨の槌頭に六小窓を側面二列で配置 |
| 双剣 | 三つずつの低い霧窓を持つ二短刃 |
| 太刀 | 峰の六窓を小さく沈めた連続曲刃 |
| 長尖槍 | 細い凝霧芯の直槍、六小灯を縦に持つ閉じた盾 |
| 環弓 | 弓の握り周辺だけ六小窓。小照準環一つと直線弦 |

### 級別の形状発達

- 初級：六灯を鈍い点に抑え、暗い靭皮を主面にする。
- 中級：後頭半環の下縁だけ青銅で留める。
- 上級：六灯の間の黒い間隔を広げて見せる。
- 極級：灯窓に薄い内縁を足す。新しい灯や全身の光膜を加えない。

### モデル制作の固定条件

- primaryForm：細い縦軸と低い後頭環
- secondaryForm：小さな灯窓
- dominantRegion：背中央と後頭部
- asymmetry：背中中心、前面は無灯
- repeatCount：背灯6、後頭半環1
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背の六灯。平常：鈍い琥珀の点。発動：納刀完了で六点が一度順に弱く点灯。点灯面積は全身の4%以下。

避ける形：

- 頭上の浮遊輪や天使の輪にしない
- 背の灯を六つ以外へ増やさない
- 長い尾や霧の常時大雲を付けない
