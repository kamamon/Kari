## 戦い方

**櫛を戻す前に麻痺を刻む装備**

左の櫛棘の根元にある冷痺管。薄い冷却液で棘表面を固め、棘先にだけ痺れ液をにじませて獲物を引き留める。

同じ相手へ斬撃を三行動通し、短い時間に麻痺を稼いで離れる。櫛を開いた連撃は消耗が増える。

- 得意：麻痺量1.60倍、会心20。三斬撃後の麻痺+12/16%。
- 代償：基礎攻撃0.80倍、防御0.78倍、刃容量0.75倍、消耗1.40倍、火耐性-30。技能中さらに消耗+18/25%。
- 推奨：双剣、太刀、護刃
- 避けたい状況：不利な運用: 消耗を無視して麻痺中も同じ連打を続ける運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：左櫛の三筋開き

240tick内に同じ対象へ3行動の斬撃を通して櫛を開く。一行動の多段斬撃は一回。開いている間は消耗が増す。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続240tick、発動時から再使用660tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | slash / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 4秒 |
| 効果（Lv1 / Lv2） | 状態蓄積 +12/+16%、刃消耗 +18/+25% |
| 持続 / 再発動待ち | 4秒 / 11秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe。再発動待ちは戻さない |

## 見た目と制作

前半身の左側だけ短い櫛、背腰は平面。琥珀は櫛先の点だけで灰青の面を保つ。

配色：灰青 / 暗灰 / 琥珀の点

### 器官の転用

- 左の櫛棘→左額と左前腕の短櫛
- 冷痺管→櫛根元の短い内溝
- 平たい後半節→平らな背と腰

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元左側の峰に低い三櫛、切先は一枚の連続刃 |
| 護刃 | 短い櫛鍔の剣と左上だけ三櫛を低く飾る硬盾 |
| 大槌 | 側面に三櫛の小突起、前後は閉じた硬い打面 |
| 双剣 | 同長二剣の峰に短い三櫛、刃先の線を途切れさせない |
| 太刀 | 左側の刃元へ低い三櫛を置き鞘と干渉させない太刀 |
| 長尖槍 | 小三櫛の刃元を持つ直槍と、左上だけ櫛縁の独立盾 |
| 環弓 | 櫛飾りを握り左側の小片へ限定、小環と一本の直線弦を空ける |

### 級別の形状発達

- 極級：灰青の前半身の左側だけに短い櫛を並べ、背と腰は平らにする。棘先の琥珀色は点で抑える。 極級完成形のみ。短い櫛は前半身左側だけ、琥珀色は棘先の点にとどめる。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：短い左櫛
- secondaryForm：平らな後半身
- dominantRegion：左額と左前腕
- asymmetry：左前だけ櫛、背と右は平面
- repeatCount：額櫛3、前腕櫛3
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左櫛の先端。平常：琥珀色の小点。発動：棘先だけ六つの小点が順に灯る。点灯面積は全身の4%以下。

避ける形：

- 消耗を無視して麻痺中も同じ連打を続ける運用
- 背や右肩まで櫛を増やす形
- 櫛を長くして武器判定や防具外形を広げる形
