## 戦い方

**二度の受け流しで冷却を保つ氷盾**

二列の畝殻に冷晶を含む溝が通り、掬った水を薄い氷の層にする。左右の溝は別々に閉じるため、攻撃に使う側だけが白く曇る。 六脚で岩の縁を横歩きし、片方の鋏を上げて接近者を測る。凍った地面でも腹を接地させずに向きを変える。

同じ敵へ二度の受け流しを成功させる→氷攻撃とガードを交互に続ける→再使用中は条件を貯めない。

- 得意：同級基準の物理倍率0.94、会心率-5ポイント。既存のice属性量を1.20倍。固有技能「双畝の交互冷却」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.94（同級基準比6%低い。系統補正前）、会心率-5ポイント、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.10倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍
- 避けたい状況：受け流しを持たない武器での固有技能運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：双畝の交互冷却

同じ敵への二度の受け流しを、左右の溝を交互に閉じる拍へ対応させる。冷えた畝の間は氷と受けの効率を保つ。  360tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 6秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、ガード消費 -12/-20% |
| 持続 / 再発動待ち | 5秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

## 見た目と制作

頭から背へ同高の二本の低い畝が平行に走り、両前腕が同じ幅の浅い匙甲になる。丸い横幅の中に厳密な二列を通す。

配色：青灰 / 白氷 / 鈍青銅

### 器官の転用

- 二列の畝殻→頭から背の二本平行稜
- 左右別に閉じる冷導溝→二列の短い独立窓
- 左右同幅の掬い鋏→対称な匙状籠手

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 幅広い峰に二本の冷導稜を平行に通す。刃は一続きで氷刃を突き出さない |
| 護刃 | 二本稜の細剣と、同幅二つの匙面を中央で合わせた硬い盾 |
| 大槌 | 二列の閉じた畝を横断させた低い槌頭。両打面は同じ硬い平面 |
| 双剣 | 一本ずつ同じ畝を持つ二本刃。並べると正確な平行二列になる |
| 太刀 | 細い峰に近接した二本線を通し、刃元でのみ畝の厚みを見せる |
| 長尖槍 | 二条の溝を持つ直槍と、左右同幅の匙面を持つ盾。中央の芯は直線 |
| 環弓 | 握りの外側に低い二本畝、弓端は薄い灰青。小環は中央、弦は一本の直線 |

### 級別の形状発達

- 中級：青灰の二畝に白い溝を短く見せる。左右を同じ形にする。
- 上級：畝の外側に鈍青銅の細い縁、両籠手を同じ厚さで二層にする。
- 極級：二溝の小窓だけ透明感を増す。畝の高さと間隔は変えず、大きな氷晶は追加しない。

### モデル制作の固定条件

- primaryForm：同高の平行二畝
- secondaryForm：対称な浅匙
- dominantRegion：頭・背・両前腕
- asymmetry：厳密な左右対称
- repeatCount：2
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は胸の独立した二本溝。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 片側の鋏だけ巨大化しない
- 二列を三列へ増やさない
- 氷の棘で外周を覆わない
