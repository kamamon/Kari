## 戦い方

**受け流した敵へ一点の会心を返す**

脱皮のずれで殻の一層が外向きに育った逆硝冷板。板の内側の冷却液が海霧を凍らせ、鋏で押すと氷片が前へ滑る。 オルグラスのうち殻の成長方向が反転した希少個体である。潮だまりを横歩きで巡り、近づく相手へ反り殻を向けて威嚇する。

同じ敵を受け流す→次の別行動の一撃へ会心を集める→短い窓を逃したら無理に追わない。

- 得意：同級基準の物理倍率0.92、会心率+20ポイント。既存のice属性量を1.40倍。固有技能「逆硝の一点反射」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.92（同級基準比8%低い。系統補正前）、刃容量0.84倍、刃消耗1.32倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.06倍、防具一式の基準防御力0.88倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍
- 避けたい状況：受け流しの無い武器と別の敵への乗り換え。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：逆硝の一点反射

受け流した相手へ次の別行動を返す時だけ、反り板の一点へ刃を沿わせる。会心率と刃の保持を得るが、別の敵では消費も発生しない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、600tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 会心pt +8/+12pt、刃消耗 -12/-18% |
| 持続 / 再発動待ち | 3秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | あり / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

## 見た目と制作

横に広い胴の右肩だけ外へ反る半透明板。左前腕の長い低甲で釣り合い、短い脚装甲が横幅を支える。

配色：透ける灰青 / 白氷 / 暗青銅

### 器官の転用

- 右の逆硝冷板→右肩の外反り一枚板
- 長い左鋏→左前腕の低い長甲
- 冷却液の内層→反り板の奥の細い白い筋

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の右面だけ外へ浅く反った一枚殻。刃の有効長を変えず先を閉じる |
| 護刃 | 細い氷筋の剣と、右側だけ外反り一枚板を持つ硬い盾 |
| 大槌 | 半透明殻を側面へ伏せた硬い二打面の槌。反り先は打面を越えない |
| 双剣 | 二本の刃の外側へ鏡像の反り縁。先端長と手元の厚みを揃える |
| 太刀 | 細い連続刃の峰へ浅い反り筋を付け、鞘から飛び出す板を作らない |
| 長尖槍 | 直槍の根元を薄い逆硝板で囲み、盾の右縁だけ外へ反らせる |
| 環弓 | 中央右側に一枚の浅い反り板。弓端は細い骨弓、一本弦と小環を保つ |

### 級別の形状発達

- 上級：右肩だけ透ける灰青、左前腕は不透明な低甲。白筋は反りの内側。
- 極級：反り板の根元へ短い暗青銅の押さえ、左甲の先を手首で明確に切る。大きな氷片は足さない。

### モデル制作の固定条件

- primaryForm：右肩の外反り一枚板
- secondaryForm：左前腕の長い低甲
- dominantRegion：右肩と左前腕
- asymmetry：右上と左下へ量を分ける
- repeatCount：1
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は右肩反り板の内側の白筋。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 左籠手を指先まで伸ばさない
- 全身を透けるガラスにしない
- 左右両肩を同じ反り殻にしない
