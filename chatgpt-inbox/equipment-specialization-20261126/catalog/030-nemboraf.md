# 030 ネムボラフ — 泥層

## 戦い方

**受けて水を返す濾過重装**

腹下の層状濾嚢で根の隙間の水を濾し、食べられる菌と有機物を集める。濾嚢の端にたまる発酵液は、膨らんだ袋から局所的な眠りの泡として漏れる。 脚を確かめながら同じ道をゆっくり歩く。進路を塞がれると頭を引いて警告し、しつこく攻撃する相手だけを押し返す。

同じ攻勢を二度受ける→三層を満たす→水の攻撃へ転じる→重くなる回避を連発せず次の受けに戻る。

- 得意：同級基準の物理倍率0.84、会心率+0ポイント。既存のwater属性量を1.55倍。固有技能「三層濾膜の返し水」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.84（同級基準比16%低い。系統補正前）、刃消耗1.12倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.12倍。弱点耐性は一式でfire -20,thunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：ガードできない武器で固有技能を主軸にする運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三層濾膜の返し水

二度受けて濾膜に水を残す。攻め直しの水属性が強い間は、濡れた層の重さで回避消費も増える。  240tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 4秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、回避消費 +8/+12% |
| 持続 / 再発動待ち | 5秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：濾膜の受け溜め

水を層に残す濾膜を、受け止めた後の一撃へ回す。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。解除しても再使用時間は戻さない。

## 見た目と制作

肩幅より腹の横幅を大きくした低い台形。三段の濾膜を硬い胸の下へ吊り、四角い脛で支える。背中は平らで、後腰だけ薄い横扇。

配色：灰緑 / 泥褐 / 鈍い青銅

### 器官の転用

- 層状濾嚢→胸下の三つの浅いカセット状の折り膜
- 四本の柱脚→左右の前腕と脛の四角い短甲
- 泥扇骨→後腰の一枚の水平扇板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三段の濾膜を峰の奥へ収めた幅広い台形大剣。刃側は一続きの灰骨面 |
| 護刃 | 濾歯の細剣と、三本の水平濾膜窓を持つ角盾。窓の裏は連続した硬い板で閉じる |
| 大槌 | 柱脚甲の四角い二打面を持つ低い大槌。側面だけ三段の膜を見せる |
| 双剣 | 短い匙先を対にした二本の刃。両方の峰に同じ高さの三層線を入れる |
| 太刀 | 細い骨芯の連続刃と、刃元だけに段状の濾膜房を置く太刀 |
| 長尖槍 | 角い濾歯の槍先と、柱状稜二本で挟む幅広い盾。膜は盾裏の縁に収める |
| 環弓 | 平たい弓中央へ三枚の短い濾膜板を重ね、曲がる両端を細く残す。小環と一本弦 |

### 級別の形状発達

- 中級：三段の濾膜をすべて灰緑の不透明膜で作り、角甲の縁は泥褐。
- 上級：段の間へ短い青銅の留めを増やす。胸板幅と三段の数は保持。
- 極級：各段の中央に小さな澄んだ水色窓を一つずつ足す。光る面を広げず、四角い脛の外周だけ二重縁。

### モデル制作の固定条件

- primaryForm：低い台形と水平三層
- secondaryForm：四角い柱甲
- dominantRegion：胸下と脛
- asymmetry：左右対称、後腰の扇だけ前後差
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は胸下三段の膜縁。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 全身を丸い水袋にしない
- 盾の濾膜窓を穴のままにしない
- 水嚢を足先へ垂らさない
