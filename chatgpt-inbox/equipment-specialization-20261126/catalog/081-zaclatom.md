## 戦い方

**三角喉を開いて火の一手を差す装備**

左喉の三角形の炉喉嚢。食べた脂と鉱物性の分泌膜を別室に蓄え、喉を伸ばした時だけ短い熱息へ変える。

HPを守って抜刀し、その次の別行動へ火を集中する。短い準備中は受ける痛みが増す。

- 得意：火量1.78倍、会心25。HP80%以上の抜刀で次行動の火+12/16%。
- 代償：基礎攻撃0.83倍、防御0.80倍、刃容量0.80倍、消耗1.25倍、水耐性-30。技能中の被ダメージ+10/15%。
- 推奨：太刀、環弓、断岳剣
- 避けたい状況：不利な運用: HPを削られたまま抜刀反復で発動を狙う運用

### 防具固有：左炉喉の一息

抜刀完了時にHP80%以上なら左喉を開く。抜刀攻撃自身を除く次の別行動へ火を渡すが、喉を開いた間は被弾に弱い。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続180tick、発動時から再使用600tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

左襟だけ細長い三角を立て、灰褐の胴を細くする。短い扇板を後腰へ広げる。

配色：灰褐 / 琥珀 / 青銅

### 器官の転用

- 三角炉喉嚢→左襟の縦三角
- 別室の脂膜→三角の内側だけの二条熱筋
- 短い幅広尾→後腰の短い扇板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三角喉の形を刃元の峰へ寄せた細幅大剣 |
| 護刃 | 小三角鍔の剣と左上だけ三角縁の硬盾 |
| 大槌 | 槌頭側面に小三角室、前後の打面は硬く閉じる |
| 双剣 | 同長二刃の峰へ細い三角溝を刻む |
| 太刀 | 刃元の低い三角鍔から伸びる細長い太刀 |
| 長尖槍 | 三角形の小刃元から直槍を伸ばし独立盾の左縁へ短い三角 |
| 環弓 | 握り周りに小三角室、細い弓身・小環・一本の直線弦 |

### 級別の形状発達

- 極級：灰褐色の細い胴へ左側だけ三角の襟を立て、後ろ腰を短い扇板で広げる。熱筋は襟の内側へ抑える。 極級完成形のみ。三角形は左襟と握り周辺へ限定し、炎の大型装飾を付けない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：左だけの縦三角
- secondaryForm：短い扇腰
- dominantRegion：左襟と後腰
- asymmetry：三角は左側のみ
- repeatCount：主三角1、内側熱筋2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左襟の内側。平常：暗い二条の熱筋。発動：襟の内側だけ琥珀の二線が短く点く。点灯面積は全身の4%以下。

避ける形：

- HPを削られたまま抜刀反復で発動を狙う運用
- 右襟にも同寸の三角を増やす形
- 炎の翼や全面の赤熱表現
