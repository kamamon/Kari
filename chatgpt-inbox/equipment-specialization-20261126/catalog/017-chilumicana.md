## 戦い方

**二点を合わせる幼燐精密装**

三〜五羽が交替で尾を光らせ、岩陰の仲間へ居場所を示す。追われると翼で低く滑ってから走る。

短い間隔で同じ弱点へ二つの行動を合わせ、二点灯の短い射線を作る。

- 得意：会心+20、雷倍率1.35。二弱点命中後の短時間精度。
- 代償：基礎物理0.84倍、防御0.77倍。三秒以内の二行動を外すと蓄積が途切れる。
- 推奨：環弓、双剣、太刀
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.84倍、防御0.77倍。三秒以内の二行動を外すと蓄積が途切れる。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：二燐の瞬き

同じ相手の弱点へ3秒以内に二つの行動を通すと、3秒だけ二灯が揃う。成体の長い放電区間より短い。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | weakspot / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 3秒 |
| 効果（Lv1 / Lv2） | 会心pt +8/+12pt、属性ダメージ +8/+12% |
| 持続 / 再発動待ち | 3秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |

## 見た目と制作

淡い青灰の成人軽装。背の最下部に離れた琥珀二点だけを置き、長い灯列を作らない。

配色：淡い青灰 / 琥珀二点 / 生成り

### 器官の転用

- 二節だけの幼燐節器。光は点滅するが蓄電量が少なく、放電は尾先のすぐ近くに限られる。
- 幼燐節は必ず二つだけ。背の下部へ置き、成体の長尾の列と区別。
- 交替で居場所を知らせる二灯を、短い二命中の精度区間へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の片面に二小燐節だけ置く薄い大剣 |
| 護刃 | 細い短刃と、下縁に二点を持つ小盾 |
| 大槌 | 閉じた小骨打頭の両側へ一小燐節ずつ |
| 双剣 | 各短刃の根元に一つずつ小燐節 |
| 太刀 | 峰の根元へ二点を寄せた細い曲刃 |
| 長尖槍 | 直槍の握り上へ二小節、細い盾の下縁に二点 |
| 環弓 | 握り上に離れた二小節。小環一つと直線弦 |

### 級別の形状発達

- 初級：二点の燐節は小さく淡い。
- 中級：二点の間に生成りの革幅を明瞭に残す。
- 上級：節の外周を細い骨縁で支える。
- 極級：二節の内面だけ琥珀を濃くする。数は二のまま。

### モデル制作の固定条件

- primaryForm：細い灰青胴着と離れた二点
- secondaryForm：短い放電膜
- dominantRegion：背下部
- asymmetry：二点は背中心の左右、他部位は無灯
- repeatCount：主要燐節2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背下部の二灯。平常：淡い琥珀。発動：二命中後に二点が同時に短く点く。点灯面積は全身の2%以下。

避ける形：

- 成体の五節・長尾へ変えない
- 点灯数を二つより増やさない
- 幼児体型にしない
