# 007 オルグラス — 硝殻

原種ID `monster.orglass`。初級〜極級。 [JSON原本](../data/species/007-orglass.json) / [全級の装備・レシピ](../data/equipment/007-orglass.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**硝殻を合わせる受け流し装**

正面の接近には鋏を広げるが、背後へ回られると横歩きで向き直る。脱皮の直後は硬い板が育つまで争いを避ける。

受け流しで敵の向きを読み、次の別行動を未破壊部位へ戻す。

- 得意：会心+25、刃容量1.20倍。受け流し後の部位攻撃が得意。
- 代償：基礎物理0.92倍、防御0.88倍。受け流しの失敗を防御で押し切れない。
- 推奨：護刃、長尖槍
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.92倍、防御0.88倍。受け流しの失敗を防御で押し切れない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：片鋏の面合わせ

薄い硝板の面を合わせ、受け流した相手への短い会心・部位攻撃区間を作る。通常ガードでは発動しない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 会心pt +8/+12pt、破壊・切断蓄積 +12/+18% |
| 持続 / 再発動待ち | 4秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change。再発動待ちは戻さない |

## 見た目と制作

右前腕の大きな三角硝板と、右肩から左腰へ下がる斜めの板列。左腕と腹の革面は広く見せる。

配色：灰緑の半透明 / 鈍い青銅 / 灰茶

### 器官の転用

- 右大鋏の内側にある硝殻成形腺。硝砂から得た成分を薄い半透明板として外殻へ重ね、鋏の当たり面だけ厚くする。
- 右大鋏を右籠手一か所へ集約し、全身を透明装甲にしない。
- 硬い板の面を正確に合わせる特性を、受け流し後の会心へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 片側だけ三角硝板を三枚重ねた鋭い片刃大剣 |
| 護刃 | 硝殻の細い刺突刃と、右上が高い三角盾 |
| 大槌 | 硬い硝骨打面を持つ角柱頭。透明な板は側面のみ |
| 双剣 | 小鋏の内面を形にした細い二本。刃の重さは一致 |
| 太刀 | 薄い硝板を低く連ねる滑らかな曲刃 |
| 長尖槍 | 硝鋏芯のまっすぐな槍穂と、斜め三枚の硬板盾 |
| 環弓 | 硝板は握り横の小三角二枚だけ。細い骨弓身、直線弦、小環 |

### 級別の形状発達

- 初級：硝板三枚を浅い灰緑に。右籠手の輪郭を一段だけ大きく。
- 中級：板縁の青銅留めを細く増やし、板同士の間を残す。
- 上級：右籠手に内外二層の面。透明度を上げ過ぎない。
- 極級：斜め三板の内面に小さな晶片。左腕は軽いまま。

### モデル制作の固定条件

- primaryForm：右の大三角面
- secondaryForm：斜めに重なる半透明板
- dominantRegion：右前腕と右肩
- asymmetry：右大、左小。ガルドロスの左偏りと逆
- repeatCount：胸硝板3、主籠手1
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は右籠手の三角縁。平常：灰緑の半透明。発動：受け流しで三角の内側二辺だけ白く反射。点灯面積は全身の3%以下。

避ける形：

- 右籠手を実物の巨大な鋏へしない
- 全身を宝石で覆わない
- 透明板を顔全面に被せない
