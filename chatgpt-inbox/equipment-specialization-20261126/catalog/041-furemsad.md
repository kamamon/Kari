## 戦い方

**頭への打撃で殻割りと霧を両立**

喉の横鰭に細かな分霧孔が並び、吐いた水を地面近くの二本の霧帯へ分ける。尾端の厚い骨は貝を割る器官で、叩く前に高く持ち上がる。 短い肢で砂州を歩き、地面近くへ頭を下ろして獲物を探る。喉鰭を傷つける相手には尾を高く示して威嚇する。

頭へ二つの打撃行動→同じ敵の頭・部位へ霧と破壊蓄積→間合いを外して次の二拍を狙う。

- 得意：同級基準の物理倍率0.87、会心率+5ポイント。既存のmist属性量を1.60倍。固有技能「鰭霧と鈍尾の継ぎ目」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.87（同級基準比13%低い。系統補正前）、防具一式の基準防御力0.83倍。弱点耐性は一式でwind -20,thunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：大槌、護刃
- 避けたい状況：斬撃や矢だけで頭を狙う構成。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：鰭霧と鈍尾の継ぎ目

同じ頭へ二つの打撃行動を当て、尾骨が割った継ぎ目へ分霧孔の霧を通す。斬撃や矢の頭命中では蓄積しない。  300tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | head, blunt / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +10/+16%、破壊・切断蓄積 +14/+20% |

### 武器主題（Lv1固定）：鈍尾の分霧

殻を割る尾骨の打撃の後に、喉鰭の霧を次の別行動へ移す。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

灰青の細身に一枚だけ横へ広い喉襟。後腰の低い丸骨が重心を締め、肩には鰭を反復しない。

配色：灰青 / 骨白 / 砂褐

### 器官の転用

- 喉の一枚横鰭→首下の単一の薄い襟
- 分霧孔→襟下縁の左右二列の小孔
- 鈍い尾骨→後腰の一枚の丸骨板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の横幅だけ一枚鰭のように広げ、峰の後ろへ丸い骨芯を低く収める |
| 護刃 | 細い霧孔の剣と、上縁だけ一枚の横鰭を写す低い盾 |
| 大槌 | 鈍い尾骨の閉じた二打面。中央に小さい横鰭形の側板を一枚挟む |
| 双剣 | 細い刃二本の刃元へ小さい一枚鰭鍔。左右の先端長を揃える |
| 太刀 | 細い連続刃に二列の小霧孔を刃元だけ刻み、横鍔を低くする |
| 長尖槍 | 直槍の根元に薄い一枚襟、盾は鈍い骨面と短い横鰭の上縁 |
| 環弓 | 細い弓の中央に短い一枚横鰭。小環と一本弦を守り、丸い尾骨は握り下の小覆いにする |

### 級別の形状発達

- 中級：灰青の単襟と骨白の後腰板。霧孔は小さい暗点だけ。
- 上級：襟の根元へ短い支持筋を足し、丸骨の外縁を一段だけ厚くする。
- 極級：孔の縁だけ淡い霧色。背面の丸骨は鈍い形を保ち、棘を追加しない。

### モデル制作の固定条件

- primaryForm：喉の単一横鰭
- secondaryForm：後腰の丸骨
- dominantRegion：首下と後腰
- asymmetry：左右対称、前後に二つの焦点
- repeatCount：1
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は喉襟下縁の小さい二列孔。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 丸骨を前腰へ移さない
- 横鰭を二枚以上重ねない
- 尾骨を鋭い尾槍へ変えない
