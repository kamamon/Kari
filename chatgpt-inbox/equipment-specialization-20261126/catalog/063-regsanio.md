## 戦い方

**左盤を守りながら雷を整える盾装備**

左首に偏る片盤電鰭。円盤状の発電膜と、周縁の麻痺粘液腺を分けて持ち、盤を反らすと湿った地面へ短い放電を流す。

二度の受けで盤の電位を揃え、維持時間に小さな雷攻撃を続ける。途中の被弾で整流が切れる。

- 得意：雷量1.65倍、技能中はガード消費-12/20%と雷+8/12%。
- 代償：基礎攻撃0.81倍、防御0.90倍、消耗1.22倍、氷耐性-25。回避主体では固有技能を作動できない。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：不利な運用: ガード不能系統で固有技能を主力にする運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：片盤の二度受け

360tick内の通常ガード2回で整流を始める。受け流しは回数に含めない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続420tick、発動時から再使用960tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

左肩の薄い円盤を斜め前へ傾け、右肩を細くする。腰を長く見せる二列の低い背骨。

配色：灰青 / 暗灰 / 鈍い青銅

### 器官の転用

- 片盤電鰭→左肩だけの一枚盤
- 周縁腺→盤裏の細い環状溝
- 背骨→腰へ下る二列の低稜

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 盤の一弧を峰へ残し直刃へ削ぐ片刃大剣 |
| 護刃 | 細い雷溝の剣と、一枚斜盤の独立盾 |
| 大槌 | 薄い盤を側飾りに持つ閉じた硬い両打面槌 |
| 双剣 | 同長二刃の片方に環溝、もう片方に直溝 |
| 太刀 | 低い盤鍔と長い一条の峰を持つ太刀 |
| 長尖槍 | 直槍の刃元に半環、盾は薄い円盤を偏心配置 |
| 環弓 | 握り上の小照準環だけ盤縁を写し、細い弓身と一本の直線弦 |

### 級別の形状発達

- 上級：左肩に丸く薄い灰青の盤を一枚置き、右肩を細く保つ。背には低い骨の二列だけを走らせ、腰を長く見せる。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級は左盤の内側に細い電膜を二重で張り、外径は固定。背の二列骨の間隔を保ち、首周りへ増やさない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：薄い斜盤
- secondaryForm：低い二列骨
- dominantRegion：左肩
- asymmetry：左肩だけ円盤、右は細い
- repeatCount：盤1、背稜2
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左肩盤の裏側。平常：灰青の細環が暗い。発動：盤裏の環だけに青銅の点が巡る。点灯面積は全身の4%以下。

避ける形：

- ガード不能系統で固有技能を主力にする運用
- 左右二枚の同寸円盤
- 背骨を大きい棘へ膨らませる形
