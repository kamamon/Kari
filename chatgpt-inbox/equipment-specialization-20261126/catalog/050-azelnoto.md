## 戦い方

**疲れた受けを次の受けへつなぐ潮環装**

骨環の腹側に発達した潮環水枕。浅瀬で水を含んで膨らみ、腹を順に押すと低い水筋が進む。 氷の裂け目を使うラズメルから、周期的な増水へ適応した亜種である。水たまりと根のある洲を順に巡り、食べ物の無い相手には追跡を続けない。

受けの後にスタミナ35%以下→次の受けと息継ぎを助ける→ガードが崩れる前に手を止めて回復する。

- 得意：同級基準の物理倍率0.86、会心率+0ポイント。既存のwater属性量を1.55倍。固有技能「潮環の引き潮支え」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.86（同級基準比14%低い。系統補正前）、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.08倍。弱点耐性は一式でthunder -20。形状による当たり判定・リーチの優遇はない。
- 推奨：長尖槍、護刃、断岳剣
- 避けたい状況：ガード失敗を条件成立として数える運用。

## 見た目と制作

背を平らにし、腹側へ張る半環を腰と腿外側に集める。上半身を細く、下半身だけに浅い横の膨らみを作る。

配色：灰青 / 水白 / 骨白

### 器官の転用

- 腹側の薄い骨環→前腰の二つの低い半環
- 潮環水枕→半環の内側の白い柔膜
- 短肢の長胴→低い腰と小さい肩

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元に二つの低い半環を腹側へ伏せた平刃。背側を滑らかにする |
| 護刃 | 小半環の鍔を持つ剣と、下半分へ二つの水枕面を収めた盾 |
| 大槌 | 側面下へ二つの半環を伏せ、二打面は閉じた硬い骨面 |
| 双剣 | 二本の刃元に同じ低い半環。柔膜は峰の固定部だけ |
| 太刀 | 細い連続刃の根元へ低い半環の筋。長い背を滑らかに保つ |
| 長尖槍 | 直槍の根元に二つの低半環、盾の下縁だけ水枕の丸面 |
| 環弓 | 握り下へ二つの浅い半環を付ける。弓の背は平ら、小環と一本弦を保つ |

### 級別の形状発達

- 上級：灰青の二半環と水白の内膜。背は平らで骨白の短い縁だけ。
- 極級：半環内膜に細い水筋を追加し、左右の腿外側の受けを二重縁にする。輪を閉じた大円にしない。

### モデル制作の固定条件

- primaryForm：腹側の半環
- secondaryForm：平らな背
- dominantRegion：前腰と腿外側
- asymmetry：左右対称、腹側のみ膨らむ
- repeatCount：2
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は前腰半環の白い内膜。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 背中へ大きな骨輪を張らない
- 原種の氷棘を残さない
- 腿の半環を膝の前へ渡さない
