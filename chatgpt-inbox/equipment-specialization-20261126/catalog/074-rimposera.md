## 戦い方

**整備で四室を満たす水装備**

腹下の折り畳み皮に囲まれた四室の汐函嚢。海水を濾して水を蓄え、食べた潮藻由来の眠り成分を一室ずつ混ぜて吐き出す。

砥石を実際に一個消費して四室を整え、水攻撃を続ける。消耗の速さを整備間隔へ組み込む。

- 得意：水量1.76倍、防御0.98倍。整備後の水+12/16%。
- 代償：基礎攻撃0.84倍、刃容量0.70倍、消耗1.35倍、雷耐性-25。技能中の被ダメージ+8/12%。環弓では砥石条件を満たせない。
- 推奨：護刃、断岳剣、太刀
- 避けたい状況：不利な運用: 環弓装備で整備型の防具技能を主力にする運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：汐函の整備充填

整備アイテムを実際に1個以上消費して成功した時だけ発動。現行の対象は砥石。回復薬・睡眠道具・使用開始では発動しない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続480tick、発動時から再使用1200tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 整備アイテムの実消費 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、被ダメージ +8/+12% |

## 見た目と制作

平たい背と小さな頭、腰の四隅だけ短い生成り袋。四室の留め以外を鈍い灰褐へ抑える。

配色：灰褐 / 生成り / 青銅

### 器官の転用

- 四室汐函嚢→腰の四隅の短袋
- 折り畳み皮→袋の四角い低い襞
- 濾水口→袋留めの小さな青銅窓

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 四室を刃元の小側室へまとめた平大剣 |
| 護刃 | 低い四角鍔の剣と、四隅に小室を持つ硬盾 |
| 大槌 | 四室は槌頭の側面へ、前後は硬く閉じた打面 |
| 双剣 | 二短剣へ二室ずつを刃元側だけ配る |
| 太刀 | 細い太刀の鍔元へ四つの短い濾溝 |
| 長尖槍 | 直槍の基部に四室留め、盾の四隅へ短い袋縁 |
| 環弓 | 四室の小窓を握り側面へ置く外見案、小環と一本の直線弦。防具技能は弓では起動しない |

### 級別の形状発達

- 極級：灰褐色の平たい背板と、腰の四隅へ短く下がる生成りの袋を写す。袋の留め部だけ青銅色にする。 極級完成形のみ。四隅の袋は短く固定し、膝や武器の軌道へ垂らさない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：四角い短袋
- secondaryForm：平たい背板
- dominantRegion：腰の四隅
- asymmetry：四隅は同寸、背を平らに保つ
- repeatCount：腰袋4
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は腰の四つの留め。平常：生成りの襞に暗い窓。発動：四つの小窓が順に灰青へ変わる。点灯面積は全身の4%以下。

避ける形：

- 環弓装備で整備型の防具技能を主力にする運用
- 回復薬を四室充填の条件へ読み替えること
- 腰袋を腹の大袋一つへ合体する形
