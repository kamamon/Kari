# 019 ミトガロン — 幼鉤

原種ID `monster.mitogaron`。初級〜極級。 [JSON原本](../data/species/019-mitogaron.json) / [全級の装備・レシピ](../data/equipment/019-mitogaron.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**閉じ切らぬ輪で刻む幼鉤装**

三〜六体が近い間隔で歩き、体節の湿りを保つ。丸まり切れないため、追われると倒木の隙間へ逃げる。

短い三つの行動を同じ相手へ通して痺液をまとめ、回避で輪を開き直す。

- 得意：麻痺倍率1.15、戦闘スタミナ0.90倍。短い連係の後に回避しやすい。
- 代償：基礎物理0.87倍、防御0.79倍。三秒で三行動が必要で、長い溜めには合わない。
- 推奨：双剣、護刃、太刀
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.87倍、防御0.79倍。三秒で三行動が必要で、長い溜めには合わない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：開輪の三渡り

同じ相手へ3秒以内に三つの行動を当てると、短い痺液区間が生まれる。多段一行動は一回。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 3秒 |
| 効果（Lv1 / Lv2） | 状態蓄積 +10/+14%、回避消費 -8/-12% |

## 見た目と制作

生成りの成人胴着に、閉じない半円板を三つずらす。鉤先は小さく丸く、成体の尖った螺旋にしない。

配色：灰褐 / 淡い赤銅 / 生成り

### 器官の転用

- まだ締まり切らない輪留め腱と、丸い鉤先へ続く細い痺液管。弧状には曲がるが成体の斜め回転はできない。
- 閉じ切らない輪留め腱を開いた半円板へ、丸い鉤先を短い丸突起へ移す。
- 幼体が丸まり切れず短く逃げる様子を、短い三行動と回避費用へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の峰に小さな丸鉤を三つ並べた薄い片刃 |
| 護刃 | 細い短刃と、開いた半円意匠を硬い裏板へ載せる軽盾 |
| 大槌 | 閉じた硬い小節の打頭、側面の鉤は丸く短い |
| 双剣 | 小さな丸鉤を峰の根元に一つずつ持つ二短刃 |
| 太刀 | 低い半円筋を峰へ沈めた連続曲刃 |
| 長尖槍 | 細い痺液管の直槍、半円板一枚の低い盾 |
| 環弓 | 弓根元に小さい開輪の留め二つ。直線弦、小環 |

### 級別の形状発達

- 初級：丸い小鉤と開いた半円を生成り服に留める。
- 中級：半円の両端へ淡い赤銅の点留め。
- 上級：痺液管の細筋を板内側へ一本。
- 極級：半円の縁を磨くが輪を閉じず鉤を伸ばさない。

### モデル制作の固定条件

- primaryForm：閉じない三つの半円
- secondaryForm：ごく短い丸鉤
- dominantRegion：胸外側と腰後ろ
- asymmetry：半円を互い違いにずらす
- repeatCount：主半円3、各板の丸鉤1～2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は胸の開輪の両端。平常：淡い赤銅点。発動：三行動後に両端だけ淡く灯る。点灯面積は全身の2%以下。

避ける形：

- 成体の長い鉤や巨大な巻き角にしない
- 閉じた輪へ完成させない
- 成人装備を幼児サイズへしない
