## 戦い方

**息切れ際に風を拾う回避軽装**

用心深く、まず横跳びで間合いを外す。角膜を大きく開く威嚇を無視されると、短い突きを繰り返す。

スタミナが減った局面で敵の攻撃を回避し、呼吸を戻して短い属性攻撃へ移る。

- 得意：風倍率1.70、戦闘スタミナ消費0.90倍。回避成功後の回復速度に特化。
- 代償：基礎物理0.85倍、防御0.77倍、刃容量0.80倍。発動中の被ダメージ+8/+12%。
- 推奨：双剣、太刀、環弓
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.85倍、防御0.77倍、刃容量0.80倍。発動中の被ダメージ+8/+12%。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：風下の息継ぎ

残スタミナ45%以下の回避成功で呼吸が戻るが、帆が開く間は守りが薄い。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。 回避入力ではなく、敵の攻撃との接触を回避無敵で抜けた成功時だけ判定。

## 見た目と制作

背の中央から後ろ肩へ流れる二枚の畳み帆。胴は細く、脚と前面の余白で軽さを出す。

配色：灰緑 / 乾いた象牙 / 鈍青銅

### 器官の転用

- 頭の分割角膜を支える弾性軟骨と、鼻先の整流孔。角膜の開閉で短い空気の押し出しを前方や斜め前へ整流する。
- 分割角膜を飛行翼にせず、肩の後ろに畳む短い布骨として移す。
- 低スタミナで開く余裕の少なさを、回復と受けの弱さを同時に持つ技能へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰だけ三折りの帆骨を沿わせた薄い片刃大剣 |
| 護刃 | 小さな斜め帆刃と、薄膜を硬い骨枠に張った閉じた楕円盾 |
| 大槌 | 閉じた骨打面の間に畳み膜を挟む細い鼓形大槌 |
| 双剣 | 帆の折り筋を峰に一本ずつ持つ後流れの短刃二本 |
| 太刀 | 細く連続する曲刃の根元だけ二折り膜骨 |
| 長尖槍 | 二枚の細い帆骨で挟む直槍と、硬い骨裏板を持つ畳み帆盾 |
| 環弓 | 細い弓身に後ろへ寝た膜筋。握り上の小環と直線弦一本 |

### 級別の形状発達

- 初級：二枚帆を完全に畳み、乾いた膜筋を一本だけ見せる。
- 中級：折り目へ細い骨縁。背で交差させず二枚を分ける。
- 上級：膜の内側だけ淡い象牙の筋。薄さと細い脚を保つ。
- 極級：二段の折りを明瞭化。大型の翼へ拡張せず腰裾は短いまま。

### モデル制作の固定条件

- primaryForm：細い後流れの二折り
- secondaryForm：露出した灰緑革と腱帯
- dominantRegion：背肩
- asymmetry：前面は左右均等、背の流れだけ後方へ偏る
- repeatCount：畳み帆2、外脚帯2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背肩の折り筋。平常：閉じた灰緑の筋。発動：成功時に内側の二筋だけ淡く明るむ。点灯面積は全身の3%以下。

避ける形：

- 飛行できそうな横長翼にしない
- 大きなマント・肩の板鎧で胴を太らせない
- 弓を巨大な輪や円盤にしない
