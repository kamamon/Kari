## 戦い方

**三露を納めて霧を一手に渡す軽装**

首を伸ばして草越しに周囲を見ながら地上を歩く。翼は低い段差を滑り降りるために使い、飛び続けない。

残スタミナ85%以上で明示的に納刀し、三露を保ったまま次の別行動一つへ霧を渡す。

- 得意：霧倍率1.85、会心+15。納刀後の一行動に属性+12/+16%。
- 代償：基礎物理0.81倍、防御0.76倍。蓄えた区間は被ダメージ+8/+12%。睡眠属性や睡眠道具は追加しない。
- 推奨：環弓、太刀、双剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.81倍、防御0.76倍。蓄えた区間は被ダメージ+8/+12%。睡眠属性や睡眠道具は追加しない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

## 見た目と制作

細い紫灰の襟から軽い胴へつなぎ、腰後ろの低い三つの露珠袋だけが丸い。前と肩は細く背下に重さを置く。

配色：淡い紫灰 / 灰緑 / 琥珀の細縁

### 器官の転用

- 尾節の二重露腺が霧の水滴を集め、餌の菌から得た眠気を誘う成分を薄く混ぜる。尾節が順に膨らんだ後だけ、狭い帯へ霧を散らす。
- 尾の三露珠を腰後ろへ低く置く。細首は襟で示し、珠を頭や肩へ移さない。
- 明け方に露を集めて風下で保つ習性を、高スタミナの納刀で一手だけ保つ霧へ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元背面に三小珠を低く収める霧の片刃 |
| 護刃 | 細い霧刃と、盾の下縁裏へ三小珠を置く硬盾 |
| 大槌 | 閉じた硬骨打頭の下面に三小珠。打面に袋を使わない |
| 双剣 | 刃元の小珠を二つと一つへ分けた二短刃。重さは同じ |
| 太刀 | 鞘口の後ろに三つの低い露留めを付ける曲刃 |
| 長尖槍 | 直槍の根元へ三小珠、盾下縁に短い露膜 |
| 環弓 | 握り下へ三小珠を短く固定。細い弓身、直線弦一本、小環 |

### 級別の形状発達

- 中級：腰後ろ三珠を淡い紫灰で低く揃え、襟は細い。
- 上級：三珠の各根元へ二重の細い留めを足す。
- 極級：露膜の内縁だけ琥珀の細線。珠の数と腰後ろの位置は維持。

### モデル制作の固定条件

- primaryForm：細襟と低い三珠
- secondaryForm：淡い露膜と細い琥珀縁
- dominantRegion：腰後ろ
- asymmetry：珠は背下中央、肩は低く均等
- repeatCount：主露珠3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は腰後ろ三珠の細い縁。平常：淡紫灰の閉じた縁。発動：納刀完了で三縁だけ鈍く琥珀色へ。点灯面積は全身の4%以下。

避ける形：

- 露珠を胸・肩・正面腰へ移さない
- 三つ以外の大珠を増やさない
- 眠りを無条件付与したり睡眠薬必須にしない
