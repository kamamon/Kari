## 戦い方

**余力のある受けから整備へつなぐ火装**

首の四角襟の下に、晶粉を含む熱脂を分泌する羽鞘が並ぶ。襟の一辺を持ち上げてから、その方向だけへ熱い粉を吐く。 短い翼で灰を掬い、襟へ積もる粉をこまめに落とす。相手が近づくと襟の一辺を立てて先に警告する。

スタミナ60%以上を残す受け→火の反撃または短い整備→襟が閉じるまでに次の位置を取る。

- 得意：同級基準の物理倍率0.92、会心率+10ポイント。既存のfire属性量を1.30倍。固有技能「四角襟の灰落とし」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.92（同級基準比8%低い。系統補正前）、刃消耗1.25倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.12倍、防具一式の基準防御力0.93倍。弱点耐性は一式でwater -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍、断岳剣
- 避けたい状況：スタミナを残せない連続ガード。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：四角襟の灰落とし

スタミナ60%以上を残した受けで襟の一辺を開く。余熱を攻撃へ送りつつ、整備品の使用時間だけを短くする。回復薬は短縮しない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から360tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 60〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +8/+12%、整備使用時間 -12/-20% |
| 持続 / 再発動待ち | 6秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：襟辺の灰選り

一辺だけを開く四角襟にならい、頭へ当てた後の別行動で部位を選って削る。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

低い四角襟が首を囲み、四隅の角を丸く落とす。小さい匙肩と平らな胴で、四角い首の水平面を主役にする。

配色：灰黒 / 鈍赤銅 / 煤灰

### 器官の転用

- 四角襟→首周囲の低い四辺枠
- 一辺ごとの熱粉→四辺内縁の短い窓
- 匙翼→肩の小さい浅皿

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元に低い四角枠の鍔、峰の一辺だけ赤銅の細い溝を付ける |
| 護刃 | 四角い低鍔の剣と、四辺を灰黒の厚縁で囲む角丸盾 |
| 大槌 | 四辺を短い熱窓で区切った角丸槌頭。両打面は閉じた煤灰面 |
| 双剣 | 二本の小さな四角鍔と平らな細刃。小窓は刃元の内縁だけ |
| 太刀 | 長い細刃の刃元へ四角襟を潰した低い鍔。峰の色線は短く留める |
| 長尖槍 | 直槍の根元に小さな四辺枠、盾は低い四角面で角を丸める |
| 環弓 | 握り外側の小四角枠の上に小照準環。弓端は匙形に太らせず細く、弦は一本 |

### 級別の形状発達

- 中級：四角襟の内縁だけ赤銅、外側は灰黒。匙肩を小さく保つ。
- 上級：四辺を独立した短い継ぎ目で分け、煤灰の胸に短い排熱筋。
- 極級：四隅へ小さな青銅留め、内縁は鈍い赤銅のまま。火柱や高い襟を追加しない。

### モデル制作の固定条件

- primaryForm：低い四角襟
- secondaryForm：小さい匙肩
- dominantRegion：首の周囲
- asymmetry：左右対称の四辺
- repeatCount：4
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は四角襟の内側四辺。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 襟を高い壁にして顔を隠さない
- 四隅を長い角にしない
- 肩を火の翼にしない
