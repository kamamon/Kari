## 戦い方

**砂裾を払う消耗精密装**

普段は体を伸ばして礫の間を探り、追われると開けた方向へ丸まって逃げる。狭い通路では転がらず鉤で押し返す。

スタミナを使い切る手前の接触回避で砂を払い、刃の短い切れ味区間を保つ。

- 得意：会心+25、戦闘スタミナ0.90倍。低スタミナ回避後の精度と刃持ち。
- 代償：基礎物理0.94倍、防御0.78倍、刃容量0.72倍、刃消耗1.32倍。条件を外すと整備が頻繁になる。
- 推奨：双剣、太刀、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.94倍、防御0.78倍、刃容量0.72倍、刃消耗1.32倍。条件を外すと整備が頻繁になる。

## 見た目と制作

前身は細く、腰後ろの三節だけを横へ低く広げる砂裾装。外鉤は短く下向き、上半身の輪郭は平たい。

配色：灰黄 / 砂褐 / 鈍い赤銅

### 器官の転用

- 後部の腹砂腺が細かな礫と毒を含む樹皮脂を混ぜ、外鉤の根に塗る。丸まる直前に後ろ三節が開くため、転がる方向が分かる。
- 後ろ三節だけ広がる体を腰後ろの低い三段へ。毒脂は鈍い砂色の膜として留める。
- 開けた方へ転がって砂を払い直す生態を、息切れ際の接触回避と刃管理へ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元へ後三節を模す低い三段を置く大剣 |
| 護刃 | 砂鉤筋の短刃と、下側へ三段を寄せた硬盾 |
| 大槌 | 閉じた砂晶打頭の側面に三段の低い節 |
| 双剣 | 峰へ下向きの短い鉤を持つ二短剣。指側へ出さない |
| 太刀 | 低い三段峰を刃元にだけ残した連続曲刀 |
| 長尖槍 | 直槍の根元に短い砂鉤、盾の下側へ低い三段板 |
| 環弓 | 握り下に三段の小節留め。細い弓身、直線弦、小環 |

### 級別の形状発達

- 中級：後ろ三節を低く横へ開き、砂膜を薄く残す。
- 上級：節の内側に細い脂砂の溝。鉤の先は短い。
- 極級：三段の縁を鈍い赤銅で磨く。上半身を輪甲へ変えない。

### モデル制作の固定条件

- primaryForm：腰後ろの低い三段裾
- secondaryForm：短い下向き鉤と砂膜
- dominantRegion：腰後ろ
- asymmetry：前細、後ろ広。左右は均等
- repeatCount：後裾節3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は後ろ三節の内側溝。平常：砂褐の乾いた溝。発動：回避成功で三筋の砂色が鈍く濡れる。点灯面積は全身の3%以下。

避ける形：

- テンガロと同じ閉じた螺旋にしない
- 毒脂を毒属性の追加と解釈しない
- 三段裾を長い尾や床を引くスカートにしない
