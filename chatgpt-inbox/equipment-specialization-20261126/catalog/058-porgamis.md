## 戦い方

**受け流し後の一行動へ物理を集中**

幅広い下顎の内側に並ぶ箒顎梳板。柔らかな根をふるい分ける弾性板で、横へ撓ませて戻すと狭い範囲へ硬い礫を弾く。 普段は穏やかで、鼻先を地面へ寄せたまま草地を歩く。採食場を一定の順に巡り、下顎へ触れる相手には大きく首を引いて警告する。

同じ敵の攻撃を受け流す→次の別行動へ物理と破壊力を集中→再使用中は高摩耗を管理する。

- 得意：同級基準の物理倍率1.16、会心率-20ポイント。固有技能「箒顎の溜め返し」は同系列2部位でLv1、4部位でLv2。
- 代償：会心率-20ポイント、刃消耗1.50倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.16倍。弱点耐性は一式でwater -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍
- 避けたい状況：受け流し自体へ攻撃補正を遡って載せる運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：箒顎の溜め返し

受け流しで梳板を撓め、同じ敵への次の別行動に圧を返す。高い物理・破壊蓄積を一行動へ絞り、受け流し自身の攻撃へは加算しない。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 物理ダメージ +8/+10%、破壊・切断蓄積 +18/+25% |
| 持続 / 再発動待ち | 3秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | あり / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

## 見た目と制作

肩と背を平らにそろえ、兜の下縁だけ横へ広い短櫛。短く太い籠手に弾性板の層を集め、腰と脚は小さくする。

配色：灰褐 / 骨白 / 暗青銅

### 器官の転用

- 箒顎梳板→兜下縁の短い横櫛
- 撓む弾性板→前腕の三層の厚い面
- 低い平背→肩から背を同じ低さの板でつなぐ

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 幅広い峰の根元に五つの短い櫛溝。刃は平らで厚い一枚面 |
| 護刃 | 櫛形の低い小鍔の剣と、横長の上縁に五つの短溝を持つ平盾 |
| 大槌 | 三層の弾性板を硬い打面で閉じた太い槌頭。櫛歯を打面へ出さない |
| 双剣 | 厚い短刃二本の峰に同数の浅い櫛溝。外周は連続面で引っ掛けない |
| 太刀 | 細い長刃の根元へ低い櫛鍔。峰は一枚の滑らかな線 |
| 長尖槍 | 太い直槍の根元に短い櫛縁、盾は平らな横長の上面と三層の下板 |
| 環弓 | 中央外側に短い櫛溝五つを刻む。細い弓身と一本弦・小環を維持し、櫛を大きく開かない |

### 級別の形状発達

- 上級：灰褐の低い平背と骨白の五短櫛。暗青銅は籠手三層の短い縁。
- 極級：櫛溝の底へ細い暗青銅線、籠手の三層を短い留めで強調。櫛の数と短さを維持。

### モデル制作の固定条件

- primaryForm：低い平面と短櫛
- secondaryForm：太い三層籠手
- dominantRegion：兜下縁と前腕
- asymmetry：左右対称、肩と背を同高
- repeatCount：5
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は兜下縁の五短溝の底。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 櫛歯を長い牙にしない
- 背を高い岩山形にしない
- 武器の刃を櫛歯で途切れさせない
