## 戦い方

**雨樋を交互に満たす水間合い装**

雨を受ける向きへ体を置き、満ちた水嚢を揺らさないようゆっくり歩く。水嚢を狙われると長い胴で間合いを作る。

同じ敵の未破壊部位へ二つの突きを通し、水樋を揃えて長い間合いを保つ。

- 得意：水倍率1.70、刃容量1.24倍。二突き後の水とガード負担軽減。
- 代償：基礎物理0.84倍、会心-5、戦闘スタミナ1.12倍。突き行動を持たない系統は固有を起動できない。
- 推奨：長尖槍、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.84倍、会心-5、戦闘スタミナ1.12倍。突き行動を持たない系統は固有を起動できない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

## 見た目と制作

左右交互に下へ垂れる樋板三枚と、腰後ろの低い平尾板。肩を低く保ち、樋の縦溝が細くつながる。

配色：くすんだ青灰 / 灰緑の皮 / 鈍青銅

### 器官の転用

- 冷晶の薄板が雨を集める柔らかな樋帆へ変わり、節間の水嚢へつながる。体を捻ると片側の樋だけが前へ向く。
- 下へ垂れる交互樋帆を肩・脇・腰の三枚へ、平尾を腰後ろの短板へ。
- 満ちた水嚢を揺らさず間合いを作る生態を、二つの突きから続くガード可能な水区間へ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の片面へ浅い雨樋を一本通す片刃大剣 |
| 護刃 | 樋筋の短刃と、交互三板を硬い芯へ添える盾 |
| 大槌 | 閉じた水骨打頭の側面に浅い樋三筋 |
| 双剣 | 峰へ樋筋を一本ずつ持つ細い二短剣 |
| 太刀 | 連続曲刃の峰を低い水樋にする |
| 長尖槍 | 長い直芯に一本の水樋、交互三板と平尾板の大盾 |
| 環弓 | 弓根元へ交互に短い樋板。直線弦一本、小照準環 |

### 級別の形状発達

- 中級：三樋を浅く垂らし、後ろ平尾板は短く水平。
- 上級：樋の縁へ青銅の細い支えを付け、左右交互を明瞭化。
- 極級：内溝を二筋に磨く。樋の垂れ長さや尾板幅は増やさない。

### モデル制作の固定条件

- primaryForm：交互に垂れた三樋板
- secondaryForm：低い平尾板と灰緑皮
- dominantRegion：体側と腰後ろ
- asymmetry：左上・右中・左下の交互配置
- repeatCount：主樋板3、平尾板1
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は三樋の内溝。平常：くすんだ青灰。発動：二突き後に溝三本だけ濡れ色がつながる。点灯面積は全身の3%以下。

避ける形：

- 氷帆の尖った三角形へ戻さない
- 平尾板を長い尻尾へ伸ばさない
- 薄い樋膜だけを盾の支持構造にしない
