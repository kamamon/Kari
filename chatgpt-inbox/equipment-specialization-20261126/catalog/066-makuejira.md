## 戦い方

**締めを二度通して風路を開く装備**

梯子状の胸骨に分かれた梯胸風路。喉の毒液を少量ずつ風路へ送って水滴にし、開いた骨の段から狭い前方へ吹き出す。

同じ相手に締めの攻撃を二度通し、風と部位補正が重なる短い時間へ攻撃を集める。

- 得意：風量1.80倍、固有技能で風+12/16%・部位+10/16%。
- 代償：基礎攻撃0.80倍、防御0.85倍、消耗1.30倍、氷耐性-30。通常連打だけでは風路が開かない。
- 推奨：環弓、断岳剣、大槌
- 避けたい状況：不利な運用: 締めの技を使わず弱い通常打だけ続ける運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：梯胸の二段開路

同じ対象へ300tick以内に締めの攻撃を2行動通し、胸の風路を開く。部位補正はHPへ重複計上しない。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 同じ対象に蓄積し、攻撃効果もその対象に限定する。 持続300tick、発動時から再使用840tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | finisher / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、破壊・切断蓄積 +10/+16% |

### 武器主題（Lv1固定）：梯骨の溜め渡し

1段階以上の溜め解放で、次の別行動の部位破壊だけを助ける。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続240tick、発動時から再使用660tick。

## 見た目と制作

胸の水平骨を五段の梯子へ整理し、肩先だけ下へ折る。長い脚と暗い喉の小点が対比。

配色：灰褐 / くすんだ灰紫 / 青銅

### 器官の転用

- 梯胸風路→胸だけの五本横骨
- 毒喉→喉元に残る小さい紫室（武器は風のみ）
- 下降翼→下へ折れる肩先

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 五段梯子を峰側の浅い凹凸へ移す大剣 |
| 護刃 | 段溝の短剣と、五本の骨を硬い裏板で支える盾 |
| 大槌 | 梯骨を側面に積んだ箱形の硬槌頭 |
| 双剣 | 同長の二短剣へ二段と三段の低い峰飾りを分ける |
| 太刀 | 五本の短い留めで細い連続刃を支える太刀 |
| 長尖槍 | 直槍の刃元へ梯段を縮め、盾胸部に五段骨 |
| 環弓 | 弓身の握り近くへ五つの低い留め、小環と一本の直線弦 |

### 級別の形状発達

- 上級：灰褐色の胸に横向きの骨縁を段状に並べ、肩先だけ下へ折る。喉元にくすんだ紫を小さく置き、脚は細く長く見せる。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級は胸の梯子の間を薄い膜で連結し、横骨の段数を保つ。紫色は喉だけ、肩先の下折れを明瞭にする。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：五段梯子
- secondaryForm：下向き肩先
- dominantRegion：胸
- asymmetry：左右の肩先は同じ下折れ
- repeatCount：胸の横骨5、喉室1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は五段骨の隙間。平常：喉の紫点だけ見える。発動：下から二段ずつ白い風筋が細く流れる。点灯面積は全身の4%以下。

避ける形：

- 締めの技を使わず弱い通常打だけ続ける運用
- 梯子の隙間を盾の貫通穴にする形
- 喉の紫室を毒属性の追加と扱うこと
