# 052 ムルゼナト — 泥鉤

原種ID `monster.murzenato`。上級〜極級。 [JSON原本](../data/species/052-murzenato.json) / [全級の装備・レシピ](../data/equipment/052-murzenato.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**麻痺させた敵へ重い追撃を集中**

腹向きの泥鉤の根元にある鉤底湿腺。水と麻痺性の分泌液を粘土に混ぜ、丸めた泥粒を体節の隙間から押し出す。 テンガロから湿った泥床へ適応した亜種である。根の並ぶ浅瀬を歩いて巡り、刺激されると体節を低く広げて進路を塞ぐ。

麻痺を新しく付与→同じ敵へ重い物理の追撃→増えた回避消費を見て拘束終了前に退く。

- 得意：同級基準の物理倍率0.82、会心率-5ポイント。既存のparalysis蓄積量を1.55倍。固有技能「腹鉤の泥止め」は同系列2部位でLv1、4部位でLv2。
- 代償：物理基礎倍率0.82（同級基準比18%低い。系統補正前）、会心率-5ポイント、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.18倍。弱点耐性は一式でice -20。形状による当たり判定・リーチの優遇はない。
- 推奨：護刃、長尖槍
- 避けたい状況：麻痺が切れた後も残量を見ず回避を連発する運用。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：腹鉤の泥止め

新たに麻痺させた敵を泥鉤で留めた見立てで攻める。物理は上がるが重い泥のため回避消費も増え、拘束が切れた後の退出判断が要る。 今回新しく付与した状態だけをタグにする。既に付いていた状態は数えない。 300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から240tick有効、900tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 状態異常を新しく発症させた時 |
| 必須タグ / いずれかのタグ | paralyzed / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 物理ダメージ +8/+10%、回避消費 +12/+18% |
| 持続 / 再発動待ち | 4秒 / 15秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

無傷の部位へ二つの別行動を当て、泥鉤の湿腺を次の麻痺蓄積へ回す。  300tick以内に異なる行動で2回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

## 見た目と制作

肩を小さくし、腰の平たい輪節を水平に広げる。鉤先は裾の内側へ巻き込み、外周を滑らかな低い段にする。

配色：灰褐 / 泥緑 / 暗青銅

### 器官の転用

- 腹向き泥鉤→腰裾の内側へ丸めた鉤縁
- 平たい体節→腰の三段の水平輪節
- 鉤底湿腺→節の下側の泥緑の細い溝

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰側に内向きに巻く低い泥鉤縁。刃先を一枚の硬い連続面にする |
| 護刃 | 内巻きの小鍔の剣と、三段の水平節を持つ幅広い硬盾 |
| 大槌 | 節の側面へ泥緑溝を三本、両打面は丸い硬面。鉤は頭の内側へ収納 |
| 双剣 | 二本の峰に低い内巻き鉤を同数置く。外へ引っ掛かる先端を出さない |
| 太刀 | 細い長刃の峰に内巻きの溝を低く刻む。鞘は平らな節面 |
| 長尖槍 | 直槍の根元に小さい内巻き節、盾の下縁に三つの低い泥受け溝 |
| 環弓 | 中央部の外周を内巻きの短節で囲み、細い両弓端と一本弦・小環を独立させる |

### 級別の形状発達

- 上級：灰褐の三節を低く水平にし、泥緑は下面の溝。外周の鉤先を全部隠す。
- 極級：三節の暗青銅留めを短い二重帯にする。泥緑の小窓を追加し、外への棘は増やさない。

### モデル制作の固定条件

- primaryForm：水平三輪節
- secondaryForm：内へ巻く鉤
- dominantRegion：腰と腿外側
- asymmetry：左右対称、上半身は細い
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は腰の三輪節の下側の泥緑溝。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 鉤を外へ棘のように立てない
- 原種の高い肩鉤を残さない
- 泥の塊を足先へ垂らさない
