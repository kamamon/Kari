## 戦い方

**二段熱皿に溜めを残す火槌装**

採食中は鈍重だが、泥槽を奪おうとする相手には胸を高くして迫る。熱泥を使い切ると水場へ向かう。

溜めを解放した次の別行動へ熱泥を残し、重い追撃を選ぶ。

- 得意：基礎物理1.04倍、火倍率1.45、防御1.08倍。高体力の溜め解放後に属性を強める。
- 代償：会心-15、刃消耗1.25倍、戦闘スタミナ1.18倍。熱を逃がす装甲の隙間により、固有効果中は被ダメージ+8/+12%。
- 推奨：大槌、断岳剣、環弓
- 避けたい状況：連続で被弾する状況。熱皿を開いている間は被ダメージ+8/+12%で、環弓でもこの代償を受ける。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：後縁の蓄熱

HP70%以上で溜めを解放すると、次の別行動一つの火を+12/+16%。熱を逃がすため装甲の隙間を開き、発動中の被ダメージは+8/+12%。この代償は弓を含む全武器に働く。発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 1段以上の溜め解放 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 70〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +12/+16%、被ダメージ +8/+12% |

## 見た目と制作

兜の二段皿は後ろ縁だけ高く、胸の赤銅板を前へ張り出す。腰以下を暗い細帯にし上前方へ重さを寄せる。

配色：暗灰褐 / 赤銅 / 暗い熱朱

### 器官の転用

- 二段の頭皿の下に、発酵熱と晶粉の反応熱を蓄える泥槽を持つ。首を縮めると片側の溝だけから熱泥が押し出される。
- 二段頭皿の高い後縁と持ち上がる胸を、兜後縁と胸の三枚板へ分ける。
- 熱泥を溜めてから一方へ押し出す生態を、次の別行動だけの熱へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元に二段の低い熱皿筋を持つ重刃 |
| 護刃 | 二段の刃元留めと、後縁だけ高い閉じた熱皿盾 |
| 大槌 | 閉じた硬い両打面、頭の上面を二段の皿形にする |
| 双剣 | 二本の刃元に低い熱皿一段ずつ。刃先は細く |
| 太刀 | 鍔後ろに二段皿の小意匠を持つ連続曲刃 |
| 長尖槍 | 二重熱皿の根元を持つ直槍、前へ厚い赤銅盾 |
| 環弓 | 弓の握り背面に二段の小皿留め。小環と直線弦 |

### 級別の形状発達

- 中級：兜後縁二段と胸三枚の段差を明瞭にする。
- 上級：皿の内側へ赤銅の細い熱溝を加える。
- 極級：胸板の下縁を二重に磨く。二段皿を三段へ増やさない。

### モデル制作の固定条件

- primaryForm：二段の後高皿と前張り胸板
- secondaryForm：暗い耐熱皮
- dominantRegion：兜後縁と胸前
- asymmetry：前後の高低差、左右はほぼ均等
- repeatCount：兜皿2、胸板3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は兜の内側の二溝。平常：暗い熱朱。発動：溜め解放後だけ二溝の奥が鈍く灯る。点灯面積は全身の4%以下。

避ける形：

- 兜を顔の見えない深い鍋にしない
- 胸を砲口や開いた炉口にしない
- 炎の長い噴流を常時出さない
