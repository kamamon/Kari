## 戦い方

**未破壊部位を削る三庇掘削装**

前半身の三段の肋棚が、土を掘る際の圧力を分散する。腹の厚い振動板を地面へ押すと、前方の小範囲だけを崩して根を露出させる。 餌場の土をほぐしてから少しずつ歩を進める。小さな相手を追い回さず、前脚の周囲に居続ける者を押し退ける。

未破壊部位へ三つの別行動を通す→同じ敵の部位を削る→摩耗が進む前に整備する。

- 得意：同級基準の物理倍率1.16、会心率-15ポイント。固有技能「三庇の掘削圧」は同系列2部位でLv1、4部位でLv2。
- 代償：会心率-15ポイント、刃消耗1.24倍、回避・ガード・ため維持など元々費用を持つ戦闘行動のスタミナ消費1.18倍。弱点耐性は一式でfire -20。形状による当たり判定・リーチの優遇はない。
- 推奨：断岳剣、大槌、長尖槍
- 避けたい状況：破壊済みの部位だけを叩き続ける狩り。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三庇の掘削圧

三段の肋棚にならい未破壊部位を三つの別行動で刻む。破壊蓄積は伸びるが、板を押し付けるため刃も早く摩耗する。  360tick以内に異なる行動で3回。HP・スタミナ条件は行動費用確定後の残量%。発動から300tick有効、720tick再使用。攻撃への補正は起点と別の次行動から有効。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | unbroken / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 3行動 / 6秒 |
| 効果（Lv1 / Lv2） | 破壊・切断蓄積 +18/+25%、刃消耗 +15/+25% |
| 持続 / 再発動待ち | 5秒 / 12秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

### 武器主題（Lv1固定）：肋棚の掘り返し

まだ壊れていない部位を掘り始めた後、次の一撃へ圧力を集める。  300tick以内に異なる行動で1回。HP・スタミナ条件は行動費用確定後の残量%。発動から180tick有効、480tick再使用。攻撃への補正は起点と別の次行動から有効。次の適合する別行動の初命中で消費し、同じ行動の多段命中には共通の補正を使う。空振りでは消費しない。蓄積と効果は同じ敵個体に限定。解除しても再使用時間は戻さない。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 命中 |
| 必須タグ / いずれかのタグ | unbroken / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 物理ダメージ +4/+4% |
| 持続 / 再発動待ち | 3秒 / 8秒 |
| 1行動消費 / 同じ個体への限定 | あり / あり |
| 解除 | damage_taken, sheathe, target_change。再発動待ちは戻さない |

武器主題は系統ごとに実行可能な行動・効果へ適合済み。実装では `weapon_trait.<種>.<武器種>` を読む。上表の主題の条件を全武器へ直結しない。

## 見た目と制作

前胸と肩だけが三段の庇で前へ張り出す。後ろへ急に細く絞った腰と裸に近い背の輪郭で、前面の圧力を強調する。

配色：灰褐 / 骨白 / 青銅

### 器官の転用

- 三段の肋棚→前胸を覆う幅の異なる三庇
- 振動腹板→胸下の一枚の鈍い平板
- 根掘りの動き→前腕だけ厚い短い楔形

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 三段の庇を峰側へ階段状に積む重い台形大剣。刃は丸い角の連続面 |
| 護刃 | 短い楔刃と、三つの前庇を段状に持つ幅広い盾。側面から階段が見える |
| 大槌 | 三段の横板を束ねた厚い長方形の槌頭。打面は一体の平面 |
| 双剣 | 厚い短刃を二本、各峰に低い三段の段差。重心は左右同じ |
| 太刀 | 前へ細く絞る長い刃の根元だけ三枚の庇を低く重ねる |
| 長尖槍 | 短い楔形の槍先と、上から下へ三段の庇を置いた背の薄い盾 |
| 環弓 | 三本の低い横稜を中央の握り外側だけへ置く。両弓端は細い骨弓、小環と一本弦 |

### 級別の形状発達

- 中級：灰褐の庇三枚と骨白の断面を大きく見せ、青銅は留めに限る。
- 上級：中央庇の断面を厚く見せ、前腕の各板に短い補強線。後ろの細さは保つ。
- 極級：三庇の端へ鈍い青銅を狭く重ねる。胸下の振動板だけ細い同心線を加え、装甲を後ろへ増やさない。

### モデル制作の固定条件

- primaryForm：前面の水平三庇
- secondaryForm：後半身の絞り
- dominantRegion：前胸と前腕
- asymmetry：左右対称、前重心の外形
- repeatCount：3
- jointClearance：首の左右回旋、脇、肘内側、手首、膝裏、足首を開ける。装飾は身体寄りに伏せ、実装済みの握り・リグ可動域・攻撃判定を変更しない。
- gripRule：全7系統の既存の握り位置と有効長を保つ。護刃と長尖槍は独立盾。双剣は二本。大槌の打面は閉じた硬面。環弓は一本の直線弦・細い弓身・小照準環・矢を保つ。

技能の合図は三段庇の裏の短い縁。平常：主材と同じ鈍い色で線を閉じ、待機中は常時発光させない。。発動：固有技能の蓄積では主反復形の小窓を順に淡く示し、成立時だけ細い縁を点灯。効果終了で静かに戻す。HUDの残り時間と同じ状態を参照する。。点灯面積は全身の4%以下。

避ける形：

- 後ろまで三段の殻で包まない
- 庇の角を棘にしない
- 大槌の打面を三枚の隙間に分割しない
