## 戦い方

**四枚の逆帆で逃げ切る風軽装**

腰の前向き逆帆と、その根元の散眠嚢。食べた苦葉由来の眠り粉を少量蓄え、帆に沿う空気で狭い前方へ押し流す。

四回の回避成功で逆帆を開き、軽い回避と回復速度を使って攻める位置へ戻る。

- 得意：風量1.42倍、会心20、消費0.90倍。技能で回避消費-12/20%、回復速度+12/20%。
- 代償：基礎攻撃0.86倍、防御0.75倍、刃容量0.80倍、火耐性-30。四回を揃える前の被弾で準備が消える。
- 推奨：双剣、太刀、環弓
- 避けたい状況：不利な運用: 回避ボタンの空振りで四回を貯める運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：四逆帆の息継ぎ

600tick内に敵の接触を4行動で回避して逆帆を開く。回復速度を変えるだけでスタミナを即時加算しない。 回避入力ではなく、回避無敵中に敵攻撃の接触を避けた成功だけを数える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続360tick、発動時から再使用960tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

腰の四枚短帆を前へ向け、襟を長く低く流す。後ろに広がる量を徹底して小さくする。

配色：灰緑 / 生成り / 青銅

### 器官の転用

- 前向き逆帆→腰前の四枚短板
- 散眠嚢→帆根の小さい暗室（武器は風のみ）
- 低い長首→後ろを低く流す襟

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 四枚の逆帆を峰の刃元へ前向きに低く添える大剣 |
| 護刃 | 前向きの低い鍔の剣と四枚帆縁の硬盾 |
| 大槌 | 逆帆は硬い槌頭の側面に低く添えるのみ |
| 双剣 | 各二枚の短帆を峰へ持つ同長二短剣 |
| 太刀 | 四つの前向き低留めを刃元へ並べた太刀 |
| 長尖槍 | 前向き帆根の直槍と、下縁へ短帆を寄せる独立盾 |
| 環弓 | 四つの低い留めを握り付近へ寄せ、小環と一本の直線弦 |

### 級別の形状発達

- 極級：灰緑の四枚の短帆を腰から前へ向け、襟を低く長く流す。後ろへ広がる装飾は控える。 極級完成形のみ。四枚の帆を前向きに保ち、後ろへ広がる翼やマントを追加しない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：四枚の前向き帆
- secondaryForm：低い長襟
- dominantRegion：腰前
- asymmetry：左右二枚ずつ、後ろは狭い
- repeatCount：腰帆4
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は腰前の四枚の根元。平常：灰緑の小さい暗室。発動：四つの根元へ白点が一つずつ増える。点灯面積は全身の4%以下。

避ける形：

- 回避ボタンの空振りで四回を貯める運用
- 後ろへ大きく広がるマント
- 睡眠粉の設定から武器へ睡眠値を追加すること
