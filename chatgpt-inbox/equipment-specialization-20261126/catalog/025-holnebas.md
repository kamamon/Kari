## 戦い方

**三鐘を二度整える風管装**

岩棚を歩きながら短い音を返し、同種との距離を保つ。出口を塞がれると嚢口を向けて威嚇してから攻撃する。

二つの溜め解放で三鐘の向きを揃え、その後の別行動を部位へ集める。

- 得意：風倍率1.55、刃容量1.18倍。二度の溜め解放後は部位と属性を同時に伸ばす。
- 代償：基礎物理0.88倍、会心-5、戦闘スタミナ1.17倍。溜めを連続で作れないと固有が遅い。
- 推奨：大槌、環弓、断岳剣
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.88倍、会心-5、戦闘スタミナ1.17倍。溜めを連続で作れないと固有が遅い。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：三鐘の風合わせ

7秒以内に二つの溜め解放を終え、三鐘の風を揃える。二つ目の解放行動自身を除外し、その次から補正。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 起点 | 1段以上の溜め解放 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 7秒 |

## 見た目と制作

右肩へ斜め前に並ぶ三つの長い鐘縁。先端を硬く閉じ、左肩と首を低くして右だけ段状の重量を作る。

配色：灰緑 / 青銅管 / 骨灰

### 器官の転用

- 右肩の三つの共鳴嚢が長い風管につながり、開いた嚢だけが狭い風圧を放つ。嚢口の膨らみと向きで発射位置を読める。
- 右肩の三つの長鐘嚢を先端の閉じた段状室へ。筒口や発射機の印象を避ける。
- 嚢の向きを揃えて風を出す行動を、二つの準備行動が必要な部位攻撃区間へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 峰の刃元に閉じた三つの小鐘室を段違いに置く大剣 |
| 護刃 | 小鐘縁の短刃と、右上に閉じた三鐘室を持つ盾 |
| 大槌 | 硬い両打面の側面に閉じた三段の響室を並べる |
| 双剣 | 刃元に小鐘の筋を二本と一本へ分ける二短刃 |
| 太刀 | 鍔後ろの三つの閉じた小室、刃は連続した細い曲線 |
| 長尖槍 | 直槍の根元へ三小鐘、右上が厚い硬い大盾 |
| 環弓 | 握り外側に閉じた三小鐘室。弓身は細く、直線弦一本、小環 |

### 級別の形状発達

- 中級：右肩の三段鐘室を灰緑で閉じ、縁だけ骨灰。
- 上級：三室の長さを短中長へ分け、胸の管筋を三本へ。
- 極級：室の内側縁に青銅を足す。口は開けず、筒を長くしない。

### モデル制作の固定条件

- primaryForm：右肩の閉じた三段鐘縁
- secondaryForm：細い青銅管筋
- dominantRegion：右肩
- asymmetry：右高、左低。頭は中心
- repeatCount：主鐘室3
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は右肩の三室の内縁。平常：鈍い青銅。発動：二解放後に三つの内縁だけ順に反射。点灯面積は全身の4%以下。

避ける形：

- 鐘室の口を開いて砲口風にしない
- 弓弦を曲がる管や複数弦にしない
- 左肩へ同じ三鐘を足さない
