## 戦い方

**小冷晶を休ませて一歩滑る幼氷装**

二〜四頭が互いの体側に沿って移動し、冷えた岩溝を見失わないようにする。警戒すると小板を白くしてから離れる。

体力を保って納刀し、小さな冷晶を整えた短い区間に一度だけ攻めに戻る。

- 得意：氷倍率1.30、戦闘スタミナ0.91倍。納刀後の短い属性・回避区間。
- 代償：基礎物理0.86倍、防御0.80倍、刃容量0.85倍。HP70%未満では固有を始められない。
- 推奨：環弓、長尖槍、太刀
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.86倍、防御0.80倍、刃容量0.85倍。HP70%未満では固有を始められない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：小板の冷え待ち

HP70%以上の明示納刀完了で小板を冷やす。3秒の短い区間で、長い攻め続けは支えない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 明示的な納刀完了 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 70〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 1行動 / 5秒 |
| 効果（Lv1 / Lv2） | 属性ダメージ +8/+12%、回避消費 -8/-12% |
| 持続 / 再発動待ち | 3秒 / 10秒 |
| 1行動消費 / 同じ個体への限定 | なし / なし |
| 解除 | damage_taken。再発動待ちは戻さない |

## 見た目と制作

背に丸い幼冷晶を左右交互に四つ置く成人軽装。襟は低く、三角の大氷帆は持たない。

配色：淡い灰青 / 曇り氷 / 生成り

### 器官の転用

- 丸い小板へ冷却液を少量送る幼冷晶管。薄氷は作れるが、大きな氷帆も長い氷片列もまだ形成しない。
- 成体の長い薄帆になる前の丸い小板を、成人の背へ四点だけ交互配置。
- 長く滑れず休みながら進む幼体を、短い納刀後区間へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の峰へ丸い小冷晶四点を並べる薄い大刃 |
| 護刃 | 細い氷短刃と、丸小板四つを硬い下地へ置く軽盾 |
| 大槌 | 閉じた小冷晶の硬打面、丸板は側面二つずつ |
| 双剣 | 峰に丸い小晶を二つずつ埋める二短刃 |
| 太刀 | 峰の根元へ四点の丸小晶を沈める曲刃 |
| 長尖槍 | 小冷晶の直芯槍と、丸板四つの低い盾 |
| 環弓 | 握り上へ丸小晶四点。細い弓身、小環と直線弦 |

### 級別の形状発達

- 初級：丸小板四つを曇った灰青で置く。
- 中級：板の根元へ小さな冷晶管を一本ずつ。
- 上級：四板の内面だけ氷色を少し透かす。
- 極級：板縁を滑らかに磨く。尖った帆や大きな襟にはしない。

### モデル制作の固定条件

- primaryForm：交互の四つの丸小板
- secondaryForm：低い襟と薄い布
- dominantRegion：背中央
- asymmetry：丸小板を左右交互、肩幅を広げない
- repeatCount：背小板4
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背の四小板の根元。平常：曇った小点。発動：納刀時に四つの根元だけ白く曇る。点灯面積は全身の2%以下。

避ける形：

- キリサーヴの尖った薄帆へ成長させない
- 長い氷尾や高襟を付けない
- 幼体用の人体比例へ変えない
