## 戦い方

**高い間合いから麻痺を差す軽装**

目の下でつながる鞍頬風膜と頬底腺。膜を左右別々に縮め、腺で作る麻痺性の微滴を細い風へ乗せる。

敵の接触を二度かわして頬膜を張り、別行動の連撃で麻痺蓄積を稼ぐ。被弾で準備が崩れる。

- 得意：麻痺量1.55倍・回避等の消費0.91倍。手数よりも無傷の回避継続を評価する。
- 代償：基礎攻撃0.82倍、防御0.79倍、火耐性-30。発動中も回避消費が8/12%増える。
- 推奨：双剣、環弓、太刀
- 避けたい状況：不利な運用: 正面で被弾を受けながら蓄積を維持する運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：鞍膜の二歩張り

HP70%以上で240tick内に2回の回避成功。頬膜を張る間は麻痺蓄積が上がるが、張力で回避の負担も増す。 回避入力ではなく、回避無敵中に敵攻撃の接触を避けた成功だけを数える。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 持続300tick、発動時から再使用780tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

## 見た目と制作

胸元を高い逆U字の鞍襟で囲み、肩幅を狭く保つ。長い前腕と低い骨盤の縦比率が主役。

配色：灰緑 / 生成り / 鈍い青銅

### 器官の転用

- 頬膜→頬から胸上へ落ちる一続きの鞍襟
- 頬底腺→襟内側の左右独立した短い滴溝
- 高い前脚→長い前腕板と短い上腕袖

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 鞍膜の折れを峰側の深い一段凹みにし、細い連続刃を内側へ通す大剣 |
| 護刃 | 滴溝のある細剣と、中央だけ鞍形に盛る小型の硬い盾 |
| 大槌 | 頬底腺を左右側室へ収めた細長い硬殻の両打面槌 |
| 双剣 | 左右の鞍線を対にした短剣二本、刃先は同長で内側に滴筋 |
| 太刀 | 鞍の落ち込みを鍔元へ寄せ、先端は細い連続刃の太刀 |
| 長尖槍 | 細い直槍の刃元に二条溝、盾上縁だけ低い鞍形 |
| 環弓 | 長い膜筋を細い弓身に沿わせ、握り上の小環と一本の直線弦を空ける |

### 級別の形状発達

- 上級：灰緑の頬膜を頬当てから襟へ鞍状につなぎ、胸を高く腰を低く見せる。前腕だけ長い細板を置き、肩は張らせない。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級では頬膜の張りを二重に分け、麻痺滴を収める筋を根元側だけ太くする。灰緑の細身と長い前腕を維持し、肩幅を増やさない。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：逆U字の鞍襟
- secondaryForm：細い縦板
- dominantRegion：胸上と前腕
- asymmetry：左右の滴溝は別室、肩幅は等しい
- repeatCount：頬側の滴溝2、前腕板左右1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左右の襟内面。平常：灰緑の溝が閉じる。発動：左右の細い滴筋が交互に琥珀色へ変わる。点灯面積は全身の4%以下。

避ける形：

- 正面で被弾を受けながら蓄積を維持する運用
- 肩を横へ膨らませた大型翼
- 口前を閉じる鞍膜や長いマント
