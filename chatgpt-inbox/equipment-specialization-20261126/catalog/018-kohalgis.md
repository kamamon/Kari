## 戦い方

**一枚硝板を受ける幼硝装**

四〜七体で同じ岩を使い、一体が鋏を上げると周囲も姿勢を低くする。逃げる時は一か所へ詰まらず別の割れ目へ散る。

スタミナを保った通常ガードで薄い硝板の向きを揃え、短い部位攻撃へ移る。

- 得意：刃容量1.15倍、防御1.02倍。高スタミナの通常ガードを入り口にする。
- 代償：基礎物理0.94倍、会心+10。スタミナ70%未満では固有を起動できず、大火力は持たない。
- 推奨：護刃、長尖槍
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.94倍、会心+10。スタミナ70%未満では固有を起動できず、大火力は持たない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：乳硝の一受け

通常ガード後の残スタミナ70%以上なら、一枚硝板を整える4秒が生まれる。受け流し専用ではない。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |

| 必要な別行動 / 集計窓 | 1行動 / 5秒 |

## 見た目と制作

乳白の一枚板を左右ほぼ均等に配す成人装。右手の細い青銅縁だけが成長の偏りを示す。

配色：乳白 / 淡い灰緑 / 細い青銅縁

### 器官の転用

- 右鋏の根元で発達途中の硝殻成形腺。板は乳白色で薄く、まだ重ねて硬くできない。
- 未発達の硝殻は乳白の一枚板。右だけ巨大な成体籠手を作らない。
- 周囲と同時に姿勢を低くする行動を、余裕を残した通常ガードへ置換。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 乳白の薄い板を刃元へ二枚重ねた連続大刃 |
| 護刃 | 細い小鋏刃と、一枚硝板を硬い枠へ収めた軽盾 |
| 大槌 | 閉じた硬骨打面を乳白小板で側面だけ覆う |
| 双剣 | 同寸の乳白短刃二本。右の鍔縁だけ青銅 |
| 太刀 | 細い曲刃の根元へ乳白一枚板を沿わせる |
| 長尖槍 | 小鋏芯の直槍と、左右均等の乳白盾 |
| 環弓 | 細い骨弓の握り横へ乳白小板二枚。直線弦と小環 |

### 級別の形状発達

- 初級：乳白一枚板の薄さと左右対称を保つ。
- 中級：右手の青銅縁だけ少し明瞭化。
- 上級：小板の内側に細い支持革を追加。
- 極級：板面を磨くが透明化も巨大化もしない。

### モデル制作の固定条件

- primaryForm：左右均等の乳白小板
- secondaryForm：右手だけの青銅細縁
- dominantRegion：胸と両前腕
- asymmetry：ほぼ対称、右手の縁のみ差
- repeatCount：胸板2、前腕板2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は右手の細い青銅縁。平常：くすんだ線。発動：通常ガード成功で縁一筋だけ反射。点灯面積は全身の1%以下。

避ける形：

- オルグラスの右大鋏を縮めて付けない
- 硝板を完全透明の宝石にしない
- 左右を大きく非対称にしない
