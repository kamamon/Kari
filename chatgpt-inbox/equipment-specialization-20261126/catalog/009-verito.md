# 009 ヴェリト — 絹霧

原種ID `monster.verito`。初級〜極級。 [JSON原本](../data/species/009-verito.json) / [全級の装備・レシピ](../data/equipment/009-verito.json) / [比較原画の復元と目録](../ART.md)

## 戦い方

**毒を見届けて刃を保つ糸装**

普段は糸を手繰りながらゆっくり歩く。逃げ道を塞がれると羽袋を縮めて跳び、低い糸の帯を残す。

毒を成立させてから同じ相手の部位へ攻撃を集め、糸の被膜で刃を保つ。

- 得意：毒倍率1.60。毒成立後は刃消耗-12/-20%と部位補正+10/+16%。
- 代償：基礎物理0.79倍、防御0.75倍。相手変更と被弾で仕込みが切れる。
- 推奨：双剣、太刀、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。基礎物理0.79倍、防御0.75倍。相手変更と被弾で仕込みが切れる。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

## 見た目と制作

背上部に二つの柔らかな羽袋、胸下は細い糸布。肩幅を袋だけで作り、腰と足は絞る。

配色：淡い紫灰 / 生成り糸 / 灰茶

### 器官の転用

- 背の袋状の羽器と、尾端の二筋の紡糸管。袋で湿りを保った毒性の糸を低い位置へ張り、羽器は飛行には使わない。
- 飛行しない袋状羽器を背上の二袋へ、二本の紡糸管を短い糸縁へ。
- 毒を与えた後に糸を手繰る生態を、毒成立後の刃持ちと部位攻撃へ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元の背面にだけ二つの小袋を収める薄刃大剣 |
| 護刃 | 小さな毒糸溝の短刃と、硬い骨板に糸布を張った盾 |
| 大槌 | 閉じた硬骨打頭の側面を糸で包み、小袋は下側二室 |
| 双剣 | 峰に一本ずつ毒糸溝を持つ二短刃。刃先に糸を張らない |
| 太刀 | 低い峰溝に糸を通す連続曲刃。鞘口に二つの短房 |
| 長尖槍 | 直槍の根元を二筋糸で締め、薄い硬板盾に小袋二室 |
| 環弓 | 弓の握り背面に二小袋。弓弦は直線一本、小環一つ |

### 級別の形状発達

- 初級：袋二つを淡い紫灰に、糸の編み目を粗く見せる。
- 中級：袋の付け根に生成り糸の細い輪を加える。
- 上級：糸縁を二筋に分け、袋の体積は増やさない。
- 極級：袋内側の縫い筋を明瞭化。光る毒液を外へ滴らせない。

### モデル制作の固定条件

- primaryForm：背上の柔らかな二袋
- secondaryForm：細い編み糸
- dominantRegion：肩甲骨上
- asymmetry：背上だけ膨らみ、腹腰は細い
- repeatCount：主羽袋2、尾糸縁2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は背上袋の縫い筋。平常：生成りの糸。発動：毒成立で二筋だけ鈍い紫へ変わる。点灯面積は全身の3%以下。

避ける形：

- 大きな蝶の翼にしない
- 糸を長い触手や刃間の線として張らない
- 毒色を全身の蛍光緑にしない
