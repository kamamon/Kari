## 戦い方

**片側を受けて毒を返す盾装備**

左鋏の内側へ育った縁壺濾腔。水と小さな獲物を集め、縁の毒腺から分泌した液を濾腔の一部へためて狭く吐く。

受け流しで壺の縁を開き、別行動の刺突へ毒を集中する。毒が入った相手の部位を崩す。

- 得意：毒量1.45倍、防御1.07倍、受け流し後の毒+12/16%。
- 代償：基礎攻撃0.90倍、回避・ガード等の消費1.12倍、雷耐性-25。返しの準備中は被ダメージ+6/10%。
- 推奨：護刃、長尖槍
- 避けたい状況：不利な運用: 盾を使わず正面で打ち合い続ける運用

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：縁壺の一滴返し

護刃の受け流し、または長尖槍の受け流し反撃を成功させて毒を一撃へ濃縮。壺を開く間は被弾に弱い。 1行動につき1回だけ数える。攻撃への効果は発動した行動自身には乗らず、次の別行動から適用する。 次の有効な別行動の命中で消費し、その行動の多段命中には同じ効果を使う。 持続180tick、発動時から再使用660tick。 同系列の異なる防具2部位でLv1、4部位でLv2。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 受け流し・受け返し成功 |

| HP / スタミナ残量 | 0〜100% / 0〜100% |

## 見た目と制作

左前腕だけ深い壺の丸甲、右側は細い線。短い背甲と前へ開いた腹の空隙で左右差を見せる。

配色：灰褐 / 灰緑 / 青銅

### 器官の転用

- 縁壺濾腔→左籠手の深い側面室
- 毒腺→壺内縁の二重濾過溝
- 短い後甲→肩甲骨で終わる短背板

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 刃元に壺縁の厚い半弧、先へ細く抜ける大剣 |
| 護刃 | 壺の閉じた底を盾面へ、剣は右鋏を写す細刃 |
| 大槌 | 硬い壺底を前後の打面にし、側面の浅い濾室だけを露出 |
| 双剣 | 左鋏の弧と右鋏の直線を峰の装飾で対比、刃長は揃える二剣 |
| 太刀 | 太刀の鍔元だけに壺縁の短い返し、刀身を中空にしない |
| 長尖槍 | 濾溝を持つ細い直槍と、中央に壺底の丸いふくらみを持つ独立盾 |
| 環弓 | 壺縁を小照準環へ縮め、上下の弓身は細い骨芯、弦は一本の直線 |

### 級別の形状発達

- 上級：左腕に深い壺状の丸い甲、右腕に細い青銅の縁を置く。背は短く切り、灰褐色の胴へ水を流す細い溝を入れる。 初登場級の形。武器は同じ器官の輪郭を用途に合わせて切り分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。
- 極級：極級は壺縁の内周へ交換できる濾板を追加する。左腕の深さは増やさず、毒溝を二つの短区間に分ける。 この再設計の器官位置・枚数・握り位置を優先し、武器の有効長と防具の衝突外形を変えない。

### モデル制作の固定条件

- primaryForm：深い丸室
- secondaryForm：短い背板
- dominantRegion：左前腕
- asymmetry：左だけ厚い、右は細い線
- repeatCount：左の濾溝2、背板1
- jointClearance：首の回旋、肩の挙上、肘・膝の屈曲、手首・足首を妨げない。厚い器官は関節軸から外す。
- gripRule：既存7系統の握り・有効長・判定を固定。盾は独立した剛体で、弓は一本の直線弦と小照準環を持つ。軟部は打面と握りへ置かない。

技能の合図は左籠手の内縁。平常：灰褐の二重溝。発動：内縁の細い紫線が一周だけ巡る。点灯面積は全身の4%以下。

避ける形：

- 盾を使わず正面で打ち合い続ける運用
- 左籠手が手首や拳を飲み込む形
- 背へ巨大な蟹殻を追加する形
