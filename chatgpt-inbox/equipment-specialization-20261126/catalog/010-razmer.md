## 戦い方

**二度支えて骨環をずらす長柄装**

細長い体を大きく回す前に、必ず前半身を反対へ曲げる。警戒時も全身を一度に巻き付けず、開いた側から相手を逃がす。

同じ敵の通常攻撃を二度ガードし、骨環が噛み合う区間で長柄を押し返す。

- 得意：基礎物理1.10倍、防御1.08倍。二回受けた後のガード負担が小さい。
- 代償：会心-15、戦闘スタミナ消費1.12倍。受け流しでは通常ガードの回数は増えない。
- 推奨：長尖槍、断岳剣、護刃
- 避けたい状況：条件を満たさない立ち回りでは固有効果が出ない。会心-15、戦闘スタミナ消費1.12倍。受け流しでは通常ガードの回数は増えない。

## 固有技能

同系列の異なる2部位でLv1、4部位でLv2。級が混じっても数える。5部位目に隠し効果はない。武器は部位数へ含めない。

### 防具固有：二環の据え直し

同じ敵の二つの攻撃行動を通常ガードして骨環を噛み合わせる。 発動した行動そのものには攻撃補正を与えず、次の別行動の命中から適用。1行動につき進行は1回、時間は60tick/秒。

| 条件・挙動 | 定義 |
|---|---|
| 起点 | 通常ガード成功 |
| 必須タグ / いずれかのタグ | なし / なし |
| HP / スタミナ残量 | 0〜100% / 0〜100% |
| 必要な別行動 / 集計窓 | 2行動 / 6秒 |
| 効果（Lv1 / Lv2） | ガード消費 -12/-20%、物理ダメージ +4/+8% |
| 持続 / 再発動待ち | 7秒 / 14秒 |
| 1行動消費 / 同じ個体への限定 | なし / あり |
| 解除 | damage_taken, target_change, sheathe。再発動待ちは戻さない |

## 見た目と制作

胸と腰に二つの太い白骨半環。環の前中央は切り、細い革の縦軸でつないだ開放的な樽形。

配色：骨白 / 暗い革 / くすんだ青銅

### 器官の転用

- 胴を一周する骨環と、その内側の振動腺。二対の短肢で踏ん張って骨環をずらし、地面へ低い振動を伝える。
- 体を一周する環骨を胸と腰の開いた二環へ。短肢は太い縦支えに置換。
- 踏ん張って骨環をずらす行動を二つの通常ガードへ結ぶ。

### 武器7系統の形

| 武器 | 独自形状 |
|---|---|
| 断岳剣 | 太い骨芯の片刃、刃元を二つの半環で囲む |
| 護刃 | 白骨の直短刃と、二つの半環を硬い板へ重ねる盾 |
| 大槌 | 閉じた骨打頭を二本の半環で締める横槌 |
| 双剣 | 太さを揃えた二短刃の刃元に半環を一つずつ |
| 太刀 | 骨の細い芯を二つの低い環留めで支える曲刃 |
| 長尖槍 | 長い白骨の直芯と、胸腰を模す二半環の大盾 |
| 環弓 | しなる骨弓の握りを二つの低い半環で囲む。小環と直線弦 |

### 級別の形状発達

- 初級：白骨二環の外面を滑らかにし、内側は暗革。
- 中級：二環を結ぶ縦桟へ小さな青銅留め。
- 上級：腰環だけ二重縁。胸の空隙は残す。
- 極級：振動腺の小窓を胸環内側へ二点。環を増やさない。

### モデル制作の固定条件

- primaryForm：二つの太い骨半環
- secondaryForm：暗革の縦桟
- dominantRegion：胸と腰
- asymmetry：左右均等だが前中央は開く
- repeatCount：主要半環2
- gripRule：採用済み武器系統の握り位置・刃長・リーチを保持。手指は閉じずに通せる。装飾に当たり判定を足さない。
- jointClearance：首の振り向き、肩上げ、肘屈曲、手首、股関節、膝、足首の内側を空ける。最大可動域は共通リグで別途検査。

技能の合図は胸環と腰環の内縁。平常：くすんだ白。発動：二度支えると内縁二点が淡く灯る。点灯面積は全身の2%以下。

避ける形：

- 巨大な首輪や手錠状の閉環にしない
- 骨環を関節に食い込ませない
- 人骨の意匠へ置き換えない
