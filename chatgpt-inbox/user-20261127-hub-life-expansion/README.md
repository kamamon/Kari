# 灯継ぎの里・生活拡張
利用者の直接依頼に基づき、従来の資料提出に留まらず実装。基準 main 56578c6917ae1d958052c38db85fcd9707b5e336。既存の五段・施設・戦闘・狩場の採集・セーブschema5を維持。生活機能は「一覧→里の暮らし・施設地図」または各サービスの現地、地図キーから利用。
- 食事6種、温泉、次の1依頼だけの能力補正。食事に大獣肉が未登録なので魚と山菜の煮込みに変更。
- 5施設のLv1〜4、品種、回収、調合4種、行商人、探索隊。希少素材の確率据え置き、依頼を達成して補充。
- 地図・訪問済み施設移動・装備セット3組・持ち込み数量・欲しい装備と不足素材・入手候補・工房試着リンク・研究記録・訓練記録・住民納品5種・催し・里の発展。
- 3D景観: 小型施設の目印・食事処/石風呂・家具展示の外観・増築段階・旗、鳥/魚/仮の生活者、昼夜と天候、季節の色。採集は既存狩場クリップを描画専用で再生。
- 個々の専用高精細モデル、完全な屋内歩行、自由家具配置、実物大養魚池・坑道の新マップ、採集具耐久、精密な祭り競技や独自音源、看板モンスターのイベントの新規シナリオは未完成。既存の図鑑・物語・訓練と併用する。今回の採集施設Lv表示は基礎の増築表現、祭りは素材持ち寄りの実装。フラグとデータはゲーム内で機能する。
- 変更の検証はCI・実機試遊を別々に扱う。Nodeテストでセーブ・効果・報酬・座標・天候などを確認。iPhoneと景観の見た目・負荷は別途検証が必要。

追加: 自室の左右レイアウト保存と、独立した3D屋内ビューア（家具・窓・展示リグ、歩行・視点・簡易当たり）を実装。祭りは3回のタイミング競技で2回成功後に素材を納品する方式。専用室内マップと本編の連続遷移、自由家具配置、専用高精細モデル、専用モーションは今後の制作範囲。
