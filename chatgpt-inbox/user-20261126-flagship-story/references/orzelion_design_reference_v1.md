# 鳴天竜オルゼリオン — 看板飛竜 詳細設計 v1

制作日: 2026-11-26 / 対象: `monster.orzelion` / 提案骨格: `frame.wyvern_flight`

**雲より先に、翼が鳴る。**

オルゼリオンは、鉛雲高地の風の回廊を巡る雷の飛竜。静止時は長い首と流れる冠角で威容を見せ、動き出すと胸の重さ、翼の張力、地面をつかむ後脚が見える。雷の見せ場は、胸に電荷が集まり、翼の二条の板を走り、槍尾へ抜ける一連の動作に集約する。地上の狩人が動きを読み、翼の下へ踏み込み、放電後の胸へ反撃できる看板を目指す。

本書は原画・モデリング・リグ・アニメーション・戦闘のための**制作設計案**であり、完成した3Dモデル、実装済み飛行、物理検証済みの生物ではない。全長や時間の値は初期調整目標。現行ゲームへの導入は別工程である。

## 3. 看板としての初登場と本筋への接続

### 初登場の演出案「鳴る翼、戻る道」

高地へ続く運搬路に、三本趾の跡と翼手首の丸い跡が交互に残る。次に、低木の鳥が一斉に伏せ、風の音が消えたように感じる。画面奥の岩棚へ後脚が先に触れ、少し遅れて翼手首が地面を押す。胸腹の象牙色が見え、首を伸ばした時に二本の冠角が空を切る。低い板鳴りの後、翼の二条だけを細い電光が走る。

最初の20〜30秒は、三本の痕跡・着地・警告姿勢を順に見せる映像目標とする。長い強制鑑賞は求めず、省略した場合にも戦闘開始時の地上姿勢を同じにする。初手に画面外からの即時雷撃を置かない。戦闘は広い草棚で始まり、着地後の翼腕払いから基本の間合いを学べる。

### 主線で担う役割

既存物語「帰り道の灯」の主題である、人と獣の道が重なる問題を高地へ広げる。オルゼリオンは道を塞ぐ危険個体として対処する対象であり、全ての災害の原因にはしない。狩猟成功によって作業区間を確保し、その後に里の作業班が運搬路と休息路をずらす。討伐だけで道が直る描写にはしない。

挿入候補は中級終盤の高地エピソード。既存のST01〜ST14を置き換えず、新しい依頼IDと章間ノードを物語担当が割り当てる。章番号とランクを同一視しない。初対峙は `rank.2` を基本に、上級・極級再戦は別の調整仕様を用意する。現在の最終狩猟候補セオルミドの役割や既存セーブの達成履歴を変えない。

成功後の台詞案: 「嵐を止めたんじゃない。通れる時と、譲る場所が分かったんだ。」捕獲対応が実装される場合は討伐と同じ情報・通路開放を得る。捕獲そのものを本提出で実装済みとはしない。

## 4. 架空器官を、見える働きに分ける

ここに書く蓄雷嚢・導電板・天鳴晶は**Kariのための架空器官**であり、現実の動物の電気器官や航空力学を再現したものではない。現実らしさは、支持する骨・動かす筋肉・張る膜・硬い板の役割を分け、荷重と可動域が見えることから作る。

| 層 | 形と役割 | 画面で読める変化 |
| --- | --- | --- |
| 支持 | 胸郭、肩帯、翼腕、骨盤、後脚。胸郭は一枚の回転板にしない | 着地の負荷が胸→骨盤へ伝わり、首と尾が遅れて収まる |
| 筋肉 | 胸の深い飛翔筋、肩の回転筋、股関節の伸筋 | 翼の打ち下ろし前に胸と肩が締まり、後脚の蹴り出しで骨盤が上がる |
| 蓄雷嚢 | 胸の左右、胸筋表面を押し出す架空の嚢。心臓の代用品ではない | 蓄電時のみ左右が二度膨らむ。呼吸の膨らみと大きさ・間隔を変える |
| 翼前縁の二条板 | 翼腕と長翼指の付け根に沿う板状器官。関節上は短い重なり | 電荷が胸に近い側から外側へ順に流れる。前縁が起き、膜は少し下がる |
| 翼膜 | 皮膚状の灰琥珀膜。根元は胸側面から大腿の上部へつながる | 上反りで張り、畳むと谷折りと垂れが戻る。常に硬い三角板にしない |
| 尾槍 | 三枚の板が一つの槍の外形を作る。付け根は尾に固定 | 放電直前は三枚の隙間だけが灯り、地面へ向けて狙いが分かる |

冠角は硬い角として頭に固定する。「冠角が起きる」は、首を伸ばし頭を上げる姿勢と角の根元の皮膚が張ることで表現する。角そのものを付け根から蝶番のように開閉しない。怒り時の変化は胸嚢、頭の高さ、翼前縁の張り、呼吸音の組み合わせとし、常時赤色化だけに頼らない。

## 5. 四肢と翼の解剖構造

### 翼腕

胸郭に沿う肩甲部→上腕→前腕→手首→短い親指と4本の長翼指、という順でつなぐ。前腕の橈骨・尺骨に相当する二本の形はモデルで持たせるが、初期リグでは前腕主ノードとねじれ補助でまとめて扱う。これは変形用の簡略化で、解剖上の骨の数を95本と主張するものではない。

長翼指はII〜Vの4本。各3節を持ち、親指Iは2節。翼膜は指間、前腕から胸脇、胸脇から大腿上部へ張る。膜を尾先までつながない。肘・手首・翼指の付け根には余剰膜の折れを置き、開閉時に皮膜が骨を貫かないようにする。三段の張り出しは後縁の輪郭であり、長翼指を3本に減らす指定ではない。

### 地上姿勢

ゆっくり移動する時は後脚と折り畳んだ翼手首のパッドで四点支持する。親指の爪先と翼膜を体重の支持面にしない。手首の外側に短く硬い接地面を置き、指は背側へ折り返して地面から離す。速い短距離移動は後脚主体の二足姿勢へ移り、翼を半開きにして釣り合いを取る。翼腕接地から二足化する時は、胸の持ち上げと後脚の踏み替えを先に見せる。

後脚は大腿→下腿→飛節→足→前向き3趾と短い後方の補助趾。逆に曲がって見える部分は膝とは区別する。三本の主趾は接地時に少し開き、離地時に先端が最後まで残る。常時全身を上下させるだけの歩行にはしない。

### 離陸・着陸・飛行

離陸は後脚を深く屈め、翼手首で短く押して胸を浮かせ、翼の打ち下ろしが地面をこすらない高さで開く。尾は上へ跳ね上げず後方へ伸ばし、回転を抑える。最初の一拍は強く、続く羽ばたきは肩から前腕、指、膜へ遅れて伝わる。離陸動作のまま前方へ瞬間移動させない。

着陸は進行方向を向いた両後脚→必要なら翼手首の順。後脚の左右は地面に応じてわずかにずらせるが、足場を確認せず長く片脚だけで浮かない。接地後に飛節、膝、股関節が順に沈み、胸は一拍遅れて下がる。翼は制動姿勢から半閉じ、呼吸が収まってから全閉じへ移る。尾槍に着地荷重を掛けない。

空中の急旋回は内翼を小さく畳み、外翼を張り、胴が先に傾く。頭だけ180度回して胴が追従する動きはしない。巨大な体をこの寸法で飛ばす物理条件は未検証であり、飛行速度や質量を現実の正解として設定しない。最初はゲーム上の見やすい低空経路と接地を成立させ、飛行時間を増やすのはその後とする。

完全な名前・親子・用途は同梱の `orzelion_rig_blueprint_v1.json` に記載する。座標、バインド行列、スキンウェイト、メッシュ、アニメーションクリップは含まない。したがって、そのJSONをGLBや動作するスケルトンとして読み込めるとは扱わない。

| 体幹・頸・顔 | 21 | root、pelvis、脊椎5、chest、sternum、頸4、head、jaw、舌2、眼2、瞼2 |
| 左翼 | 20 | scapula、humerus、humerus_twist、forearm、forearm_twist、wrist、親指2、長翼指4×3 |
| 右翼 | 20 | 左翼と同じ命名と構造 |
| 左後脚 | 9 | thigh、thigh_twist、shin、hock、foot、主趾3、補助趾 |
| 右後脚 | 9 | 左後脚と同じ命名と構造 |
| 尾 | 12 | tail_01〜tail_12の連続鎖。尾槍はtail_12に固定 |
| 硬質器官・胸嚢 | 4 | 冠角左右、蓄雷嚢左右。冠角は通常は固定し破壊状態の切り替えに使う |
| **合計** | **95** | ソケットとコリジョン形状は含めない |

主な親子は `root → pelvis → spine_01…05 → chest → neck_01…04 → head`。翼は `chest → scapula → humerus → forearm → wrist`。ねじれ補助は同じ肢の主鎖から分岐し、肘や手首の親にはしない。後脚は `pelvis → thigh → shin → hock → foot`。尾は `pelvis → tail_01…12`。

後脚の趾は初期段階で各1ノードとし、趾の付け根の屈曲と開きで地面をつかむ。アップ用の末節屈曲が必要になった時だけ追加する。翼膜のはためきは最初から大量の骨を足す用途にせず、翼指による大きな張り＋限定した形状補正で成立させる。柔らかい縁の補助計算は攻撃判定へ使わない。

別枠で**16ソケット**を定義する。口、胸嚢左右、翼導電板左右、尾端、冠角左右、翼手首接地点左右、後足接地点左右、主趾先左右、頭の注視基準、胴の中心。用途と親をJSONへ明記し、数だけの「12ソケット」などは残さない。ソケットは参照点で、ダメージ判定や移動を勝手に生成しない。

### 変形と質感の要点

胸・腹・肩は滑らかな体積を持つ一つながりの形にし、各関節を球体の連結として見せない。硬い鱗の塊は主に一つの骨へ追従し、鱗の下の皮膚だけをなだらかにつなぐ。肘内側の膜、肩前面、股関節、尾根には屈曲時の形状補正を用意する。金銅板の境目をノーマルだけで描かず、近景では重なりの厚みを残す。

画面上で最も変わるのは胸と翼膜の面である。テクスチャの細密化だけで、肩の体積消失や膜の硬さを隠さない。原画の細かな鱗を全て立体棘として増やす必要はない。表示負荷の予算は現行レンダラで計測して決め、本書では完成モデルのポリゴン数やfpsを保証しない。

## 7. 「蓄電→放電→冷却」が読める戦闘

| 状態 | 形と音の予告 | プレイヤーの判断 | 遷移の約束 |
| --- | --- | --- | --- |
| 探り | 頭は低め、二条板は暗い。短い足運びと板の擦れ音 | 翼腕払い・噛み・尾槍の届く向きを学ぶ | 地上の通常技を挟んでから蓄電へ |
| 蓄電 | 胸嚢が二度膨らむ→頭を上げる→翼内側から外へ灯る | 頭や翼の部位を狙って中断を試みる。放電方向へ残らない | 初期目標2.4秒以上。予告の途中で無告知の別技へ切り替えない |
| 放電 | 光の進んだ側の翼か尾を相手へ向ける。短い板鳴り | 予告された筋の外側へ移動し、硬い板の内側へ近づく | 電弧とダメージの時刻を合わせる。見た目だけ後から追わせない |
| 冷却 | 翼を半閉じ、胸嚢がしぼむ。喉が見え、呼吸音が荒い | 頭・胸へ確実に反撃できる | 大技後は3.5〜6秒の地上回復を初期目標。怒りで消さない |
| 再定位 | 尾で釣り合いを取り、足を踏み替えて向き直る | 次の正面を見て距離を調整する | 地上で姿勢が戻ってから次の蓄電を開始する |

電撃の光量だけで危険を伝えず、胸の膨張、翼の側、尾の向き、音を併用する。画面全体の白飛びや連続フラッシュは使わない。麻痺は指定攻撃の蓄積で発生させ、攻撃を受けた瞬間から次の必殺技まで一続きに確定する構成は避ける。実際の蓄積値、耐性上昇、ダメージ値は既存ルールと照合して別途調整する。

### 空中戦の制約

- 離地から最初の安定接地まで**最長12秒**を初期目標とする。空中攻撃は一往復まで。飛行中の再蓄電と新しい空中連続技の抽選を止める。
- 着地後は**最低8秒の地上時間**を確保する。そのうち4〜5秒を明確な回復にし、残りは歩行や地上技に使う。ノックダウンで地上へ落ちた場合も直ちに飛び直さない。
- 離陸前に着地候補を選び、着地地点を尾の方向・影・土煙で先に知らせる。狩人の足元へ最後の瞬間に吸い付く追尾はしない。
- 全ての戦闘用着地点は地上武器が歩いて到達できる広さを持つ。遠い崖上、地形の外、狭い岩柱を戦闘の安全地帯にしない。
- 有効な着地経路がない時は離陸技を選ばず、地上技へ戻す。翼破壊で飛行条件が失われた場合も、突然消えず近い有効床へ着地させる。

12秒・8秒は未計測の設計値であり、現行の技データへ投入済みではない。初期試作ではさらに短い一往復を優先し、近接武器で操作待ちが生じないか確認する。

## 8. 固有技8種と反撃窓

時間は初期モーション設計の目安。硬直を途中キャンセルして別攻撃を出さないことを先に固定し、速度とダメージは試遊で調整する。

| 技 | 予備動作と攻撃 | 逃げる方向・反撃 | 初期目標 |
| --- | --- | --- | --- |
| 翼腕払い | 左翼を低く引き、肩を沈める→左前方を手首の外側で払う | 反対の右脇へ。攻撃した左翼は地面で一拍支える | 予告0.9秒、回復1.4秒 |
| 折頸の二段噛み | 首を胸へ折り、右足を踏み込む→小さく二回噛む | 一段目の後も頭の正面を避け、二段目後の頬へ | 予告0.9秒、二段の間0.45秒、回復1.6秒 |
| 三枚槍尾 | 尾を右へ浮かせ、三枚の板が鳴る→右から左へ水平薙ぎ | 尾根へ寄るか射程外へ。左で止まった尾を狙う | 予告1.2秒、回復1.8秒 |
| 双条地雷走 | 胸嚢が二度膨らみ、翼前縁が順に灯る→正面へ開く二筋の接地放電 | 二筋の外側か背後へ。放電後の胸へ踏み込む | 共通蓄電2.4秒以上、回復3.5秒 |
| 片翼の雷打 | 左翼の二条板を立てて左足を引く→左側だけを叩き、板の接地線へ雷 | 灯った翼から離れ、反対側の胸へ。左右版は予告から反転 | 予告1.3秒、回復2.2秒 |
| 尾槍の留め雷 | 尾を地面へ向け一歩退く→正面一点へ刺し、遅れて小さく放電 | 刺す点の外へ移動。尾槍が抜けるまで翼根を狙う | 予告1.4秒、刺突後0.6秒で放電、回復2.4秒 |
| 低空雷走 | 両後脚を屈め風上を向く→直線滑空し、折り返し一回で着地 | 進路を横断して避け、予告した着地点へ追う | 予告1.8秒、滞空最大12秒、接地回復4〜5秒 |
| 鳴天放電 | 首を伸ばして冠角を高く見せ、翼を大きく開く→前方三方向へ放電 | 正面の筋間か広い背後へ。終了後の頭・胸が最大の機会 | 大予告3.0秒以上、回復5〜6秒 |

鳴天放電の初期平面案は正面を0度とした−45度・0度・＋45度の三本。各危険帯を約20度幅に抑え、間に逃げ道を残す。帯の幅と射程は実装で調整するが、後から見えない円形全域判定を足さない。頭のすぐ下へ同時に別の衝撃波を置かず、接近して避けた行動が報われるようにする。

初戦では地上技→蓄電→接地放電→冷却を先に経験させ、その後に低空雷走を出す。怒りでは間合いの詰め方と技の組み合わせを変え、予告時間と地上回復を消すことで難しくしない。

## 9. 部位破壊6枠

| 枠 | 見た目 | 戦闘への効果案 | 素材との関係 |
| --- | --- | --- | --- |
| 冠角 | 2本のうち外縁が欠け、金銅の明るい断面が出る。頭そのものは欠損しない | 鳴天放電の集束が乱れ、外側二筋の長さを短くする。予告は保持 | 鳴天竜の冠角。左右を1枠で扱う |
| 左翼の導電板 | 左の二条の一部が欠け、膜の縁に限定した裂け | 左の片翼雷打の雷部分が縮小。空中の折り返しを省き、早く着地 | 鳴天竜の導電翼膜・蒼甲 |
| 右翼の導電板 | 右側に同じ破壊段階。左と独立して見分ける | 右側へ同効果。両翼破壊で通常の離陸技を停止し、地上戦へ移る | 鳴天竜の導電翼膜・蒼甲 |
| 胸の蓄雷嚢 | 外皮の保護甲が割れ、片側の膨らみが弱くなる。生々しい内臓露出にはしない | 蓄電中断を起こしやすくし、冷却時間を増やす。雷属性を完全消失はさせない | 鳴天竜の蓄雷嚢、低確率候補の天鳴晶 |
| 両後脚の爪甲 | 主趾の爪甲に欠けと擦れ。骨格と接地面は残す | 着地後の踏み直しが増え、接地回復を長くする。移動不能にはしない | 鳴天竜の蒼甲。左右を1枠で扱う |
| 尾槍 | 先端3枚を束ねる硬い部分が折れ、短い尾先になる | 尾薙ぎの先端射程と留め雷の範囲が減る。尾自体の釣り合い機能は残る | 鳴天竜の尾槍 |

冠角・後脚は左右をまとめるため、破壊達成時の見た目は両側へ小さい欠けを配る。片側を完全に失ったのに左右合算しか記録しない表現を避ける。左右翼は別の耐久・見た目を持つ。新規原種の最初のモデルでは尾槍の破壊を短い外装の脱落として作り、尾全体の切断と別扱いにする。

空中で翼破壊が成立した時は、近い有効床への落下／滑走移行を行う。地形外へ落として勝利不能にしない。数値の重複効果は上限を決める必要があるため、具体的な倍率は本書で固定しない。

素材の絵は生物の部位由来と分かる断面・繊維を残す。雷のアイコンを上に重ねるだけで属性を表さない。6種の外形を「板片・長角・膜・袋・三枚槍・小核」に分け、64pxでも取り違えにくくする。

武器は雷属性の断岳剣・長尖槍・環弓を優先して外形を確立する。防具は嵐青の細身胴、象牙の胸当て、二冠の兜、肩から前腕へ通る二条板、短い三枚尾槍の腰飾り。実物大の翼を背負わせず、腕を動かす可動域を保つ。技能の方向は短い反撃窓で間合いを整える動きと雷の扱い。具体的な技能ID、攻撃値、会心率、素材消費数を既存系列の未確認値から複写しない。麻痺武器は雷武器と同じ効果とせず、採用する場合に別枠で調整する。
