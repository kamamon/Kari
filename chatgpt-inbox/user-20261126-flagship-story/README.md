## 今回の物語

里へ荷を届けるために獣と向き合ってきた狩人が、空を横切る大きな翼を見上げる。各地の湿りと通行記録を重ねると、人だけでなく獣の道も変わっていたと分かる。谷の帰路をセオルミド戦で確保し、その先の鉛雲高地「鳴天の背」で、オルゼリオンが休む岩棚と人の点検路の重なりに対処する。勝利のあと、里の人が道と区間設備を見直し、荷車と作業者が帰ってくる。

ミナギは記録と中断判断、ロクハは交換できる補修、イサネは荷の優先順位と迂回、セナキは旧判断の更新を担う。主人公の性別・出自・外見は固定しない。

## Claudeへの読み順

1. source_audit_v2.mdで正本、並行制作の看板案、追加判断の境界を確認する。
2. story_bible_v2.mdとdialogue_and_direction_v2.mdで物語と12場面を読む。
3. implementation_handoff_v2.mdの前提を満たした区間から、物語・クエストのproposal JSONを正規データへ変換する。
4. 原画と台帳を正式な置き場へ移し、artIndex・人物・場面の参照を整合する。
5. 前章の条件、スキップ/再読込、旧セーブ、討伐/捕獲、各地域と近接武器の成立を確認して採用する。

**proposal JSONをpublic/data/story.jsonやquestsへそのまま上書きしない。** 現行物語のvalidatorは未実装章へのsteps/scene追加や、空stepsの終章を拒否する。また現行open/brief場面は前章条件がないため、全文を有効にする前に解禁判定を拡張する。

## 看板担当との合わせ方

看板の提案IDはmonster.orzelion、原種の初出は中級rank.2、主生息地は鉛雲高地。TQ07は中級終盤の任意狩猟、TQ04は物語用の極級個体、TQ06はクリア後の別個体再戦。種登録の初出rankや既存ST14/monster.segranioを上書きしない。

身体は翼腕2＋後脚2、硬い冠角2本、翼前縁の二条、三枚の尾槍。正式な通電経路は胸の左右蓄雷嚢→翼前縁→尾。先に制作した場面画の光から解剖やエネルギーの順を逆算しない。テンガロの痺液による麻痺は雷とは別として扱う。

参照時点の看板文書・原画はreferences/に保存した。その時点では並行制作の未コミット資料で、main採用済みではない。正式な看板提出が更新された場合は、そちらと照合して物語・原画・UIを揃える。

## 守れなかった決まり・迷って決めたこと

既知の書き込み範囲逸脱はない。すべて今回のinbox内で追加し、既存本体を改変していない。物語は独自の世界・人物・台詞で構成した。生成画は基準と照合したが、全方向の解剖一致・世界中の作品との非類似まで証明したとは扱わない。

迷って決めたことは、旧最終戦のセオルミドを残し、その先へ看板決戦章を追加した点。看板側の中級初対峙案は任意TQ07として接続し、必須本筋を追加周回で止めない。最終と中級は別個体とする。海岸の初目撃地点と高地への輸送路、鳴天の背の具体地形は新規の地理案で、フィールド担当との照合が必要。

## 確かめたこと・確かめていないこと

Node.js 24.22.3でnpm ciを実行。独自台帳検査、旧IDと前提の照合、新規PNGの形式・寸法・ハッシュ、文書の矛盾確認、冊子の全ページレンダリングを実施した。実際の結果はvalidation_report.mdに記録した。

新しいモンスター登録用JSONはこの提出には含めないため、bestiary:importの対象はない。全アプリのテスト/build/smokeはゲーム本体を変更していないため再実行していない。後半地域、看板のモデル/技/飛行/捕獲、難易度・報酬、保存移行、iPhoneでの視認性と性能は未検証。音素材・22項目の制作待ちを完成済みと数えない。
