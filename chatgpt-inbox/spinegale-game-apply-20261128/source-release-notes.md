# Kari — 疾棘竜スパインゲイル クエスト統合パッケージ V1

## 内容
- 初級・中級・上級の3狩猟依頼、掲示、報酬、捕獲、剥ぎ取り、部位破壊、級別素材21種。
- 全11武器系統の33武器・15防具・48レシピ・69透過PNG（256px）。現行mainの7武器系統を先に有効化し、別途11武器種化が統合されてから同じインストーラを再実行する。新4系統の戦闘機能・武器3Dモデルは含まない。
- V3ゲーム向け原型171,772三角形、77関節、53クリップ、軽量版32,074三角形。210万三角形の承認済みV3.2は別途保持。
- GLBのアニメーションから算出した23行動（級別疲労・切断後差分込み）、13攻撃軌道、10移動曲線、23部位追従表。攻撃カプセルは骨の端点から近似し、メッシュのすべての表面を厳密に追従するものではない。
- `SpinegaleRig.ts`: GLTFLoaderとAnimationMixerによる描画アダプタ。`apply.py`: 既存のクエスト・図鑑・狩場・素材・装備・アイコン・AIへの接続と疲労スケジューラのソースパッチ。

## Claude / Kari の統合方法
AGENTS.mdの規定に従い、mainへ直接書かず検証ブランチで適用する。対象は確認した v0.72.0 系のファイル構成。Python 3.10+。既存の作業をコミットしてから行う。

```
python validate.py
python apply.py /path/to/Kari
python apply.py /path/to/Kari --apply
cd /path/to/Kari
npm ci
npm run check
npm run smoke
```

初回はdry run。ソースのアンカーが変更されていた場合は書き込み前に停止し、Claudeが現行コードに合わせて移植する。`--mobile`で旧軽量版を配置できる。`--test`は適用後のtypecheck/test/buildを実行する。既存ファイルの控えは `.spinegale-backup` に作る。バックアップはGitへ入れないこと。装備シリーズの数・掲示の数などの固定件数テストは追加に合わせて見直す。
