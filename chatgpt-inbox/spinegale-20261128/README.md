## 戦闘の核
- HP1450、通常2.8m/s、走行7.2m/s、突進10.5m/s。スタミナ100、20以下で行動を終えて600tick疲労。疲労中の新規攻撃・移動なし。頭を垂れ、喉膜と胸郭を動かし呼吸する。
- 怒りは速度1.15倍・消費1.2倍。疲労を中断しない。攻撃開始時に消費1回、攻撃内の走行は重複減算しない。35以下から尾を落とし呼吸音を変える。
- 攻撃は予備動作と着地後の硬直を持つ。発進後追尾を止める。群れは最大1体が攻撃し、疲労中に新規指示を出さない。初心者の回避・位置取り・隙への攻撃を教える。
- 数値は実機未検証の制作初期値。既存ガルドロスと比較して調整する。

## 実写級モデル仕様
採用原画Dから頭・後方へ反る背棘・二股尾扇・橙の喉袋を厳守。黄緑の鱗と炭色の模様、砂色腹。鱗は貼り板を乱立させず、皮膚と連続する。大型恐竜の筋肉・腱・鳥類の足の接地を基準にし、肩から腕、股関節と尾の筋肉を連続させる。左右対称の体形、自然な小傷のみ非対称。眼は透明感、口腔は歯肉・舌・湿り気、喉は皮膜の伸び・折り目。背棘は弾性、尾扇は開閉、歯と爪は硬質。モデルの中に地面・台座を入れない。
- +Y上/+Z前、右=-X、足元原点、m。GLB。原画→高密度スカルプト→リトポ→UV→PBR焼付→変形用骨格→LOD→実機。PC近接原型80k三角形、モバイルLOD0 36k/LOD1 18k/LOD2 7k（描画予算は計測後に調整）。本体の材質をできる限り統合。透明喉膜は不透明PBRで表現し透過の多重描画を避ける。
- 骨77本目標（正式名未確定）、4ウェイト以下・和1、足IK、尾10節、尾扇左右2、喉袋3、背棘4群、眼/まぶた独立。ゲームの判定はトラックを正本にする。両脚の股・膝・飛節が不自然に逆関節にならないよう解剖と支持脚を確認する。
- クリップはその場（in-place）、60tick/s。支持脚の接地、移動曲線と足運びを一致させ、攻撃判定と見た目の軌道を照合する。視覚のみの揺れは判定を変えない。急停止の足を滑らせ続けない。
- 切断後の尾は断面専用の皮と縮んだ判定、冠・喉膜・背棘は専用差分。装備は本体の素材由来の質感・色を保つ。
