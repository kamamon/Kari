# 環境画像材質改修（2026-11-27）
ユーザー直接依頼「拠点やフィールド全てにおいて素材の画像を使わない箇所は極限まで減らして」。本体実装までの指定に従い、専用ブランチで変更。

- 10種の生成原画を512pxに縮小し、端をブレンドしてWebP化。色付きモデル向け明度補正10点、補助加工11点を加え、31ファイル。出典・ファイルサイズ・Git blob SHA は public/assets/textures/materials/manifest.json。補助材質（毛・羽・皮・骨等）は加工／近似であり、それぞれの独立生成原画や実測PBRセットではない。
- materialImages.ts に画像読込、UV補完、色倍率、画像由来bump、アニメーション水面の共有機構。読み込み前または失敗時は既存の材質を維持する。
- 里の建物・屋根・擁壁・橋・水車・布・周辺山林・生活小物・採集場・自室・坑道・養魚池・家畜、フィールドの野営地・門・晶柱・採取点・池・蔦・納品箱・障害物などに適用。
- #41 の20地域・80ツアーの採集カタログを維持し、全地域共通の採取物描画を画像化。既に画像のある地面・岩・草・遠景等は保持。地域ごとの新規固有原画は今回の対象外。
- 空、光源、UIの採集マーカー、霧、影、パーティクルなどは機能上必要なシェーダーや単色表現を維持。ポリゴンモデル・当たり判定・ゲームロジックは原則変更しない。
- 素材別バッチ分割に伴い外周の描画数テスト上限を8→14に更新。三角形上限42000は据え置き。全体の実機FPS・見た目・継ぎ目は別途ブラウザ実測が必要。全画面の画像材質率は未測定。
- 自動テスト：画像ファイル／ハッシュ、拠点と専用区画、全20地域の採取物の画像参照・UV。Node検査は実際のGPU描画やデコードを保証しない。
