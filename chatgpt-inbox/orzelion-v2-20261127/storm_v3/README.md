# Orzelion Storm V3 — 雷・接地・変形の実装試作

基点 main v0.60.0 / 5704d15256f0efda0e2448f9e20212969475cf12、PR #28の専用glTFを再利用。ゲーム本体未登録、鉛雲高地未実装のため本体は変更しない。

## 内容
- storm_core.mjs / test_storm.mjs / storm_validation.json: 60Hz、固定予告・有効窓・残光、同じ凸領域で判定と予兆を描画。1インスタンス1対象1回、範囲外・高さ外・終了時無効。6技の単体検査に合格（低空雷走は固定地表範囲の検証であり本番の空中突進判定ではない）。
- pose_corrections.mjs / pose_validation.json: 実モデル95骨、平坦地3リンクFABRIK、支持足目標、足裏水平化、root前進。検査した支持足目標誤差最大0.262mm、骨長漂移最大0.000238mm。足裏全面・傾斜・着地遷移・翼手首接地・関節可動域は未検証。
- preview_renderer.mjs: CPU LBS、UV境界を固定した膜のたわみ、肩胸腿の法線方向補正、手続き鱗・膜・金属模様。正式PBRや筋肉スカルプトではない。
- storm_compositor.mjs: 分岐電流、白芯、複数幅の青外光、地表予告、局所発光、火花、残光、簡易遮蔽。枝・粒子数は品質設定に応じ変更。
- studio.html: 34クリップ・視点/速度/雷/骨格/判定点。GitHub上ではHTMLは実行されない。取得してブラウザで開き、同梱glTFを選択。実機動作未確認。
- art/: 4枚の実モデル描画。render_validation.json。

## Claudeへ統合要件
KariのMonsterRig・SimEvent・action/shapeTrack・hazardを使用。攻撃開始時に位置/yawを確定し、固定tickの同じ領域を描画と判定に渡す。装飾雷でダメージを発生させない。回避/ガード/麻痺/地形制限、攻撃中断・終了でインスタンス破棄。低空雷走は実シミュレーション軌道の別判定へ統合。この試作の固定地表範囲を空中攻撃へそのまま転用しない。地形heightAtに足裏接地点を固定。左右翼・尾破壊別形状、肩・翼手首接地、関節制約、翼膜自己衝突を検査。Three MeshStandardMaterial、UVに合わせた法線・粗さ・AO、発光コア/外光/分岐リボン/粒子は再利用バッファで描く。品質を下げても危険領域は省略しない。各武器、破壊、捕獲、物語、セーブ互換、iPhone Safari実機計測、30分連続を確認して公開する。
