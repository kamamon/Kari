# 表面質感の追加と原画の引き継ぎ

## 追加した実データ
- 黒藍鱗・古金導電板・灰琥珀翼膜の3材質。各256×256 PNGでbase色変調、接線法線、ORM（R=AO固定255、G=roughness、B=metallic）の3枚、計9枚。
- glTFの5材質へ各テクスチャを紐付けた。色係数は既存の黒藍/象牙/古金/膜のパレットを維持。
- 生成済みの5方向プレビューは**テクスチャ追加前のバインド姿勢**であり、更新後の表示結果ではない。
- generate.mjsで基本データを再生成した後、texture_generator.mjsを同じ出力先に対して実行する。例: node generate.mjs generated && node texture_generator.mjs generated

## 未完了・重要なレビュー
バインド姿勢の斜めプレビューを目視した。専用骨格の構成は確認資料に使える一方、頭部・冠角・胸筋・後脚・背甲の造形は丸みが強く、翼の厚みや膜のシルエットにも不足がある。**現状は看板の最終品質ではない。** 正式な彫刻モデルは、横から長く鋭い顎、顔から後頭部へ流れる複合冠角、胸の左右に深い飛翔筋と保護甲、翼指と翼腕の筋肉境界、爪甲の重なり、三枚の長い尾槍を仕上げる。過剰な棘を全身へ追加せず、面の重なりで強さを出す。通常色と雷発光を分離する。今回の9枚は手続き的なタイル試作で、正式なUV焼き込み・ハイポリ法線・破壊差分・発光マスクではない。glTFの実機ローダー確認も未実施。
