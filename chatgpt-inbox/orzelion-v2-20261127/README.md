## デザイン変更と理由
既存ID・雷・鉛雲高地・中級TQ07・極級TQ04/TQ06・4肢・二冠・4長翼指・二条導電板・三枚槍尾を維持。全長15.8→17.6、翼開長23.4→25.8mは造形目標。黒藍・古金・象牙で重厚化、通常暗く放電時強く光る。極級は別個体調整、種IDを増やさない。低空飛行・蓄電→放電→冷却・反撃可能を維持。既存武器familyと同じ7系統、雷耐性と氷弱点、固有技能は段階式。技のダメージは実測ではなく初期調整案。

## 未確認・逸脱
基準v2文書、旧設計、掲示板、登録簿、装備データを読んだが、基準PNG・旧原画のバイト取得不可で画像照合なし。手続きメッシュは滑らかな断面と翼膜を持つ試作。正式スカルプト・LOD・UV画像マップ・破壊別メッシュ・接地IK・補正形状・判定・飛行物理・実機・npm ci/import --dry未検証。SVGはPNG指定に対する制作資料の例外。ゲームコードへ未導入。クリップは見た目の試作で、ゲームの当たり判定と同期していない。装備のIDと数値は既存ルールと再照合が必要。既存の86種、ストーリーとsrc/docsは変更しない。
