# 2G主基準：ハンター操作・動作と武器11系統の実装指示 v1

作成：2026-11-26。照合基準：Kari main `0925487b686473e1a4d7e45fdc63449ef3a7d2ec`（v0.34.0）。設計文書であり、ゲームコードは変更していない。

## 1. 今回採用する方針

**【採用指示】PSP日本版『モンスターハンターポータブル 2nd G』を、操作の意味、武器ごとの動作構成、攻撃を出し切る重さ、納刀して行動する判断、手動カメラの主基準にする。** PR14受領時の「参考資料」という扱いから、今回のユーザー指示によって実装方針へ進める。MHP3rd・MH3・2G for iOSを標準挙動へ混ぜない。ハンターの顔・体型・衣服、防具と武器の造形・装飾・名称はKariのオリジナルを使う。

本書の区分は、【現行確認】＝固定SHAのコードで確認、【採用指示】＝今回作る仕様、【仮設計】＝Kari用の調整値、【要検証】＝PSP実プレイと照合が必要、の4つ。原作のフレーム数・無敵時間・旋回角・歩速・当たり判定寸法は測定していない。動画の時刻や30fpsというファイル情報をゲーム内部の時間へ変換しない。

PSPの基本操作と武器の役割は資料[R1][R2]を補助にする。海外版MHFUの資料なので、日本語名称・メニュー決定ボタン・細かな操作設定は日本版で照合する。公式冊子でも紹介ガイドの簡略説明を内部仕様の根拠にしない。

## 3. 入力状態表

PSPのボタン形状を画面へそのまま写す必要はない。内部は主攻撃／副攻撃／特殊／回避／道具／武器／環境操作／視点に分け、タッチとパッドで同じ命令を生成する。主・副・特殊の複合入力を解釈する層を設ける。現行の「主があれば先に実行」だけでは同時押し技を表せない。

| 状態 | 移動・向き | 攻撃・特殊 | 回避・道具・環境 |
| --- | --- | --- | --- |
| 納刀・立ち | 通常移動、疾走はスタミナ使用 | 武器ボタンで抜刀。移動＋主攻撃は武器別の抜刀攻撃 | 道具は使用開始。環境操作は採集・剥ぎ取り等。静止時のしゃがみを別状態で実装 |
| 抜刀・自由 | 武器別の歩速と向き変更。通常疾走は不可 | 主／副／複合／特殊を武器表で解決 | 道具の通常入力は納刀まで。使用は納刀後の次入力。回避は武器別 |
| 攻撃準備 | 許可区間だけ小さく方向補正 | 溜め対応技だけ保持・解放を解釈 | 明示された遷移のみ。長い技を回避連打でいつでも中断できない |
| 攻撃判定・終端 | 技の移動曲線で進む。敵への自動旋回なし | 攻撃ごとの連係窓で次の技へ | 窓のない区間は出し切る。納刀や道具へ瞬時に飛ばさない |
| ガード | 武器別の方向変更と許可された低速移動 | 防御中攻撃は専用定義。通常の受けと反撃を分離 | 護刃のガード＋道具だけ抜刀使用。受けの反動中は行動を制限 |
| 回復・研磨・採集 | 地上の所定位置で動作する | 攻撃へ自由移行しない | 効果確定と復帰は別時刻。中断可能性は動作別に定義 |
| 登攀 | 指定の登攀区間だけ、進行方向に沿って移動 | 武器を納めて取り付き・登る・降り立つ | 上下端で地上状態へ戻す。自由ジャンプや乗り攻撃へ接続しない |
| 被弾・転倒・死亡 | 専用の移動と復帰 | 古い攻撃予約を消す | 起き上がり時に以前の入力で勝手に飲んだり攻撃したりしない |
| 照準 | 移動方向・照準方向・カメラを区別 | 弓は溜めと解放、銃系追加時は発射と装填 | 視点入力がそのまま移動方向へ化けない |

納刀静止からの抜刀、しゃがみ中の操作、回避方向、納刀からの特殊複合入力は、日本版操作図と連続プレイで対応表を埋める【要検証】。未記入の動作は「2G互換完了」にしない。タッチでは複合技を専用小ボタンに割り当てられるようにし、複数の指を強制しない。環境ボタンを押した時だけ採集へ入り、近くの採取点が通常攻撃を横取りしない。現行のボタン配置変更・左利き・サイズ調整は保持する。[K5]

フィールド側の`contextClimb`を受け、`climb_mount → climbing → climb_exit`へ接続する【採用指示：新設】。低い段差の乗越えと段端からの降下も専用遷移にする。平坦な戦闘床、通路、岩棚、登攀区間を区別し、どの斜面でも走って登れる扱いにしない。登攀案内アイコンはスマホ用の任意補助として扱う。

入力バッファは押下1回を1命令として消費する。新しい任意命令が古い予約を上書きでき、失効時に再生しない。初期6 tickは【仮設計】。命中停止中に残り猶予を進めるかは明文化して検証する。保持と再押下を混同せず、ガード・溜めはheld、単発・連係はpressed、放つ動作はreleasedを基本にする。同時入力は武器固有の複合技を優先し、成立しない時だけ単独入力へ落とす。

## 4. 動作の作り方：構えから復帰まで

各actionに最低限、K0開始姿勢、K1予備動作、K2接触／発射／効果確定、K3振り終わり、K4復帰を置く。これは制作上のキー姿勢で、原作から計測した割合ではない。各キーに支持脚、接地点、骨盤・胸・肩の向き、両手の握り、武器先端、simulationの移動量、判定の有無、次入力の許可を記す。溜めはK1付近に保持姿勢と解放分岐、連撃は打撃ごとにK2を持つ。

大振りは「足を決める→腰と胸を使う→武器を通す→重さを受け止める→戻す」。軽い武器は小さな踏み替えを連係させる。振り終わりを長くするだけで重量感を作らない。背中・正面・側面から、武器軌道と体重移動が同じ技に見えるようにする。原作の抽出アニメーションやメッシュを取り込まず、Kariの体格・武器寸法で作り直す。

**接地とroot motion：** 世界位置の正本は現行のsimulationと衝突解決に置き、描画IKが位置やダメージを変えない。`rootMotion`は累積距離曲線の差分、停止中は差分0、壁で止まった距離は実移動量へ反映する。見た目だけ武器や体が壁の向こうへ進み続けない。[K3]

現行`ContactLocomotion`は母指球を固定し、急旋回などで一時的に接地を解除する。`HunterAnimator`の世界接地は通常待機・歩行で働き、攻撃中は別のキー姿勢を使う。したがって「足のIKあり」を攻撃の接地検査済みと扱わない。[K6]

攻撃用にも左右のcontact区間を持たせる。踏み込む足が着く前に体だけ前進しない。支持足の母指球は接地中に留め、踵の回旋と踏み替えで方向を変える。斜面では左右の地面高さを別々に採り、脚が届く範囲で骨盤を調整する。武器の有効区間はトラックと見た目を一致させ、過度なブレンドで接触位置をずらさない。命中停止では処理済み接触姿勢と移動を止め、復帰時に飛ばさない。

**回避：** 予備姿勢→蹴り出し→回転／跳躍→接地→立て直しを分ける。回避の無敵と空中に見える区間は別に定義する。納刀の通常回避、武器を持った回避、槍の後方／攻撃後横ステップ、危険から離れる緊急回避を別actionにする。緊急回避の成立条件と原作の方向制限は【要検証】。現行回避を単純に長い無敵へ増強して代用しない。

**ガード：** 構え成立前、受け、反動、再構えを分離し、武器別にスタミナ・削り・のけぞりを定義する。護刃の無消費・無反動パリィと長尖槍の自動反撃を標準から除く。敵の攻撃にガード可能属性を持たせる。細かな原作の受け性能は未測定で、現在の数値を原作値とは呼ばない。

**回復・研磨：** 回復は足を止め、取り出し→飲む→効果確定→飲み終わりの決め姿勢→収納・復帰を採用する。移動回復と回避による自由な後隙消去を標準にしない。研磨はしゃがみ、武器を支え、刃へ道具を当て、終えてから戻る。消費数・HPや刃・効果音を同じ確定イベントへ結び付ける。確定前の被弾は未消費、確定後は効果と消費を維持する【仮設計：Kariの整合規則。原作の消費フレーム未確認】。現行drinkの全92 tick等は再検証対象である。

## 6. カメラと移行・完成条件

標準は手動旋回とハンター背後への視点戻し。敵へ自動的に向き続けない。PSP2GへiOS版のターゲットカメラを帰属させない。[R3] 現行の距離5.2m、FOV58度、壁衝突の縮退はKari値であり、原作値ではない。接近時は足元・敵の攻撃部位・逃げ道を読める構図を調整する。現行の視点戻し表示「正面」は「背後へ戻す」へ改める。[K5][K8]

既存ロックオン、弓の吸い付き、納刀後の自動道具使用は、残す場合は明示的な「操作補助」設定へ分離する。新規の標準は2G基準、既存ユーザーの補助設定は通知なしに上書きしない。照準は画面の飾りではなく、simulationの射線を示す。描画カメラだけで命中先を決めない。

武器・防具・素材・レシピ・所有数・強化・4等級・クエスト達成・キャラメイクを保持する。行動変更のために所持武器IDを振り直さない。行動定義の版とリプレイの版を記録し、旧記録を新しい技へ黙って解釈し直さない。保存スキーマを変える時は既存の段階移行方式に従い、元データの控えを保持する。旧技のデータは移行資料として保存できるが、新標準の技欄には混ぜない。[K7]

実装順は①状態・入力・道具と手動照準、②大剣で支持脚／判定／復帰の縦断完成、③残り6武器と専用資源、④不足4武器。各武器の完了には次を必要とする。

- 納刀・抜刀・移動・全攻撃・連係・溜め・防御または固有・回避・道具・被弾からの復帰が入力表と一致する。
- 正面／横／背後のキー姿勢と連続再生で、足滑り、握り外れ、判定と刃先のずれ、壁での位置飛びがない。
- 命中停止、空振り、被弾割込み、入力猶予切れ、画面回転・指の離脱を確認する。実機タッチで未確認ならそのまま記録する。
- PSP日本版の同じ動作との比較記録に、作品・機種・開始状態・映像時刻・観察した差・未測定値を残す。動作の方向性が近い段階と、時間まで検証した段階を分けて報告する。
