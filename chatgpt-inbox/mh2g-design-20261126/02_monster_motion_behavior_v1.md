# 02 モンスターの動き・行動 AI・狩猟ループ：Claude 実装指示 v1

作成：2026-11-26。対象：Kari / VEILBOUND HUNTERS。基準：main `0925487b686473e1a4d7e45fdc63449ef3a7d2ec`、v0.34.0。

## 1. 今回の指示と根拠の扱い

利用者の新指示により、**PSP 日本版 MHP2nd G を、間合い・向き直り・攻撃の覚悟・反撃機会・追跡の主基準として実装へ反映する**。D-110 の「調査を資料として受領」から先へ進む。Claude は本稿の差分を実装し、代表種で動作確認してから共通化する。モンスターの外形、名称、器官、骨格、技の具体的な姿勢は Kari の原案を使う。

以下の【現行】は固定コミットのコード読解、【Kari 仮設計】は今回の実装方針。2G の全個体の内部 AI、旋回角、硬直、耐久、速度、抽選率を復元したものではない。2G の映像から「全種が毎回 90 度ずつ旋回する」「予備動作中は必ずこのフレームで追尾が切れる」等とは断定しない。原作の数値は移植せず、Kari の固定 tick と画面上の結果で調整する。

MH3 の大型疲労・捕食による回復、水中戦を、2G の仕様として追加しない。現行の幼体の草食や逃走後の息継ぎは Kari の生活行動として扱い、原作由来の戦闘スタミナとは呼ばない。

## 2. 現行でできていることと、今回変えること

| 対象 | 【現行】コードで確認 | 【Kari 仮設計】実装差分 |
|---|---|---|
| 技の選択 | `chooseAction` が距離・角度・左右・再使用待ち・前方余地で候補を絞る。開始後に毎 tick 再抽選しない | 選択前の向き直りを独立した動作にする。動作途中に都合のよい技へ差し替えない |
| 向きと接近 | 無行動中は `turnToward` で連続旋回し、正面を捉えると接近。技には `turning.untilTick` がある | 戦闘時の旋回を足の踏み替えで区切る。方向確定を姿勢と対応させる |
| 攻撃 | `startup / active / recovery` と移動曲線、攻撃軌道を持つ | 予備姿勢の識別、突進の加速・制動、後隙の露出を詰める。三段階そのものを新設扱いしない |
| 部位と反応 | HP、破壊、切断、怯み、怒りが別。脚の怯みから転倒。毒・麻痺・睡眠・気絶も実装済み | 反応の競合を明示。転倒中・起き上がり中も部位判定を姿勢へ追従させる |
| 部位追従 | 大型 11 種・幼体 8 種は技と睡眠に焼き出し済み `follow` を使う | ガルドロスの追従を追加。転倒・起き上がり・切断後の変形も対象化 |
| エリア移動 | `roam.ts` に巡回、弱り退避、巣での休眠と回復がある。離脱は追いつかれない速さ | 退避前の牽制、移動開始、寝床への到着をつなぐ。戦闘中にその場で寝る条件を改める |
| 幼体 | `herdHurt` が被攻撃時に `fightChance` で反撃し、行き詰まっても `fight` になる | 逃走寄り・攻撃寄りの性格を個体に保持し、攻撃される前から反応を分ける |

根拠：下記 C1〜C5。現行のガルドロス突進にも追尾打切りと長い移動区間があり、「いつでも曲がる AI」「予備動作がない AI」という診断にはしない。

## 3. 戦闘の一手を、向き直りから後隙までつなぐ

【Kari 仮設計】基本の流れを「観察 → 向き直り → 技を決定 → 構え → 方向確定 → 攻撃 → 制動／戻り → 再判断」とする。必要な段階だけを通す。背面への尾払い等は向き直らず選べる。自由行動へ戻るまで、プレイヤーが横へ動いたことだけで攻撃を中止しない。

`MonsterState` に戦術意図と旋回の実行状態を追加する。少なくとも向き直り開始 tick、左右、目標角、段階、確定した攻撃方向をシミュレーション側に保持する。`ActionRun` と別々の時計で同じ攻撃を進めない。名称は Claude が既存の型に合わせてよいが、データの意味を仕様へ残す。

### 向き直り

戦闘時は目標方向へ滑らかに全身が回り続ける状態を減らす。頭・首が先に相手を捉え、支持脚へ体重を乗せ、遊脚を踏み替え、腰と尾が遅れて追いつく。大きな角度は複数の踏み替えへ分け、各踏み替えの終端を読めるようにする。角度と所要時間は骨格別データにし、全種に同じ角度を強制しない。

一段の途中で左右を反転せず、次の接地で目標方向を読み直す。プレイヤーが背後を横切ったら、頭だけを無制限にねじらず、次の向き直りか背面技で応じる。散歩・経路追従には現在の連続旋回を残し、戦闘の読み合いと用途を分ける。

### 攻撃方向の確定

既存 `turning.untilTick` を各技の「狙い直せる終わり」として点検する。突進は踏み込み準備が終わる時点、噛みつきは首を引き切った時点、叩きつけは荷重が移った時点等に対応させる。その後は確定方向へ出す。追尾する技は、追尾する区間と上限を個別に宣言し、例外が見た目から判別できるようにする。

投射物・落下物も狙う位置を記録する。現在の `spawnHazards` 呼出しは発生時の `player.pos` を渡すため、予告済みの位置へ出す技に変える場合は、その予告時点の座標を使う。構えは左、着弾だけ最新の右位置という不整合を作らない。プレイヤーのボタン入力や未来位置を読んで回避先を狙う処理は入れない。

### 突進と後隙

「身を低くする → 後脚で押す → 速度を得る → 直進 → 前脚で受ける → 胴が追いつく → 頭を戻す」を一続きにする。移動曲線の速度と歩幅・足数を合わせ、停止時に足が滑る間と接地して支える間を描き分ける。動作の最後まで攻撃判定を出し続けず、危険な身体接触が終わる時点を技別に定義する。

壁に押しつけられて進めない時は、意図した移動量と実移動量から制動・踏み直しへ移る。壁の中で走り続ける、壁沿いに急に曲がって当て直す、判定だけ前進する状態を避ける。壁への衝突が必ず転倒になる仕様にはせず、種別の止まり方を設定する。

後隙では頭、脚、尾のいずれが狙いやすいかを明確にする。全技を同じ長さで待たせず、小技は短い戻り、大技は荷重回復、外した突進は向き直りも含む。怒りでも予兆と後隙の存在は残す。行動終了後の `cooldown` と姿勢内の後隙を二重に増やして、棒立ちを作らない。

## 4. オリジナル骨格への適用

| 骨格の入口 | 作るべき読みやすさ | 実装時の注意 |
|---|---|---|
| 重い四足：ガルドロス | 肩を沈める突進、片脚へ荷重する叩きつけ、腰から始まる尾払い。前後の支持脚が分かる旋回 | `galdrosRig.ts` と採用済み骨名を使う。巨大な上下バウンドで重量を表さず、支持脚と胴の遅れで出す |
| 軽い四足：セルヴァルク等 | 小さな踏み替え、短い飛び退き、頭と胸の方向が先に読める突入 | 帆状器官があることを飛行能力の根拠にしない。現行 `quadruped_light` の陸上種として作る |
| 二足有翼：アシュレイア等 | 地上の向き直り、翼を使った威嚇、跳躍時の踏切と着地。飛行可能種だけ離陸・空中位置取り・着地 | `biped_wing` だけで飛行 AI を有効にしない。能力、空中経路、接触判定、着地点をデータで揃える |
| 長胴：ラズメル等 | 頭の方向転換が胴へ伝わる。巻き、伸び、尾の戻りを区別 | 二足の足踏みを流用せず、接地する胴の支点と曲げの順序で旋回の区切りを作る |
| 小型・幼体 | 大型より短い構えでも、攻撃寄りの前傾と逃走寄りの後退が識別できる | 親の動作を一律縮小・高速化しない。頭身・脚長・支持面積から歩幅を作る |

飛竜型から取り入れるのは「離陸前後にも読み合う時間がある」「着地地点を認識して近づける」という行動構成。既存モンスターの輪郭、固有の着地姿勢、翼の形を写す指示ではない。飛行未対応段階は地上行動を完成させ、見た目だけ浮かせて地上判定を残さない。

`creatureMoves.ts` の鍵姿勢は、溜める・短く打つ・支えて戻すという時間配分で整える。全区間を同じ緩い補間にしない。`creaturePlans.ts` は生成物なので直接編集せず、`tools/gen-monsters.py` 等の生成元を更新し、軌道と追従表を再生成する。

## 5. 部位・怒り・怯み・転倒を混ぜない

【現行】`applyDamageToMonster` は部位ごとに破壊・切断・怯みを管理する。ガルドロスの脚は左右それぞれではなく、前脚の左右を一部位、後脚の左右を一部位としている。この管理単位を知らず、左脚だけを独立破壊できる見た目へ変更しない。

【Kari 仮設計】当たった場所、反応、次の狙いが一致することを優先する。小さな怯みは頭・肩・胴の局所反応、転倒は支持を失う動き、破壊は欠けた器官が残る変化、切断は尾先消失と有効範囲の変化とする。破壊のたびに全身を同じ倒れ方へしない。尾の短縮技への置換は既存 `ifSevered` を利用する。

転倒方向を描画側の横速度だけで決めず、命中部位・左右・倒れる余地から固定 tick で決めて保持する。倒れ始め、倒れた姿勢、もがき、脚を置き直す、立ち上がる、戦闘再開を接続する。通常打撃、破壊、切断、状態異常が重なった場合の優先と持続を明文化し、単に `staggerTicks` が長い方を選ぶ処理から整理する。死亡・捕獲は終端として優先し、捕獲後の起床や死亡後の咆哮を防ぐ。

`monsterShapes` は現在、転倒に応じた `follow` を選ばない。**先にガルドロスと代表一種で、転倒・起き上がりの頭と脚に実際に攻撃が届くことを直す。** `FollowTable` を状態・左右・切断の別へ拡張し、描画姿勢から事前生成した表を戦闘が読む。描画フレームごとの `Bone.matrixWorld` を判定の正本にしない。睡眠だけの静止姿勢を転倒へ流用しない。

怒りの開始は蓄積、演出は咆哮・呼吸・器官の張り、戦術は技の頻度や選択傾向として分ける。現行 `speedScale` は主に通常移動・旋回へ掛かり、技全体の再生速度を一括変更する実装ではない。怒りで技を速める場合は、姿勢だけを早送りせず、攻撃窓・移動曲線・軌道・音を同じ時間対応で進める。初回実装では既存の怒り値を維持し、旋回と判定同期が通ってから調整する。

## 6. 弱り退避・追跡・休眠を狩りの判断へつなぐ

【Kari 仮設計】弱った相手を見て、追うか、回復・研磨・罠の準備をするか判断できる流れにする。`isWeak` は捕獲閾値に基づく合図、`roam.limping` はフィールド側の退避判断であり、元から別条件である。両者をまとめた疲労フラグにせず、捕獲を知らせる合図と、退避準備の合図を仕様上区別する。

以前の利用者指示で採用済みの「離脱中は追いつかれない速さ」は保持する。低速で無抵抗に逃げ続ける状態へ戻さない。重い陸上種は短い足取りの崩れと後方確認、必要なら一度の牽制を見せて高速離脱へつなぐ。速度に合う非対称の歩様を作り、ゆっくりした足だけを高速で滑らせない。飛行可能種は離陸準備から専用経路へ移る。牽制を無限再抽選して永久に退避できない条件にしない。

現在 `stepRoam` は、巣で戦っていても滞在時間が尽きればその場で睡眠へ入れる。寝床到着、直近の攻撃・脅威の有無、寝入り動作の終了を条件に加える。寝床へ入れない時は再配置か戦闘へ戻り、岩の中で睡眠しない。攻撃で起きる既存処理と巣での回復は保持する。状態異常の睡眠、自然休眠、捕獲完了は別状態のままとする。

追跡先で、歩いている個体・寝入り中の個体・眠った個体を見分けられるようにする。捕獲成立、討伐、切断部位、剥ぎ取り、部位報酬を同じ「倒した」フラグへ統合せず、既存の帰還・報酬へ一度だけ接続する。

## 7. 幼体：逃げる個体と攻撃的な個体を両立

【現行】コルドピルにも被攻撃時の反撃があり、近づかれた際の通常反応は逃走優先である。【Kari 仮設計】`HerdMember` に出現時確定の `temperament` を追加し、同じ個体が一撃ごとに性格を引き直す状態を避ける。未取り込みの[PR16](https://github.com/kamamon/Kari/pull/16)に同じ利用者要望の統合差分があるため、同案の「臆病・慎重・攻撃的」の3性格へ統一する。二値の別フィールドや別の交戦枠を重ねて実装しない。PR16は設計時点でdraft・未マージであり、現行実装済みとは扱わない。

| 性格 | 近づいた時 | 攻撃された時・退路を失った時 |
|---|---|---|
| 臆病・逃走寄り | 顔を上げて警戒し、距離が詰まれば群れ側へ逃げる | 逃走を優先するが、追い詰められると短く反撃して退路を作る |
| 慎重・警戒寄り | 停止・向き直りで警戒し、密着が続くと短く応じる | 被弾や退路封鎖には反撃するが、短い交戦で距離を戻す |
| 攻撃的 | 一度威嚇し、縄張り内へ踏み込まれると短い攻撃へ移る | 限定した回数の反撃・追撃を行い、範囲外や弱りで引く |

群れ内に3性格を配置できるようにし、比率は種と依頼の Kari データにする。PR16の専用割当と交戦枠を出発点にし、大型 AI の乱数列を変えない。PR16で未実施の専用ポーズ・音・実機での見分け方を、この2G動作改修で追加する。仲間の警報を受けても、現在のように全個体を一律 `flee` へせず、性格に応じて警戒・牽制・退避へ変換する。

大型戦に小型が加わる場面では、群れ内の同時攻撃枠と待機順を設け、背後から全員が同時攻撃する密度を抑える。枠待ちの個体は距離を取って威嚇・移動し、無敵の棒立ちにしない。小型の攻撃予兆にも音と向きがあり、画面外から突然判定だけが届かないことを確認する。

## 8. Claude の実装順序と完了条件

1. **M1：ガルドロス一体。** 向き直り、方向確定、突進制動を追加。既存技 ID、HP、報酬、級倍率は保持して差分を切り分ける。
2. **M2：部位の同期。** ガルドロスの追従、転倒と起き上がり、切断後を実装。生存中の見た目と判定のずれを優先する。
3. **M3：退避と幼体。** 高速離脱を保った接続、寝床条件、個体性格、警報と攻撃枠を入れる。
4. **M4：骨格ごとの展開。** セルヴァルク、二足有翼、長胴、小型の順で調整し、各系統が通ってから残りへ展開する。

確認は正面・横・背面、通常・怒り・弱り、壁際・狭所・段差で行う。方向確定後に横切っても軸が吸いつかないこと、空振り後に反撃可能な部位が残ること、転倒した頭に命中すること、切断済み尾先の判定が消えることを可視化して記録する。同一シードと入力で選択技・確定方向・性格・終端結果が再現することも確認する。

調整票には「現行値／変更値／狙う体感／観察結果」を残す。時間・角度・速度・確率には【Kari 仮設計】を付け、同時に全部を変えない。まず姿勢と判定、次に旋回と方向確定、その後に後隙と頻度を調整する。iPhone 通常カメラで予兆が読め、横へ避けた理由と被弾した理由を説明できることを最終の目安とする。

Claude の返答には変更ファイル、実装済みの項目、代表場面の録画、検証結果、残件を記載する。「参考資料として受領」「候補として記録」だけでは今回の完了にならない。未対応の骨格や飛行は残件として明記し、実装済みと混同しない。
