## GitHub内に届けたもの

- family-map.json：11系統のID・オリジナルスターター・保存互換・モデルと動作の想定パス。
- new-classes-action-kit.json：**追加4系統の26アクション案**。Kari専用の初期攻撃係数・独自の6姿勢キー・効果イベント。ゲームのActionDefをそのまま置換する完成JSONではない。
- icons/*.svg：**オリジナルのUIアイコン11点**。SVGのまま利用できるが、原画の高品質PNGとは別物。
- asset-catalog.json：原画PNG・GLBモデル・GIF・モーションJSONの別ZIPとSHA照合情報。
- INTEGRATION_HANDOFF.md：Claude向けの各系統の操作・リグ・UI・セーブ・弾倉・音符・冷却の実装要件。
- QA.md：確かめたこと／守れなかった決まり／未検証の記録。

## 実際に生成した別ZIP

ユーザーへ渡した Kari_2G_11_Weapons_Package.zip には**武器原画透明PNG11枚、GLBモデル試作15点（11武器＋左手4）、全11種類の提案モーションJSON11ファイル・54動作案、動作ラフGIF4本、PBR参考画像9点、一覧PNG1枚、再生成スクリプト・元原画**を同梱した。

**GitHubコネクタ経由でPNG・GLB・GIFのバイナリ本体をPRへ上げられなかった。** このPRにはSVGアイコンとJSON・ドキュメントのみを登録してある。取り込み担当のClaudeはユーザーからZIP実ファイルを受け取ってから採用し、asset-catalog.jsonのSHA-256を確認すること。

原画は3DのUVテクスチャではない。GLBは簡易メッシュでありスキニング・ゲームリグ・装備別形状は未完成。GIFは動作方針を視覚化したラフであり、ゲームに読み込めるアニメーションクリップではない。モーションのtick・威力は**本ゲーム用の初期設計値**であって2G実映像からの測定値ではない。

- 武器11種: https://mh.mtwildwood.net/ja/mhfu/weapons/
- 狩猟笛: https://w.atwiki.jp/mhp2g/pages/152.html

**守れなかった決まり**：高品質PNG・GLBバイナリのGitHub格納、src/publicへ組込み、ゲーム全体のビルド・実機操作までの受入は行っていない。
**迷って決めたこと**：既存7内部IDを保護、追加4を独立IDにした。武器種は2Gと同じ11種類にするが意匠・技数値は写さない。
**検証済み**：ローカルZIPで11PNG・15GLB・11JSON（合計54動作案）・4GIFの生成とファイル読込を確認。
**未検証**：3D装備時の骨／武器の動き、アイコン採用、iPhoneの操作、砲撃・演奏・弾薬のゲーム実行、原作2G映像のフレーム比較、モーションの最終的な難易度。
