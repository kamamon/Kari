# Claudeに渡す導入契約（11系統）

本件は「素材生成と導入案」であり、ゲーム本体へ反映済みではない。AGENTS.mdに従い src/public はChatGPTから変更しない。

## 取り込み順

1. 11武器種：既存 heavy_blade, long_blade, guard_blade, twin_blades, war_maul, long_lance, ring_bow のIDを保ち、新規 hunting_horn, gunlance, light_bowgun, heavy_bowgun の4種類を加える。
2. 武器データ：public/data/weapons.json の families と weapons に各種のスターター、モデル参照、系統を定義。工房・装備選択・所持品・一覧・セーブ復旧から使えるようにする。画面は11の種類名を表示。
3. 武器モデル：src/render/rig.ts の WEAPON_BUILDERS と各左手装備に登録。ZIPのmodels/GLBを簡易なブロックアウトとして確認し、正式モデルにする際は原画を基にUV・マテリアル・メッシュを制作する。+Yが武器先端（ボウガンは+Z銃口）、右手側は-X。盾と左刃と銃口は固有ソケットを持つ。
4. 動作：new-classes-action-kit.json の26個は厳密なKari ActionDefではないため変換して tools/gen-weapons.mjs 系の生成を通す。ZIP内の全11種54動作JSONは参考用。移動はゲーム側controllerを正本とし、手と武器を接触し続け、当たり時刻・弾の射出・ヒットストップを一致させる。
5. 遊べる状態：新4系統の操作状態と音・エフェクト・リソース消費・入力の打ち切り・持ち替え・セーブ保存を追加する。初期係数は原作データのコピーではなくKari専用の調整候補。
6. テスト：全11種の装備表示、各武器の主副特殊、弾切れ・演奏状態・砲撃中断・残弾と演奏効果、既存7種のセーブ互換。npm ci、npm run check、npm run smoke、iPhone横画面・タッチを実機検証。

## 新4種類のプレイ機構

**狩猟笛**：打撃（左右のぶん回し／つか殴り／大叩き）と演奏状態を切り替える。3種類の音を入力で奏で、組み合わせによりパーティ向け時限バフを発動。演奏中の行動制限と中断、バフ期限を作る。古典的な演奏モードを守り後年の音符システムを機械的に流用しない。

**ガンランス**：主の前方突き、副の砲撃（弾倉消費）、複合の斬り上げ、ガード中のリロード、独立した大技（竜撃砲）と冷却。前進・ガード・後ステップは槍と盾を持って行う。砲撃の反動と弾射出を同じtickへ置く。残弾負数を防止。リロード途中の中断時に弾が不正に増えない。

**ライトボウガン**：照準、通常射撃、対応弾の速射、弾倉からの発射、装填、軽い回避。速射は複数弾が飛ぶが弾の消費ルールは武器・弾種とセットで定義し、打点を多重計上しない。通常弾・貫通・散弾・状態異常などの対応可能弾リストを武器個別に持つ。

**ヘビィボウガン**：照準・重い射撃・大きい反動・遅い装填・重い回避。補助に銃身か盾の選択を用意し、初期段階で「しゃがみ撃ち」は導入しない（2Gの標準技ではない）。下半身が衝撃を受け止める姿勢を制作する。

## 安全な受け入れ条件

- 本体が暗黙に「新系統は大剣モデルを表示」する代用で完成したことにしない。
- モデル15点をGLBとして表示し、腕・盾・先端・銃口の位置と向きを目視確認する。
- 同じ攻撃の複数接触や速射の発射を正しく処理し、フレームレートにより結果が変わらない。
- 狩猟笛の演奏は効果発生、期限、中断まで。ガンランスの残弾と熱は保存・ロードを含む。
- 攻撃力・素材レシピは現行ゲームの難易度と実測プレイに合わせて調整。既存7武器の攻撃力を今回の参考係数で無断変更しない。
- 2Gのモーションを直接コピーしていないため、原作との動作一致は別途の実映像観察が必要。
