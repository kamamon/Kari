# 灯継ぎの里・外周景観のゲーム本体変更（2026-11-27）
ユーザーから「ゲーム本体の変更もしてください」と明示されたため、従来の提出資料のみの分担から、この依頼に限って実装差分を専用ブランチに作成しました。main の直接変更・公開は行いません。原画の資料は PR #24。

## 変更
- `src/render/hubOutskirts.ts`: 全周の連続地形、固定seedの杉林と紅葉、山腹の木造建物・見張り台・作業桟道、温泉候補、既存の沢からつながる上下流の滝、暖色の窓と灯を描画。地形面は拠点矩形の外側に限定し、門の斜面と沢の筋を予約する。
- `src/render/villageScene.ts`: ゲーム本体の拠点描画の一部として上記を追加し、川の流れと湯気を更新。既存の山の岩、水車、施設を残す。
- `src/render/arena.ts`: 里だけ霧を調整し、狩場の光や霧は変えない。
- `tests/hub-outskirts.test.ts`: 全周、内側面なし、正本不変、決定性、描画数、既存水車、外周水面の更新を検査するテスト。

## 仕様上の判断
追加物はすべて見た目のみ。新しい探索先や入浴の操作、物理判定、保存項目は増やさない。生成原画と同一の建築の完全なモデル化ではなく、既存アート素材を使う3D試作。遊べる5段の地形や7施設、4人のNPCを変更しない。
