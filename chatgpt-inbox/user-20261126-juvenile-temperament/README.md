# 幼体の個体差 — 設計と統合用差分

作成日: 2026-11-26（日本時間）  
利用者の直接の指示: 「幼体が逃げる一択。逃げる個体もいれば攻撃的な個体もいる。」

同じ種・同じ群れの中に、**臆病・慎重・攻撃的**な個体を混在させます。臆病な個体は逃げ、慎重な個体は警戒し、攻撃的な個体は向き直って予告した後、自分から攻撃します。性格は生成時に固定し、刺激のたびには再抽選しません。

仲間の警報は一律の逃走命令にせず、個体が判断する危険情報に変えます。攻撃的な個体でも瀕死なら退避し、交戦の長さと追跡距離に上限を設けます。

## 2. 迷って決めたこと・守れなかった決まり

守れなかったリポジトリ規則はありません。GitHubへ追加するのはこのフォルダ内だけで、mainへの直接書込みや本体の改変は行いません。実装案はリポジトリとは別の検証用コピーで作成し、patchとして返しています。モンスター登録簿のJSONは作成していないため、bestiary importerの対象はありません。

次の点は利用者の指定を具体化するための**新しい初期案**です。

| 項目 | 統合用差分の値・判断 |
| --- | --- |
| 性格の目安 | 4頭で臆病1・慎重2・攻撃的1。2頭は臆病＋攻撃的、3頭は各1。4枠周期で繰り返す |
| 割当の再現 | 群れ乱数のstateを読み、専用ハッシュで先頭2枠の順番を入れ替える。性格のための乱数消費は追加しない |
| 攻撃的な個体の先制 | 狩人が `min(fleeRange, 6m)` 以内に30tick続けていると交戦。30tickは通常更新で約0.5秒 |
| 慎重な個体の密着反撃 | 距離 `min(fleeRange × 0.45, 個体半径＋狩人半径＋1.3m)` 以内に45tick続けていると交戦。通常更新で約0.75秒 |
| 威嚇の意味 | 既存の `alert` による停止・向き直りの予告。専用のポーズ・鳴き声は未実装 |
| 被弾反撃 | 慎重・攻撃的は反撃意思を持つ。臆病は基本逃走、疲労中の被弾や壁際では反撃を試みる |
| 退避する体力 | 最大HPの30%以下。性格、被弾、壁際の反撃より優先 |
| 同じ群れの交戦数 | 原則1頭。死亡・捕獲・怯み・罠・麻痺・睡眠・気絶で枠を解放。ヒットストップ中は維持 |
| 一回の交戦 | 既存 `fightTicks` の抽選値と360tickの小さい方まで。最大で攻撃的2技、他1技 |
| 追跡終了 | 交戦開始点から8mを超える、または狩人との距離が10mを超える場合、新しい技を始めない |
| 再交戦 | 180tick待つ。再被弾で待ち時間を飛ばさない |
| 旧 `fightChance` | 既存JSON/スキーマの互換性のため残すが、新しい判断では使わない。削除や生成器の整理は後続 |

時間・距離・技数は**次の技を始める条件**です。実行中の技は本来の怯み等を除き最後まで完了してから退くため、最後の技の移動で上限時間や距離を越える瞬間はあり得ます。ヒットストップや行動不能で群れAI更新が止まる間はタイマーも止まります。常に壁時計で6秒・3秒という意味ではありません。

初期段階は8種共通の性格配分です。モデル、骨格、技の定義、攻撃窓、威力は変更していません。専用ポーズの前に、既存の警戒・逃走・攻撃で行動差を成立させます。

## 4. 確かめていないこと

- ブラウザ・iPhoneでの視認性、操作感、実測性能、適切な威嚇時間や難易度。
- リポジトリ全体のテスト、完全なアセットを含めたbuildとsmoke。今回の検証は上記の関連範囲。
- 複数の群れと大型が集まる時の、場全体の同時攻撃数。この差分の上限は一群につき一頭。
- 新しい性格専用の頭・胴のポーズ、鳴き声、仲間を守る割り込み、仲間や親の死亡による恐怖反応。
- 遮蔽物の視線判定。今回も現行と同じ平面距離による判断。

## 5. Claudeへの取り込み依頼

1. 基準コミットとの差を確認し、別の作業ブランチでpatchの適用を確認する。mainへ自動で当てるスクリプトは付けていません。
2. patchを適用し、既存のフル検証とbuildを実行する。現在の内容と衝突した場合は、性格判断・交戦枠・状態の指紋・テストを一緒に移す。
3. ブラウザとiPhoneで、逃げる個体と攻撃する個体が同じ群れの中で見分けられることを確認する。まず臆病・慎重・攻撃的が各一頭いる群れを使う。
4. 種ごとの配分、予告時間、交戦数や待ち時間を調整する。専用ポーズは行動の違いを確認してから追加する。
5. 採用時に仕様・決定事項・掲示板へ反映し、この資料を正式な保存先へ移す。
