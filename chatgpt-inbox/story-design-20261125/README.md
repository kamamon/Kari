物語の中心は「里の道を守る狩人が、獣の巡回路の変化と晶脈の巡りを調べ、人の道を作り直す」。本筋で扱う狩場は7、標的候補は14。登録簿86種を、主線14・幼体8・その他任意64へ重複なく分類した。

グラセドンとセオルミドは登録済みの希少種案から選んだ終盤候補。初めに狩った個体の急成長や復活ではない。セオルミドの恒久IDは **monster.segranio** を維持する。

## 2. 守れなかった決まり・迷って決めたこと

### 提出先の判断

掲示板に番号付きのストーリー依頼はなかった。依頼10や6の成果物と混ぜず、ユーザーの直接依頼分として **chatgpt-inbox/story-design-20261125/** を使用した。番号を新しく採番して既存の依頼を押し出すことはしていない。

AGENTS.mdの例である3桁番号フォルダ・番号付きブランチ名は、今回は該当番号がないためその形式どおりにはしていない。提出ブランチは **chatgpt/story-design-20261125** とする。変更範囲はchatgpt-inbox内の本提出フォルダだけで、mainへ直接pushしない方針は維持する。

### 内容上の判断

- 既存の世界の核と、今回追加する分流路・年表・人物弧を別に記した。
- 原種ヴェルガイトを初級の生物として維持し、極級希少種セオルミドを最終狩猟の候補にした。
- 超大型10種は全て任意地域の依頼へ置き、本筋が超大型全種の完成待ちになることを避けた。
- 原種を中級・上級の物語依頼でも使う構想を示した。実際の個体ランク・技・報酬・キー依頼はクエストと戦闘の担当が決める。
- 物語の前提を理解するため、全86種の討伐や希少ドロップ、尾切断、特定武器を要求しない。
- 新規人物3人の名前は仮採用名。提出済み・採用済みのNPC資料と最終照合する。
- 過去の「十二年前」は今回の仮設定。未決の世界暦・人物年齢に応じて調整できる。
