# モンスター骨格設計 v2 の実行前差分監査

確認日: 2026-11-25。対象: `kamamon/Kari` main v0.26.0、commit `1e078bfce1e68f287ae577cf41d2fe5bafb94afa`。読み取りのみ。ここに記載する行番号はこのcommitのもの。

## 結論

前回の43ページ版はv0.22.0を基準としており、現在は3つの主要な改善がv0.25.0で入っている。旧原本はその時点の設計として保存し、今回の提出にはこの差分を添えて、実装済みの仕事を再発注しない。ガルドロス79ノード案、正式GLB、個別の趾・翼関節、硬殻と皮膚の分離、LODなどは未実装の制作提案として残る。

## 残る対象と優先順

1. **ガルドロスの安定した骨名・部位の対応表を確立する。** 現在は53骨で、Bone.nameは設定されていない（`src/render/galdrosRig.ts` 26–28、443–454）。一般リグもBone.name未設定（`src/render/creatureRig.ts` 272–278）。mesh名があることと、骨名があることを混同しない。
2. **79ノード案を制作リグとして組み、スキニングを成立させる。** 新しい骨を増やすだけでは趾・胸郭・肩の面は変形しない。旧53ノードの位置を維持したうえで、局所軸、bind matrix、ウェイト、可動域と補正形状を検証する。
3. **ガルドロスの被攻撃部位追従を追加する。** 現在のfollow表の生成はCREATURE_PLANS専用で、GaldrosRigは対象外。`tests/follow.test.ts` 29でガルドロスのfollow無しを明示している。ガルドロスの専用描画軌道を、固定tickで再現できる生成/ベイク経路へ取り込む必要がある。
4. **転倒・怯み・切断後の追従を広げる。** 現行`monsterShapes()`は技と睡眠のみで、倒れる向きや怯み状態の分岐がない。切断後形状は`!severed`条件のため追従表を使わない（monster.ts158）。描画側で決める転倒方向を戦闘側の確定した状態へ移す/共有する契約が先に要る。
5. **趾・翼・多脚・長胴の個別接触を制作する。** 一般趾と爪は今も脚末端の骨1本へ100%付く（creatureRig.ts582–609）。短翼の作動もown翼骨単位（同1870–1873）。四足/二足以外の足の接地保持は対象外（同1648–1652）。これらに旧改善の完了範囲を広げて解釈しない。
6. **正式GLBと材質、LOD、実機確認へ進む。** 原画の採用待ち状態を変更せず、採用済みガルドロスを基準に通す。ゲーム全長約5.8m（galdrosRig.ts33–34）を、図鑑全長へ無断拡大しない。

## 79ノード化で具体的に注意すること

- 現在のガルドロスは骨番号の定数に依存し、脚を`LEG + i * 4`、岩板を`PLATE + i`で参照する（galdrosRig.ts27、405–409、437–440、457–459）。JSONの配列順をそのまま既存番号と扱わない。
- 現行構築ループは親が先に存在する前提（同443–450）。旧番号を維持して末尾へ肩甲骨を追加し、その新しい肩甲骨を既存上腕の親にすると、その前提が崩れる。全Bone生成→親子接続の2段階、または明示的index移行が必要。
- 親を変更しても、基準姿勢のactor-space座標は保持する。actor座標差を回転済み骨のlocal offsetへ直接入れず、親のbind逆行列で変換する。
- 胸郭左右分離では、現行`B[RIBS].scale`（同1466）と体幹のウェイトを連動して置き換える。名前の追加だけで呼吸が左右へ分かれるとはしない。
- けづめはwrist、前向き4趾はpalmへ。twist補助骨はIKの主鎖へ挿入せず枝として扱う。後脚3制御群と実趾数を分ける。
- 尾切断は現行CUT=4（同35）、TAIL_Z[4]=-2.22（同31）。切断後に残るtail_04側へ切断面socketを置く設計を保つ。消えるtail_05側に切断後の判定を残さない。
- 骨追加/ウェイト変更は既存メッシュのAO・UV・アトラスと同期が必要。AOはメッシュ生成時に適用される（同723–729）。頂点数変更後の焼き直しは既存handoffの手順に従う。
- 既存の一般部位追従は固定tick表が正本で、描画のフレームdtや視線に左右されない。新しいsocket追従を導入しても、戦闘が表示フレーム数で変わる設計へ逆戻りさせない。
- 現在の接地検査は四足・二足10種の直進5秒の水平滑りを対象（creature-motion.test.ts438–488）。全種の旋回、攻撃、転倒、斜面、実機性能まで合格したことにはならない。
