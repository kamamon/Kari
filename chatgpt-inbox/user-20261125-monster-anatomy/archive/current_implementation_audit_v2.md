# Kari v0.22.0 モンスター実装監査（設計の根拠）

- 基準: `4851d57ecc24c8fd127508b084999cec5d0e975f`、2026-11-25 の main 作業コピー。
- 読み取り専用。AGENTS.md / docs/chatgpt-board.md を確認。リポジトリのコード・データ・設定を変更していない。
- 実施: ソース読解、生成済み CreaturePlan の JSON を Python で読み取った集計。ブラウザ描画、実機、アニメーション映像の検収はしていない。

## 1. 重要な結論

1. **現在も単純な箱だけではない。** ガルドロスは 53 骨の専用 SkinnedMesh リグ、追加 11 大型+8 幼体も 19〜50 骨の SkinnedMesh。改善は「骨を導入」ではなく、既存骨の役割・独立関節・接地制約・表面構造を完成させること。
2. **一般リグの顎チャンネルは未接続。** `Pose.jaw` を咀嚼・罠・転倒等で更新しても、顎骨を作らず、`apply()` も適用しない。ガルドロスの顎は実装済み。種ごとに「開かない口を回す」のではなく、頭蓋+下顎+口腔を独立造形する必要がある。
3. **一般リグの足は world-space の接地点を保持しない。** 移動距離から位相を進めて sin/cos で付け根・膝を振る。足滑りの構造的原因候補。横たわりの地面侵入回避はあるが、通常歩行の接地IKとは異なる。
4. **翼は片側 1 骨に板全体が付く。** 翼肩・肘・手首・翼指/羽列がないので、折り畳み/打ち下ろし/翼端遅れを独立して表現できない。
5. **足指の外観追加は実装済みだが、動きは全指が足先 1 骨に固定。** つま先の踏切・鳥の指の把持・蹄の左右分配を別段階として設計すべき。
6. **攻撃を与える判定と、攻撃を受ける部位は進捗が異なる。** 173 本の攻撃軌道はリグの部位マーカーからオフライン生成する仕組みがある。一方、被攻撃部位は root の位置+yaw だけで変換され、顎・首・翼・尾の描画姿勢を追わない。
7. **前回指摘の 3 項目は修正済み。** チルミカナの幼燐節=2、ユルテピカの紡糸管=2、キリサーヴの fin0/fin1 は左右計 4 可動骨。再び「欠落」を修正依頼にしない。

## 4. ガルドロスは再利用できる基礎がある

- `galdrosRig.ts` 27〜40: BONES=38+15=53。尾8節、岩板15、jaw/tongue/左右lid、脚各4骨。
- 既存全長は約5.8m、鼻先z=2.64、晶の先z=-3.2というコメントを持つ。設計で大きさを変更する場合は既存当たり・カメラも影響する。
- 369〜408: BODY→腰/胸→頸→頭の親子。前脚付け根はCHESTに直接、後脚はPELVISに直接。独立肩甲骨や上腕/前腕のねじり補助骨はまだない。
- 391〜401: 前脚は .76+.70m、後脚は .72+.66m の2節。前肘は後ろ・後膝は前へ向くpole vectorあり。
- 413〜440: 殻15枚には一枚ずつ独立骨。背6・頭2・肩3・腰2・前脚甲2。殻を皮膚と同じように曲げない基盤は既にある。
- 1473: JAW.rotation.xへjawチャンネルを適用するので、一般リグの未接続とは状況が違う。
- 1515〜1636: 接地点plantを保持し、予測着地位置、2節IK、足裏水平、つま先反り、弱化した左後脚の引きずり、着地効果がある。
- 通常の踏み替えは対角ペア（1570付近）。常に静的3脚支持する重歩行ではない。重獣の低速歩行をさらに重く見せるなら、低速4拍/高速対角/疾走の別歩容が必要という設計提案になる。
- groundは `m.pos.y`（909行）。サンプリングした地形法線や左右足ごとの高さではない。現状フィールドは基本平面なので既存不具合と断言せず、将来段差対応の要件とする。

## 5. 設計へ反映すべき優先順

### P0: 身体と判定の一貫性

顎の独立メッシュ+ヒンジ、接地アンカー、world rootと局所poseの契約、被攻撃部位の骨アンカー、攻撃軌道再ベイクと同期検証。視線/呼吸/二次揺れで主攻撃点が大きく動く場合は、戦闘用姿勢へ入れるか描画加算の振幅を制限する。

### P1: 骨の増やし方

四足の肩甲帯+足指、二足翼の肩/肘/手首/翼指または羽列、多脚の各脚接地群、長胴の腹面接触パッチ。形が違うだけの共通「筒」から、支持構造を持つ体型別リグへ移す。骨数の目標だけで完成判定しない。

### P2: 表面と破壊

肌・硬殻・膜・湿潤組織を材質/変形方式で分ける。原画の明暗をbumpに兼用する仕組みは、描かれた陰影まで凹凸になる可能性があるので、専用normal/roughnessへ移す。ただし今回の監査では照明下の見え方を確認していない。破壊は暗色縮小から、殻片の差替え・継ぎ目・断面・器官機能の変化を具体化する。
