## 分担と検証
通常はAGENTS.mdに従いinboxだけを変更する。今回は利用者から本体反映・公開の明示指示があるため、例外として専用ブランチの本体3ファイル・smokeを更新し、PR経由とする。mainへの直接push・gh-pagesへの直接書き込みはしない。既存のGitHub Actionsの型検査・テスト・ビルド・公開経路を使う。並行開発との競合を避けるためバージョン番号は変更しない。
ローカルはGitHubの名前解決ができず完全なcloneとnpm ciは実施できない。今回の変更を実機やブラウザで確認済みとは扱わない。PRのCI結果を確認し、公開後のgh-pagesの状態を確認する。
