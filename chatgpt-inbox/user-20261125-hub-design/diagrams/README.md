以前の SVG・生成スクリプトは今回の復旧時に確認できなかったため、編集用 SVG は原本 PNG の数値・構成・設計意図を基に作り直しています。**旧 SVG の同一バイト復元や、PNG とのピクセル単位の一致を示すものではありません。** 文字、経路、建物、段丘は SVG のベクター要素で、PNG を貼り込んだ画像ではありません。

配置の大幅な変更は行っていません。編集用平面図では水系の流下方向を矢印でも示しています。完成済み PDF の「SVG 原本も同梱」という記述は、今回の提出では上記の**編集用再構成版 SVG**に読み替えてください。PNG 原本と PDF の画像内容は変更していません。

## 数値と経路の読み方

| 段 | 中央広場を基準とする相対標高 | 主な役割 |
| --- | ---: | --- |
| 水音の庭 | −10 m | 沢、水車 1 基、荷揚げ、水辺の仕事 |
| 炉の段 | −3 m | 工房、資材、半屋外の作業 |
| 灯の広場 | 0 m | 依頼板、商店、装備箱、帰還・出発 |
| 暮らしの段 | ＋8 m | 狩人の宿、民家、縁側 |
| 灯見の台 | ＋22 m | 集会所、調査、見張り灯、眺望 |

歩行床の最高段と最低段の差は **32 m** です。海抜ではなく設計上の相対値で、屋根・塔・遠景の高さは含みません。

- 平面図の約 120 × 110 m と約 20 m の目盛りは、投影範囲を理解するための概念値です。経路長、階段数、当たり、坂の勾配をこの線から確定しません。
- 茶色の実線は主な準備動線です。依頼板・商店・装備箱は中段 0 m、工房は隣接する −3 m の段に置きます。すべての施設への「一覧」アクセスも維持します。
- 茶色の破線は生活の道、青緑の破線は見晴らしの道と水辺からの戻り道です。上層・下層へ散策した後、中段へ戻れる回遊を示します。
- 沢は北・山側から南・谷側へ流下する想定です。清水・作業用水・排水を分ける詳細は設計本文で扱います。
- 断面図は**高さ方向だけを統一**しています。12 px = 1 m とし、人物の目安は 1.75 m です。水平距離と坂の描画は模式表現です。施設は同じ断面へ投影しており、実際の建物の一直線配置を意味しません。
- 坂・階段は平面方向にも折り返します。主経路幅 3.5〜4 m、常用階段幅 2.5〜3 m、踊り場幅 4.5 m、橋幅約 2.8 m は試作値です。橋の上と下を同じ XZ で歩く多層床は P2 の検討項目です。

## 検証と優先関係

編集用 SVG は日本語フォント `Noto Sans CJK JP` / `Noto Sans JP` を想定しています。フォントのない環境では代替フォントで字幅が変わる場合があります。文字をアウトライン化していないため編集できます。

両 SVG は XML として読み込めること、埋め込み画像要素がないこと、Inkscape で PNG へ描画できることを確認しました。再描画した図を目視し、五段の名称・標高、平面図の施設番号 1〜9、経路の接続、断面の 32 m 表記と注記、文字の欠落・重なり・画面外へのはみ出しを確認しています。

ゲーム上の到達性、足の接地、上下階の施設誤操作、カメラ、NPC の移動、橋の上下通行、実機性能は未検証です。原画の見た目の細部より、設計本文・この図の標高と接続関係を優先します。既存機能や最新の実装状態については [v0.26 追補](../latest_state_addendum_v026.md) を参照してください。
