## 1. 高さを移動と感覚の変化にする

灯継ぎの里は、歩ける床の最低−10mから最高+22mまで、32mの高低差を持つ五段の集落として提案する。同じ里を異なる高さから繰り返し見られることが体験の軸になる。

中央広場では下段の炉、石段の途中、人の住む上段の縁側が一緒に見える。踊り場で振り返ると、少し前まで自分の目線の高さにあった屋根と灯が下へ移る。最高段では里の灯と霧の盆地を同じ景色へ収め、帰る場所と次の狩場を結び付ける。

日常の準備は中央0mと隣接する工房−3mに集約する。上層や水辺は眺望と生活を知る散策先とし、受注のたびに32mを往復する条件にはしない。装備箱・商店・工房・依頼板の利用、「一覧」からの直接利用は保つ。

## 2. 四つの視点

| 視点 | 見せたい景色 | 遊ぶ人の行動 |
| --- | --- | --- |
| 帰還口 | 岩と軒の向こうに里の灯、工房の煙、仕事の気配 | 帰還直後に装備箱と進行方向を理解する |
| 中段広場 | 手前の施設、下段の作業、上段の縁側の重なり | 次の準備を進めながら里の中心を感じる |
| 坂の踊り場 | 先ほど通った屋根と灯を眼下に望む | 立ち止まり、振り返り、見回す |
| 最上段 | 里の灯と霧の盆地を同じ画面に収める | 歩いてきた道と次の冒険を見比べる |

これらは演出確認用の視点で、カメラの強制固定を意味しない。見回す余白を踊り場や施設前へ設け、普段の操作を続けながら景色が変わる構成を試す。

## 3. 回遊しながら生活を知る

**生活の道**は、広い石段と折り返し坂で工房、水辺、広場をつなぐ。荷物を運べる経路、置き場、作業の向きを見せる。次の踊り場や灯が一つ先まで見えるようにし、目的地の見当がつく歩行体験にする。

**見晴らしの道**は、住居の縁側、岩棚の回廊、短い吊り橋を経て別の道で中段へ戻る。屋根越しに同じ広場が見え、上ることと戻ることの両方に景色の変化がある。初期は床のXZ重複を避け、橋の上下を両方歩く体験はP2の対応後に追加する。

原画の橋、階段、建物が見えているだけでは通行できることの証明にならない。各段への往復、踏み外し、カメラの振る舞いは、実際の地形で確認する。

## 4. 音・光・材質を用途に結び付ける

| 場所 | 生活音の候補 | 光と材質 | 用途として伝えること |
| --- | --- | --- | --- |
| 水音の庭 −10m | 沢、滑車、濡れた板の軋み | 水の反射、苔、湿った石 | 水と物資の入口 |
| 炉の段 −3m | 槌、炉、道具の持ち替え | 炉の暖色、煤、手入れされた金床 | 狩りを支える仕事 |
| 灯の広場 0m | 短い呼び声、足音、食器 | 天幕の影、摩耗した石、低い灯 | 人と用事の集まる場所 |
| 暮らしの段 +8m | 布、窓辺の会話、調理 | 継ぎ当て、手すりの艶、窓明かり | 人が帰って暮らす場所 |
| 灯見の台 +22m | 風、遠い鐘、下の里の音 | 広い空、霧、風除けの中の灯 | 見晴らしと調査の場所 |

軒下では風を弱め、曲がり角を越えると広場の音が届く。BGMは生活音を覆わない密度に調整する。音源、同時再生数、距離減衰、実装方法は未確定であり、完成した音響設計や性能保証ではない。

石は擁壁と基礎、木は梁・柱・手すり・橋、布は日よけと一部の屋根に使う。補修跡、継ぎ目、摩耗は用途のある場所へ置く。強い発光を多数の建物へ広げず、里の灯と仕事の光が位置を知らせるようにする。素材の基準は[採用アートボードv2](https://github.com/kamamon/Kari/blob/4851d57ecc24c8fd127508b084999cec5d0e975f/art-source/board/style_board_v2.png)と[景観依頼8](https://github.com/kamamon/Kari/blob/4851d57ecc24c8fd127508b084999cec5d0e975f/docs/chatgpt-request-8.txt)に従う。

## 5. 水、仕事、物資のつながり

沢と小滝を低層の仕事へつなぐ。水車は製材・製粉などの用途として見せ、工房への資材は荷揚げ設備で運ぶ。清水の樋と作業用の水路を分け、洗い場や工房の排水を飲み水へ戻さない。

工房は未加工材を奥、冷却槽を側面へ置き、利用者の立つ場所と作業場所が読み取れる配置にする。煙突を住宅の布屋根直下から離し、炉の近くの屋根は石・板・瓦系にする。商店も、荷箱を置く裏側と接客する表側を分け、通行域へ商品を散らしすぎない。

これらは里が生活できる場所だと感じるための配置規則であり、資材の自動生産、プレイヤーの労働、施設維持のゲームループを追加する決定ではない。

## 6. 短い仕事に始まりと終わりをつくる

住民の動きは、用途の分かる短いまとまりを候補とする。

| 役割 | 行動のまとまりの案 |
| --- | --- |
| 鍛冶 | 作業する → 道具を持ち替える → 炉を確かめる |
| 受付 | 記録を読む → 紙を張り替える → 帰還に気付く |
| 店主 | 品を足す → 布を整える → 短く声を掛ける |
| 運び手 | 縄を締める → 荷を上げる → 荷を確かめる |
| 住居・見張り | 布を干す、薪を足す、灯を手入れする |

ミナギ・ロクハ・イサネの現在の静止表示と会話機能は既存実装として継承する。上記の生活動作、直接話しかける操作、歩行AI、立体NPCは追加制作・実装の対象であり、現時点で完成済みとは扱わない。[v0.26.0の仕様](https://github.com/kamamon/Kari/blob/1e078bfce1e68f287ae577cf41d2fe5bafb94afa/docs/spec.md#L917)

人数、会話数、巡回の有無は未確定。住民を動かす場合も通路、窓口、施設前のカメラ空間を塞がない。原画の背景人物は生活と縮尺の参考であり、採用済みNPCの確定デザインを置き換えない。

## 7. 時間帯と帰還

| 時間帯の案 | 表情 |
| --- | --- |
| 朝 | 荷の到着、清掃、作業の始まり |
| 昼 | 工房や商店の仕事、生活の賑わい |
| 夕方 | 片付け、灯の手入れ、暖かい窓 |
| 夜 | 窓明かり、静かな会話、冷たい霧 |

昼夜と天候は追加案で、時間の進行方式は未確定。窓口の担当や演出が変わっても主要施設は利用できる状態を保つ。現実時間の待機や営業時間を、狩りの準備の条件にはしない。

通常の帰還地点は灯の広場につなぐ。受付が顔を上げる、工房で仕事が続くなど、小さな反応を操作を止めずに見せる。失敗して戻ってきた場合も主要施設を閉ざさない。毎回の長い映像、強制歩行、全住民への報告を求めない。

## 9. 室内から同じ里を見る

狩人の宿では、寝床、装備棚、机、外套、使い込まれた箱を置き、窓と縁側から同じ広場と沢を見せる。外観の高低差と室内の眺めがつながり、歩いてきた位置が理解できる構成にする。

集会所は低い木造建物と開いた庇、地図机、資料、住民の席で構成し、里と狩場を眺める拠点にする。宿・室内・休憩機能は新設提案。建物の四方向の整合、室内と屋外の接続、カメラの扱いは今後の確認事項である。

## 10. 体験の受入条件と未検証事項

中段から上下の生活域が見え、上層から通った広場を見下ろせること。常用4施設と各段へジャンプなしで往復できること。階段、庇、柵、橋で視点が大きく跳ねず、主人公が見えること。住民が通行と窓口を塞がず、場所ごとの仕事が分かることを、実装後に確認する。

音、光、生活動作、昼夜、室内、景観変化は設計案の段階。iPhone/iPadの操作、視認性、描画間隔、字幕、タッチ旋回を含む実機検証は未実施。原画の雰囲気だけで、遊べる拠点の完成とは判定しない。
