## 復元と訂正

前回提出中断後、PDF原本・原画4枚・図PNG2枚を復旧し、記録済みのハッシュとの一致を確認しました。作業用Markdown、元SVG、PDF生成ソースは復旧できなかったため、設計本文はPDFから再構成し、SVGは原PNGの内容を編集可能な形へ再構成しています。失われた旧ソースの完全な複製ではありません。

PDF15ページの「SVG原本も同梱」は、このPRでは「原PNGと、再構成した編集用SVGを同梱」と読み替えてください。PDF16ページの文書一覧は内容の対応を示すもので、旧作業用ファイルの逐語的復元を保証しません。PDFの生成用HTML/PythonはこのPRには含みません。

原PDFにあるNPC・会話未実装の記述はv0.22.0時点の記録です。現在の実装状態は[最新追補](../latest_state_addendum_v026.md)に従います。五段地形・生活動作・局所音・昼夜などの新提案は引き続き未実装です。
