これはClaudeがゲーム本体へ適用した**後に**実行する項目。ここに書いたことを試験合格として報告しない。

| 場面 | 手順 | 期待結果 |
| --- | --- | --- |
| 初級 | 広場の受付を開く | まず★1/★2の縦メニュー。長いカード群が出ない |
| 別級 | 西/東/帰路の受付を開く | 対応する級の星だけ。別級の仕事は混ざらない |
| 星から一覧 | 星を選択 | その星の依頼名だけを縦表示。右に選択中の依頼書 |
| 依頼の移動 | 上下キー、D-pad、指で別の行へ | 選択枠と右の依頼内容が一致。選択だけでは出発しない |
| 一覧に戻る | 詳細から戻る、星から戻る | 1階層だけ戻る。選択行・スクロールが保たれる |
| 受付間 | ★2→里へ→中級→里へ→初級 | 各級が混ざらず、前回の初級の選択が保たれる |
| 未解放 | 上位のロックされた仕事を選ぶ | 文と解禁条件を読める。受注は押せない |
| 混成群れ | 盆地の若い群れを選ぶ | コルドピル×2とパルセイト×3を正しい画像と頭数で表示 |
| 素材仕事 | 採集・採掘・現地納品を選ぶ | モンスターの仮アイコンを出さず、種類と目標を表示 |
| 里納品 | D09の所持が16個／15個の場合を確認 | 16個のときのみ2個渡せる。納品後14個残り、二重納品不可 |
| 契約確認 | 通常依頼を選び「受注」を押す | 受注確認からのみstartHuntを呼ぶ。キャンセルは無変化 |
| 描画更新 | 別のデータの保存完了、図鑑の開閉 | 級・星・選択・スクロール・フォーカスが飛ばない |
| 互換 | `?hub=menu`と`?hunt=arena` | 選択導線を失わず、従来の採集除外も維持 |
| 画面狭い | 956×440、844×390、568×320 | 操作でき、文と戻るボタンが隠れない |
| 安全領域 | iPhone実機・ホーム画面追加 | ノッチ・下端と干渉しない。スクロール操作が取れる |
| アクセシビリティ | VoiceOver、キーボードフォーカス | 行の名前・星・状態・頭数を読み、選択と受注を区別 |
| 全体検査 | `npm ci && npm run check && npm run smoke` | 既存ゲーム操作と新UIがともに通る |

最低限、横画面スクリーンショットの星画面・依頼一覧・依頼書・確認ダイアログを4状態保存して比較する。
