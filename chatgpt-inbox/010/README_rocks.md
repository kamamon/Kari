# 岩 R-01〜R-20 原画・検査メモ

正式依頼10の岩20枚を1対象1回のbuilt-in画像生成で制作し、返却PNGを無加工で保存した。20枚すべてを目視確認した。すべて2172×724のRGBAで、指定1536×512とは一致しない。画像は規格合格済みではなく、寸法調整前の原画として扱う。

## 数値の読み方

各画像を実際の幅724pxの3セルとして分け、alpha≥128のbboxを測定した。幅=正面幅、奥行=平面図高さ、高さ=正面高さ。1セルの実幅をS=2m、M=4m、L=8mで換算した。三面差は100×絶対差/2値の平均。地面行は512pxセルへ正規化した最後のalpha≥128行で、指定はy384、土の許容はy392まで。厳密なalpha=0以外の微小な縁は別途JSONへ記録した。

## 結果と未確認点

- 全20画像は寸法2172×724のため、指定1536×512の受け入れ条件に未適合。全体の技術合格は0/20。
- 3ビューの寸法差±8%はR-02、R-05、R-09、R-15、R-19の5種で達成。残りは上表の差が残る。
- 地面の下8px以内はR-02、R-17の2種で達成。これも地面線y384そのものへの一致を保証しない。
- 全60ビューの明るさ標準偏差は18以上。R-10側面のみ35.2446で目標20〜35の上限をわずかに超える。岩以外の苔・草・晶脈も測定に含む。
- 真の透明画素が全画像に存在するが、半透明の縁や微小なalphaノイズが残る。完全にクリーンなマスクとは断定しない。
- R-10の裾に根のような筋が追加された。草のあるR-11は草を含むbboxなので、岩本体の高さと異なる。
- 裾は地面へ入る形に見え、丸い底や隙間は見当たらない。人物・文字・枠・背景・地面に落ちる影は見当たらない。
- 15cmの割れ幅、30度の傾き、各岩の地下体積、正面/側面/上面の微細模様の投影一致は未測定。立体としての成立は別途確認が必要。
