# Kari：11武器種の実装統合候補（v0.60.0基準）
基準コミット: 56578c6917ae1d958052c38db85fcd9707b5e336。依頼：既存7武器に不足4武器を加え、操作・武器モデル・攻撃判定・素材強化を統合する。PR #25 の原画と設計票の次段階として、今回は実行コードと生成済みデータを納品する。

## 内容
- 既存7種を残し、狩猟笛、ガンランス、ライトボウガン、ヘビィボウガンを追加。
- 4系統38行動、41判定軌道、10移動曲線、38クリップ定義。新規構え、抜納刀、攻撃・回避、演奏、砲撃、弾切替・装填・射撃。
- 新規武器164件・レシピ184件。里の初期武器と5段強化、既存のモンスター系列、鉱石・骨の4級装備。既存7系統の性能を保存する。
- 音符、演奏効果、砲弾、冷却、弾倉、弾種選択、照準、HUD、合成音、11アイコン、手続き型3D武器形状を追加。PR #25 の精密原画・GLBはゲーム内で直接読み込まず、今回は動作に必要な形状を使用。
- 新規武器は保留モーション設定でも同じ新規動作を使用し、従来7系統の保留定義を維持。

## 操作（Kari独自初期実装）
|武器|主攻撃|副攻撃|同時押し|特殊・補助|
|---|---|---|---|---|
|狩猟笛|左右振り|柄打ち|叩きつけ|演奏開始/終了、演奏中の攻撃入力で音1/2/3。123・111で攻撃強化、231で持久強化|
|ガンランス|突き3段|砲撃|斬り上げ|ガード。ガード中の主で突き、副で装填、同時押しで大砲撃|
|ライト|射撃|装填|通常弾速射|照準切替。照準中の道具前/次で通常・貫通・散弾選択|
|ヘビィ|射撃|装填|重構え|照準切替と弾種選択|
