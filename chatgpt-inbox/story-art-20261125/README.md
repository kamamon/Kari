# 『帰り道の灯』人物原画・物語素材 v1

『霧境の狩人 / VEILBOUND HUNTERS』の物語『帰り道の灯』（Kari PR #7）に必要な人物、会話表情、小物、場面画を制作しました。**新規24点と、人物の基準となる既存参照6点を収録しています。**

## 内容

| 区分 | 新規点数 | 内容 |
| --- | ---: | --- |
| 人物の原画 | 3 | ミナギ背面、セナキ正面・背面 |
| 会話用の表情 | 8 | ミナギ：集中・安堵、ロクハ：平静・思案、イサネ：平静・安堵、セナキ：平静・回想 |
| 小物・設備 | 8 | 記録板、灯の点灯・消灯、荷車、閉鎖札、分流口の補修前・補修後、交換部材 |
| 場面画 | 5 | 里の受付、最初の荷、古い記録、灯を減らす夜、新しい道からの帰還 |
| 合計 | 24 | 会話8点と小物6点は背景透過PNG |

既存参照6点はミナギの全身と顔、PR #5の職人・商い手の正面と背面です。新規点数には含めていません。

## 人物の扱い

ミナギは既存設定の外見を継承しています。ロクハとイサネは、PR #5の職人・商い手の原画を継承しています。再提出基準のmainでは、この名前と外見の対応が使用されていますが、名前は引き続き仮です。セナキは、短い雨除け、補修した仕事着、縄と工具袋を持つ年配の道守として新しく設計しました。

ミナギの参照2枚は既存の元生成画像です。採用設定文との外見一致を目視しましたが、repoに登録されたPNGとはバイト列が異なり、同一画素であることは未確認です。PR #5の参照4枚はrepoのGit blob SHAと一致しました。

## Claudeへの引き継ぎ

今回の新規24点は追加原画案として提出します。採用確認後のゲーム用加工、正式配置と組み込みはClaudeが担当します。現行データでは未設定のセナキの会話素材と、正面絵を再使用しているミナギの背面を補う用途があります。

会話PNGはalphaを保持して表示し、台詞・名前・枠を別に重ねてください。記録板、道札、荷札は空白です。日付、通行先、正確な水路図などは実装時に重ねます。

灯の点灯・消灯と、設備の補修前・補修後は同じ物の状態差です。分流口の補修後は下流の石積みの出口も変わるため、同一メッシュのテクスチャ差分としては扱いません。背景の閉鎖路は右側の階段路として描かれています。実装のルートIDや地形への割当は別途決めてください。

人物の正背は形と材質の制作参考です。微細な縫い目、実寸、3Dの連続性、UV、リグ、アニメーション、設備の可動・流量、ゲーム内表示は今回の検証対象に含みません。
